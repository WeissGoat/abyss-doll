# Profile routing

- `art_focus`: one registered target; inspect live and keep only `final` or `issue`.
- `art_runtime`: a registered set of runtime targets; inspect live and capture decisions.
- `art_iteration`: capture `before`, persist through a registered adapter, reload PlayMode, then capture `after`.
- `t0_art_seal`: capture every registered fixed semantic `seal` target.
- `art_regression`: run and import the complete legacy ArtAcceptance package.
