# 序章演出与对话节奏

本文描述序章前半段的开场演出。开场前段全部使用过程 CG、镜头调度、环境音和对白推进，不安排调查点击、物件选择、确认选项或轻 UI。玩家第一次输入只发生在“发现零号魔偶”之后：画面停在她身上，出现唯一按钮 `启动人偶`。按下这一按钮后，零号苏醒，游戏才开始逐步解锁状态卡、整理动作、浅层入口和第一次下潜确认。

## 0. 开场总流程

```text
黑屏醒来
  -> 工坊过程 CG 建立处境
  -> 债务 / 手记 / 工具匣由镜头与对白带过
  -> 镜头发现零号魔偶
  -> 玩家第一次输入：启动人偶
  -> 零号苏醒
  -> 状态小卡出现
  -> 玩家做一次整理
  -> 浅层入口亮起
  -> 第一层出发确认
```

开场前 3-5 分钟像一段可跳过但首次默认播放的剧情 CG。它不是 point-and-click 调查，也不是教程。玩家在前半段只看、听、理解处境；第一次动手就是把零号启动起来。

## 1. 黑屏醒来

时长：20-30 秒。

画面先黑。没有 HUD，没有点击继续提示。声音先进入：

- 旧工坊漏雨，水滴落进金属盆。
- 旧设备低频空转，时响时停。
- 门外脚步停下，纸张从门缝滑进来。

字幕：

```text
主角：又到早上了。
```

门外敲两下。停半秒。画面自动淡入工坊。

## 2. 工坊过程 CG 建立

淡入后是一个固定或近固定构图：

- 中央偏右：旧工作台，防尘布下面露出人偶的手。
- 左侧门边：催缴纸被雨水打湿一角。
- 桌面：旧工匠手记摊开，旁边夹着破损合照。
- 前景：工具匣半开，里面只有核心碎片、绝缘带和旧钳子。
- 右后方：深渊入口暗门，只是背景轮廓，暂不可点。

此时没有可点击高亮，没有按钮，没有完整工坊 UI。画面停 2 秒，让玩家看见这个空间，然后镜头自动开始推进。

## 3. 处境信息由镜头和对白带过

这一段不让玩家逐个点击旧物。三个信息点由镜头切换、物件特写和主角短对白完成。

### 3.1 债务压力

镜头推到门边催缴纸。纸面只清楚露出三行：

```text
工坊封存预告
今晚钟响前
可估价器械抵扣
```

主角对白：

```text
主角：他们连坏掉的东西也收。
主角：不，他们最喜欢收坏掉的东西。
```

催缴纸被风吹动，露出工作台上防尘布下的手指。

### 3.2 修复线索

镜头移到旧工匠手记。页面上只出现一段被圈出的笔记：

```text
浅层晶核可暂时稳定魔偶核心。
不可替代长期修复。
不可连续使用。
```

主角对白：

```text
主角：父亲写字从不写“也许”。
主角：所以浅层至少还有一点办法。
```

深渊暗门的缝隙短暂透出冷光，但立刻熄掉。

### 3.3 最后一枚核心碎片

镜头落到工具匣。主角打开匣子，这是 CG 动作，不是玩家点击。

匣中只有：

```text
干净核心碎片 x1
绝缘带 x1
旧钳子 x1
```

主角对白：

```text
主角：卖掉它，够一天。
主角：用掉它，也许够她醒一次。
```

核心碎片的微光照到防尘布下的人偶手指。

## 4. 发现零号魔偶

镜头从工具匣移到工作台。主角没有询问玩家，也没有出现任何可操作目标。防尘布周围散着其他残件：断臂、烧坏核心仓、旧底盘、破损面部外壳。镜头扫过这些残件，最后停在防尘布下的完整人形。

主角掀开布。零号完整露出：

- 核心灯几乎熄灭。
- 肩部和腿部有裂线。
- 手保持抓握姿势，像在抓一段失去的记忆。

主角对白：

```text
主角：没有第二台了。
主角：也没有第二个早上。
```

画面停在零号脸部和核心仓之间。此时出现开场第一个玩家交互。

## 5. 第一次交互：启动人偶

屏幕只出现一个按钮：

```text
[启动人偶]
```

这个按钮同时承担三件事：

- 玩家确认救起她。
- 玩家把最后资源押给她。
- 主角完成核心接入并启动她。

除 `启动人偶` 外，不再出现其他按钮或选项。玩家按下后，CG 继续：

- 主角把核心碎片推进核心仓。
- 核心灯从暗红变成微弱冷白。
- 工坊灯短亮一下，又熄掉一半。
- 环境声压低，只留下零号启动的细小声音。

这一按钮是序章从纯演出进入可互动系统的门槛。

## 6. 零号苏醒

零号第一批对白要短，不像功能助手，也不解释系统。

```text
零号：……这里……
零号：不是下面。

主角：你醒了？

零号：我还……能动。
零号：不要拆掉我。

主角：没人会拆你。

零号：他们会。
零号：你也会。等你没钱的时候。

主角：那就先别走到那一步。

零号：下面……有一段声音。
零号：很浅。
零号：像我的。
```

“你也会。等你没钱的时候。”后保留短停顿。不要立刻用教程 UI 打断这句。

## 7. 第一次状态小卡

对白结束后，状态小卡从零号身侧浮出，不是全屏教学。

初始小卡：

```text
零号
核心：不稳定
身体：多处裂纹
意识：断续
判断：无法长时间行动
```

此时才开始解锁轻交互。屏幕只出现一个整理动作：

```text
[擦去核心仓灰尘]
```

点击后：

- 主角用布擦开核心仓灰尘。
- 核心灯稳定一点。
- 小卡刷新。

刷新后：

```text
零号
核心：短时稳定
身体：多处裂纹
意识：断续
判断：可进行一次浅层下潜，返回后需要照看
```

短对白：

```text
零号：你手在抖。
主角：灰太多。
零号：你说谎的声音……很明显。
```

这一刻以后，玩家才开始感到“我能对她做点什么”。

## 8. 下潜理由出现

整理完成后，门外远处钟声响起。催缴纸角标轻轻震动。此前 CG 给过债务、手记和核心碎片，现在主角把它们合成行动理由。

```text
主角：浅层有稳定材料。
主角：带回来，能让你撑过今晚，也能让他们暂时闭嘴。

零号：如果带不回来？

主角：那就先带你回来。
```

这句之后，深渊入口第一次变成主行动。它不是“地下城系统开放”的弹窗，而是工坊里的暗门亮起。

主行动文案：

```text
浅层入口
她还能撑一次。
```

## 9. 转入工坊主界面

此时才露出半开放工坊 UI：

- 零号仍是画面主体。
- 状态小卡收起成一行：`短时稳定 / 可浅层下潜一次`。
- 右下是主行动：`浅层入口`。
- 角落保留：`今晚前`。
- 维护、出售、义体、底盘、订单、传闻、势力不在第一屏开放。

如果玩家尝试看其他灰态入口，只给一句短反馈：

```text
现在先让她撑过这一次。
```

## 10. 第一层出发确认

点击浅层入口后，镜头从零号移到暗门。暗门打开一条缝，工坊滴水声降低，深渊风声进入。随后进入第一层出发确认。

界面文案：

```text
第一层：旧矿井浅缘
可抵达

可能带回：
稳定核心碎屑 / 可售废料 / 记忆噪声

当前状态：
零号可行动一次，返回后需要照看。
```

按钮：

```text
[出发]
[再看她一眼]
```

点击“再看她一眼”返回工坊半开放界面。零号只说一句：

```text
零号：我还在。
```

点击“出发”：

```text
零号：下面比这里安静。
主角：那不是好事。
零号：我知道。
```

随后切黑，声音从工坊转到深渊。第一层遭遇由后续切片承接。

## 11. 交互密度表

| 阶段 | 玩家操作 | 说明 |
|---|---|---|
| 黑屏醒来 | 无 | 过程 CG 自动推进 |
| 工坊建立 | 无 | 债务、手记、工具匣由镜头和对白带过 |
| 发现零号 | 无 | 主角掀开布，镜头停在零号身上 |
| 启动人偶 | 点击 `启动人偶` | 开场第一个输入，同时完成救起她、押上最后资源和启动她 |
| 苏醒后整理 | 点击 `擦去核心仓灰尘` | 从这里开始逐渐解锁轻系统交互 |
| 浅层入口 | 点击主行动 | 进入第一层出发确认 |
| 出发确认 | 出发 / 再看她一眼 | 完成首次下潜前的决定 |

## 12. 后续回声预留

第一次下潜回来后，序章必须回应前半段埋下的东西：

- 如果带回修复材料，小卡里的“短时稳定”变成“今晚稳定”。
- 如果带回可售废料，催缴纸旁出现“可先抵一部分”的反馈。
- 如果带回记忆噪声，零号说出一段更完整的名字或地点。

前半段只负责把玩家带到“我亲手启动了她，所以我要带她下去一次”。真正的操作深度从零号苏醒后开始长出来。
