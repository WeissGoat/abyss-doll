# 剧情大纲

> 本文基于 `草稿/剧情.txt` 整理为正式剧情母版。它定义故事主轴和后续填充边界，不替代剧本调度规则、内容包、剧本表、对话树或配置源。

## 1. 定位与范围

剧情服务三个玩家问题：

```text
我为什么必须下深渊？
她为什么不是普通战斗单位？
我赚到的钱、带回的遗物和做过的选择，最终把我们推向什么结局？
```

主线核心句：

```text
没落工匠修复零号魔偶，在债务和深渊之间寻找家族失踪真相，也逐步确认她不是工具，而是被深渊与人类共同重构过的灵魂。
```

本剧情大纲负责：

- 主角、零号魔偶、悬丝镇和深渊真相的母题。
- 0-12 小时剧情节奏与中后期展开方向。
- 记忆拼图、关键遗物、债务压力、Bond / 房间记忆和多结局的叙事边界。

不负责：

- 具体事件字段、触发器、优先级、跳过 / 重入和系统指令。
- 完整对白正文、CG 分镜、剧本表、配置 JSON 或 UI / 美术资源。

## 2. 核心主题

| 主题 | 含义 | 系统承接 |
|---|---|---|
| 记忆 | 她和主角都缺失关键过去，深渊遗物会逐步补回真相。 | 关键遗物、Lore、日记、房间纪念物、主线旗标。 |
| 重构 | 修复魔偶不是换零件，而是让破碎灵魂重新形成自我。 | 维护、底盘 / 义体、Bond、特质转化、结局裁决。 |
| 深渊诅咒 | 深渊既提供生存资源，也持续侵蚀身体、心智和小镇秩序。 | HP / SAN / 侵蚀、路线污染、深渊 lore、高层压力。 |
| 虚假的永生 | 魔偶技术把将死少女的灵魂碎片封进机械核心，看似救赎，实则可能是剥削。 | 零号魔偶身世、势力动机、黑市 / 医疗会 / 贵族需求。 |
| 债务与羁绊 | 玩家每次赚钱都可能是救她，也可能是压榨她。 | 月租、订单、维护费用、赠礼、低 SAN 出战选择。 |

## 3. 世界观基准

### 3.1 悬丝镇

悬丝镇是深渊之上的地下奇幻小镇，也是玩家的据点、压力源和交易场。

它不是单纯菜单大厅。镇上的账单、债主、订单、黑市、传闻和势力，会把深渊结果转换成下一轮目标。玩家在这里出售遗物、修复人偶、处理债务，也逐渐看见小镇依赖深渊剥削维持繁荣。

### 3.2 晶化病与深渊

晶化病是旧灾难留下的核心威胁。感染者会逐步失去自我，身体和灵魂都被晶体化力量改写。深渊中残留着晶化病、旧文明遗迹、纯净能源和能唤醒记忆的遗物。

深渊不是单纯诅咒源。它既毁坏人，也保存被人类丢弃的真相。中后期剧情应逐步把玩家从“深渊很危险”推进到“深渊为什么会回应她”。

### 3.3 魔偶技术

魔偶是人类为了下潜而制造的机械少女。她们可以承受人类无法承受的深渊环境，但心智核心并非纯机械。核心真相是：部分魔偶的心智来自晶化病患者临终前的灵魂碎片。

零号魔偶是特殊原型。她的核心更完整，也更危险。她保留的不是一段功能人格，而是一个被切碎后仍试图回忆自己的灵魂。

### 3.4 风格口径

当前全局风格遵守 `13` 的“日系二次元地底奇幻冒险 + 低信息密度”。旧草稿中的蒸汽朋克、赛博朋克、废土等词，只作为工坊、旧工具、局部机械或黑市语义参考，不作为全局美术 / UI 方向。

剧情基调是温柔伤感、带债务压迫和深渊危险感。它可以黑，但不应只有黑；玩家需要在照顾她、带她冒险和承受现实压力之间感到拉扯。

### 3.5 演出口径

序章和关键剧情节点默认采用“短剧情段 -> 可玩操作段 -> 结果回声段”的组织方式，参考 `设计文档/参考/01_This_Is_the_Police_演出参考.md` 中可借鉴的方法。

它的意义不是模仿外部题材，而是保证 P3 的剧情先把玩家放进处境，再让系统自然打开。尤其在 T0，不能先把玩家扔进完整工坊功能页，再由功能页代替开场。

## 4. 主角设定

主角是没落工匠世家的后代，当前身份是负债累累的初级工匠 / 魔偶修复师。

基本状态：

- 家族曾经参与魔偶技术、深渊勘探或晶化病处理，后来没落。
- 家人曾在一次探索或调查中消失，留下破败工坊、债务和零散资料。
- 主角为了重新开始，翻找家中旧仓库或工坊遗物，发现破损的零号魔偶。
- 主角对过去有缺口：可能忘记家族实验的细节，也可能刻意回避某段责任。

主角不是纯粹拯救者。中后期应逐步揭示：主角家族与零号魔偶的改造有关；主角本人可能曾经无能为力，也可能间接导致她被送入魔偶化流程。真相要逐步确认，避免早期直接把玩家钉死成罪人。

## 5. 零号魔偶设定

零号魔偶是玩家从破败工坊中修复出的特殊原型，也是长期陪伴和主线真相的中心。

初始状态：

- 机体破损严重，记忆库大面积缺失。
- 能战斗和下潜，但每次深渊行动都会加重磨损、SAN 或侵蚀压力。
- 启动初期更像服从命令的工具，但会通过反馈、维护、赠礼和房间记忆逐步恢复人格。
- 她对深渊底层有模糊预感，知道自己缺失的东西在那里。

中期变化：

- 她开始主动回应名字、害怕、请求、抗拒或保护主角。
- 关键遗物会触发记忆闪回，证明她曾经是普通少女或旧实验中的受害者。
- 高侵蚀时，她会听见深渊召唤，出现幻觉、失控风险或低语。

终局问题：

```text
玩家最终面对的不是“如何制造最强人偶”，而是“是否承认她拥有自己的灵魂、过去和选择”。
```

“魔偶变人后可以在家里生活”作为真结局和高 Bond 长线承诺保留：早中期表现为人格恢复、房间生活和陪伴感；终局真结局再处理机械身体是否重获血肉或获得等价新生。

## 6. 主线推进

### 6.1 序章：苏醒、债务与零号魔偶

主角在破败工坊中重新开业或醒来。开场先是环境、工坊和零号魔偶本体，再是债主、租金或许可证压力，说明玩家不能只躲在小镇。

主角翻找家中旧物，发现破损的零号魔偶。玩家不应一开始就进入完整系统，而应先通过调查 2-3 个对象，拼出工坊窘境、她的损坏程度和今天的现实压力。

修复她需要钱、材料和深渊资源；她启动后不说长篇解释，只留下一个明确方向：自己缺失的记忆在深渊下方，而她还能勉强行动一次。

序章目标：

- 赚钱交租活下去。
- 修复她，让她能继续行动。
- 下深渊寻找能稳定核心和唤回记忆的东西。

序章演出要求：

- 先让玩家对她产生责任感，再解释深渊入口。
- 每段对话之后都给玩家一个真实的小动作。
- 第一次下潜前只开放最低限度 UI。
- 第一次回城后必须有照看与结果回声，不能只做结算。

### 6.2 发展期：虚假的繁荣与残酷真相

玩家逐步掌握搜打撤、小镇出售、维护和订单。悬丝镇看似依赖深渊遗物繁荣，但玩家越赚钱，越能看见这套经济正在消费底层探索者和魔偶。

剧情通过系统状态碎片化推进：

- 深渊遗物显示旧文明、晶化病和魔偶实验的线索。
- 订单和传闻显示贵族、黑市或医疗会对深渊资源的需求。
- 人偶维护和 Bond 事件显示她不是单纯机器。
- 房间纪念物让玩家看见每次深渊选择留下痕迹。

中期核心揭示：魔偶心智核心来自晶化病少女的灵魂碎片。零号魔偶与主角家族、失踪家人和旧实验之间存在直接关系。

### 6.3 高潮期：深渊深处的召唤

随着层级深入，深渊不再只是物理风险。它开始呼唤零号魔偶“回归”，高侵蚀或低 SAN 会让她听见声音、看见旧记忆，甚至短暂失控。

这一阶段的情绪重点：

- 玩家赚来的钱不只用来升级，也可能用来买净化剂、维护材料和安抚时间。
- 强迫低状态出战会有更尖锐的人偶反馈。
- 关键遗物会让她短暂接近真相，也让她更痛苦。

可保留的高压台词方向：

```text
下面有声音在叫我。
如果我彻底变成怪物，请你亲手拆掉我。
```

实际对白后续由文案 Owner 细化；当前只锁定情绪功能：让玩家理解“继续深入”和“照顾她”已经无法完全兼得。

### 6.4 终局：家族真相与灵魂裁决

终局真相围绕三件事展开：

1. 晶化病并非单纯自然灾害，它与旧文明核心、深渊能源和人类改造技术有关。
2. 主角家族曾试图用魔偶技术保存晶化病患者，结果制造出剥削与救赎纠缠的系统。
3. 零号魔偶的灵魂不是可替换组件。她是否被当作工具、是否保留自我、是否完成记忆拼图，会决定结局。

终局不是单一数值判定，应综合深渊进度、Bond、侵蚀 / SAN、关键记忆拼图、债务 / 黑市 / 势力旗标和房间记忆。

## 7. 0-12 小时剧情节奏

| 时长段 | 剧情功能 | 玩家应感受到 |
|---|---|---|
| T0：0-30 分钟 | 发现破损零号魔偶，背上债务和修复压力，以对话式序章进入第一次下潜 / 回城 / 照看。 | 她很脆弱，但不是负担；下深渊是当前唯一可行的开始。 |
| T1：30 分钟-2 小时 | 第一层搜打撤成形，带回第一批遗物、材料和浅层记忆钩子。 | 深渊会带回钱和线索，也会带走她的状态。 |
| T2：2-5 小时 | 小镇压力成形，订单 / 传闻 / 维护需求让下一轮下潜有具体目标。 | 赚钱不是抽象目标，而是在债务、修复和真相之间取舍。 |
| T3：5-8 小时 | 第二 / 三层开始把路线、污染、构筑和房间记忆绑定；出现第一批明确记忆拼图。 | 她的过去和深渊有关，带回某些东西比卖钱更重要。 |
| T4：8-12 小时 | 候选主循环稳定，玩家能为了债务、材料、订单、Bond、记忆或构筑多目标下潜。 | 每一轮不再只是刷资源，而是在决定如何对待她和这座镇。 |

## 8. 记忆拼图与关键遗物

记忆拼图不是独立收集品清单，而是把背包取舍、房间展示、Bond 和主线旗标连起来的叙事工具。

候选关键遗物：

| 遗物 | 玩法职责 | 剧情职责 |
|---|---|---|
| 生锈的八音盒 | 占 2x2，低卖价，可作为关键赠礼或房间纪念物。 | 唤醒她作为人类少女时的生活记忆。 |
| 旧人偶铭牌 | 深渊事件或旧工坊发现物。 | 指向零号魔偶不是普通量产型号。 |
| 家族工匠手记 | 工坊 / 深渊 / 势力线索。 | 揭示主角家族参与魔偶核心改造。 |
| 晶化病残片 | 高风险材料，可能被黑市高价收购。 | 解释晶化病与灵魂碎片的关系。 |
| 红线结 | 高 Bond 或真相低语后的纪念物。 | 表示她开始把主角和自己的过去连起来。 |
| 纯净能源核心碎片 | Boss 或深层节点奖励。 | 同时是升级资源和终局真相钥匙。 |

设计原则：

- 关键遗物可以很占格、低售价或有风险，但必须有明确情感 / 主线回报。
- 普通出售不硬保护所有遗物；只有剧情锁定、订单绑定或情感锚点物才进入硬保护。
- 送礼、封存、出售、典当或带回房间，都应成为不同记忆方向的触发来源。

## 9. 债务、小镇与势力线

债务是主线压力，不只是经济 UI。

早期债务负责给玩家下潜理由；中期债务把玩家推向订单、典当、黑市和风险路线；后期债务与势力、背叛、许可证和结局风险绑定。

小镇势力建议保留为叙事功能，而不是先扩成复杂政治剧：

- 债主 / 许可证代理：代表现实压迫和失败后果。
- 正规客户 / 工坊同行：代表稳定但低收益路线。
- 黑市 / 面具商人：代表高收益、违禁品和真相入口。
- 医疗会或研究组织：代表晶化病、灵魂核心和“救治还是实验”的灰区。
- 贵族 / 赞助人：代表悬丝镇虚假繁荣和魔偶剥削。

## 10. 人偶 Bond 与房间生活线

人偶线不应只靠好感等级播固定剧情，而应读玩家经历。

关键方向：

- 首次维护后，她从“服从启动”变成“回应照看”。
- 首次战败后，房间留下补片、毯子或修复痕迹。
- 关键赠礼后，房间出现展示物或日记，证明她记得这件事。
- 低 SAN / 高侵蚀安抚后，她可以表达恐惧，而不只是恢复数值。
- 高 Bond 后，她开始主动谈起深渊、家族和自己的名字。

房间生活线的职责是让玩家看见她逐步“住进这个家”。这条线不承担仓库功能，也不替代维护、日程或经济规则。

## 11. 多结局方向

| 结局 | 条件方向 | 结局含义 |
|---|---|---|
| A：悬丝的木偶 | 财富 / 债务处理成功，但 Bond 低、长期高侵蚀或工具化改造严重。 | 主角活下来了，却把她变成真正的工具；小镇繁荣继续吃掉灵魂。 |
| B：逃离的幻梦 | 未打穿底层，攒够逃离资源，Bond 中等或关键记忆不全。 | 两人离开悬丝镇，但深渊阴影和机体问题仍在；这是温柔的逃避。 |
| C：重铸的灵魂 | 打穿深渊底层，Bond 高，关键记忆拼图完整，侵蚀 / 真相旗标满足。 | 她完成灵魂重构，机械身体获得新生或等价自由；主角也正面承担家族真相。 |

结局判断不应只看金币。金币是压力与选择来源，但最终问题是：玩家如何看待她、如何处理真相、是否愿意承担深渊和家族的代价。

## 12. 系统触发承接

剧情采用“系统触发的主线 + 人偶情感 / 房间记忆回声”，不采用线性章节播放器。

候选触发来源：

- `OnGameStart`：债务工坊、零号魔偶启动。
- `OnFirstDiveReturn`：第一次带回战利品和人偶状态变化。
- `OnFirstDefeat`：战败修复、房间补片记忆。
- `OnLayerFirstClear`：层级 Boss、深层入口、世界观线索。
- `OnMementoGifted`：关键遗物赠礼和 Bond 事件。
- `OnMonthRent`：月租、欠债、典当、黑市诱惑。
- `OnSanityLow` / `OnCorruptionHigh`：深渊召唤、安抚、崩溃风险。
- `OnTruthFlagUnlocked`：家族真相、零号魔偶身世、终局门槛。

所有触发最终应回到 `GDD_05`、`规则卡/10`、`content_packs/23` 或后续剧本表中定义字段、优先级、系统指令和验收。
