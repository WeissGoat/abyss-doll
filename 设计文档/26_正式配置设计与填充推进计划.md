# 正式配置设计与填充推进计划

> **定位：** 本文档定义策划下一阶段的工作计划：把已经确认的正式版规则、内容包和验收要求推进到“正式配置设计 + 配置验收标准”。它不替代 GDD、规则卡、内容生产规格或具体内容包；它负责从整体可玩时长和内容结构出发，安排正式配置如何从宏观到局部逐步补齐。

---

## 1. 核心判断

当前策划工作的重点已经不是继续扩写顶层概念，而是让正式版设计能被配置、验收和后续内容生产承接。

可以拆成两条主线：

| 主线 | 含义 | 对应工作 |
|---|---|---|
| 完善正式配置 | 让已有配置域、README、字段、标签、引用和 Validator 口径对齐正式版规则。 | 配置承接审计、字段补齐、约束定义、Validator 规则、验收样例。 |
| 补充正式配置 | 从整体可玩时长出发，补足物品、怪物、地图、奖励、成长、经济、订单、剧情和房间记忆等正式内容。 | 内容量规划、层级内容包、成长和经济内容池、长期循环目标、可玩时长验收。 |

简化表述：

```text
下一阶段策划工作 = 正式配置设计 + 配置验收标准 + 正式内容填充节奏
```

---

## 2. 总目标

### 2.1 当前纵切候选目标

当前优先目标不是一次填满完整商业版内容量，而是让前三层和局外循环形成可持续扩展的正式配置骨架。

目标体验：

```text
第 1 层低压入门
  -> 第 2 层背包压力
  -> 第 3 层路线侵蚀 / 订单冲突
  -> 回城出售 / 制造 / 维护 / 成长
  -> 经济目标推动再次下潜
```

当前纵切候选目标应支撑：

| 目标 | 时长口径 | 说明 |
|---|---|---|
| 首次有效体验 | 30-60 分钟 | 玩家能完成第 1 层基础闭环，并理解背包、战斗、撤离和出售。 |
| 三层纵切体验 | 3-5 小时 | 玩家能体验第 1-3 层递进、局外成长、经济压力和至少一种路线目标。 |
| 反复构筑体验 | 6-10 小时 | 通过不同物品、怪物、订单和成长选择形成多轮下潜差异。 |

这些目标用于配置设计，不是市场承诺。后续程序、数值和试玩结果可以调整时长，但内容结构应按这个量级准备。

### 2.2 完整正式版内容目标

为了避免“只为当前三层写配置”，正式配置填充需要保留完整游戏的内容容量规划。建议完整正式版按以下目标设计：

| 目标 | 时长口径 | 内容支撑 |
|---|---|---|
| 主线首次通关 | 8-12 小时 | 5 个正式层级、局外成长、经济压力、订单目标、关键剧情事件。 |
| 深度构筑 / 多路线 | 15-25 小时 | 多义体构筑、势力订单、黑市背叛、房间记忆、事件分支和高层内容。 |
| 长尾收集 / 完成度 | 25 小时以上 | 更多遗物、义体、订单链、房间纪念物、剧情回收和挑战路线。 |

当前阶段不要求立即填满 5 层和终局内容，但所有配置设计要允许自然扩展到这个规模。

## 3. 内容量宏观模型

### 3.1 层级内容容量

每一层正式深渊至少应具备以下内容量。低层可以略少，高层可以增加复杂度，但结构不应缺项。

| 内容类型 | 每层基础量 | 设计目的 |
|---|---:|---|
| 普通怪 | 4-6 只 | 提供基础战斗节奏、层级主题和构筑检查。 |
| 精英怪 | 2 只 | 提供路线风险选择和关键材料来源。 |
| Boss | 1 只 | 提供层级终点、成长钥匙和剧情 / 经济推进点。 |
| 层级物品 | 10-14 件 | 支撑战斗、经济、材料、风险、订单和展示。 |
| 地图画像 / MapProfile | 2-3 个 | 支撑不同路线节奏和 seed 验收。 |
| 节点模板 | 10-18 个 | Combat、Elite、Event、Reward、SafeZone、Stairs、Boss 等组合。 |
| 层级订单 / 目标 | 2-4 个 | 让玩家带着目的下潜，而不是只刷随机收益。 |
| 传闻 / 价格波 | 2-3 条 | 让经济系统反向指导捡什么。 |
| 剧情 / Lore / 房间记忆 | 3-5 条 | 让层级经历能沉淀到局外和叙事。 |

当前已有 `19`、`20`、`25` 分别覆盖第 1、2、3 层。下一步不是盲目扩第四层，而是检查前三层内容是否已经能落到配置、表现和验收。

### 3.2 全局内容容量

除了层级内容，完整正式版还需要全局系统内容池。

| 内容域 | 当前纵切建议量 | 完整正式版建议量 | 说明 |
|---|---:|---:|---|
| 底盘 Chassis | 3 | 6-8 | 当前先覆盖空间、战斗、续航三类方向。 |
| 义体 Prosthetics | 6-10 | 25-40 | 按槽位和构筑路线扩展。 |
| 制造配方 CraftingRecipes | 8-12 | 40-70 | 覆盖材料转化、义体制造、维护和特殊物品。 |
| 维护方案 | 4-6 | 10-16 | 覆盖 HP、SAN、磨损、侵蚀和高风险恢复。 |
| 特质 / 标签效果 | 8-12 | 40-80 | 当前先覆盖负面、转化、构筑触发和订单查询。 |
| 势力 | 3-5 | 5-7 | 当前已有 5 势力方向，可先落核心字段。 |
| 订单模板 | 12-20 | 80-150 | 按层级、势力、风险和背叛路线扩展。 |
| 经济传闻 | 8-12 | 40-80 | 支撑价格波、路线目标和订单预告。 |
| 剧情事件 | 12-20 | 80-150 | 当前先覆盖主干事件、债务事件和 Bond 事件。 |
| 房间纪念物 / 日记 | 12-20 | 80-150 | 支撑长期记忆、展示品和情感反馈。 |

这些不是立即配完的任务量，而是用于校准“正式配置填充”最终要支撑的游戏时长。

## 4. 从整体到局部的推进顺序

### 4.1 阶段 D0：配置承接审计

目标：确认当前配置域是否能承接正式规则。

优先检查：

| 配置域 | 检查重点 | 对应事实来源 |
|---|---|---|
| `Items` | 形状、旋转、标签、售价、生命周期、VisualID、战斗 / 经济 / 材料职责。 | `02`、`15`、`18`、`19/20/25` |
| `Monsters` | 意图、AI 行为、对包干涉、掉落、CombatVisualID、层级归属。 | `03`、`15`、`19/20/25` |
| `Dungeons` | LayerConfig、MapProfile、节点池、路线主题、seed、安全区、楼梯、Boss。 | `GDD_02`、`15`、`19/20/25` |
| `Rewards` | 掉落、订单、材料、成长资源、金币和稀有奖励引用。 | `15`、`17`、内容包 |
| `Chassis / Prosthetics / CraftingRecipes` | 构筑方向、槽位、成本、材料缺口、维护和下潜许可。 | `05`、`16`、`21` |
| `Dolls / Effects` | SAN、Bond、情绪、特质、动态标签和反馈。 | `08`、`06`、`16` |

产出：

1. 每个配置域的字段缺口。
2. 每个字段的合法值、引用关系和默认值建议。
3. 需要进入 Validator 的检查项。
4. 需要内容包补条目的空白内容池。

### 4.2 阶段 D1：前三层正式配置填充

目标：让第 1-3 层内容能支撑三层纵切体验。

执行顺序：

1. `Items`：先补每层 10-14 件正式物品的职责、标签、形状、来源和去向。
2. `Monsters`：补每层普通怪、精英、Boss 的教学目标、意图规律、反制方式和掉落逻辑。
3. `Dungeons`：补每层 MapProfile、节点池、路线主题、Boss / SafeZone / Stairs 规则。
4. `Rewards`：补物品、材料、金币、义体图纸、订单奖励的引用闭环。
5. 验收场景：补固定 seed 和玩家路径，确认配置不只是存在，而是能形成体验。

完成标准：

* 每层至少有一条低风险路线、一条高收益路线和一个明确 Boss 终点。
* 每层至少有 2 类背包取舍：空间形状取舍、风险 / 价值取舍、订单 / 经济取舍中的任意两类。
* 每层至少有 1 个局外回流点：制造材料、经济目标、订单推进、房间记忆或剧情触发。

### 4.3 阶段 D2：局外成长与经济压力填充

目标：让玩家回城后有明确选择，而不是只清包和再下潜。

执行顺序：

1. `Chassis`：补三类底盘方向，分别服务空间、战斗、续航。
2. `Prosthetics`：按槽位补义体，保证每类至少有 2 个不同策略选择。
3. `CraftingRecipes`：把第 1-3 层材料接到义体、维护、关键物品和订单。
4. 经济压力：补月租、维护费用、传闻价格波和至少一条订单目标链。
5. 人偶状态：补 SAN、磨损、侵蚀、情绪反馈和下潜许可检查。

完成标准：

* 玩家完成第 2 层后，至少能看到 2 条成长方向。
* 玩家完成第 3 层后，至少能形成 1 条中期目标链：制造、月租、订单或势力声望。
* 经济压力能驱动下潜目标，但不能在前三层阶段形成不可恢复死锁。

### 4.4 阶段 D3：长期内容池规划

目标：为完整正式版时长预留内容生产结构。

当前只做规划和模板，不立即填满：

| 内容池 | 近期动作 | 后续扩展 |
|---|---|---|
| 第 4-5 层 | 先定义层级主题、核心压力和内容量目标。 | 等前三层配置验收稳定后拆内容包。 |
| 订单链 | 先落 5 势力字段、订单状态机和首批模板。 | 扩展到 80+ 订单模板。 |
| 剧情事件 | 先落主干事件和系统指令结构。 | 扩展章节、Bond、债务和结局事件。 |
| 房间记忆 | 先落战败、Boss、赠礼、债务等关键纪念物。 | 扩展日记、窗外状态、家具和展示物。 |

## 5. 正式配置填充的设计标准

### 5.1 每条配置都要有玩法职责

任何正式配置条目都必须能归入至少一个职责：

| 职责 | 说明 |
|---|---|
| 教学 | 帮玩家理解规则。 |
| 检验 | 检查玩家是否掌握规则。 |
| 取舍 | 迫使玩家在空间、金币、SAN、风险或时间之间选择。 |
| 回流 | 把局内收益带回局外成长、经济或叙事。 |
| 目标 | 给下一次下潜提供明确方向。 |

如果一条配置只是在数值上更高或更低，但没有职责，不应进入正式配置。

### 5.2 每个内容包都要闭环

一个正式内容包至少要包含：

1. 内容来源：玩家从哪里遇到或获得它。
2. 玩家判断：玩家看到时能知道什么。
3. 玩法影响：它改变哪类选择。
4. 风险代价：它占用什么资源或带来什么后果。
5. 局外去向：它卖出、制造、展示、赠礼、交订单或触发剧情后的去向。
6. 验收路径：至少一条可复现玩家路径。

### 5.3 内容量不能替代节奏

增加物品、怪物和订单数量不是目的。正式配置填充应优先补齐以下节奏：

```text
看到目标 -> 选择路线 -> 付出风险 -> 带回资源 -> 转化成长 / 金币 / 关系 -> 再次下潜
```

如果新增内容不能进入这条链路，应降优先级。

## 6. 可玩时长反推

### 6.1 单次下潜节奏

策划配置应按以下节奏设计：

| 阶段 | 目标时长 | 配置支撑 |
|---|---:|---|
| 备战 / 选层 | 2-5 分钟 | 层级入口、订单、传闻、成长缺口。 |
| 单层探索 | 10-20 分钟 | 5-8 个节点、2-4 场战斗、1-2 次路线取舍。 |
| Boss / 撤离 / 结算 | 5-10 分钟 | Boss、楼梯、安全区、战利品整理、结算。 |
| 回城处理 | 5-15 分钟 | 出售、制造、维护、订单、账单、房间反馈。 |

因此，一次完整“下潜 -> 回城”循环目标为 25-50 分钟。前三层纵切通过多轮下潜、失败重试、成长规划和订单目标支撑 3-5 小时。

### 6.2 内容复用规则

为了支撑时长而不堆无效内容，每类内容应有复用方式：

| 内容 | 复用方式 |
|---|---|
| 物品 | 同一物品在战斗、出售、制造、订单、展示中有不同价值。 |
| 怪物 | 同一怪物在不同 MapProfile、节点组合和层级修正中形成不同压力。 |
| 地图画像 | 同一层用不同路线主题改变风险收益。 |
| 订单 | 同一物品池通过不同势力需求改变取舍。 |
| 经济传闻 | 同一掉落池因价格波动改变拾取优先级。 |
| 房间记忆 | 同一事件结果在局外形成长期反馈。 |

正式配置填充的关键不是每小时都新增完全不同内容，而是让已有内容在不同系统中产生新判断。

## 8. 下一步执行顺序

1. 先做 `Items` 配置承接审计。
2. 再做 `Monsters` 配置承接审计。
3. 再做 `Dungeons` / `Rewards` 承接审计。
4. 根据审计结果补前三层正式配置设计。
5. 同步补 Validator 口径和验收样例。
6. 再进入局外成长、经济和长期内容池。

执行原则：

* 先让已有前三层内容能真实支撑 3-5 小时纵切体验。
* 再补完整正式版 8-12 小时主线所需的第 4-5 层和长期系统内容。
* 不用低质量内容堆时长；所有正式配置都必须有玩法职责、风险代价、系统去向和验收路径。

---

## 9. 完成判定

本阶段策划工作完成的判定不是“文档数量增加”，而是：

1. `Items`、`Monsters`、`Dungeons`、`Rewards` 的正式配置字段和内容缺口清楚。
2. 前三层内容能从配置上支撑 3-5 小时纵切体验。
3. 局外成长和经济压力能解释玩家为什么继续下潜。
4. 每类核心配置都有 Validator 或验收样例。
5. 后续扩到 8-12 小时正式版主线时，内容量模型和扩展方向明确。

如果某类内容只能说明“后续会做”，但没有内容量目标、配置落点和验收路径，则视为未完成。
