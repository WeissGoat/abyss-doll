# 设计参考阅读入口

> 本目录只承接外部作品参考，回答“我们可以借鉴什么演出方法”。它不是本项目正式需求、规则卡、剧情母版或配置来源。

## 1. 目录定位

`设计文档/参考/` 用来保存稳定、可反复引用的外部参考。

适合放在这里：

- 外部游戏的演出拆解。
- 镜头、节奏、声音、信息密度的参考总结。
- 对本项目可借鉴 / 不可照搬的明确结论。

不放在这里：

- 本项目正式剧情设定、系统规则、配置字段或 UI 接入规范。
- 一次性灵感碎片、聊天摘录或没有稳定结论的临时笔记。

## 3. 使用规则

- 参考文档只提供方法论，不直接替代 `剧情/`、`版本规划/`、`GDD/` 或 `规则卡/`。
- 写序章、剧情节奏或 UI 开场时，可以先读这里，再回写到本项目正式文档。
- 任何外部参考都必须明确写出“借鉴什么”和“不要照搬什么”。
