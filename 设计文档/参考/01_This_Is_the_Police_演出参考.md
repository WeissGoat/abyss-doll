# This Is the Police 演出参考

> 本文参考的是 `This Is the Police` 的演出组织方式，不是它的题材、价值观或世界观。P3 借的是“怎么开场、怎么编排、怎么让管理和剧情互相咬合”，不是去做警匪 noir。

## 2. 值得借鉴的地方

### 2.1 先用氛围抓人，再放系统

它的开场不是“功能总表”，而是先把玩家放进一个已经有压力、有立场、有口吻的处境里。玩家在理解系统前，先理解自己是谁、为什么今天必须做事。

对 P3 的启发是：序章先让玩家看见破败工坊、债务压力和零号魔偶的状态，再逐步开放工坊与深渊入口。

### 2.2 用短剧情段驱动一整段操作

它很擅长用一小段剧情建立当天目标，然后让管理操作承担主体时间，最后再用结果回声收束当天体验。

对 P3 更合适的结构是：

```text
短对话式序章
  -> 工坊有限交互
  -> 第一次下潜许可
  -> 第一次深渊短遭遇
  -> 回城后的照看与结果回声
```

### 2.3 固定画面也能有戏

它不是靠大量复杂动画取胜，而是靠构图、表情、音乐、配音、旁白和切点，让静态或近静态画面仍有戏剧强度。

对 P3 的启发是：序章完全可以用低动画成本达成商业化开场质感。关键是镜头顺序、停顿、环境音、人偶的短句反馈和 UI 露出的时机。

### 2.4 主观视角很强

它的剧情不是百科介绍，而是明确从主角处境出发，让玩家先进入“这个人今天必须撑下去”的主观压力。

对 P3 的启发是：序章必须先让玩家站在“我得把她修到还能动、我得想办法活过今天”的位置上，而不是先讲完整世界观。

## 3. 不要照搬的地方

### 3.1 不要把 cutscene 拉得太长

`This Is the Police` 的长处是氛围浓，但也容易让玩家觉得前半段“看比玩多”。P3 的序章应该借它的编排方式，不借它偏长的讲述习惯。

P3 的原则应是：每一段对话后都尽快给玩家一个很小但真实的动作。

### 3.2 不要复制它的题材气质

P3 不是都市 noir，也不是愤世嫉俗的权力叙事。它的底色仍然是“日系二次元地底奇幻冒险 + 照看脆弱人偶”。

所以 P3 只借：

- 演出节奏
- 信息投放方式
- 剧情段与操作段的衔接

不借：

- 警匪题材
- 黑色幽默口吻
- 男主独白式压迫叙事

### 3.3 不要让开场只有旁白

P3 更适合“环境 + 可点击对象 + 人偶短对话”的混合式开场，而不是纯旁白推进。

## 4. 对 P3 序章的直接映射

### 4.1 开场顺序

推荐的 P3 序章演出顺序：

1. 黑屏与环境音。
2. 工坊定帧，先看到坏掉的人偶。
3. 玩家调查 2-3 个对象，拼出“债务、工坊、她的状态”。
4. 人偶苏醒，说出极短但带情绪的句子。
5. 开放非常有限的工坊 UI。
6. 给出第一次下潜理由。
7. 进入第一层入口确认。

### 4.2 UI 开放方式

不要一开场就把工坊完整功能摊开。更适合的顺序是：

```text
几乎无 HUD
  -> 轻交互提示
  -> 小型人偶状态卡
  -> 工坊主界面主行动入口
  -> 第一层入口确认
```

### 4.3 结果回声

和 `This Is the Police` 一样，剧情段不能白讲。第一次下潜回来后，必须让工坊、小镇和人偶都对这次结果给出回声，哪怕只是很短的一句反馈和一个状态变化。

## 5. 给 P3 的结论

`This Is the Police` 对 P3 最有价值的，不是“写成什么故事”，而是下面这条组织原则：

```text
先像一段游戏开场，
再像一套系统入口。
先用情绪和处境把玩家拉进去，
再让功能在推进里自然露出。
```
