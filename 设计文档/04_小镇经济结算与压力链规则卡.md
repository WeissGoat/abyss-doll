# 小镇经济结算与压力链规则卡

> **定位：** 本规则卡把 `GDD_04` 的“小镇经营 / 价格波浪 / 租金压力”落实为正式经济规则。它不替代 `GDD_04` 的体验设计，而是定义每日营业如何结算、物品如何定价、传闻如何改变玩家下潜目标、欠债如何裁决，以及这些规则如何与 `GDD_07` 的 Day / Week / Month 节奏接上。

---

## 1. 设计目标

小镇经济不是独立经营小游戏，而是深渊循环的压力泵。它要让玩家在每次回城后都明确感到：

| 目标 | 说明 |
|---|---|
| 战利品有重量 | 每个格子都能折算为金币，但形状、标签、污染和行情会改变实际价值。 |
| 钱永远不够用 | 金币同时承担租金、维护、制造、成长、购物和危机处理，不能让玩家早早财富自由。 |
| 情报反向指导下潜 | 传闻、订单和橱窗需求应改变玩家下一次深渊中“捡什么、舍弃什么”。 |
| 结算爽快 | 每日营业是高反馈结算，不把玩家拖进低频手动议价。 |
| 压力可预期 | 月租、欠债、强制典当必须提前可读，失败应刺痛但不随机秒杀。 |

---

## 2. 经济循环状态机

每日小镇经济固定嵌入 `GDD_07` 的日循环：

```text
DayStart
  -> PrepPhase
  -> CoreChoice(Dive / Rest)
  -> LootIntake
  -> ShopStaging
  -> BusinessSettlement
  -> DailyBillReport
  -> WeekOrMonthSettlement?
  -> NextDay
```

| 状态 | 规则 |
|---|---|
| `DayStart` | 刷新今日倒计时、当前传闻、订单截止日、租金压力提示。 |
| `PrepPhase` | 玩家可零时耗整理背包、购物、维护、摆橱窗、查看订单和传闻。 |
| `CoreChoice` | 选择下深渊或休息，推进一天；局外不存在 AP 消耗。 |
| `LootIntake` | 若当日下潜，把撤离带回的物品进入安全区容器；若休息，则只处理既有仓库存货。 |
| `ShopStaging` | 玩家决定哪些物品进倾倒箱、哪些进橱窗、哪些保留、哪些交订单。 |
| `BusinessSettlement` | 统一结算倾倒箱、橱窗、订单、黑市和违禁品后果。 |
| `DailyBillReport` | 展示收入、支出、未售出物、状态损伤、订单进度和租金倒计时。 |
| `WeekOrMonthSettlement` | 第 7 / 14 / 21 / 28 天触发周结；每月第 28 天额外触发月租。 |

营业结算是每天强制流程。若仓库、倾倒箱和橱窗均为空，也生成 `0G` 日报，用来强化断货压力。

## 3. 容器与物品流向

### 3.1 经济容器

| 容器 | 设计含义 | 结算规则 |
|---|---|---|
| `Backpack` | 当日带回或准备带下深渊的真实背包。 | 不直接售卖，必须由玩家移入经济容器或保留。 |
| `SafeBox` | 局外长期保管容器。 | 不参与当日出售，但违禁 / 污染物可产生隔夜代价。 |
| `DumpBox` | 普通出货箱。 | 自动以基础价快速售卖，可吃到传闻和人偶经营属性加成。 |
| `ShowcaseGrid` | VIP 橱窗网格。 | 使用网格拼图、相邻标签和顾客偏好产生高倍率。 |
| `OrderSlot` | 势力 / VIP 订单提交位。 | 满足订单条件时按订单固定奖励结算，不再进入普通出售。 |
| `BlackMarketSlot` | 黑市 / 违禁品渠道。 | 只在黑市事件或特定势力通道开启时可用。 |
| `PawnPool` | 强制典当池。 | 月租不足时临时打开，只能按低折扣卖出。 |

### 3.2 流向优先级

同一物品在同一天只能进入一个结算出口：

```text
OrderSlot > BlackMarketSlot > ShowcaseGrid > DumpBox > SafeBox > Lost
```

裁决规则：

*   订单提交优先，因为它通常消耗特定物品并推进势力目标。
*   违禁品默认不能进入 `DumpBox`，除非传闻或渠道允许。
*   放入 `ShowcaseGrid` 的物品若未售出，默认回到 `SafeBox`，不丢失。
*   放入 `DumpBox` 的普通物品视为玩家确认出售，结算后进入 `Consumed / Sold`。
*   玩家可以手动丢弃污染物，进入 `Lost`，不产生金币，但可避免隔夜代价。

## 4. 售价公式

### 4.1 基础售价

物品的经济基准来自空间本位：

```text
BaseSellValue =
  GridCellCount
  * CellValue
  * RarityMultiplier
  * ShapeMultiplier
  * RiskCompensation
```

字段含义：

| 字段 | 规则 |
|---|---|
| `GridCellCount` | 物品占格数量，旋转不改变占格数量。 |
| `CellValue` | 当前阶段每格基准价值；中期参考 `100G / 1x1`。 |
| `RarityMultiplier` | 普通、稀有、精英、Boss、剧情物的价值系数。 |
| `ShapeMultiplier` | 越难放的异形可获得更高单格价值补偿。 |
| `RiskCompensation` | 污染、违禁、SAN 压力、耐久损坏等风险补偿。 |

### 4.2 倾倒箱结算

```text
DumpBoxSellValue =
  BaseSellValue
  * GlobalPriceMultiplier
  * TagMarketMultiplier
  * DollComputeBonus
  * ConditionMultiplier
```

| 字段 | 规则 |
|---|---|
| `GlobalPriceMultiplier` | 当前世界经济总倍率，通常为 0.8 至 1.2。 |
| `TagMarketMultiplier` | 当前传闻对物品标签的涨跌倍率。 |
| `DollComputeBonus` | 人偶算力或经营属性带来的普通货溢价。 |
| `ConditionMultiplier` | 耐久、污染、损坏、赝品等状态影响。 |

倾倒箱是“低操作成本、低上限”的金币出口。它允许玩家快速处理大量普通物，但不应超过橱窗或订单的爆发收益。

### 4.3 橱窗结算

```text
ShowcaseSellValue =
  BaseSellValue
  * GlobalPriceMultiplier
  * TagMarketMultiplier
  * ShowcaseAdjacencyMultiplier
  * CustomerPreferenceMultiplier
  * DollCharmBonus
  * HeatMultiplier
```

| 字段 | 规则 |
|---|---|
| `ShowcaseAdjacencyMultiplier` | 橱窗中相邻同标签、套装标签或主题标签带来的拼图倍率。 |
| `CustomerPreferenceMultiplier` | 当日抽到的顾客偏好与展示物标签匹配时生效。 |
| `DollCharmBonus` | 人偶魅力或好感状态影响 VIP 顾客成交率和溢价。 |
| `HeatMultiplier` | 当日橱窗热度，通常每日只结算一次，不可无限刷。 |

橱窗是“高操作成本、高上限”的收益出口。橱窗空间必须小，且只对少量高价值物品有意义，避免玩家把所有垃圾都塞进去蹭倍率。

### 4.4 订单结算

订单不使用普通售卖公式，而使用订单定义：

```text
OrderReward =
  FixedGold
  + ReputationDelta
  + RewardTable
  + UnlockRefs
```

如果订单要求特定形状、标签、层级或污染状态，物品必须逐项满足。订单提交后物品进入 `Consumed / Delivered`，不能再售卖。

## 5. 传闻与价格波浪

传闻是经济系统指导深渊目标的主要手段。

### 5.1 刷新规则

| 项目 | 规则 |
|---|---|
| 刷新时机 | 每周结算后刷新下周传闻，部分事件可临时插入日传闻。 |
| 生效周期 | 默认 7 天；强事件可持续 1 至 3 天或整月。 |
| 目标范围 | 按物品标签、来源层级、稀有度、势力需求或违禁类型筛选。 |
| 数值范围 | 常规涨跌建议 0.7x 至 1.5x；极端事件需带风险或稀有条件。 |
| 玩家可读性 | 玩家在备战期必须能看到“哪些标签涨价 / 跌价 / 剩余几天”。 |

### 5.2 传闻类型

| 类型 | 设计作用 | 示例 |
|---|---|---|
| `DemandUp` | 鼓励玩家主动寻找某类战利品。 | 本周源石 +50%。 |
| `DemandCrash` | 迫使玩家换目标或囤货。 | 史莱姆素材 -70%。 |
| `ContrabandWindow` | 临时打开黑市渠道。 | 今夜可卖违禁遗物。 |
| `FactionRequest` | 把经济目标接到势力订单。 | 机械工坊收购齿轮核心。 |
| `RiskPremium` | 高污染 / 高危险物获得高价。 | 腐蚀样本价格翻倍，但隔夜 SAN 代价增加。 |

### 5.3 与深渊的闭环

一条有效传闻必须满足：

1. 玩家在备战期能看到目标标签。
2. 深渊节点或掉落池中有可追踪的来源。
3. 目标物会占用背包空间或带来风险。
4. 带回后能在 `DumpBox`、`ShowcaseGrid`、`OrderSlot` 或 `BlackMarketSlot` 中兑现。

如果传闻只改变数值、不能改变玩家下潜时的取舍，它不是合格传闻。

## 6. 顾客与成交

顾客不是逐个手动议价对象，而是营业结算中的抽象买方。

### 6.1 顾客字段

| 字段 | 设计含义 |
|---|---|
| `CustomerID` | 顾客类型 ID。 |
| `BudgetMin / BudgetMax` | 可支付价格范围。 |
| `PreferredTags` | 偏好标签。 |
| `RejectedTags` | 拒绝标签，例如普通顾客拒绝违禁品。 |
| `PriceTolerance` | 可接受溢价范围。 |
| `AppearanceWeight` | 出现权重，可受传闻、势力、魅力影响。 |
| `SpecialRule` | 特殊购买规则，例如清空橱窗、只收违禁品。 |

### 6.2 成交流程

```text
抽取当日顾客池
  -> 先结算订单和黑市
  -> 为橱窗物品匹配高预算顾客
  -> 为倾倒箱批量匹配普通顾客
  -> 未匹配物按保底回收价或退回规则处理
```

规则：

*   橱窗优先匹配高预算 / 偏好顾客。
*   倾倒箱可以抽象为批量散客，不需要逐件演算到可见层。
*   预算不足的顾客不能购买高价橱窗物，除非触发特殊规则。
*   违禁品必须匹配黑市、走私或特殊顾客，否则不成交。

## 7. 违禁品与隔夜代价

违禁品是经济高收益与情感 / SAN 压力之间的桥。

| 状态 | 规则 |
|---|---|
| 放入 `DumpBox` | 默认退回，普通顾客拒收。 |
| 放入 `ShowcaseGrid` | 只有特定传闻或顾客存在时可成交，否则退回并可能触发风险。 |
| 放入 `BlackMarketSlot` | 黑市开启时可高价成交，但可能降低公开声望。 |
| 留在 `SafeBox` 过夜 | 根据污染强度造成 SAN、侵蚀、耐久或事件风险。 |
| 手动丢弃 | 不得金币，但避免隔夜代价。 |

隔夜代价建议：

```text
NightTax =
  ContrabandSeverity
  + CorruptionLevel
  + StorageLeakFactor
  - ContainmentBonus
```

NightTax 可以表现为 SAN 损伤、侵蚀提升、人偶情绪下降、仓库污染或小镇风险事件。严重违禁品必须提前提示，不能在玩家无信息时暗扣关键状态。

## 8. 租金、账单与欠债

### 8.1 月租结算

月租在每月第 28 天营业结算后触发。

```text
MonthlyBill =
  BaseRentByMonth
  + WorkshopMaintenance
  + LicenseFee
  + DebtInterest
  + StorySurcharge
```

| 字段 | 规则 |
|---|---|
| `BaseRentByMonth` | 月份递增的主压力。 |
| `WorkshopMaintenance` | 工坊维护，随已解锁系统和设施增加。 |
| `LicenseFee` | 深渊许可证或势力保护费，可作为剧情压力。 |
| `DebtInterest` | 上月欠债产生。 |
| `StorySurcharge` | 剧情事件临时加压，必须可预告。 |

### 8.2 欠债裁决

月租不足时不立刻 Game Over，而是进入欠债裁决：

| 情况 | 裁决 |
|---|---|
| 缺口 <= 10% | 允许欠账，加入下月利息，并给出强警告。 |
| 缺口 > 10% 且可典当 | 打开 `PawnPool`，玩家必须典当安全区物品补足。 |
| 典当后仍不足 | 进入重度违约，触发债主事件和状态惩罚。 |
| 连续两次重度违约 | 进入经济破产结局或高危分支。 |

### 8.3 强制典当

强制典当必须刺痛，但要公平：

*   玩家先手动选择典当物。
*   典当折扣默认 10% 至 30%，视物品类型和事件而定。
*   绑定剧情物、人偶情感锚点和不可替代主线物默认不可典当，除非剧情明确允许。
*   若玩家拒绝选择，系统按“非绑定、最高估值、低构筑依赖”的顺序推荐，但最终仍应给确认。
*   典当记录进入经济日志，后续可产生赎回、剧情或好感后果。

## 9. 人偶状态对经营的影响

经济结算要让人偶养成和状态有存在感，但不能让玩家为了结算反复刷 UI。

| 状态 / 属性 | 影响 |
|---|---|
| 算力 | 提升倾倒箱普通货溢价和账单误差修正。 |
| 魅力 | 提升 VIP 顾客出现率、橱窗成交率和高价容忍。 |
| 好感 | 提高经营稳定性，降低负面突发事件概率。 |
| SAN 低 | 降低成交效率，增加误判、退货和顾客流失。 |
| 机体重损 | 可能降低营业表现，严重时必须先维护。 |
| 特质 | 触发少量特色事件，但不应形成无脑刷钱漏洞。 |

原则：人偶状态影响“同样货物能卖得多好”，但不能凭空生成大量收益。主要金币仍来自深渊战利品、订单和高风险物。

## 10. 经济日志与玩家反馈

每日账单至少展示：

| 字段 | 说明 |
|---|---|
| `GrossIncome` | 当日总收入。 |
| `DumpBoxIncome` | 倾倒箱收入。 |
| `ShowcaseIncome` | 橱窗收入。 |
| `OrderIncome` | 订单收入和非金币奖励。 |
| `BlackMarketIncome` | 黑市收入。 |
| `Expenses` | 当日维护、购买、治疗和账单支出。 |
| `UnsoldItems` | 未售出并退回的物品。 |
| `NightTaxResult` | 违禁 / 污染隔夜代价。 |
| `RentCountdown` | 距离月租剩余天数和预估缺口。 |
| `NotableEvents` | 特殊顾客、退货、失误、传闻变动。 |

玩家必须能复盘“今天为什么赚这么多 / 这么少”。任何大额收益或损失都应在账单中有来源。

## 11. 验收样例

### 11.1 倾倒箱基础售卖

| 输入 | 期望 |
|---|---|
| 3 个普通 1x1 战利品，基准 100G，无传闻，无状态修正。 | 倾倒箱收入约 300G，物品进入 `Sold`。 |
| 1 个 2x2 异形战利品，基准 4 格，形状系数 1.2。 | 基础售价按 480G 进入后续倍率计算。 |
| 物品耐久严重损坏，`ConditionMultiplier=0.5`。 | 售价减半，并在账单显示“损坏折价”。 |

### 11.2 橱窗拼图

| 输入 | 期望 |
|---|---|
| 两件同 `OriginStone` 标签物品相邻，传闻 `OriginStone * 1.5`。 | 同时吃到传闻倍率和橱窗相邻倍率。 |
| 橱窗塞满低价 1x1 普通垃圾，无顾客偏好。 | 收益可高于倾倒箱少量，但低于高价值物，不能形成最优策略。 |
| 高价物超过当日顾客预算。 | 物品未售出并回到 `SafeBox`，账单显示“无人买得起”。 |

### 11.3 传闻指导下潜

| 输入 | 期望 |
|---|---|
| 周传闻显示 `Slime` 跌至 0.2x。 | 当日售卖史莱姆素材明显低价，玩家可选择囤货或换目标。 |
| 周传闻显示 `Weapon` 涨至 1.3x，深渊掉落池包含武器。 | 玩家下潜前可见该信息，售卖时按涨价结算。 |
| 传闻目标标签当前无任何来源。 | 该传闻不合格，应从配置或传闻池中剔除。 |

### 11.4 违禁品

| 输入 | 期望 |
|---|---|
| 违禁品放入普通倾倒箱。 | 不成交并退回，账单说明普通顾客拒收。 |
| 黑市事件开启，违禁品放入黑市槽。 | 高价成交，并记录黑市收入与潜在声望后果。 |
| 高污染违禁品留在仓库过夜。 | 触发 NightTax，SAN / 侵蚀 / 事件风险按提示结算。 |

### 11.5 月租与欠债

| 输入 | 期望 |
|---|---|
| 月末账单 1500G，玩家金币 1600G。 | 扣款成功，剩余 100G，进入次月。 |

| 连续两月重度违约。 | 触发经济破产结局或高危剧情分支。 |
