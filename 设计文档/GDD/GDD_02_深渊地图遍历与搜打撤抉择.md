# 详案_02：深渊地图遍历与搜打撤抉择 (GDD_02)

> **定位说明：** 本文档定义了深渊探索的完整流程——从下潜前的整备，到节点树地图的推进规则，到安全区的撤离博弈，再到失败后的惩罚机制。这是"搜打撤"三字的完整游戏体验设计。
>
> **交付导航：** 地图生成算法、层级入口和安全区节奏以本文为主；配置 / 表现 / 验收承接需同时读取 `15_P0主干配置表现验收承接清单.md`，具体前三层内容读取 `19`、`20`、`25` 内容包。

---

## 零、当前阶段对齐：正式版核心纵切

顶层路线见：`版本规划/09_正式版核心纵切开发路线.md`。

当前项目按正式版口径纵向处理系统。对深渊系统来说，纵切不等于先做单线临时地图；当深渊地图进入开发批次时，应按正式版节点网络、路线选择和搜打撤节奏完整处理。

本文重点锁定：

*   层级入口、已通层直达、阶梯继续深入三者的体验边界。
*   安全区作为层间节奏释放、免费全恢复、撤离/继续深入决策点的正式定位。
*   战斗损耗、背包空间、深层怪物机制、高价值战利品携带代价与局外经济共同构成压力来源。
*   节点网络生成、路线风险差异、战争迷雾、Boss 前节奏和层间安全区共同构成正式版深渊地图体验。

---

## 一、深渊探索的整体流程

一次完整的深渊探索（下潜）分为四个阶段：

```
【整装待发】→ 【迷宫探索】→ 【安全区抉择】→ 【撤离结算 / 失败惩罚】
     ↑                                              │
     └──────────────────────────────────────────────┘
                    （返回地面，进入日常循环）
```

---

## 二、阶段一：整装待发（Pre-Dive）

### 2.1 仪式感与最后的策略调整
在玩家确认日程"下深渊"后、正式点击"下潜"按钮之前，进入「整备界面」。

**界面构成**：
- 左侧：魔偶的全身展示（显示当前底盘、义体、穿着的装甲）
- 右侧：背包网格 + 仓库面板，玩家在此完成最终的局前背包管理

### 2.2 局前背包管理的核心博弈
玩家需要从仓库中选择带入深渊的物品，塞入背包网格。

**核心矛盾**：
- 带的武器/防具越多 → 战斗越安全 → 但初始留给搜刮的空余格子越少
- 带的消耗品越多 → 续航越强 → 但使用前也在占格子
- 带的情感锚点物 → 保护心智 → 但没有任何战斗力
- 物品可以旋转放入 → 同样的装备组合会因为角度不同产生不同空隙和相邻关系

**预期玩家心理**：
>"我是塞满武器然后只捡小东西回来？还是轻装上阵只带一把匕首和三瓶药，赌一波大宝箱？"

### 2.3 委托物预留
如果玩家接了势力委托（如"带回一个3×3的深渊熔炉核心"），就必须在局前背包中**预留出相应大小的空位**来装委托物。这极大压缩了可用战斗空间，让"跑委托"成为高风险高回报的专项挑战。

### 2.4 魔偶状态检查
整备界面会醒目展示魔偶当前的HP/SAN/磨损度状态。如果状态不佳（参见GDD_07中的"状态对日程的反向约束"），界面会弹出警告提示。玩家可以选择无视警告强行下潜，但后果自负。

### 2.5 下潜前的情感互动
整备界面可以触发一次简短的魔偶反馈：
- 状态良好时："准备好了，主上，我们走吧。"（元气语音）
- 状态不佳时："主上……上次的伤还没好……但如果你需要的话……"（犹豫语音）
- 好感度极高时："不管前面是什么，有主上在我就不怕。"（温柔语音）

## 三、阶段二：迷宫探索（Exploration）

### 3.1 地图表现形式
进入深渊后，画面切换为2D的「节点树状图」（参考《杀戮尖塔》）。

- 地图由**节点和连线**组成，从下往上延伸
- 玩家通过**点选节点**前进，不是自由移动
- **不可回头**：走过的节点灰化，无法返回
- **战争迷雾**：只能看清当前节点和前方1~2层的分支，更远处被瘴气遮蔽

### 3.2 层级结构
深渊由多个"层（Layer）"纵向叠加，每一层是一张独立的节点网络。

| 概念 | 说明 |
|---|---|
| 层（Layer） | 深渊的一个大区段，有独立的主题和敌人池 |
| 层内节点 | 每层包含6~12个节点，通过分支路线连接 |
| 层末Boss节点 | 每层最后一个节点固定为Boss战 |
| 层间安全区 | 每层结束后（Boss之后）必定出现一个安全区 |

**层级推进**：
- 击败层末Boss → 进入层间安全区 → 选择撤离或深入下一层
- 总共设计约 **8~10层**，但一般玩家单次下潜只能推进2~4层

### 3.3 节点类型图鉴

#### 🗡️ 普通战斗节点（Minor Combat）
- 出现频率：最高（约50%）
- 内容：1~3只杂兵怪物
- 战利品：低价值小型物品（1×1或1×2），偶尔出现中等素材
- 体验：快节奏清理，消耗少量HP，积累零散战利品

#### ⚔️ 精英战斗节点（Elite Combat）
- 出现频率：中等（约15%）
- 内容：1只精英怪（或1只精英+1~2只杂兵）
- 战利品：必掉中高价值物品，概率掉落遗物
- 体验：真正的策略考验，需要消耗品支撑。是"高回报但高风险"的诱惑
- **地图标识**：精英节点在地图上用特殊颜色标识，玩家可以选择绕路避开

#### 💀 Boss战斗节点（Boss）
- 出现频率：每层末尾固定1个
- 内容：层Boss，阶段切换型战斗
- 战利品：必掉稀有/珍稀级物品，形状通常极大
- 体验：决定性关卡，是继续深入的门槛

#### ❓ 未知事件节点（Mystery/Event）
- 出现频率：中等（约15%）
- 内容：随机事件。可能是好事也可能是坏事
- 事件类型：
  - **祝福型**：发现遗迹宝箱（免费获得物品）
  - **交易型**：遇到流浪商人，可以用金币/物品换稀有道具
  - **献祭型**：祭坛要求牺牲HP/SAN/物品，换取强力临时增益
  - **陷阱型**：触发陷阱，背包中随机格子被封锁（SAN不足时陷阱概率大幅增加）
- **设计意图**：不确定性制造冒险感。高SAN时好事概率高，低SAN时坏事概率高——鼓励维护心智状态

#### 🎁 宝箱节点（Treasure）
- 出现频率：较低（约10%）
- 内容：免费获得1~2件战利品，无战斗
- 特殊规则：部分宝箱上锁（需要大地图上使用「万能钥匙」）；部分宝箱有诅咒陷阱
- 体验：纯粹的搜刮奖励，但可能引诱玩家为了装下宝箱物品而扔掉武器

#### 🏕️ 层内营地节点（Rest Stop）
- 出现频率：低（每层0~1个，出现在中段）
- 内容：不同于层间安全区，这是一个简易休息点
- 可用功能：
  - 恢复少量HP（消耗带来的修复材料）
  - 恢复少量SAN
  - **不能撤离**——只有层间安全区才能撤离
- 体验：喘息的机会，但不是逃生口

### 3.4 路线选择的策略性
每层地图中，玩家面临多条通往层末Boss的路线：

- **安全路线**：杂兵多、精英少，战利品平庸但风险低
- **冒险路线**：精英多、宝箱多，高风险高回报
- **探索路线**：未知事件密集，充满不确定性

路线的选择受当前状态强烈影响：
- 满血满SAN → 可以走冒险路线
- 残血低SAN → 被迫走安全路线
- 带了万能钥匙 → 优先走有宝箱的路线

### 3.5 环境侵蚀（过路税）
每移动一个节点，魔偶自动扣除少量SAN值——这是深渊的"过路税"。

- 基础扣除：每节点2点SAN
- 加重条件：
  - HP低于30%时，过路SAN消耗翻倍（机体暴露于瘴气，更脆弱）
  - 背包中携带`[高侵蚀]`标签物品时，过路SAN消耗+50%
  - 深层（Layer 5+）环境瘴气加重，基础消耗递增

**设计意图**：SAN是"计时器"。走的节点越多、SAN流失越快。这天然限制了玩家在一次下潜中能走多远，迫使适时撤离。

## 四、阶段三：安全区抉择（Safe Zone / Extraction Point）

### 4.1 安全区的位置
- **层间安全区**：每层Boss击败后必定出现，是唯一可以撤离的地点
- 层内营地不能撤离，只能短暂休整

### 4.2 安全区的视觉与氛围
- 画面从阴暗紧张切换为温暖安静：一团营火、一座古代传送门遗迹
- 魔偶放下背包，坐在营火旁。战损立绘展示（如果受伤严重的话）
- BGM从战斗紧张变为舒缓的环境音

### 4.3 安全区可用操作

#### A. 安全收纳盒打包
- 将背包中的部分高价值物品放入「安全收纳盒」
- 收纳盒中的物品**不算在背包构筑中**（无战斗效果），但**绝对安全**（即使之后战斗失败也不会丢失）
- 初始收纳盒大小仅2格，可通过局外投资扩大
- **设计意图**：让谨慎的玩家有"落袋为安"的安全感。但放进去就不能在后续战斗中使用了

#### B. 免费全恢复
- 进入层间安全区后，魔偶的 HP / SAN 自动恢复到当前上限
- 这不是收费服务，也不消耗金币、天数或背包内修复素材
- 磨损度、侵蚀度、诅咒物、战利品携带压力等长期问题不在安全区免费抹除
- **设计意图**：安全区是层间节奏释放和继续深入的奖励节点，不是主要成本点。玩家的压力应来自抵达安全区之前的战斗、背包空间、深层机制和局外长期经济

#### C. 远程通讯（情感交互点）
- 玩家通过"通讯器"与魔偶进行简短对话
- 对话内容根据当前状态变化（满载而归时的喜悦 / 残血时的恐惧 / 好感度高时的信任）
- 此处的对话选择可能小幅影响好感度和SAN

#### D. 核心抉择：撤离还是深入

界面中央呈现两个醒目的选项：

**【撤离（Extraction）】**
- 确认后，魔偶启动传送门，画面切回工坊
- 背包中所有物品 + 安全收纳盒中物品全部安全转入地面仓库
- 结算本次深渊的总收益（战利品/素材/记忆碎片）
- 玩家感受："安全感" + "松了一口气" + 可能的"贪心未满足的遗憾"

**【深入下一层（Descend）】**
- 地图生成下一层更难、奖励更丰厚的节点网络
- 播放侵蚀度增加的动态效果
- 魔偶可能发出语音："主上，瘴气越来越浓了，我们真的要继续吗？"
- 玩家感受："贪婪" + "赌一把" + "如果死了之前的全白给"的恐惧

### 4.4 撤离时机的博弈
这是搜打撤玩法的灵魂——"到底什么时候该跑"：

| 当前状态 | 理性选择 | 贪婪的诱惑 |
|---|---|---|
| 状态已恢复、背包小半满 | 可以继续 | "下面肯定有更好的东西" |
| 状态已恢复但背包携带高侵蚀物 | 谨慎评估 | "再下一层也许能把收益翻倍" |
| 抵达前残血但背包满载 | 倾向撤离 | "恢复了之后还能再贪一层" |
| 满状态但背包已满 | 该撤了 | "但如果我扔掉那把剑就能再装一个遗物……" |

## 五、阶段四：结算——成功撤离 vs 失败惩罚

### 5.1 成功撤离结算
- 背包中所有物品（含绑定装备、战利品、两栖物品）安全转入地面仓库
- 安全收纳盒中物品安全转入地面仓库
- 本次下潜积累的记忆碎片归入心智天赋树可用总量
- 魔偶的HP/SAN/磨损度/侵蚀度状态带回地面，等待后续日程中安排修复

### 5.2 失败（战斗失败/SAN崩溃）惩罚

#### 物品丢失规则
| 物品类型 | 战败后处置 |
|---|---|
| 本次深渊新获得的战利品（`IsBinding=false`） | **全部丢失** |
| 安全收纳盒中的物品 | **保留** |
| 局前带入的绑定装备（`IsBinding=true`） | **保留**，但附加严重的「深渊损坏」标签（磨损度暴增） |
| 情感锚点物（`[Bond]`标签） | **保留**（自动绑定，不会因战败丢失） |
| 记忆碎片 | **保留**（非实体，不受战败影响） |

#### 魔偶状态惩罚
- HP清零（回到地面后从维修台醒来）
- SAN值大幅下降
- 磨损度暴增（可能导致回到地面后立刻需要维修才能再次下潜）
- 如果是高层战败，可能获得永久性的「深渊创伤」特质（如：最大HP永久-5%，或背包某个角落格永久封死直到用特殊材料修复）

#### 情感冲击
战败后的工坊画面：
- 魔偶躺在维修台上，战损立绘，面无表情或低声道歉
- 弹出丢失物品列表，物品在玩家面前逐个变为灰烬消散
- 弹出维修账单（通常金额很高）
- 如果好感度较高，她可能会说："对不起主上，我太弱了……那些东西都丢了……"

**设计意图**：失败的惩罚不仅仅是"损失数据"，更要让玩家在**情感上感到心痛**。这种心痛会转化为下一次下潜时"绝对不能再贪"的行为驱动力。

## 六、深渊的层级设计

### 6.1 难度与主题递进

| 层数 | 深度名称 | 环境主题 | 难度特征 | 核心产出 |
|---|---|---|---|---|
| 1~2层 | 浅渊回廊 | 被遗忘的矿道，微弱光线 | 杂兵为主，教学向 | 基础素材、低价值贸易品 |
| 3~4层 | 腐蚀甬道 | 菌丝蔓延的生物区域 | 精英频率增加，开始有对包干涉型怪物 | 中等素材、义体图纸碎片 |
| 5~6层 | 晶化深域 | 大量深渊结晶的异变区域 | 环境侵蚀加重，Boss格子封锁能力强 | 稀有素材、底盘升级核心 |
| 7~8层 | 绝望边境 | 极端扭曲的空间 | 怪物组合极端，多种行为同时出现 | 传说级物品、剧情关键道具 |
| 9~10层 | 深渊核心 | 终极区域 | 真结局相关内容 | 结局触发道具 |

### 6.2 每层的节奏曲线
每层的节点分布遵循一个情绪曲线：

```
起点（安全）→ 几场小战斗（热身）→ 一次事件或宝箱（惊喜/恐惧）
  → 精英战斗（高压高峰）→ 可能的营地（喘息）→ Boss战（决战）
    → 安全区（巨大的释放感 + 撤离/深入的终极抉择）
```

每一层都是一个完整的情绪"小山峰"——从安全到紧张到高潮到释放。玩家选择深入下一层，就是踏入下一座"山峰"的起点。

## 七、深渊地图节点网络生成规则

本节定义正式版深渊地图生成规则。深渊地图不是线性关卡列表，而是由多行节点、跨行连线、路线主题和战争迷雾组成的节点网络。纵切开发时可以先控制内容量和层数，但地图系统本身应按正式版网络结构设计、配置和验收。

### 7.1 生成目标

每一层生成一张独立节点网络：

```text
入口行
  -> 中段路线行若干
  -> Boss 前缓冲行
  -> 层末 Boss
  -> 层间安全区
  -> 撤离 / 继续深入下一层
```

设计目标：

*   让玩家在每层都能做路线选择，而不是只能沿单线推进。
*   让路线体现风险差异：安全路线、冒险路线、探索路线各有收益和代价。
*   让玩家稳定经历“热身 -> 选择 -> 压力 -> 高峰 -> 释放”的层内节奏。
*   让每层都有可感知差异：敌人池、奖励池、节点权重、路线密度和环境压力随层级变化。
*   让自动化试玩可以复现同一 seed 的节点网络，便于调试和数值校准。

### 7.2 生成输入

地图生成器至少需要以下输入：

| 输入 | 说明 |
|---|---|
| `LayerID` | 当前生成的层级，例如 1、2、3。 |
| `RunSeed` | 本轮下潜的随机种子。同一 `LayerID + RunSeed + MapProfileID` 应生成相同地图。 |
| `MapProfileID` | 地图生成画像，用于区分浅层教学、腐蚀层、精英密集层、事件密集层等正式策略。 |
| `RowCount` | Boss 前的路线行数。浅层建议 5-6 行，中层 6-8 行，深层 8-10 行。 |
| `MinWidth` / `MaxWidth` | 每行节点列数范围。浅层建议 2-3 列，中后层逐步提升到 3-5 列。 |
| `NodeTypeWeights` | 本层可抽取节点类型和基础权重。 |
| `RouteThemes` | 路线主题权重，例如 `Safe`、`RiskReward`、`Explore`、`Attrition`。 |
| `RequiredNodes` | 本层必须出现的节点或节点标签，例如教学战斗、精英、Boss、关键材料。 |
| `EncounterPool` | 本层战斗节点可抽取的怪物组或遭遇表。 |
| `RewardPool` | 本层可掉落的战利品、素材和核心物。 |
| `EventPool` | 本层事件节点可抽取事件。 |
| `Constraints` | 连续类型限制、最低战斗数、精英上限、Boss 前缓冲、路线可达性等约束。 |

### 7.3 节点类型与权重

正式版基础节点类型如下：

| 节点类型 | 状态 | 默认权重 | 说明 |
|---|---|---:|---|
| `Start` | 固定 | 固定 | 每层入口。若从已通层直达，则直接生成该层入口。 |
| `CombatMinor` | 必做 | 50 | 普通战斗，承担基础消耗、基础掉落和构筑验证。 |
| `CombatElite` | 必做 | 14 | 精英战斗，承担高风险奖励和机制压力。 |
| `Treasure` | 必做 | 10 | 宝箱 / 免费战利品，制造背包取舍。 |
| `Event` | 必做 | 12 | 随机事件，承担不确定收益、风险和世界观表达。 |
| `RestStop` | 必做 | 6 | 层内营地，不允许撤离，用于层内缓冲。 |
| `ShopOrTrade` | 可选 | 4 | 层内交易点，可出售、交换或付出代价换资源。 |
| `Hazard` | 可选 | 4 | 环境危险或陷阱，主要考验 SAN、背包状态或路线判断。 |
| `Boss` | 固定 | 固定 | 层末固定节点，不参与普通权重抽取。 |
| `SafeZone` | 固定 | 固定 | Boss 后固定节点，承载免费全恢复、撤离 / 深入决策。 |

权重不是直接概率，而是“在满足约束后的候选权重”。如果抽取结果违反约束，需要重新抽取、替换或整体重生成该行。

### 7.4 节点网络生成流程

生成流程建议如下：

```text
1. 读取 LayerConfig 与 MapProfile。
2. 初始化随机数发生器 rng(runSeed, layerID, mapProfileID)。
3. 创建 Start 行，固定 1 个入口节点。
4. 根据 RowCount 生成 Boss 前路线行。
5. 为每行决定节点数量：
   - 前 1-2 行宽度较窄，降低新手决策负担。
   - 中段行宽度增加，提供真实分支选择。
   - Boss 前 1 行收束为 1-2 个缓冲节点。
6. 为每行分配 RouteTheme 倾向。
7. 按 NodeTypeWeights 抽取节点类型，并应用 RequiredNodes。
8. 生成相邻行之间的连线：
   - 每个非终点节点至少连到下一行 1 个节点。
   - 每个非入口节点至少有 1 条来自上一行的连线。
   - 中段至少保留 2 条可通 Boss 的有效路线。
9. 执行约束校验：
   - 可达性、路线数量、节点类型连续性、Boss 前缓冲、精英 / 宝箱 / 事件数量。
10. 若校验失败，优先局部替换节点或连线；多次失败后重生成整层地图。
11. 追加 Boss 行和 SafeZone 行。
12. 为每个 Combat 节点绑定 EncounterID。
13. 为每个 Treasure / Boss / Event 节点绑定 RewardID 或 EventID。
14. 生成战争迷雾初始可见范围。
15. 输出地图网络和调试摘要。
```

### 7.5 连线规则

连线决定玩家的路线选择质量。正式规则如下：

| 规则 | 说明 |
|---|---|
| 相邻行连接 | 节点只连接下一行，不允许跨多行跳跃，除非特殊事件明确允许。 |
| 不回头 | 玩家通过节点后不能返回上一行或已走过的旁支。 |
| 入口分流 | Start 至少连接到第 1 行 2 个节点，让玩家开局有选择。 |
| 中段交叉 | 中段允许交叉连线，形成路线切换机会。 |
| Boss 收束 | Boss 前 1 行最终都应能通向 Boss。 |
| 无孤岛 | 不生成不可进入或无法通向 Boss 的节点。 |
| 分支数量 | 浅层至少 2 条有效路线；中后层至少 3 条有效路线。 |
| 视觉可读 | 连线不应大量交叉到难以阅读；优先连接相邻列或近邻列。 |

### 7.6 路线主题

每条可通 Boss 的路线应大致呈现一种风险主题，帮助玩家形成直觉判断：

| 路线主题 | 常见节点 | 体验职责 |
|---|---|---|
| `Safe` | `CombatMinor`、`RestStop`、少量 `Treasure` | 风险低、收益平稳，适合残血或背包已满时选择。 |
| `RiskReward` | `CombatElite`、`Treasure`、高价值 `Event` | 高风险高收益，适合状态好且想赌更大收益的玩家。 |
| `Explore` | `Event`、`Treasure`、`ShopOrTrade` | 不确定性强，适合想寻找特殊机会的玩家。 |
| `Attrition` | 多战斗、`Hazard`、少休息 | 消耗高，收益或关键材料更集中。 |

路线主题不是硬锁死的预设路径，而是生成器对节点权重和连线倾向的调制。玩家仍然可以通过中段交叉连线在路线之间切换。

### 7.7 层级节奏模板

#### 第 1 层：教学与基础取舍

目标：

*   让玩家理解 AP 战斗、拾取、旋转放入、背包取舍和路线选择。
*   至少提供一条明显安全路线和一条明显高收益路线。
*   不过早塞入复杂负面机制。
*   Boss 保底给出一阶成长材料。

建议结构：

| 参数 | 建议值 |
|---|---|
| `RowCount` | 5-6 |
| `MinWidth / MaxWidth` | 2 / 3 |
| 有效路线数 | 至少 2 条 |
| 精英数量 | 1 个左右，必须可绕开 |
| 事件数量 | 1-2 个，事件复杂度低 |
| 宝箱数量 | 1 个左右，用于背包取舍教学 |

#### 第 2 层：机制压力验证

目标：

*   引入毒性携带代价、武器腐蚀、塞包 / 占格等“对包干涉”压力。
*   让玩家感受到 2 层不是纯数值提高，而是路线和背包一起变难。
*   Boss 或精英节点给出下一阶段素材钩子。

建议结构：

| 参数 | 建议值 |
|---|---|
| `RowCount` | 6-7 |
| `MinWidth / MaxWidth` | 2 / 4 |
| 有效路线数 | 至少 2-3 条 |
| 精英数量 | 1-2 个，至少 1 个可绕开 |
| 事件数量 | 1-2 个，允许出现轻度负面事件 |
| 宝箱数量 | 1-2 个，高价值物品体积更大 |

### 7.8 约束规则

| 约束 | 正式规则 |
|---|---|
| 最低战斗数 | 任意通 Boss 路线至少包含 2 个战斗节点；第 2 层及以上至少 3 个。 |
| 最高连续同类 | 任意路线不允许连续 3 个相同节点类型。 |
| 精英可绕 | 浅层精英必须至少有一条非精英路线可绕开；中后层可按主题提高精英密度。 |
| 事件密度 | 事件不能连续 3 个，也不能替代战斗成为主要推进内容。 |
| 宝箱密度 | 宝箱应分布在不同路线，避免一条路线收益碾压其他路线。 |
| Boss 前缓冲 | Boss 前 1 行至少存在 1 个非精英节点；深层高压地图可以例外但要显式配置。 |
| 安全区位置 | Boss 后固定出现，不参与权重随机。 |
| 层级直达 | 从小镇选择已解锁层出发时，直接生成该层地图，不重复生成前置层。 |
| 阶梯深入 | 从安全区继续深入下一层时，保留本轮探索账本并生成下一层地图。 |
| Seed 复现 | 同一 `LayerID + RunSeed + MapProfileID` 生成相同节点、连线和绑定内容。 |

### 7.9 节点绑定规则

节点类型只决定“房间职责”，具体内容由节点绑定表决定：

| 节点类型 | 绑定内容 |
|---|---|
| `CombatMinor` | 从本层普通遭遇表抽取 `EncounterID`。 |
| `CombatElite` | 从本层精英遭遇表抽取 `EncounterID`，奖励表权重更高。 |
| `Boss` | 读取本层固定 `BossEncounterID` 和 `BossRewardID`。 |
| `Treasure` | 读取本层 `TreasureRewardID`，不进入战斗。 |
| `Event` | 读取本层 `EventPool`，事件结果可影响 HP、SAN、背包格、金币、物品或路线可见性。 |
| `RestStop` | 读取本层营地配置；不可撤离，不等同于层间安全区。 |
| `ShopOrTrade` | 读取本层交易配置，限制可交易物、货币或代价。 |
| `Hazard` | 读取本层危险配置，可触发环境伤害、SAN 损失、临时格子封锁等。 |
| `SafeZone` | 固定进入层间安全区流程，允许免费全恢复、撤离或继续深入。 |

### 7.10 战争迷雾与信息可见

正式版地图不是一次性完全明牌：

| 信息 | 可见范围 | 说明 |
|---|---|---|
| 当前节点 | 完全可见 | 玩家必须知道自己当前所在位置和可选下一步。 |
| 下一行节点类型 | 完全可见 | 允许玩家做短期路线判断。 |
| 再下一行节点类型 | 半可见 | 可显示类型或轮廓，但隐藏具体遭遇和奖励。 |
| 更远节点 | 迷雾遮蔽 | 保持深渊未知感。 |
| Boss | 可提前提示 | Boss 类型或主题可预告，方便玩家做长期准备。 |

高 SAN、特殊道具或事件奖励可以扩大可见范围；低 SAN、诅咒或环境效果可以缩小可见范围。

### 7.11 调试输出与验收

每次生成地图时，应能输出可读摘要，方便策划和自动化试玩复查：

```text
Layer 2 / Seed 1024 / Profile layer2_branching
Rows:
R0: Start(S0)
R1: CombatMinor(N1A), Event(N1B)
R2: CombatMinor(N2A), CombatElite(N2B), Treasure(N2C)
R3: RestStop(N3A), CombatMinor(N3B), Event(N3C)
R4: CombatElite(N4A), Treasure(N4B)
R5: Boss(Boss_layer2)
R6: SafeZone(SafeZone_layer2)
Edges:
S0 -> N1A, N1B
N1A -> N2A, N2B
N1B -> N2B, N2C
...
Checks:
connectivity=PASS
routeCount=PASS(3)
eliteBypass=PASS
bossBuffer=PASS
seedReproducible=PASS
```

策划验收标准：

*   同一 seed 可复现同一层节点、连线和绑定内容。
*   每张地图至少存在 2 条有效路线；中后层按配置提升到 3 条以上。
*   所有可见节点都可达，且都能通向 Boss。
*   第 1 层精英可绕开，不会生成过高复杂度压力。
*   第 2 层稳定出现至少一种机制压力。
*   Boss 后必定进入安全区。
*   从已解锁层出发不会重复生成前置层。
*   继续深入下一层不会清空本轮探索账本。

## 八、深渊的随机性与可控性平衡

### 8.1 战利品掉落的可控随机
- 怪物的掉落池随层级变化而更新（浅层不会掉深层材料）
- 掉落物品的形状是固定的（不会随机变形），玩家可以根据背包空间预判
- 委托物品只在匹配的层级出现

### 8.2 玩家可获取的信息量
| 信息 | 可见性 | 说明 |
|---|---|---|
| 下一个节点的类型 | 可见（图标标识） | 玩家可以做路线选择 |
| 精英怪的具体种类 | 不可见（仅显示⚔️标识） | 保留不确定性 |
| 事件节点的内容 | 不可见（仅显示❓） | 保留冒险感 |
| Boss的种类 | 进入前可见（有前瞻提示） | 允许玩家为Boss做针对性准备 |
| 战利品的具体内容 | 战斗胜利后才可见 | 不会因为预知就做出无风险决策 |

## 九、边界规则

| 情况 | 规则 |
|---|---|
| 玩家在安全区一直不做选择怎么办？ | 时间不消耗。安全区是纯决策节点，不施加时间压力。玩家可以充分权衡 |
| Boss太强了玩家打不过，卡关了怎么办？ | Boss战失败后触发标准的失败惩罚。玩家回到地面后可以通过养成变强后重新挑战。不存在"必须打赢才能回家"的情况——失败也会被强制救回 |
| 玩家裸奔（不带任何装备）进深渊刷碎片 | 允许，但空手无攻击手段，杂兵也打不过。战败的磨损惩罚 + 维修账单远超碎片收益。设计上确保"躺平刷低保"的净收益为负 |
| 安全收纳盒满了但还想保命怎么办？ | 只能在背包中保留绑定物品，其余全凭撤离成功。安全盒容量有限是故意设计的稀缺性 |
| 连续两次下潜同一层，地图一样吗？ | 不一样。每次下潜重新随机生成地图（即使是同一层级）。只有层级主题和敌人池相同 |
