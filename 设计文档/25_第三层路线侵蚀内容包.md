# 第三层路线侵蚀内容包

> **定位：** 本内容包把第三层“菌脉深庭”的正式体验交到内容粒度。第一层教会搜打撤和背包旋转，第二层让玩家稳定面对塞包 / 封格 / 委托物占格；第三层开始检验玩家是否能在“路线越贪、状态越脏、订单越冲突”的环境里做长期取舍。
>
> 第三层不是第二层的数值加强版。它的核心职责是让玩家第一次明显感到：深渊路线会在一次下潜内累积侵蚀代价，战利品会携带长期处理成本，势力订单之间会争夺同一类目标物，安全区免费全恢复也不能抹掉物品污染、路线债务和声望风险。

## 1. 内容包总览

| 项 | 内容 |
|---|---|
| `PackID` | `pack_layer3_route_corrosion` |
| `PackName` | 第三层路线侵蚀内容包 |
| 目标层级 | `layer_03` 菌脉深庭 |
| 前置条件 | 玩家已击败第二层 Boss 并解锁第三层直达；也可从第二层安全区继续深入。 |
| 目标体验 | 让玩家在多路线、多订单、多污染目标之间权衡：继续深入能拿到更好成长材料，但会把背包、物品状态、人偶维护和势力关系一起拖进后续成本。 |
| 覆盖系统 | `Items`、`Monsters`、`Dungeons`、`Orders`、`Rewards`、经济传闻、ScenarioEvents、RoomMemory。 |
| 主要验收 | `V-L3-PACK-DIRECT-01`、`V-L3-PACK-ATTRITION-01`、`V-L3-PACK-ORDER-CONFLICT-01`、`V-L3-PACK-CORRUPT-ITEM-01`、`V-L3-PACK-BOSS-01`。 |

第三层的复杂度可以高于第二层，但必须继续保持可读。所有侵蚀、污染、封格、订单冲突和势力风险都必须在接取、进入节点或提交前给出明确提示；玩家输掉或亏掉时，应能复盘自己是贪路线、贪订单、贪黑市，还是没有处理污染。

## 2. 第三层体验目标

| 体验目标 | 内容承担方式 |
|---|---|
| 路线风险开始累积 | 地图画像提供 `Attrition` 和 `OrderConflict` 路线；部分事件会叠加本次下潜的临时侵蚀标记。 |
| 污染从战斗扩展到物品生命周期 | 部分战利品带 `CorruptionMid` 或 `SporeDormant`，撤离后需要净化、出售、交付或承担隔夜代价。 |
| 订单不再只是额外收益 | 同一类核心样本可被机械工坊、法师塔、炼金公会或黑市争夺，交给谁会影响成长、经济和声望。 |
| 精英路线有真实机会成本 | 精英奖励更高，但会封锁背包区域、污染物品或增加 Boss 前消耗。 |
| 安全区成为“止损点” | 免费全恢复 HP / SAN 后，玩家仍要面对满包、污染物、绑定委托物、势力期限和继续深入后的污染加重。 |
| 成长材料进入中期构筑 | 第三层产出稳定连接底盘二阶段、污染义体、净化服务和心智催化。 |

### 3.2 核心物品职责说明

#### `loot_living_mycelium` 活性菌丝

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 它是好材料，但不是干净材料；带回去之后要处理。 |
| 玩法职责 | 把“污染风险”从战斗中延伸到撤离后的物品生命周期。 |
| 空间承诺 | 2x2，占格稳定，不能轻易塞进碎片空隙。 |
| 风险承诺 | 带 `SporeDormant`；当日出售或净化无额外代价，隔夜保留会触发轻微污染提示或维护成本。 |
| 经济承诺 | 炼金公会高价收；黑市可额外加价但提高怀疑。 |
| 验收路径 | `V-L3-PACK-CORRUPT-ITEM-01`：撤离后保留过夜，账单或房间提示显示污染来源和处理入口。 |

#### `order_contested_spore_core` 争夺孢核

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 一个大到夸张的核心样本，谁都想要，但只能给一个势力。 |
| 玩法职责 | 第一次稳定制造多势力订单冲突。 |
| 空间承诺 | 3x3，不可普通出售；可旋转无意义但可移动。 |
| 绑定承诺 | 获得后绑定当前订单或进入“可争夺委托物”状态；提交给一个势力后其他同源订单失败或进入冷却。 |
| 背叛承诺 | 黑市可高价收购，原正规订单转 `Betrayed`。 |
| 验收路径 | `V-L3-PACK-ORDER-CONFLICT-01`：玩家同时看到工坊、法师塔和黑市的不同回报，提交后互斥裁决清楚。 |

#### `trade_singing_fossil` 低唱化石

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 值钱、好看、不安静。它会让玩家想卖掉，也会让玩家想留下。 |
| 玩法职责 | 连接经济、房间记忆、法师塔、黑市和长期剧情线。 |
| 空间承诺 | 2x2；容易和防具 / 大材料竞争空间。 |
| 风险承诺 | 带 `AbyssRelic`、`Whispering`、`SanUneaseMid`。 |
| 去向 | 普通出售、法师塔研究、黑市高价、房间展示快照。 |
| 验收路径 | 玩家带回后，营业、订单、房间展示都能给出不同可见后果，不出现“只能卖钱”的单一用途。 |

### 4.2 普通怪职责

#### `mob_mycelium_crawler` 菌丝爬行体

| 字段 | 内容 |
|---|---|
| 教学目标 | 让玩家理解污染不只封格，也会附着到物品实例。 |
| 意图规律 | 攻击 -> 污染一个低价值非绑定物 -> 攻击。 |
| 反制方式 | 抢杀、携带净化盐、让低价值物承担污染、走安全路线减少遭遇。 |
| 失败教训 | 满包高价值物进入第三层，会让撤离收益承担额外处理成本。 |
| 内容边界 | 普通怪只加中低级污染，不直接销毁物品。 |

#### `mob_nerve_midge_swarm` 神经虫群

| 字段 | 内容 |
|---|---|
| 教学目标 | 把 SAN 压力和背包弱点标记结合，让玩家感到路线累积损耗。 |
| 意图规律 | 中等 SAN 压力 -> 标记一个空格或低耐久物 -> 小攻击。 |
| 反制方式 | 锚定符坠抵消一次；尽快击杀；避免低 SAN 进入探索路线。 |
| 失败教训 | 状态差时继续探索不是免费试错。 |
| 掉落逻辑 | 掉腐蚀神经束或锚定符坠，支撑风险与反制循环。 |

### 4.3 精英职责

#### `elite_spore_matriarch` 孢巢母体

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 她会让战斗越来越脏，但胜利后给出中期关键材料。 |
| 意图规律 | 召唤小孢子 -> 污染 1-2 个格子 -> 重击；低 HP 时污染优先级升高。 |
| 反制方式 | 清小孢子、净化盐、爆发抢杀、地图绕开。 |
| 奖励 | 高概率掉 `loot_living_mycelium` 和 `loot_spore_amber`，小概率掉三阶材料。 |
| 失败教训 | 没有净化或爆发就挑战污染精英，会把本次收益拖进长期成本。 |

#### `elite_vein_knight` 菌脉骑士

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 一个真正检验构筑薄弱点的精英，奖励是第三层异形武器线。 |
| 意图规律 | 守护 -> 标记弱槽 -> 穿刺攻击；如果玩家关键武器被标记，下一击伤害提升。 |
| 反制方式 | 调整背包位置、用护盾承压、用长条武器抢杀、绕路。 |
| 奖励 | 高概率掉 `gear_vein_sickle` 或 `loot_vein_plate`。 |
| 内容边界 | 标记只影响本战，不永久改变物品。 |

### 4.4 Boss：`boss_mycelium_oracle` 菌脉神谕体

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 第三层毕业战，考验玩家是否理解路线侵蚀、污染物品、背包干涉和订单目标冲突。 |
| 入场检查 | 若本层走过 `Attrition` 或高污染路线，Boss 获得 1 层 `RouteCorrosion`；最多 3 层。 |
| 阶段 1 | 攻击、SAN 压力、低级污染轮换。 |
| 阶段 2 | HP 低于 65% 后，按 `RouteCorrosion` 层数强化污染或召唤小孢子。 |
| 阶段 3 | HP 低于 30% 后预告“菌脉合唱”，对被标记物品施加中级污染并进行重击；之后疲惫 1 回合。 |
| 反制方式 | 少走高侵蚀路线、使用锚定符坠或净化盐、提前清理小孢子、在安全区止损。 |
| 奖励 | 必掉 `mat_core_tier3_seed`；概率掉 `trade_singing_fossil`、`gear_mycelium_cloak` 或争夺孢核。 |
| 安全区连接 | 击败后进入 SafeZone，HP / SAN 免费全恢复，但 `RouteCorrosion` 只作为本层 Boss 变量清除；物品污染和订单状态保留。 |

## 6. 第三层订单内容

## 11. 内容包完成判定

`pack_layer3_route_corrosion` 达到正式内容包完成，需要同时满足：

1. 12 件物品、5 只普通怪、2 个精英、1 个 Boss、2 个地图画像、4 个订单、3 个事件、3 条传闻和 4 个房间记忆都能落到配置 README。
2. 玩家能直接从已解锁第三层出发，不重复打一层或第二层。
3. 第三层至少稳定出现一次路线侵蚀、物品污染或势力订单冲突，并且都有玩家可见预告和反制 / 止损方式。
4. 精英至少一个可绕，挑战精英时奖励、污染风险和反制窗口可读。
5. 多势力订单围绕同一核心样本产生真实互斥，提交、失败、背叛和声望变化均可复盘。
6. Boss 根据路线侵蚀变量调整压力，但战后进入安全区仍免费全恢复 HP / SAN；物品污染、委托物和长期成本保留。
7. 至少通过 `V-L3-PACK-DIRECT-01`、`V-L3-PACK-ATTRITION-01`、`V-L3-PACK-CORRUPT-ITEM-01`、`V-L3-PACK-ORDER-CONFLICT-01`、`V-L3-PACK-BOSS-01` 五条验收。

这个内容包完成后，深渊前三层就形成清晰递进：第一层是正式低压入口，第二层是背包压力稳定化，第三层是路线侵蚀和势力目标冲突的中期门槛。
