# 局外成长与维护规则卡

> **定位：** 本规则卡把 `GDD_08` 中的底盘、义体、心智天赋、维护和换装从“模块设想”落实为正式局外成长规则。它定义玩家回城后如何把战利品转化为长期能力、哪些操作是零时耗、哪些状态会限制下潜，以及不同成长模块之间如何避免冲突。

---

## 1. 设计目标

局外成长系统要回答一个问题：玩家为什么愿意再次下深渊？

| 目标 | 说明 |
|---|---|
| 回城后有明确变强路径 | 玩家能看到底盘、义体、天赋、维护和换装各自需要什么。 |
| 构筑方向可形成 | 成长不是单纯加数值，而是改变背包形状、规则边界和下一次下潜策略。 |
| 维护保持压力 | 维护阻止角色失控变弱，是金币和材料的稳定消耗口。 |
| 失败也有沉淀 | 心智碎片让失败不等于空转，但成功撤离仍显著更赚。 |
| 情感不被工具化吞掉 | 换装、护理档位和好感反馈有情感意义，但不能变成强制刷数值。 |

---

## 2. 局外成长状态机

```text
OutgameEnter
  -> ReviewState
  -> FreeMaintenanceAndPlanning
  -> GrowthOperationLoop
  -> ValidateDiveReadiness
  -> CoreChoice(Dive / Rest)
```

| 状态 | 规则 |
|---|---|
| `OutgameEnter` | 从战斗、撤离、战败、休息或日结算返回小镇。 |
| `ReviewState` | 展示 HP、SAN、磨损、侵蚀、Bond、已装备底盘、义体槽、天赋点和资源缺口。 |
| `FreeMaintenanceAndPlanning` | 零时耗整理、购物、修理、净化、装配义体、查看升级需求。 |
| `GrowthOperationLoop` | 玩家可以执行底盘更换、义体制造 / 装配、天赋点亮、维护、换装。 |
| `ValidateDiveReadiness` | 检查是否允许下潜：重损、极端侵蚀、剧情危机、底盘适应期等。 |
| `CoreChoice` | 选择下深渊或休息 / 深度疗愈，推进一天。 |

除“休息 / 深度疗愈”外，常规成长操作不推进 Day。它们的限制来自金币、材料、图纸、槽位、冷却、状态和每日有效次数，而不是局外 AP。

## 3. 人偶成长实例字段

人偶实例需要保存以下成长状态：

| 字段 | 设计含义 |
|---|---|
| `DollID` | 当前人偶身份。 |
| `CurrentChassisID` | 当前底盘。 |
| `ChassisAdaptationDaysLeft` | 更换底盘后的适应期剩余天数。 |
| `EquippedProsthetics` | 义体槽位到义体 ID 的映射。 |
| `UnlockedBlueprints` | 已解锁底盘 / 义体 / 配方图纸。 |
| `MemoryShards` | 当前可用心智碎片。 |
| `UnlockedTalents` | 已点亮的心智天赋节点。 |
| `WearLevel` | 机体磨损，影响格子裂纹、封锁和下潜许可。 |
| `CorruptionLevel` | 深渊侵蚀，影响幻觉格、SAN 压力和危机事件。 |
| `WardrobeOwned` | 已拥有服装 / 涂装。 |
| `CurrentOutfitID` | 当前穿着。 |
| `MaintenanceHistory` | 最近维护档位、材料和情感影响，可供事件 / 特质读取。 |

配置定义和运行时实例要分开：底盘、义体、天赋、维护方案和服装是配置；当前装备、适应期、磨损、侵蚀、已解锁状态是运行时实例。

## 4. 底盘规则

### 4.1 底盘定义字段

| 字段 | 规则 |
|---|---|
| `ChassisID` | 全局唯一。 |
| `GridWidth / GridHeight / GridMask` | 决定背包基础形状。 |
| `RuleModifiers` | 底盘带来的特殊规则，例如中心禁区、同标签共鸣、空格加速。 |
| `UnlockCondition` | 图纸、势力声望、Boss 核心、剧情或成就要求。 |
| `BuildCost` | 金币、素材、Boss 核心等制造 / 更换成本。 |
| `AdaptationDays` | 更换后的适应期天数，默认 0 至 3。 |
| `AllowedProstheticSlots` | 可选，用于特殊底盘改变义体槽。 |
| `EndingTags` | 结局倾向标签，例如 `HeavyWeapon`、`Merchant`、`Resonance`。 |

### 4.2 更换底盘

更换底盘只允许在小镇工坊进行，且要求当前出战背包为空或已自动卸回安全容器。

流程：

```text
检查图纸 / 材料 / 金币
  -> 检查当前状态是否允许手术
  -> 扣除成本
  -> CurrentChassisID = NewChassisID
  -> ChassisAdaptationDaysLeft = AdaptationDays
  -> 重建背包网格
  -> 重新校验义体槽和底盘规则
```

裁决：

*   底盘不是线性升级树，也可以是横向构筑选择。
*   旧底盘不销毁，可作为收藏、周目解锁或后续回装对象。
*   更换后若当前义体槽不再合法，非法义体自动卸下进入工坊库存，不销毁。
*   适应期可以带来轻微不稳定，但不能让新底盘完全不可用。

### 4.3 适应期

适应期是“更换大构筑”的短期代价：

| 适应期状态 | 效果 |
|---|---|
| `1-3 天` | 下潜时出现边缘格不稳定、轻微 SAN 压力或维护费用上升。 |
| 维护缩短 | 高级维护可减少 1 天适应期。 |
| 休息推进 | 选择休息 / 深度疗愈会推进适应期。 |
| 不可叠加滥用 | 再次更换底盘会重置适应期，不累加到荒谬长度。 |

## 5. 义体规则

### 5.1 槽位

基础正式版义体槽：

| 槽位 | 职责 |
|---|---|
| `HeadSensor` | 情报、侦察、地图预读。 |
| `RightArm` | 攻击操作、武器标签辅助。 |
| `LeftArm` | 防御、拾取、撤离保护。 |
| `Legs` | 移动、负重、耐久、撤离。 |
| `CorePump` | 全局资源、SAN、AP、维护效率。 |

每个槽位同一时间只允许装备一件义体。义体不占背包格，但必须通过成本、槽位和互斥规则限制，避免成为无脑堆叠数值。

### 5.2 义体定义字段

| 字段 | 规则 |
|---|---|
| `ProstheticID` | 全局唯一。 |
| `SlotType` | 装配槽位。 |
| `Tier` | 基础、强化、极致或特殊。 |
| `Effects` | 效果引用，必须能被规则解释。 |
| `Tags` | 义体标签，如 `MeleeSupport`、`Scout`、`SanStabilizer`。 |
| `UnlockCondition` | 图纸、声望、研究、Boss 材料或剧情。 |
| `CraftCost` | 制造成本。 |
| `InstallCost` | 安装 / 更换成本，可为 0。 |
| `ConflictGroup` | 互斥组。 |
| `MaintenanceModifier` | 对维护费用、磨损或侵蚀的影响。 |

### 5.3 装配与拆卸

规则：

*   装配义体是零时耗工坊操作。
*   制造义体消耗材料和金币，生成可装备义体实例或直接解锁义体。
*   同槽位更换时，旧义体卸回库存。
*   义体默认可拆卸，但不可在深渊中更换。
*   剧情绑定或损坏义体可禁止拆卸，但必须提前展示原因。

设计限制：

*   义体优先改变规则、效率、视野和容错，不应只是大幅裸加攻击 / 血量。
*   如果义体直接影响局内 AP、伤害或护盾，必须有明确数值上限和触发条件。
*   义体之间的互斥优先用 `ConflictGroup` 表达。

## 6. 心智天赋规则

心智天赋是失败低保和长期人格方向，不是普通经验等级。

### 6.1 资源获取

| 来源 | 规则 |
|---|---|
| 进入深渊节点 | 获得少量记忆碎片，失败也保留。 |
| 击败精英 / Boss | 获得额外碎片。 |
| 成功撤离 | 按到达深度和携带风险获得撤离奖励。 |
| 剧情 / 好感事件 | 可奖励少量指定分支碎片或节点解锁。 |

建议公式：

```text
MemoryGain =
  VisitedNodeCount * NodeShardValue
  + EliteBonus
  + BossBonus
  + ExtractDepthBonus
  + EventBonus
```

失败保留 `VisitedNodeCount` 与已获得战斗奖励，撤离额外给 `ExtractDepthBonus`，确保“失败不空转，撤离更优秀”。

### 6.2 天赋节点字段

| 字段 | 规则 |
|---|---|
| `TalentID` | 全局唯一。 |
| `Branch` | 战斗直觉、商业头脑、深渊抗性等分支。 |
| `Tier` | 节点层级。 |
| `PrerequisiteTalentIDs` | 前置节点。 |
| `ShardCost` | 消耗碎片。 |
| `EffectRefs` | 效果引用。 |
| `UnlockCondition` | 可选，绑定剧情、好感、深度或结局路线。 |
| `EndingTags` | 对结局倾向的贡献。 |

### 6.3 点亮规则

*   必须满足前置节点和碎片消耗。
*   不允许跳级点亮，除非特殊事件明确赠送。
*   三条主分支可自由分配碎片。
*   一局内不应轻易点满所有分支；设计目标是 1 条主分支 + 半条副分支。
*   天赋重置默认不开放；若开放，必须有高额成本或剧情代价。

## 7. 维护规则

维护是“抗减法”系统，分为磨损修复和侵蚀净化。

### 7.1 磨损

| 区间 | 状态 | 影响 |
|---|---|---|
| `0-29` | 正常 | 无惩罚。 |
| `30-59` | 轻度磨损 | 边缘格裂纹、易碎物风险、维护提示。 |
| `60-89` | 重度磨损 | 部分格子封锁、义体效率下降。 |
| `90-100` | 极端磨损 | 禁止下潜，必须维护或休息处理。 |

磨损来源：受击、战败、腐蚀物、深层环境、低质量义体副作用。

### 7.2 侵蚀

| 区间 | 状态 | 影响 |
|---|---|---|
| `0-49` | 可控 | 无或轻微 UI 表现。 |
| `50-69` | 中度侵蚀 | 幻觉格、SAN 消耗提升。 |
| `70-89` | 高侵蚀 | 下潜警告、随机干扰、特质变异风险。 |
| `90-100` | 崩溃边缘 | 替换当日核心抉择为危机处置或禁止下潜。 |

侵蚀来源：深渊节点、恐怖敌人、污染物、违禁品 NightTax、剧情事件。

### 7.3 维护方案字段

| 字段 | 规则 |
|---|---|
| `MaintenanceID` | 全局唯一。 |
| `TargetState` | `Wear`、`Corruption`、`SAN` 或组合。 |
| `RecoverAmount` | 恢复 / 降低数值。 |
| `Cost` | 金币和材料。 |
| `QualityTier` | 廉价、标准、高级、剧情。 |
| `BondDelta` | 对好感或情绪的影响。 |
| `SideEffect` | 廉价维护可带副作用，高级维护可缩短适应期。 |
| `DailyLimit` | 可选，用于防止无限堆叠。 |

维护默认零时耗，但极端崩溃、深度疗愈和剧情手术可占用当天核心抉择。

## 8. 换装与涂装规则

换装是情感消费和视觉记录，不是战斗装备。

| 规则 | 说明 |
|---|---|
| 不提供直接战斗力 | 不加攻击、护盾、HP 上限等核心战斗数值。 |
| 可提供轻微经营或情绪加成 | 例如营业魅力 +5%、维护心情修正，但不得成为必买项。 |
| 一经购买不退货 | 强化消费决策重量。 |
| 可作为好感 / 事件里程碑奖励 | 配饰可免费解锁，代表情感纪念。 |
| 穿着场景可分离 | 战斗装、工坊便服、特殊服装可在不同界面显示。 |

## 9. 解锁与资源优先级

成长系统的自然资源优先级：

```text
必须维护 > 月租 / 债务 > 关键义体 > 底盘里程碑 > 天赋长期成长 > 换装情感消费
```

解锁来源：

| 来源 | 适合解锁 |
|---|---|
| 深渊 Boss | 底盘核心、极致义体、关键天赋门槛。 |
| 势力声望 | 图纸、义体、订单专属维护材料。 |
| 传闻 / 商店 | 临时折扣、稀有维护品、服装。 |
| 好感事件 | 情感服装、特殊维护方案、心智节点门槛。 |
| 记忆碎片 | 心智天赋。 |

原则：底盘和义体给构筑方向，维护给压力，天赋给长期补偿，换装给情感消费。不要让五个模块都争同一种资源，否则玩家只会计算最高 DPS。

## 10. 下潜许可检查

玩家选择下深渊前，必须做统一检查：

| 检查项 | 不通过时 |
|---|---|
| 极端磨损 | 禁止下潜，要求维护。 |
| 极端侵蚀 | 禁止或强警告，并可能触发危机处置。 |
| 底盘不存在 / 网格非法 | 禁止下潜。 |
| 义体槽非法 | 自动卸下非法义体后再检查。 |
| 剧情强制事件 | 替换当日核心抉择。 |
| 适应期 | 允许下潜，但应用不稳定惩罚。 |

禁止下潜必须给明确原因和可操作解决路径，例如“先做基础维护”“选择休息日”“卸下冲突义体”。

## 11. 验收样例

### 11.1 底盘

| 输入 | 期望 |
|---|---|
| 玩家拥有图纸、Boss 核心和金币，更换新底盘。 | 扣除成本，切换 `CurrentChassisID`，设置适应期，重建背包网格。 |
| 新底盘不支持某义体槽。 | 对应义体卸回库存，不销毁，并给出提示。 |
| 更换底盘后立即下潜。 | 允许下潜，但适应期惩罚生效。 |

### 11.2 义体

| 输入 | 期望 |
|---|---|
| 装备同槽位新义体。 | 旧义体卸下，新义体装备，效果刷新。 |
| 装备互斥组冲突义体。 | 阻止装配或要求先卸下冲突义体。 |
| 深渊中尝试更换义体。 | 不允许，提示只能在工坊操作。 |

### 11.3 天赋

| 输入 | 期望 |
|---|---|
| 失败前访问 5 个节点。 | 获得基础记忆碎片，失败不清空。 |
| 成功撤离到更深层。 | 获得额外撤离深度奖励。 |
| 尝试点亮无前置节点的高阶天赋。 | 阻止点亮并提示前置需求。 |

### 11.4 维护

| 输入 | 期望 |
|---|---|
| 磨损 65，执行标准修复降低 40。 | 磨损降至 25，重度惩罚解除。 |
| 侵蚀 92，玩家想下潜。 | 禁止或触发危机处置，提示需要净化 / 休息。 |
| 使用廉价维护品。 | 状态恢复，但可产生轻微 Bond / 情绪负面。 |

### 11.5 换装

| 输入 | 期望 |
|---|---|
| 购买便服。 | 扣除金币，加入 `WardrobeOwned`，可切换显示。 |
| 试图用服装提高攻击力。 | 不允许；战斗力由底盘、义体、背包物品和天赋承担。 |
| 好感事件赠送配饰。 | 免费加入衣柜，作为情感纪念。 |

## 12. 文档同步要求

后续修改局外成长规则时，同步检查：

*   `GDD_08` 是否仍准确描述底盘、义体、天赋、维护和换装定位。
*   `GDD_03` 的 Bond / SAN / Trait 是否与维护和心智天赋边界一致。
