# 局外时间与日程口径规则卡

> **定位：** 本规则卡统一 `设计文档/` 内所有局外日程口径，避免程序把旧版“每天 AP 分配”误实现为正式版规则。正式版局外时间只使用 Day / Week / Month；AP 只保留给局内战斗回合。

---

## 1. 核心结论

正式版局外日程不是“AP 点数分配游戏”，而是“每天一次核心抉择”的生存轮转。

| 概念 | 正式定义 | 不再使用的旧口径 |
|---|---|---|
| 局内 AP | 战斗回合中的能量 / 行动点，用于发动武器、义体或技能。 | 不用于小镇、工坊、房间、对话、经营。 |
| 局外 Day | 玩家做出一次核心抉择的最小时间单位。 | 不拆成上午 / 下午 / 夜晚三个 AP。 |
| Week | 每 7 天触发一次中观刷新。 | 不由玩家手动消耗时间点触发。 |
| Month | 每 28 天触发租金、阶段和结局相关结算。 | 不由玩家跳过或购买。 |

程序实现上只需要两套时间概念：

1. **CombatAP**：只存在于局内战斗状态机。
2. **CalendarDay**：只存在于局外日程、周月结算和剧情触发。

---

## 2. 一天的正式状态机

每天固定经历以下阶段：

```text
DayStart
  -> PrepWindow        // 零时耗整备与交互
  -> CoreChoice        // 当天唯一推进时间的选择
  -> DiveRun 或 RestDay
  -> BusinessResolve   // 营业结算期
  -> DayEnd
  -> Week/Month Check
```

| 阶段 | 玩家可做什么 | 是否推进天数 |
|---|---|---|
| `PrepWindow` 备战期 | 整理背包、购物、出售、安装义体、保养、轻互动、赠礼、势力拜访、查看情报。 | 否 |
| `CoreChoice` 核心抉择 | 选择“跳下深渊”或“停工休息 / 深度疗愈”。 | 确认后锁定当天方向 |
| `DiveRun` 深渊日 | 进入深渊地图、战斗、搜刮、撤离或失败。 | 是 |
| `RestDay` 休息日 | 触发深度疗愈、危机处理、长线陪伴或特殊剧情。 | 是 |
| `BusinessResolve` 营业结算期 | 出货、橱窗结算、账单、经营事件。 | 随当天结束自动执行 |

天数只在 `DayEnd` 时 +1。玩家在 `PrepWindow` 里停留多久、点多少次界面、整理多少次背包，都不改变日期。

---

## 3. 零时耗行为边界

零时耗不是无限收益，而是不推进日期。它们仍然可以有资源、次数、状态或边际收益限制。

| 行为 | 时间口径 | 主要限制 |
|---|---|---|
| 背包整理 / 旋转 / 装卸装备 | 零时耗 | 只受背包规则、物品绑定和配置限制。 |
| 购物 / 出售 / 势力兑换 | 零时耗 | 消耗金币、物品、声望或库存刷新次数。 |
| 轻触摸 / 普通闲聊 | 零时耗 | 每日有效次数、情绪状态、边际收益递减。 |
| 普通赠礼 | 零时耗 | 消耗赠礼物品；第 2 件起好感收益显著递减。 |
| 基础保养 / 净化 | 零时耗 | 消耗金币、材料；可受动画、材料档位和状态阈值限制。 |
| 房间浏览 / 陈列调整 | 零时耗 | 纯表现或轻量触发，不推进天数。 |

设计意图：把“整理、陪伴、欣赏、准备”从时间惩罚中释放出来，让玩家把压力集中在真正残酷的选择上：今天是继续下深渊，还是停下来救她。

---

## 4. 推进天数的核心抉择

每天只有一个真正消耗日期的选择。

### 4.1 跳下深渊

| 输出 | 说明 |
|---|---|
| 收益 | 战利品、素材、记忆碎片、势力委托物、深渊进度。 |
| 代价 | HP / SAN / 磨损 / 侵蚀压力，失败时丢失新获战利品。 |
| 结算 | 回到地面后进入营业结算期，然后日期 +1。 |

### 4.2 停工休息 / 深度疗愈

| 输出 | 说明 |
|---|---|
| 收益 | 高额 HP / SAN 恢复、侵蚀处理、负面特质处理、羁绊剧情。 |
| 代价 | 当天没有新深渊产出，租金与委托截止继续逼近。 |
| 结算 | 可处理仓库存货营业，之后日期 +1。 |

---

## 5. 危机处理规则

危机不会回退到旧 AP 制，而是占用当天核心抉择。

| 危机 | 触发条件 | 正式处理 |
|---|---|---|
| 崩溃事件 | 侵蚀度达到 100% 或 SAN 崩溃。 | 当天 `CoreChoice` 被替换为“崩溃处置”，无法选择深渊。 |
| 机体重损 | 磨损度或战损达到锁定阈值。 | 下深渊按钮锁定，必须先零时耗保养到阈值以下，或把当天用于深度修复。 |
| 过劳状态 | 连续多日下深渊。 | 强制要求连续休息日，或高风险强行下潜并触发负面事件。 |
| 债主登门 | 月末欠款。 | 占用营业结算期或触发强制剧情，不额外引入 AP。 |

---

## 6. 防滥用原则

| 风险 | 解决方式 |
|---|---|
| 无限摸头刷好感 | 每日前若干次有效，之后只有表现反馈。 |
| 无限闲聊补 SAN | 轻互动只能补到低保线；真正恢复依赖休息、保养或材料。 |
| 无限赠礼堆好感 | 当日多次赠礼边际递减，并受偏好、状态、剧情门槛限制。 |
| 零时耗保养让经济失压 | 保养不耗时间，但消耗金币和材料，作为经济回收池。 |
| 玩家永远下深渊 | 过劳、侵蚀、磨损和委托节奏共同打断。 |

---

## 7. 程序验收用例

| 用例 | 输入 | 期望 |
|---|---|---|
| 背包整理不推进天数 | Day=12，在备战期旋转、放置、移除物品 20 次。 | Day 仍为 12。 |
| 普通交互不推进天数 | Day=12，触摸 10 次、赠礼 3 次、闲聊 2 次。 | Day 仍为 12；好感按每日上限和边际递减结算。 |
| 下深渊推进一天 | Day=12，选择跳下深渊并完成撤离。 | 营业结算后 Day=13。 |
| 休息推进一天 | Day=12，选择停工休息。 | 恢复效果结算，营业结算后 Day=13。 |
| 崩溃占用核心抉择 | Day=12，侵蚀度=100%。 | 深渊选项不可用，当天核心抉择替换为崩溃处置。 |
| 局内 AP 与局外天数隔离 | 战斗中 AP 从 3 降到 0。 | 局外 Day 不变化；AP 只在战斗回合内恢复或消耗。 |

---

## 8. 文档同步要求

所有 GDD 写局外行为时使用以下词：

- 零时耗
- 推进天数
- 占用当天核心抉择
- 营业结算期
- 夜间情感窗口

避免在局外语境使用：

- 消耗 1AP
- 夜晚 AP③
- 每天三次机会
- 小镇行动点
- 地面 AP
