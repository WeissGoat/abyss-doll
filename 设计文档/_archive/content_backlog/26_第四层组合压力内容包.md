# 第四层组合压力内容包

> **当前状态：** 本文档是后续层内容填充草案，暂不列入当前优先推进范围。当前策划优先级是整理 `设计文档/` 的事实来源层级，并把 GDD、规则卡、交付矩阵和前三层 / 核心系统内容包落到配置、表现和验收。待第四层正式进入内容生产批次时，应按 `18_正式版内容生产规格.md` 复审本文，再恢复为 active 内容包。

> **定位：** 本内容包把第四层“菌冠温床”的正式体验交到内容粒度。第三层让玩家第一次面对路线侵蚀、污染物品和多势力订单冲突；第四层负责把这些压力组合起来，形成 3-4 层生物腐蚀区的中期门槛。
>
> 第四层不是“第三层再难一点”。它的职责是检验玩家能否在一次下潜中同时处理：背包被干涉、关键物被污染、订单目标互斥、精英路线诱惑、Boss 前资源消耗和安全区止损。玩家通过第四层后，才算真正准备进入 5-6 层“晶化深域”的稀有素材和高强度封格阶段。

## 2. 第四层体验目标

| 体验目标 | 内容承担方式 |
|---|---|
| 组合压力成立 | 普通路线也可能同时出现封格、污染物品、SAN 压力或订单占格中的两种。 |
| 路线规划更重要 | 地图画像区分 `RecoveryPlan`、`EliteHarvest`、`OrderChain`、`BlackMarketShortcut`。 |
| 精英不只是高收益 | 第四层精英可能给关键材料，但会消耗净化资源或污染背包关键区域。 |
| 订单形成链式目标 | 第三层争夺孢核之后，第四层出现后续加工、研究、背叛或赎回订单。 |
| Boss 是生物腐蚀区总结 | Boss 根据玩家本层污染、精英挑战和订单携带情况改变压力，而不是固定流程。 |
| 安全区止损被强化 | 安全区仍免费全恢复 HP / SAN，但玩家要决定是否带着污染核心继续进入晶化深域。 |

### 3.2 核心物品职责说明

#### `gear_sporeward_aegis` 拒孢盾

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 一件很难摆的防具，但能明显降低第四层最烦人的污染压力。 |
| 玩法职责 | 让玩家开始用装备构筑主动应对环境主题，而不是只堆伤害。 |
| 空间承诺 | T 形 5 格，可旋转；会强迫玩家重排武器和消耗品。 |
| 战斗承诺 | 每场战斗首次中低级污染效果降低或改为延迟。 |
| 成本 | 维护费用较高，离开第四层后仍需局外修复。 |
| 验收路径 | `V-L4-PACK-COMBO-01`：装备后污染压力明显降低，但背包空间变窄。 |

### 4.2 普通怪职责

#### `mob_crown_sporeling` 菌冠幼体

| 字段 | 内容 |
|---|---|
| 教学目标 | 让玩家理解第四层污染会扩散，而不是只停在单格或单物品。 |
| 意图规律 | 攻击 -> 扩散已有低级污染 -> 攻击。 |
| 反制方式 | 先净化再拖回合；快速击杀；拒孢盾降低首次扩散。 |
| 失败教训 | 带着污染进战斗会被放大，污染处理时机很重要。 |
| 内容边界 | 扩散只提升中低级污染，不直接销毁物品。 |

#### `mob_bile_sower` 胆汁播撒者

| 字段 | 内容 |
|---|---|
| 教学目标 | 组合塞包和污染，迫使玩家同时考虑空间和状态。 |
| 意图规律 | 塞入 1x1 胆汁残渣 -> 污染相邻格 -> 攻击。 |
| 反制方式 | 预留空格、深净化瓶、抢杀、避免满包进入。 |
| 失败教训 | 只准备清格或只准备净化都不够，需要组合反制。 |
| 掉落逻辑 | 掉菌冠孢簇，并小概率掉深净化瓶补给。 |

### 4.3 精英职责

#### `elite_crown_broodguard` 菌冠巢卫

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 一只强硬的中期门槛精英，奖励能支撑抗污染构筑。 |
| 意图规律 | 守护 -> 扩散污染 -> 重击；若玩家没有污染，改为封边。 |
| 反制方式 | 净化后挑战、携带拒孢盾、爆发抢杀、地图绕开。 |
| 奖励 | 高概率掉 `gear_sporeward_aegis` 或 `loot_pulsing_chitin`。 |
| 地图职责 | 在组合压力地图中必须可绕；在精英收割地图中可作为高收益路线核心。 |

#### `elite_bile_cantor` 胆汁咏唱者

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 它不一定打死你，但会把你的收益和心智一起拖脏。 |
| 意图规律 | SAN 压力 -> 污染关键物 -> 召唤孢子 -> 攻击。 |
| 反制方式 | 锚定符坠、快速击杀、用低价值物承担标记、绕路。 |
| 奖励 | 高概率掉 `loot_memory_hypha` 或 `trade_larval_crown`。 |
| 失败教训 | 低 SAN、满包、高价值物同时存在时，不该硬贪该精英。 |

### 4.4 Boss：`boss_crown_incubator_queen` 菌冠育母

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 3-4 层生物腐蚀区的总结 Boss，检验污染处理、召唤处理、背包空间和订单携带。 |
| 入场检查 | 读取本层 `PollutionCount`、是否携带 `order_crown_incubator`、是否挑战过精英；生成 0-4 层 `BroodPressure`。 |
| 阶段 1 | 攻击、召唤小孢子、轻污染轮换。 |
| 阶段 2 | HP 低于 70% 后按 `BroodPressure` 强化污染扩散或召唤数量。 |
| 阶段 3 | HP 低于 35% 后预告“菌冠开裂”，对最大连通空区施加封锁 / 污染组合，并进行重击；之后疲惫 1 回合。 |
| 反制方式 | 提前净化、少走污染路线、携带拒孢盾、处理召唤物、在安全区止损。 |
| 奖励 | 必掉 `mat_core_tier4_gland`；概率掉 `loot_stabilized_spore_core`、`gear_crown_cleaver`、`trade_larval_crown`。 |
| 安全区连接 | 击败后进入 SafeZone，HP / SAN 免费全恢复；`BroodPressure` 清除，但物品污染、委托物、四阶材料和长期维护成本保留。 |

| 验收 | 提交前二次确认显示原订单失败、声望代价、怀疑状态和不可挽回。 |

## 7. 第四层事件内容

### 7.1 `event_cleanse_pool` 净化菌池

| 字段 | 内容 |
|---|---|
| 触发节点 | `Event` 或 `RestStop`，`RecoveryPlan` 路线权重提高。 |
| 玩家承诺 | 可以处理污染，但要牺牲收益或资源。 |
| 选项 A | 花费金币或材料，清除 1 件物品中级污染。 |
| 选项 B | 花费 8 SAN，清除 2 个污染格或孢子残渣。 |
| 选项 C | 采集菌池沉淀，获得 `loot_crown_spore_cluster`，但增加污染风险。 |
| 系统连接 | 物品生命周期、SAN、经济、路线规划。 |
| 验收 | 玩家能看清每个选项清什么、花什么、留下什么风险。 |

### 7.2 `event_incubator_growth_spurt` 培养舱躁动

| 字段 | 内容 |
|---|---|
| 触发节点 | `Event`，携带培养舱时权重提高。 |
| 玩家承诺 | 可以提高培养舱品质，也可能让它失控。 |
| 选项 A | 用深净化瓶稳定，`IncubatorStress -1`。 |
| 选项 B | 冒险催熟，获得额外奖励但 `IncubatorStress +1`。 |
| 选项 C | 放弃处理，保持当前状态。 |
| 系统连接 | 订单品质、消耗品、风险收益、黑市背叛。 |
| 验收 | 不携带培养舱时该事件不应出现或应变成普通菌冠事件。 |

### 7.3 `event_black_market_brood_whisper` 黑市育巢低语

| 字段 | 内容 |
|---|---|
| 触发节点 | `Event`，黑市信任 >= 7 或携带培养舱时出现。 |
| 玩家承诺 | 黑市给出捷径或买断承诺，但会污染正规势力关系。 |
| 选项 A | 接受黑市标记，下一个高污染节点变成交易节点，但正规势力怀疑提高。 |
| 选项 B | 拒绝并记录黑市接触，轻微增加正规势力信任。 |
| 选项 C | 提前卖出部分污染材料，获得金币和黑市信任。 |
| 系统连接 | 黑市、势力怀疑、路线节点替换、经济。 |
| 验收 | 黑市事件不能绕过 Boss，只能改变路线风险和收益结构。 |

## 9. 第四层联合验收路径

### 9.1 `V-L4-PACK-DIRECT-01` 第四层直达

| 项 | 内容 |
|---|---|
| 前置状态 | 玩家已击败第三层 Boss，第四层已解锁。 |
| 玩家行为 | 从小镇选择第四层出发。 |
| 期望结果 | 直接生成 `layer_04` 地图；不重复打一到三层；UI 显示组合压力、净化建议和订单风险。 |
| 失败信号 | 必须重打前置层、第四层仍使用第三层内容池、直达后订单目标无法出现。 |

### 9.2 `V-L4-PACK-COMBO-01` 组合压力遭遇

| 项 | 内容 |
|---|---|
| 前置状态 | 玩家进入 `layer4_combined_pressure`，背包有低级污染物和少量空格。 |
| 玩家行为 | 遭遇胆汁播撒者或菌冠幼体。 |
| 期望结果 | 塞包、污染扩散或封格至少两种压力组合出现；玩家可用深净化瓶、拒孢盾、抢杀或路线止损应对。 |
| 失败信号 | 压力无预告、污染暗中扩散、反制道具无效或失败原因不可读。 |

### 9.3 `V-L4-PACK-ELITE-CHOICE-01` 精英路线选择

| 项 | 内容 |
|---|---|
| 前置状态 | 地图出现巢卫精英路线和恢复路线。 |
| 玩家行为 | 玩家选择挑战精英或绕向净化菌池。 |
| 期望结果 | 精英奖励显著更高但污染压力强；恢复路线收益较低但降低 Boss 入场压力。 |
| 失败信号 | 精英强制必打、恢复路线没有意义、奖励和风险不成比例。 |

### 9.4 `V-L4-PACK-ORDER-CHAIN-01` 培养舱订单链

| 项 | 内容 |
|---|---|
| 前置状态 | 玩家接取工坊或法师塔培养舱订单。 |
| 玩家行为 | 携带 `order_crown_incubator` 进入第四层，经过事件调整 `IncubatorStress`，撤离后交付。 |
| 期望结果 | 培养舱占格、压力层数、交付品质、失败和背叛代价都可见；提交后互斥订单裁决清楚。 |
| 失败信号 | 压力层数不可见、品质奖励不清楚、同一培养舱可重复交付。 |

### 9.5 `V-L4-PACK-BOSS-01` 菌冠育母中期门槛

| 项 | 内容 |
|---|---|
| 前置状态 | 玩家以不同 `BroodPressure` 进入 Boss。 |
| 玩家行为 | 击败 `boss_crown_incubator_queen`，进入安全区。 |
| 期望结果 | Boss 根据污染、精英挑战和培养舱携带情况强化压力；击败后必掉四阶腺核；安全区免费恢复 HP / SAN，但不清理物品污染、订单和长期维护成本。 |
| 失败信号 | Boss 与路线规划无关、安全区错误净化所有污染、四阶材料无成长去向。 |

## 11. 内容包完成判定

`pack_layer4_combined_pressure` 达到正式内容包完成，需要同时满足：

1. 12 件物品、5 只普通怪、2 个精英、1 个 Boss、2 个地图画像、4 个订单、3 个事件、3 条传闻和 4 个房间记忆都能落到配置 README。
2. 玩家能直接从已解锁第四层出发，不重复打一到三层。
3. 第四层至少稳定出现一次组合压力，并且玩家能通过装备、消耗品、路线或撤离止损应对。
4. 地图至少提供一条恢复 / 净化路线和一条高收益精英路线，二者风险收益差异可读。
5. 培养舱订单链的占格、压力层数、品质奖励、互斥和黑市背叛全部可复盘。
6. Boss 根据污染、精英挑战和订单携带情况调整压力；战后安全区仍免费恢复 HP / SAN，但不清除物品污染、委托物和长期维护成本。
7. 至少通过 `V-L4-PACK-DIRECT-01`、`V-L4-PACK-COMBO-01`、`V-L4-PACK-ELITE-CHOICE-01`、`V-L4-PACK-ORDER-CHAIN-01`、`V-L4-PACK-BOSS-01` 五条验收。

这个内容包完成后，3-4 层生物腐蚀区形成完整中期段落：第三层引入路线侵蚀和订单冲突，第四层把这些压力组合成 Boss 门槛，并把玩家推向 5-6 层晶化深域的稀有素材阶段。
