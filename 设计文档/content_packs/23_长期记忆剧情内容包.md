# 长期记忆剧情内容包

> **定位：** 本内容包把剧情事件和房间视觉日记从“规则可开发”推进到正式内容粒度。它不写长篇对白正文，也不替代剧本表、对话树或房间配置；它规定第一批事件、日记、纪念物、窗外状态和待机规则应如何由系统状态触发、如何进入队列、如何落到房间记忆，以及如何验收“经历被记住”。

---

## 1. 内容包总览

| 项 | 内容 |
|---|---|
| `PackID` | `pack_longterm_memory_story_v1` |
| `PackName` | 长期记忆剧情内容包 |
| 目标阶段 | 正式版核心纵切中的长期叙事与房间记忆主干。 |
| 前置内容 | 第一层正式核心内容包、第二层背包压力内容包、人偶成长修复内容包、小镇经济月租内容包。 |
| 目标体验 | 玩家每次战败、胜利、修复、欠债、背叛、赠礼或深入，都能在事件日志、房间日记、纪念物或待机状态中留下长期痕迹。 |
| 覆盖系统 | ScenarioEvents、DialogueTrees、Flags、Commands、RoomMemory、Mementos、Diary、WindowState、IdleRules。 |
| 主要验收 | `V-P2-SCENARIO-01`、`V-P2-ROOM-01`、`V-SCENARIO-QUEUE-01`、`V-SCENARIO-SKIP-01`、`V-ROOM-MEMORY-01`、`V-ROOM-IDLE-01`。 |

长期剧情的重点不是一次性播放“章节”，而是把系统经历转化为长期记忆。事件可以短，但触发、结果、旗标、日记和房间反馈必须稳定。

---

## 2. 玩家体验目标

| 目标 | 设计说明 | 失败表现 |
|---|---|---|
| 经历被记住 | 首次战败、Boss 胜利、奇迹、欠债、背叛、关键赠礼等经历进入日志或房间。 | 房间一直像默认背景，剧情只播完即消失。 |
| 剧情不丢状态 | 跳过文本、读档重入、缺资源 fallback 都不能丢奖励、惩罚、旗标和记忆。 | 跳过导致 Bond、债务或解锁丢失。 |
| 情感有层次 | Bond 事件、低 SAN 安抚和奇迹后对话读当前人偶状态，不使用同一套温馨反馈。 | 所有互动都像固定好感台词。 |
| 压力有余波 | 月租、欠债、黑市和违禁品不只是账单数字，也会影响窗外、日记和房间氛围。 | 经济危机只存在于结算界面。 |
| 房间零压力 | 房间负责记忆和休憩，不推进 Day，不承担仓库，不阻止普通出售。 | 房间变成另一套仓库或倒计时界面。 |
| 长线可扩展 | 第一批事件用统一字段、触发器、旗标和 RoomMemory 落点，后续只扩内容。 | 每个剧情事件都要写特殊规则。 |

| `EventID` | 展示名 | 触发器 | 优先级 / 表现 | 系统指令 | 房间 / 反馈落点 | 玩法职责 |

| `evt_bond_lv4_low_san_promise` | 低 SAN 下的约定 | SAN < 15 且 Bond Lv.4+，完成安抚 | 700 / `AVG` | `SetFlag low_san_promise_seen` | 解锁低 SAN 安抚台词池 | 低 SAN 不是刷好感，而是谨慎照料。 |

债务事件负责让经济压力进入叙事，但不得替代账单裁决。账单先裁决状态，剧情事件再解释余波。

| `evt_debt_pawn_aftertaste` | 典当后的空位 | 首次典当成功 | 650 / `RoomMemory` | `AddRoomMemory pawn_empty_slot` | `memento_pawn_empty_tag` | 让典当刺痛但不误伤核心物。 |

## 11. 内容边界

| 不做 | 原因 |
|---|---|
| 不写成长篇固定章节。 | 正式口径是系统触发的碎片化事件，不是线性关卡播片。 |
| 不让剧情绕过规则裁决。 | 任何 Bond、SAN、金币、物品、债务和记忆变化都走系统指令。 |
| 不让跳过文本跳过状态。 | 跳过只影响文本观看，不影响奖励、惩罚、旗标和日志。 |
| 不让房间承担仓库。 | 展示品是快照，来源物出售后清空展示或保留历史。 |
| 不让日记删除历史。 | 特质消除、物品出售、债务清偿后，历史仍保留。 |
| 不让窗外状态随机闪变。 | 同一存档状态必须按优先级稳定选择窗外表现。 |

## 12. 完成判定

本内容包达到可交付开发，需要同时满足：

1. 8 个主线事件、8 个 Bond 事件、5 个债务事件、8 个 deep lore 事件、10 个纪念物、12 条日记、7 个窗外状态和 7 条待机规则都有触发、落点和验收路径。
2. 事件能证明队列优先级、跳过不丢指令、读档重入和资源 fallback 不破坏系统状态。
3. 房间能证明战败、Boss 胜利、欠债、典当、黑市、奇迹和真相低语都能留下长期痕迹。
4. 房间观察保持零时耗，不推进 Day，不触发经济结算，不承担仓库。
5. 至少通过 `V-PACK-STORY-FLOW-01`、`V-PACK-STORY-FLOW-02`、`V-PACK-STORY-FLOW-04`、`V-PACK-STORY-FLOW-06` 四条联合验收。

当以上条件满足后，长期记忆剧情主干可进入剧本表、房间配置、UI / 美术表现和验收拆分。
