# 第一层正式核心内容包

> **定位：** 本内容包把第一层“浅渊回廊”的正式搜打撤体验交到内容粒度。它不是配置 JSON，也不替代配置 README；它规定第一层首批物品、怪物、地图画像、Boss、经济传闻、事件和房间记忆应承担什么玩法职责，如何被玩家读懂，以及如何共同跑通 `V-P0-RUN-01`。

---

## 1. 内容包总览

| 项 | 内容 |
|---|---|
| `PackID` | `pack_layer1_formal_core` |
| `PackName` | 第一层正式核心内容包 |
| 目标层级 | `layer_01` 浅渊回廊 |
| 目标体验 | 教会玩家背包旋转、AP 战斗、怪物意图、战利品取舍、路线选择、Boss 后安全区和撤离回流。 |
| 覆盖系统 | `Items`、`Monsters`、`Dungeons`、`Rewards`、经济传闻、ScenarioEvents、RoomMemory。 |
| 主要验收 | `V-P0-RUN-01`、`V-ITEM-ROTATE-01`、`V-COMBAT-INTENT-01`、`V-MAP-ROUTE-01`、`V-SAFEZONE-01`、`V-P2-ECON-01`。 |

第一层不是临时教学关，而是正式循环的低压入口。它的复杂度要克制，但规则必须完整：路线不是单线，战斗有意图，背包有旋转和取舍，战利品能进入经济，Boss 后安全区免费全恢复并允许撤离。

---

## 2. 玩家体验目标

| 体验目标 | 内容承担方式 |
|---|---|
| 看懂背包是战斗空间 | 武器、防具、消耗品和战利品都有形状；至少一件核心武器需要旋转才能合理放入。 |
| 看懂怪物意图 | 第一层怪物只使用攻击、防御、轻度塞包和低压 SAN 干涉，不投放复杂连锁。 |
| 看懂路线选择 | 两个地图画像都至少提供安全路线和冒险路线；精英可绕。 |
| 看懂搜打撤 | 战斗获物、宝箱获物、Boss 获物都占背包，玩家需要决定撤离或继续贪。 |
| 看懂局外回流 | 撤离物品可出售、制造或触发房间记忆；传闻让玩家感到“下次想捡什么”。 |
| 感到失败有代价 | 战败丢新获物、保留绑定物但损坏，并触发房间战败记忆。 |

### 3.2 核心物品职责说明

#### `gear_tactical_blade` 折刃战术刀

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 一把窄长武器，横放占战斗核心位，竖放能腾出拾取空间。 |
| 玩法职责 | 教玩家旋转不是装饰，而会改变背包空隙和方向相邻效果。 |
| 空间承诺 | 1x3，可 0 / 90 度旋转；相邻前端格可获得轻微伤害加成。 |
| 战斗承诺 | 低中 AP 单体攻击，适合作为第一层主武器升级目标。 |
| 经济承诺 | 作为武器标签可受 `rumor_old_blades` 影响涨价，但通常比不上战斗价值。 |
| 验收路径 | `V-ITEM-ROTATE-01`：背包只有竖向空位时，旋转后能放入并保存朝向。 |
| 美术需求 | 细长刀图标需要方向可读，旋转后刀尖朝向清楚。 |

#### `loot_toxic_filter` 毒雾滤芯

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 一个不好塞但值钱的异形材料，带着它会让背包整理更别扭。 |
| 玩法职责 | 第一层轻度引入风险物和异形战利品，不直接制造高压。 |
| 空间承诺 | L 形 3 格，可旋转；常常需要玩家丢弃小件才放得下。 |
| 风险承诺 | 带 `RiskToxicLow`，当日出售无额外代价；隔夜保留时可能造成轻微 SAN 压力提示。 |
| 经济承诺 | 在 `rumor_filter_shortage` 下价值上浮，是玩家追逐特定怪物的诱因。 |
| 验收路径 | 战斗后掉落时，玩家能看见异形占格、风险标签和售价预估。 |
| 内容边界 | 第一层只做轻污染提示，不触发复杂污染扩散。 |

#### `trade_cracked_relic` 裂纹圣牌

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 高价、占格、略不安的遗物，适合在安全区选择落袋为安。 |
| 玩法职责 | 引导玩家理解“高价值物 -> 背包压力 -> 撤离冲动”。 |
| 空间承诺 | 2x2，不可旋转；对小背包有明显压迫。 |
| 风险承诺 | 带 `AbyssRelic` 和 `SanUneaseLow`，不会在第一层立即惩罚，但账单和房间会记录异样。 |
| 经济承诺 | 普通出售高价；黑市或事件可给更高价，但第一层只预告不强推。 |
| 验收路径 | Boss 前获得该物时，玩家面对“继续打 Boss 还是保守撤离”的心理压力。 |
| 美术需求 | 图标需要有裂纹和浅层深渊符号，便于和普通材料区分。 |

### 3.3 物品内容边界

| 边界 | 说明 |
|---|---|
| 不投放强绑定物 | 第一层除初始装备和情感锚点外，不大量投放不可出售物。 |
| 不投放高污染连锁 | 第一层风险物只提示长期风险，不制造仓库污染灾难。 |
| 不投放复杂套装 | 第一层可以有相邻效果，但不做多件套强组合。 |
| 不让高价物完全无代价 | 高价值物至少通过体积、风险、用途竞争或 Boss 前压力制造取舍。 |

## 4. 第一层怪物与遭遇

### 4.1 怪物总表

| MonsterID | 展示名 | 职责 | 意图组合 | 掉落逻辑 | 投放 |
|---|---|---|---|---|---|
| `mob_scavenger_bug` | 拾荒虫 | 基础攻击教学 | `Attack`、低概率 `Defend` | 齿轮废料、小金币 | 普通战斗。 |
| `mob_rust_hound` | 锈牙犬 | AP 节奏教学 | `Attack`、`ChargeAttack` | 锈红线圈、齿轮废料 | 普通战斗 / 冒险路线。 |
| `mob_acid_slime` | 酸液软体 | 轻度塞包教学 | `Attack`、`AddJunkSmall` | 毒雾滤芯、废料 | 第 1 层后半或事件路线。 |
| `mob_lost_miner_echo` | 失声矿工影 | 低压 SAN 教学 | `SanPressureSmall`、`Attack` | 矿工提灯、镇静剂 | 事件 / 探索路线。 |
| `elite_scrap_guard` | 废铁守卫 | 第一层精英构筑检查 | `Defend`、`HeavyAttack`、低频 `GridLockEdge` | 折刃战术刀、裂纹圣牌 | 精英节点，可绕。 |
| `boss_gatekeeper_mk1` | 一层守门机核 | 第一层 Boss | 阶段攻击、护盾、轻封边 | 一阶机核、裂铁胸甲 | Boss 固定。 |

### 4.2 怪物职责说明

#### `mob_scavenger_bug` 拾荒虫

| 字段 | 内容 |
|---|---|
| 教学目标 | 教玩家读攻击意图、消耗 AP 攻击、叠盾抵消。 |
| 意图规律 | 70% 攻击，30% 防御；不使用背包干涉。 |
| 反制方式 | 低 HP，玩家可抢杀；叠盾也能稳定过。 |
| 失败教训 | 忽略攻击意图会导致不必要损血。 |
| 掉落逻辑 | 低价废料，主要让玩家体验战利品占格。 |

#### `mob_acid_slime` 酸液软体

| 字段 | 内容 |
|---|---|
| 教学目标 | 第一次让玩家看到“怪物能往背包塞东西”。 |
| 意图规律 | 攻击 -> 攻击 -> 塞入 1x1 酸液残渣，循环或低概率提前塞包。 |
| 反制方式 | 在塞包前击杀，或预留空格，或用清理消耗品。 |
| 失败教训 | 背包塞满不只是拾取问题，也会影响战斗承压。 |
| 掉落逻辑 | 掉落 `loot_toxic_filter`，把怪物职责和风险物连接起来。 |
| 表现需求 | 塞包意图必须显示 1x1 形状和目标倾向。 |

#### `elite_scrap_guard` 废铁守卫

| 字段 | 内容 |
|---|---|
| 教学目标 | 检查玩家是否理解攻击、叠盾、抢杀和绕开精英。 |
| 意图规律 | 首回合防御，第二回合重击，第三回合轻封边缘格，之后循环。 |
| 反制方式 | 精英节点地图可绕；进入后可在重击前爆发或叠盾。 |
| 失败教训 | 贪精英需要准备伤害或防御，不是免费高收益。 |
| 掉落逻辑 | 高概率给折刃战术刀或裂纹圣牌，奖励足以解释风险。 |
| 内容边界 | 第一层封格只锁边缘 1 格，战后解除，不永久破坏背包。 |

### 4.3 Boss：`boss_gatekeeper_mk1` 一层守门机核

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 第一层的正式毕业战，考验玩家是否理解 AP、护盾、消耗品和背包空间。 |
| 阶段 1 | `Attack` 与 `Defend` 交替，稳定教学。 |
| 阶段 2 | HP 低于 50% 后加入 `GridLockEdge`，每 3 回合锁 1 个边缘格，本战结束后解除。 |
| 反制方式 | 用消耗品修复、保留 AP 叠盾、在封边前整理关键物品。 |
| 奖励 | 必掉 `mat_core_tier1`，概率掉 `gear_iron_armor` 或 `trade_cracked_relic`。 |
| 安全区连接 | 击败后固定进入 SafeZone，免费全恢复并选择撤离 / 深入。 |
| 房间记忆 | 首次击败触发 `room_memory_first_gatekeeper_core`。 |
| 内容边界 | 不使用多怪召唤、不使用永久封格、不使用高污染扩散。 |

## 5. 第一层地图画像

### 5.1 `layer1_tutorial_branching`

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 第一层标准地图，保证安全路线和一次明确高收益诱惑。 |
| RowCount | 5 |
| Width | 2 / 3 |
| 路线 | `Safe`、`RiskReward` 至少各 1 条。 |
| 必出内容 | 2 个普通战斗、1 个宝箱或事件、1 个可绕精英、Boss、SafeZone。 |
| 约束 | 精英可绕；事件不连续；Boss 前至少一个非精英缓冲。 |
| Seed 样例 | `LayerID=layer_01`、`RunSeed=1024`、`MapProfileID=layer1_tutorial_branching`。 |
| 验收 | `V-MAP-SEED-01`、`V-MAP-ROUTE-01`、`V-SAFEZONE-01`。 |

目标摘要：

```text
Layer layer_01 / Seed 1024 / Profile layer1_tutorial_branching
Routes:
Safe: CombatMinor -> RestStop/EventLowRisk -> CombatMinor -> Boss -> SafeZone
RiskReward: CombatMinor -> CombatElite -> Treasure -> Boss -> SafeZone
Checks:
routeCount=PASS(2+)
eliteBypass=PASS
bossReachable=PASS
safeZoneAfterBoss=PASS
```

## 6. 第一层经济传闻

| RumorID | 展示名 | 目标 | 玩法职责 | 持续 |
|---|---|---|---|---|
| `rumor_filter_shortage` | 滤芯短缺 | `ItemTag:ToxicFilter` | 鼓励玩家挑战酸液软体或事件路线。 | 7 天 |
| `rumor_old_blades` | 旧刃回收价上涨 | `ItemTag:Weapon AND Layer:1` | 让玩家在出售武器和保留构筑之间取舍。 | 3 天 |

传闻边界：

* 第一层传闻只影响目标和售价，不引入复杂黑市背叛。
* 每条传闻都必须有第一层可获得来源。
* 传闻在备战期可见，出售账单中必须显示倍率来源。

## 7. 第一层事件内容

### 7.1 `event_miner_lost_pack` 失落矿工背包

| 字段 | 内容 |
|---|---|
| 触发节点 | `Event`，第一层探索路线。 |
| 玩家承诺 | 免费收益，但要面对背包空间不足。 |
| 选项 A | 打开背包，获得 `trade_miner_lamp` + `loot_gear_scrap`。 |
| 选项 B | 拿走镇静剂，获得 `con_cheap_sedative`，少量 SAN 恢复。 |
| 选项 C | 不碰，获得少量 SAN 稳定反馈。 |
| 系统连接 | 物品生命周期、经济传闻、房间矿工记忆。 |
| 验收 | 选项产物进入拾取窗口，不直接塞爆背包；放弃有明确反馈。 |

### 7.2 `event_cracked_relic_whisper` 裂纹圣牌低语

| 字段 | 内容 |
|---|---|
| 触发节点 | `Event` 或精英奖励后。 |
| 玩家承诺 | 高价值遗物和轻微不安。 |
| 选项 A | 拿走 `trade_cracked_relic`，获得高价值 2x2 风险物。 |
| 选项 B | 触碰但不带走，获得少量深渊 lore 和 SAN -2。 |
| 选项 C | 离开，无收益无损失。 |
| 系统连接 | 经济、SAN 提示、房间记忆、后续黑市。 |
| 验收 | 玩家拿走前能看到体积、风险标签和售价预估。 |

## 8. 第一层房间记忆

| RoomMemoryID | 触发 | 表现 | 设计职责 |
|---|---|---|---|
| `room_memory_first_defeat_layer1` | 第一层首次战败。 | 房间角落出现断裂齿轮或破损绷带，日记记录“第一次被带回”。 | 让失败留下情感痕迹。 |
| `room_memory_first_gatekeeper_core` | 首次击败一层 Boss 并撤离。 | 书桌或墙面出现守门机核碎片纪念物。 | 让 Boss 胜利进入长期记忆。 |
| `room_memory_miner_lamp_gift` | 带回 `trade_miner_lamp` 后选择展示。 | 展柜出现矿灯微光，夜间待机时房间更暖。 | 连接战利品、展示和房间视觉日记。 |

房间边界：

* 纪念物只记录经历，不锁定来源物品的普通出售。
* 查看房间不推进 Day。
* 第一层房间记忆不提供直接战斗力加成。

## 9. 第一层联合验收路径

### 9.1 `V-L1-PACK-RUN-01` 标准撤离

| 项 | 内容 |
|---|---|
| 前置状态 | 玩家携带锈蚀短匕、拼木盾和简易修复包，进入 `layer1_tutorial_branching`。 |
| 玩家行为 | 走安全路线，击败普通怪，拾取齿轮废料和锈红线圈，击败 Boss，在安全区撤离。 |
| 期望结果 | 背包布局保存；战利品进入地面库存；Boss 奖励带回；HP / SAN 在安全区免费全恢复；账单能出售战利品。 |
| 失败信号 | 路线单线、Boss 后无安全区、撤离后物品丢失或金币来源不明。 |

### 9.2 `V-L1-PACK-RUN-02` 贪精英取舍

| 项 | 内容 |
|---|---|
| 前置状态 | 地图出现可绕精英，玩家背包剩余 4 格。 |
| 玩家行为 | 选择精英路线，击败废铁守卫，获得裂纹圣牌或折刃战术刀。 |
| 期望结果 | 精英奖励明显优于普通路线，但体积造成取舍；玩家可选择丢弃低价物或在 Boss 后撤离。 |
| 失败信号 | 精英不可绕，奖励无明显价值，或高价值物无占格压力。 |

### 9.3 `V-L1-PACK-RUN-03` 轻度塞包教学

| 项 | 内容 |
|---|---|
| 前置状态 | 玩家遭遇酸液软体，背包有至少 1 个空格。 |
| 玩家行为 | 不抢杀酸液软体，等待其塞入酸液残渣。 |
| 期望结果 | 怪物意图提前预告；酸液残渣进入合法空格；战后可清理或带出；玩家理解背包也是战场。 |
| 失败信号 | 塞包无预告、覆盖已有物、战后状态不可解释。 |

### 9.4 `V-L1-PACK-FAIL-01` 首次战败记忆

| 项 | 内容 |
|---|---|
| 前置状态 | 玩家在第一层携带新获战利品，战斗失败。 |
| 玩家行为 | 接受战败结算并回到工坊。 |
| 期望结果 | 新获未绑定物丢失；局前绑定物保留但损坏；房间新增首次战败记忆；玩家可复盘主要伤害来源。 |
| 失败信号 | 战败无代价、全部无差别丢失、房间没有记录或失败原因不可读。 |

## 11. 内容包完成判定

`pack_layer1_formal_core` 达到正式内容包完成，需要同时满足：

1. 12 件物品、5 只普通 / 精英怪、1 个 Boss、2 个地图画像、3 条传闻、2 个事件、3 个房间记忆都能落到配置 README。
2. 玩家能完成第一层“备战 -> 地图路线 -> 战斗 -> 拾取 -> Boss -> 安全区 -> 撤离 -> 出售 / 房间记忆”的完整路径。
3. 精英可绕、Boss 后 SafeZone、免费全恢复、已获得战利品撤离回流、战败损失和房间记忆全部成立。
4. 至少通过 `V-L1-PACK-RUN-01`、`V-L1-PACK-RUN-02`、`V-L1-PACK-RUN-03`、`V-L1-PACK-FAIL-01` 四条验收。

这个内容包完成后，第一层就不再只是系统测试场，而是正式版核心循环的低压入口。
