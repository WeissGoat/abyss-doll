# 势力订单声望内容包

> **定位：** 本内容包把 `GDD_10` 和 `07_势力声望与订单规则卡` 落到第一批正式可配置内容。规则卡负责说明订单如何刷新、裁决、失败和背叛；本文负责说明首批势力、声望阶梯、订单池、订单模板、奖励和验收路径具体是什么。
>
> **开发口径：** 本文不是 MVP 临时订单表。进入正式纵切批次的势力 / 订单系统应按本文质量标准拆到 Factions、Orders、Rewards、Shops、Rumors、ScenarioEvents、Items 和 UI 表现规格。

---

## 1. 内容包总览

| 项 | 内容 |
|---|---|
| 覆盖系统 | 势力、声望、订单、黑市信任、订单奖励、委托物绑定、势力商店解锁。 |
| 主要事实来源 | `GDD_10`、`07_势力声望与订单规则卡`、`17_P2长期循环叙事承接清单`。 |
| 配置落点 | `Factions`、`Orders`、`Rewards`、`Shops`、`Items`、`Dungeons`、`Rumors`、`ScenarioEvents`。 |
| 首批规模 | 5 个势力、5 套声望 / 信任阶梯、5 个订单池、19 个订单模板、12 类奖励、7 条联合验收路径。 |
| 核心体验 | 玩家为了特定势力目标改变下潜路线，把背包空间让给委托物，并在声望收益、短期金币、黑市背叛和长期解锁之间做选择。 |

---

## 2. 玩家体验目标

| 目标 | 设计要求 |
|---|---|
| 下潜前有明确目的 | 每周刷新后至少有 1 个订单能把玩家指向特定层级、节点类型、物品标签或怪物目标。 |
| 背包压力可感知 | 至少 30% 的中高价值订单要求大型委托物、捕获容器、污染样本或绑定物品。 |
| 声望不是数值装饰 | 每个正规势力每级声望都应解锁商店、图纸、服务、情报、剧情旗标或订单池变化。 |
| 黑市有诱惑也有代价 | 黑市短期收益高于普通订单，但会触发正规势力背叛、怀疑、涨价或订单权重下降。 |
| 配置可验证 | 每个订单模板必须声明需求表达、期限、奖励引用、失败惩罚、可见条件、重复策略和验收路径。 |

## 3. 势力内容

### 3.1 `faction_adventurer_guild` 冒险者公会

| 项 | 内容 |
|---|---|
| 玩法定位 | 深渊路线与撤离安全的长期支持者。 |
| 偏好目标 | 地图拓本、环境报告、怪物图鉴、撤离信标校准数据。 |
| 核心奖励 | 地图预览、基础消耗品折扣、撤离信号、已通层入口情报。 |
| 风险画像 | 低到中风险，偏探索和路线规划；很少要求大型委托物。 |
| 叙事语气 | 务实、照顾新人、强调“活着回来”。 |

### 3.2 `faction_mechanic_workshop` 机械工坊

| 项 | 内容 |
|---|---|
| 玩法定位 | 底盘、义体、武器改造和大型工程订单的核心来源。 |
| 偏好目标 | 矿石、机械残骸、炉芯、齿轮、Boss 核心、稳定能源件。 |
| 核心奖励 | 底盘蓝图、义体图纸、武器改造、制造折扣。 |
| 风险画像 | 中到高风险，常要求重型或大尺寸委托物，直接挤压战斗背包。 |
| 叙事语气 | 冷淡、技术至上、认可交付质量而不是好听话。 |

### 3.3 `faction_mage_tower` 法师塔

| 项 | 内容 |
|---|---|
| 玩法定位 | 遗物、诅咒、心智催化和深渊真相的研究入口。 |
| 偏好目标 | 遗物、未鉴定物、诅咒物、活体样本、异常节点报告。 |
| 核心奖励 | 遗物鉴定、心智催化材料、共鸣底盘线索、净化服务折扣。 |
| 风险画像 | 中到高风险，偏污染、SAN 压力和活体捕获。 |
| 叙事语气 | 好奇、傲慢、重视异常价值。 |

### 3.4 `faction_alchemy_guild` 炼金公会

| 项 | 内容 |
|---|---|
| 玩法定位 | 消耗品、经济传闻、顾客出价和药剂供应链的控制者。 |
| 偏好目标 | 有机素材、毒液、孢子、净化样本、密封药材。 |
| 核心奖励 | 消耗品折扣、高级药剂、传闻提前量、营业加成。 |
| 风险画像 | 中风险，偏时间截止、污染保管和经济路线收益。 |
| 叙事语气 | 礼貌、精算、把玩家视为高风险供货商。 |

### 3.5 `faction_black_market` 黑市

| 项 | 内容 |
|---|---|
| 玩法定位 | 违禁品、背叛订单、高价收购和隐藏剧情入口。 |
| 偏好目标 | 诅咒物、高侵蚀物、正规势力委托物、违禁义体材料。 |
| 核心奖励 | 短期金币、黑市信任、违禁材料、走私入口、隐藏旗标。 |
| 风险画像 | 高风险，高收益，长期触发正规势力怀疑。 |
| 叙事语气 | 不问来源、不保证后果、只确认玩家是否愿意付代价。 |

## 4. 声望与信任阶梯

### 4.1 正规势力通用阶梯

| 等级 | 阈值 | 体验含义 | 订单池变化 | 解锁方向 |
|---|---:|---|---|---|
| Lv.0 陌生 | 0 | 只给基础试探单。 | 低风险采购、探索报告。 | 无或基础商品。 |
| Lv.1 认识 | 10 | 玩家被视为可靠供货者。 | 增加稳定采购和低阶目标物。 | 基础折扣、基础图纸、基础服务。 |
| Lv.2 熟人 | 30 | 允许接触势力内部需求。 | 增加指定节点、指定怪物、批量素材。 | 中阶商店、情报、服务升级。 |
| Lv.3 伙伴 | 70 | 进入势力专属资源线。 | 增加大型委托物、活体捕获、专属链式订单。 | 底盘 / 义体 / 心智 / 经营关键解锁。 |
| Lv.4 核心 | 140 | 势力愿意承担玩家带来的风险。 | 高价值稀有订单、冲突订单、Boss 目标。 | 高阶服务、终局线索、稀有图纸。 |
| Lv.5 盟友 | 250 | 一局中少数势力才能达到。 | 终局倾向订单、唯一奖励订单。 | 势力结局倾向、终极蓝图或隐藏路线。 |

### 4.2 黑市信任阶梯

| 信任 | 解锁内容 | 长期代价 |
|---:|---|---|
| 0 | 只高价收购违禁品。 | 无明显风险。 |
| 3 | 出售低阶违禁义体材料。 | 黑市交易日志开始影响剧情旗标。 |
| 7 | 接受正规势力委托物背叛。 | 原势力订单转 `Betrayed`，可触发怀疑。 |
| 12 | 解锁深渊走私入口。 | 正规势力订单高价值权重下降。 |
| 15 | 解锁面具商人身份线索。 | 进入隐藏剧情，同时提高正规势力冲突事件权重。 |

### 4.3 势力专属解锁摘要

| 势力 | Lv.1 | Lv.2 | Lv.3 | Lv.4 | Lv.5 |
|---|---|---|---|---|---|
| 冒险者公会 | 基础消耗品折扣 | 地图节点预览 +1 | 已通层入口情报 | 紧急撤离信号 | 深层入口线索 |
| 机械工坊 | 基础义体图纸 | 武器改造 | 超载供能底盘 | 紫色义体图纸 | 重装堡垒底盘 |
| 法师塔 | 遗物鉴定 | 遗物转化 | 共鸣回路底盘线索 | 侵蚀净化折扣 | 隐藏心智分支 |
| 炼金公会 | 药剂商店扩容 | 进货价折扣 | 高级消耗品 | 提前传闻 | 顾客出价加成 |

## 5. 订单池

### 5.1 `pool_guild_exploration`

| 字段 | 建议值 |
|---|---|
| 势力 | 冒险者公会 |
| 每周槽位 | 2 |
| 刷新条件 | 解锁公会后常驻；新层首次到达后提高对应层报告权重。 |
| 订单类型 | `ExplorationReport`、`Procurement`、`TargetItem`。 |
| 风险限制 | Lv.0-Lv.1 不生成精英强制路线；至少 1 单可在已达层完成。 |

### 5.2 `pool_workshop_engineering`

| 字段 | 建议值 |
|---|---|
| 势力 | 机械工坊 |
| 每周槽位 | 2 |
| 刷新条件 | 完成首次矿石交付或解锁第二层后出现。 |
| 订单类型 | `Procurement`、`TargetItem`、大型 `LargeCargo`。 |
| 风险限制 | 每周最多 1 个大型委托物订单，除非玩家 Lv.3 以上主动刷新。 |

### 5.3 `pool_mage_relic`

| 字段 | 建议值 |
|---|---|
| 势力 | 法师塔 |
| 每周槽位 | 1-2 |
| 刷新条件 | 首次获得遗物、异常传闻或第二层污染节点后出现。 |
| 订单类型 | `Procurement`、`LiveCapture`、`ExplorationReport`、`TargetItem`。 |
| 风险限制 | Lv.0 不生成活体捕获；高污染订单必须显示 SAN 风险。 |

### 5.4 `pool_alchemy_purification`

| 字段 | 建议值 |
|---|---|
| 势力 | 炼金公会 |
| 每周槽位 | 2 |
| 刷新条件 | 小镇营业系统解锁后常驻。 |
| 订单类型 | `Procurement`、`TargetItem`、限时高价订单。 |
| 风险限制 | 限时订单金币高，但截止短；污染保管需触发隔夜风险。 |

### 5.5 `pool_black_market_betrayal`

| 字段 | 建议值 |
|---|---|
| 势力 | 黑市 |
| 每周槽位 | 0-1，按信任和夜晚事件出现。 |
| 刷新条件 | 黑市信任 >= 3 后出现普通违禁单；信任 >= 7 后出现背叛单。 |
| 订单类型 | `BlackMarketBetrayal`、`Procurement`、违禁 `TargetItem`。 |
| 风险限制 | 背叛单必须二次确认，并展示原势力惩罚。 |

| `reward_mage_mind_catalyst` | 材料 | 心智天赋催化材料。 | 活体样本订单。 |
| `reward_alchemy_potion_discount` | 商店 | 药剂折扣与高级药剂入口。 | 炼金供货订单。 |
| `reward_alchemy_price_forecast` | 情报 | 下周传闻提前显示。 | 市场预测订单。 |
| `reward_black_forbidden_material` | 材料 | 违禁义体材料。 | 黑市收购 / 背叛订单。 |
| `reward_black_smuggled_route_flag` | 旗标 | 走私入口可见。 | 走私钥匙订单。 |

奖励价值约束：

*   普通采购订单总价值为卖店价值的 1.2 到 1.8 倍。
*   大型委托物、活体捕获、污染样本可到 2.0 到 3.0 倍。
*   黑市背叛短期金币可高于 3.0 倍，但必须附带声望惩罚、怀疑旗标或订单权重下降。
*   图纸 / 服务 / 情报奖励应减少金币部分，避免同时给过高现金和长期解锁。

## 8. 失败、放弃与背叛

| 情况 | 裁决 | 玩家可见反馈 |
|---|---|---|
| 超期 | 订单转 `Expired`，按配置扣少量声望或本周槽位冷却。 | 订单面板显示失效原因和势力态度变化。 |
| 主动放弃 | 订单转 `Abandoned`，默认不扣声望，但本周不补新槽。 | 显示“放弃不扣声望，但本周不会刷新替代订单”。 |
| 委托物丢失 | 按订单 `FailurePenalty` 决定超期、失败、赔偿或转普通战利品。 | 背包日志显示绑定物丢失来源。 |
| 黑市背叛 | 原正规订单转 `Betrayed`，黑市订单完成。 | 二次确认明确原势力惩罚、黑市收益和不可挽回。 |
| 正规势力怀疑 | 黑市信任或背叛次数过高时触发。 | 正规势力面板显示价格上浮、订单减少或对话冷淡。 |

硬保护边界：

*   普通高价值物品不需要出售保护，玩家可以自己处理。
*   订单绑定物、剧情锁定物、情感锚点物是硬保护对象，不能普通出售。
*   黑市背叛不是普通出售，是明确订单行为；必须有二次确认和日志。

## 9. 配置拆分建议

| 配置表 | 必要字段 |
|---|---|
| `Factions` | `FactionID`、显示名、标签、声望 / 信任阶梯、订单池、商店解锁表、冲突规则、刷新策略。 |
| `Orders` | `OrderID`、势力、类型、需求表达、期限、奖励、声望 / 信任变化、失败惩罚、可见条件、重复策略、权重、标签。 |
| `Rewards` | 金币、物品、图纸、服务、商店、情报、旗标、长期解锁。 |
| `Shops` | 势力商店、声望等级要求、商品解锁条件、价格倍率。 |
| `Items` | 委托物 ID、形状、旋转、标签、绑定规则、污染状态、出售限制。 |
| `Dungeons` | 订单目标节点类型、层级限制、路线主题权重、Boss / 精英目标引用。 |
| `ScenarioEvents` | 声望升级、背叛、怀疑、黑市身份、势力冲突事件。 |

配置作者写订单时必须能回答：

1. 这个订单为什么会改变玩家本次下潜路线？
2. 这个订单占用了什么资源：时间、背包空间、SAN、战斗风险、经济机会，还是声望机会？
3. 玩家完成后得到的是短期金币、长期成长、情报、剧情旗标，还是势力关系？
4. 失败、放弃、背叛和超期分别如何裁决？
5. UI 上玩家是否能在接取前读懂目标、期限、风险、奖励和惩罚？

## 10. 联合验收路径

### B-01：每周订单刷新可复现

输入：

```text
RunSeed=240524
CurrentWeek=4
ReachedLayer=2
FactionID=faction_mechanic_workshop
ReputationRank=2
VisibleSlots=2
```

期望：

*   连续刷新结果一致。
*   不出现要求第 4 层素材的订单。
*   两个槽位不重复。
*   至少一个订单可在第 1 到第 2 层完成。
*   大型委托物订单最多出现 1 个。

### B-02：订单驱动路线选择

流程：

1. 接取 `order_guild_layer2_route_report`。
2. 通过已通层入口直接从第二层出发。
3. 在地图上选择 3 个非 Boss 节点并撤离。

期望：

*   不需要重打一遍第一层。
*   地图 UI 标记订单相关节点。
*   撤离后订单可完成，奖励和声望正常发放。

### B-03：大型委托物背包压力

流程：

1. 接取 `order_workshop_furnace_core_large`。
2. 在第二层获得 3x3 `large_furnace_core`。
3. 玩家必须旋转 / 调整背包布局才能带走。
4. 带着委托物击败或绕过后续节点并撤离。

期望：

*   委托物带 `OrderBound` 标签。
*   可以移动和旋转，但不能普通出售或制造消耗。
*   完成后发放底盘蓝图并移除委托物。

### B-04：活体捕获与 SAN 风险

流程：

1. 接取 `order_mage_live_slime_sample`。
2. 接取时获得 2x2 捕获容器。
3. 战斗中捕获目标并撤离。

期望：

*   捕获容器全程占格。
*   捕获后实例状态从空容器变成活体样本。
*   UI 显示 SAN 风险与交付收益。

### B-05：黑市背叛

流程：

1. 接取机械工坊 Boss 核心订单。
2. 获得绑定 Boss 核心。
3. 黑市刷新 `order_black_bound_core_betrayal`。
4. 玩家二次确认后把核心交给黑市。

期望：

*   机械工坊订单转 `Betrayed`。
*   机械工坊声望下降或进入怀疑 / 冷却。
*   黑市信任增加并发放高额奖励。
*   背叛后不能再补交同一核心挽回原订单。

### B-06：声望等级解锁

流程：

1. 连续完成机械工坊订单，使声望跨过 Lv.3。
2. 打开机械工坊商店和图纸列表。

期望：

*   声望等级刷新为 Lv.3。
*   对应订单池增加大型工程订单。
*   `blueprint_chassis_overload_frame` 或同等级图纸可见。
*   若解锁来自特定订单，未完成该订单时只显示条件，不提前开放。

### B-07：正规势力怀疑与恢复

流程：

1. 玩家多次完成黑市订单，使信任 >= 10。
2. 打开正规势力订单面板。
3. 完成 1-2 个正规高难度订单。

期望：

*   正规势力高价值订单权重下降或价格上浮。
*   对话 / UI 显示怀疑状态。
*   完成正规高难度订单后，怀疑状态逐步降低。

## 11. 内容边界

| 范围内 | 范围外 |
|---|---|
| 首批 5 个势力的订单池、声望 / 信任阶梯、订单模板、奖励方向和验收路径。 | 全量正式版所有中后期订单、所有结局势力线文本、所有 NPC 对话。 |
| 订单如何占用背包、改变路线、触发经济和成长解锁。 | 具体 UI 版式、美术资源尺寸、运行时代码结构。 |
| 黑市背叛、正规势力怀疑和委托物绑定的内容口径。 | 复杂外交系统、阵营战争、可加入势力职业线。 |

后续扩展订单时应沿用本内容包结构：先定义势力体验职责，再定义订单池，再写订单模板，最后给出奖励、失败惩罚和联合验收路径。
