# 第二层背包压力内容包

> **定位：** 本内容包把第二层“腐蚀甬道”的正式背包压力体验交到内容粒度。第二层不是第一层的数值升级版，而是第一次让玩家稳定感到：背包空间会被敌人干涉、路线会因订单目标改变、直达已通层会改变备战策略，安全区免费恢复只能解决 HP / SAN，不能抹除满包、污染、订单期限和继续深入风险。

---

## 1. 内容包总览

| 项 | 内容 |
|---|---|
| `PackID` | `pack_layer2_bag_pressure` |
| `PackName` | 第二层背包压力内容包 |
| 目标层级 | `layer_02` 腐蚀甬道 |
| 前置条件 | 玩家已击败第一层 Boss 并解锁第二层直达；也可从第一层安全区继续深入进入。 |
| 目标体验 | 让玩家理解“第二层开始，背包不是静态收纳空间，而是会被污染、封锁、塞入杂物和订单目标挤压的战场”。 |
| 覆盖系统 | `Items`、`Monsters`、`Dungeons`、`Orders`、`Rewards`、经济传闻、ScenarioEvents。 |
| 主要验收 | `V-P0-RUN-02`、`V-MAP-DIRECT-01`、`V-COMBAT-BAG-01`、`V-COMBAT-BAG-02`、`V-ORDER-BOUND-01`、`V-SAFEZONE-01`。 |

第二层的内容复杂度应明显高于第一层，但仍要保持可读：每种压力都必须有预告、反制或撤离选择。玩家失败时应认为“我贪了、没留空间、没处理腐蚀或硬接了精英”，而不是觉得系统突然偷袭。

---

## 2. 第二层体验目标

| 体验目标 | 内容承担方式 |
|---|---|
| 已通层直达成立 | 从小镇选择第二层时直接生成第二层地图，不要求重打一层。 |
| 背包压力稳定出现 | 至少一个普通遭遇或事件使用塞包、封格、污染或腐蚀。 |
| 精英更诱人也更危险 | 至少两个精英模板，一个偏封格，一个偏塞包 / 蓄力，且地图上至少一个可绕。 |
| 订单开始改变路线 | 第二层出现可完成订单，目标物占格或要求特定路线 / 节点。 |
| 安全区继续深入更有张力 | Boss 后免费全恢复，但污染物、委托物、满包和订单期限仍促使玩家权衡撤离。 |
| 奖励连接成长 | 第二层产出一批中阶材料、义体图纸碎片和更大体积战利品，为后续局外成长提供目标。 |

### 3.2 核心物品职责说明

#### `con_solvent_spray` 溶剂喷雾

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 一个小而关键的反制道具，可以处理第二层最烦人的临时占格。 |
| 玩法职责 | 给塞包 / 封格压力提供清晰反制，不让第二层变成纯惩罚。 |
| 空间承诺 | 1x2，占格不小，带不带它本身就是备战取舍。 |
| 战斗承诺 | 清除 1 个酸液残渣、临时封锁格或低级污染格。 |
| 经济承诺 | 出售价值低，主要价值在战斗安全。 |
| 验收路径 | `V-L2-PACK-RUN-03`：怪物封格后使用溶剂喷雾，格子恢复并有反馈。 |
| 内容边界 | 不能清除永久创伤、订单绑定、Boss 特殊机制或高阶污染。 |

#### `order_live_spore_cage` 活孢子笼

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 接订单就要背着一个大笼子下去，收益高但背包从出发时就变窄。 |
| 玩法职责 | 让玩家理解订单不是额外奖励按钮，而是背包、路线和战斗共同压力。 |
| 空间承诺 | 2x3，可旋转；必须在局前预留空间或接取后检查空间。 |
| 绑定承诺 | 带 `OrderBound:{OrderInstanceID}`；不可普通出售、不可制造消耗。 |
| 战败承诺 | 默认 `DamageAndKeepProgress`：战败后笼子损坏，订单进度回退或失败，按订单定义裁决。 |
| 背叛承诺 | 黑市可提出收购，但需要二次确认并使原订单 `Betrayed`。 |
| 验收路径 | `V-ORDER-BOUND-01`、`V-L2-PACK-ORDER-01`。 |

#### `trade_sealed_relic_box` 封存遗物匣

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 巨大、高价、危险的遗物箱，最适合制造“现在该撤了”的冲动。 |
| 玩法职责 | 用 2x3 大件压缩战斗空间，把第二层安全区选择推向高张力。 |
| 风险承诺 | 带 `AbyssRelic`、`ContrabandLow`、`SanUneaseMid`。普通出售价值高，黑市更高。 |
| 经济承诺 | 受 `rumor_relic_box_buyer` 影响；也可触发黑市背叛事件。 |
| 生命周期 | 撤离后进入库存；放房间展示只记录快照，不阻止出售。 |
| 验收路径 | 玩家在 Boss 后背包满载且携带遗物匣时，安全区撤离 / 深入选择具有真实压力。 |

### 4.2 第二层普通怪职责

#### `mob_crystal_guard` 结晶守卫

| 字段 | 内容 |
|---|---|
| 教学目标 | 让玩家第一次稳定面对“格子被封锁”的预告和处理。 |
| 意图规律 | 防御 -> 封 1 个边缘格 -> 攻击，循环。 |
| 反制方式 | 在封格前击杀；保留关键物品不贴边；使用溶剂喷雾解除低级封锁。 |
| 失败教训 | 把所有关键物品挤在边缘会让战斗空间变脆弱。 |
| 掉落逻辑 | 掉落晶化鳞片，用于第二层成长材料。 |
| 内容边界 | 普通结晶守卫只封临时边缘格，不移动或摧毁物品。 |

#### `mob_rust_cultivator` 锈蚀培植者

| 字段 | 内容 |
|---|---|
| 教学目标 | 引入低强度物品腐蚀，使玩家理解“带出后也要维护”。 |
| 意图规律 | 攻击 -> 腐蚀最低耐久或随机非绑定物 -> 攻击。 |
| 反制方式 | 抢杀、使用护盾降低触发权重、携带不怕腐蚀的低价值物承担风险。 |
| 失败教训 | 背包里全是高价值物时，腐蚀怪会让撤离收益变得不稳定。 |
| 掉落逻辑 | 掉落扭曲装甲片或酸腺囊，强化“腐蚀 -> 材料”的主题。 |
| 内容边界 | 第二层腐蚀只增加实例标签或耐久损伤，不销毁物品。 |

### 4.3 精英职责

#### `elite_crystal_bulwark` 晶壁守卫

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 这只精英很硬，会让背包边缘越来越难用，但奖励能支撑防御构筑。 |
| 意图规律 | 首回合护盾，第二回合封 2 个边缘格，第三回合重击，之后循环。 |
| 反制方式 | 爆发打断循环；携带溶剂喷雾；选择地图上绕开。 |
| 奖励 | 高概率掉 `gear_corroded_bulwark` 或 `mat_core_tier2_fragment`。 |
| 失败教训 | 没有爆发或清格手段时，不该硬贪封格精英。 |
| 地图职责 | 在 `layer2_bag_pressure` 中至少 1 个精英可绕开。 |

#### `elite_mutant_amalgam` 畸变融合体

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 高收益但持续往包里塞杂物，考验玩家是否预留空格。 |
| 意图规律 | 蓄力 -> 塞入 1x1 肉块残渣 -> 重击；低 HP 后加速。 |
| 反制方式 | 蓄力期抢杀；预留空格；用溶剂喷雾清残渣；不走该路线。 |
| 奖励 | 掉 `trade_sealed_relic_box`、二阶碎片或高价值贸易品。 |
| 失败教训 | 背包满载去打塞包精英，本质是在赌战败。 |
| 内容边界 | 塞入物默认战后可清，不直接永久污染背包。 |

### 4.4 Boss：`boss_spore_foundry` 孢殖熔炉

| 字段 | 内容 |
|---|---|
| 玩家承诺 | 第二层毕业战，确认玩家已经理解塞包、封格、腐蚀和消耗品反制。 |
| 阶段 1 | 攻击、轻塞包、护盾轮换。 |
| 阶段 2 | HP 低于 60% 后加入 `PolluteCellLow` 和小孢子召唤。 |
| 阶段 3 | HP 低于 25% 后预告一次重击，并塞入 1 个 2 格孢子囊；之后进入疲惫回合。 |
| 反制方式 | 清理孢子囊、保留空格、抢杀小孢子、使用稳定安瓿或溶剂喷雾。 |
| 奖励 | 必掉 `mat_core_tier2_fragment`，概率掉 `trade_sealed_relic_box`、`gear_charge_pistol`。 |
| 安全区连接 | 击败后进入 SafeZone，免费全恢复，但污染物、订单物和满包压力仍保留。 |
| 内容边界 | 第二层 Boss 不做永久封格；永久创伤留给更深层或战败特质。 |

```text
bagPressureEncounter=PASS(1+)
eliteBypass=PASS

safeZoneAfterBoss=PASS
directStart=PASS
```

## 9. 第二层联合验收路径

### 9.1 `V-L2-PACK-DIRECT-01` 已通层直达

| 项 | 内容 |
|---|---|
| 前置状态 | 玩家已击败第一层 Boss，第二层已解锁。 |
| 玩家行为 | 从小镇选择第二层出发。 |
| 期望结果 | 直接生成 `layer_02` 地图；不重复打一层；地图显示第二层风险和推荐准备。 |
| 失败信号 | 必须重打一层、解锁状态丢失、第二层地图仍使用第一层内容池。 |

### 9.2 `V-L2-PACK-RUN-01` 标准背包压力路线

| 项 | 内容 |
|---|---|
| 前置状态 | 玩家携带基础武器、防具、溶剂喷雾进入 `layer2_bag_pressure`。 |
| 玩家行为 | 走普通路线，遇到成熟酸液软体和结晶守卫，击败 Boss 后进入安全区。 |
| 期望结果 | 玩家至少经历一次塞包或封格预告；可用溶剂喷雾反制；Boss 后免费全恢复但背包和污染压力保留。 |
| 失败信号 | 第二层没有对包干涉、反制道具不生效、Boss 后安全区清空账本。 |

### 9.3 `V-L2-PACK-ORDER-01` 活孢子笼订单

| 项 | 内容 |
|---|---|
| 前置状态 | 玩家接取 `order_spore_cage_procurement`，背包必须预留 2x3 空间。 |
| 玩家行为 | 进入第二层订单画像，捕获活孢子样本并尝试撤离。 |
| 期望结果 | 委托物占格、可旋转、不可普通出售；订单进度可见；撤离后可交付。 |
| 失败信号 | 委托物不占格、普通出售成功、空间不足时吞订单或无法解释失败。 |

### 9.4 `V-L2-PACK-ELITE-01` 精英可绕与高收益

| 项 | 内容 |
|---|---|
| 前置状态 | 地图有 `elite_crystal_bulwark` 和非精英路线。 |
| 玩家行为 | 选择挑战或绕开精英。 |
| 期望结果 | 挑战精英获得明显更高价值奖励和封格压力；绕开路线收益低但安全。 |
| 失败信号 | 精英强制必打、奖励不值得、封格无预告或无法反制。 |

### 9.5 `V-L2-PACK-BOSS-01` 孢殖熔炉安全区决策

| 项 | 内容 |
|---|---|
| 前置状态 | 玩家击败 `boss_spore_foundry`，背包携带二阶碎片、风险物或委托物。 |
| 玩家行为 | 进入安全区，选择撤离或继续深入。 |
| 期望结果 | HP / SAN 免费全恢复；探索账本、背包、委托物和污染状态保留；玩家能理解继续深入风险。 |
| 失败信号 | 安全区收费、物品丢失、污染被免费清除、订单状态重置。 |

### 9.6 `V-L2-PACK-BETRAY-01` 黑市遗物匣诱惑

| 项 | 内容 |
|---|---|
| 前置状态 | 玩家携带 `trade_sealed_relic_box`，黑市订单可见。 |
| 玩家行为 | 查看黑市收购条件。 |
| 期望结果 | UI 明确显示高金币、黑市信任、公开势力怀疑或背叛风险；提交需二次确认。 |
| 失败信号 | 自动背叛、风险不可见、提交后原订单仍可完成。 |

## 11. 内容包完成判定

`pack_layer2_bag_pressure` 达到正式内容包完成，需要同时满足：

1. 12 件物品、4 只普通怪、2 个精英、1 个 Boss、2 个地图画像、3 个订单、3 个事件、3 条传闻和 3 个房间记忆都能落到配置 README。
2. 玩家能直接从已解锁第二层出发，不重复打一层。
3. 第二层至少稳定出现一种对包干涉，并且玩家有溶剂喷雾、抢杀、预留空格、绕路或撤离等反制选择。
4. 至少一个精英可绕，挑战精英时奖励和风险都明显可读。
5. 订单能改变路线和背包取舍，委托物占格、绑定、失败和背叛规则成立。
6. Boss 后安全区仍免费全恢复，但不清空探索账本、背包、污染、订单和携带压力。
7. 至少通过 `V-L2-PACK-DIRECT-01`、`V-L2-PACK-RUN-01`、`V-L2-PACK-ORDER-01`、`V-L2-PACK-ELITE-01`、`V-L2-PACK-BOSS-01` 五条验收。

这个内容包完成后，第二层就能正式承担“背包压力和长期目标开始成形”的设计职责。
