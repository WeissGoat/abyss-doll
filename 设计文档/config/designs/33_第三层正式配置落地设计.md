# 第三层正式配置落地设计

> **定位：** 本文是 `26_正式配置设计与填充推进计划.md` 中 W2「前三层正式配置补齐」的第三份落地产物。它只负责第三层 `Items` / `Rewards` / `Monsters` / `Dungeons` / `Orders` / 事件与记忆钩子的配置落地设计，把 `25` 内容包和 `27-30` 审计结论转成后续改 JSON 前的策划清单。本文不直接修改 JSON，不替代配置 README，也不表示配置已经完成。

---

## 1. 落地目标

第三层配置落地的目标是让“菌脉深庭”成为前三层纵切的中期门槛：玩家不再只是处理空间压力，而是要处理路线侵蚀、污染物品生命周期和势力订单互斥。

```text
已通层直达 -> 接取互斥订单 / 准备净化与锚定物
  -> 第三层路线选择
  -> 路线侵蚀 / 污染 / 订单目标节点
  -> 精英高收益与污染代价
  -> Boss 按路线侵蚀变量强化
  -> 免费恢复 HP / SAN 的安全区
  -> 撤离 / 深入 / 回城处理污染、订单和势力结果
```

本轮第三层配置设计必须满足：

| 目标 | 完成口径 |
|---|---|
| 直达闭环 | 已解锁第三层后，小镇出发直接生成第三层地图，不重复生成第一层或第二层。 |
| 物品闭环 | 12 件第三层物品都有明确 `ConfigID`、形状、职责、来源、去向和污染 / 订单字段。 |
| 路线侵蚀闭环 | `RouteCorrosion` 是本次下潜变量，可由地图事件或路线累积，并影响 Boss 入场；撤离或本层结束后清除。 |
| 污染生命周期闭环 | 至少 2 类物品带污染或低语风险，撤离后仍有处理入口和可复盘来源。 |
| 订单互斥闭环 | 至少 3 个势力围绕同一核心样本互斥，黑市买断能触发背叛 / 怀疑。 |
| 怪物闭环 | 5 个普通怪、2 个精英、1 个 Boss 有独立职责、意图、奖励和反制方式。 |
| 地图闭环 | 2 个 MapProfile、至少 3 条路线倾向、1 个订单目标节点、1 个可绕精英、Boss 后 SafeZone。 |
| 奖励闭环 | 普通怪、精英、Boss、宝箱、事件、订单奖励职责拆开，Boss 保底三阶成长材料。 |
| 验收闭环 | 至少能支撑 `V-L3-DIRECT-3072-ROUTE-01`、`V-L3-ATTRITION-01`、`V-L3-CORRUPT-ITEM-01`、`V-L3-ORDER-CONFLICT-01`、`V-L3-BOSS-REWARD-01`。 |

---

## 2. 本轮不处理范围

| 范围外 | 原因 |
|---|---|
| 第四层及以后副本内容 | 当前仍以前三层纵切闭合为主，第四层以后属于后续内容生产批次。 |
| 完整黑市势力线 | 第三层只做黑市买断和背叛样例，不完成完整黑市剧情线。 |
| 永久污染和不可逆毁物 | 第三层可投放中级污染和隔夜代价，但不直接销毁玩家核心物品。 |
| 完整房间经营 | 第三层只提供房间记忆钩子，不实现房间经营系统。 |
| 实际 JSON 改值 | 后续单独进入配置实现批次时处理。 |

---

## 3. 第三层配置落地顺序

建议按以下顺序改配置，避免引用断裂：

1. `Items`：先补第三层物品 ID、污染生命周期、订单互斥物、反制消耗品和去向。
2. `Rewards`：补普通怪、精英、Boss、宝箱、事件和订单奖励表，保证物品有来源。
3. `Monsters`：补第三层普通怪、精英和 Boss，把 `RewardID` 指到奖励表。
4. `Dungeons`：补第三层直达、MapProfile、路线侵蚀字段、订单目标节点、BossNode、SafeZone 和固定 seed 样例。
5. `Orders`：补争夺孢核相关订单互斥、黑市买断、声望 / 信任奖励和失败裁决。
6. `Events / Rumors / RoomMemory`：补路线侵蚀事件、污染物处理提示、经济传闻和房间记忆钩子。
7. Validator / 验收样例：最后把第三层固定路径、路线侵蚀、污染物和订单互斥纳入机械检查。

### 6.2 第三层意图边界

| IntentType | 第三层允许程度 | 说明 |
|---|---|---|
| `Attack` | 常规 | 基础伤害继续存在。 |
| `Defend` / `Guard` | 常规 | 壳层嫁接者、菌脉骑士使用。 |
| `ChargeShot` | 常规 | 孢刺射手给玩家反制窗口。 |
| `SanPressure` | 中低级 | 神经虫群、回声朝圣者和 Boss 使用。 |
| `MarkWeakSlot` | 常规 | 标记本战弱点，不永久改变物品。 |
| `PolluteItem` | 中级 | 可附着到物品实例，撤离后保留处理入口。 |
| `PolluteCell` | 中级 | 战内格子污染，战后可按规则降级或转为物品污染。 |
| `RouteCorrosion` | 仅地图 / Boss 变量 | 怪物可读取该变量增强行为，但普通怪不直接永久增加它。 |
| 直接销毁物品 | 不投放 | 第三层仍以污染、维护和选择成本为主。 |

### 6.3 Boss 行为模板

`boss_mycelium_oracle` 建议用三阶段，并读取本次下潜 `RouteCorrosion`：

| 阶段 | 条件 | 行为 |
|---|---|---|
| Phase 1 | HP > 65% | `Attack`、`SanPressureMid`、`PolluteItemLow` 轮换。 |
| Phase 2 | HP <= 65% | 按 `RouteCorrosion` 层数强化污染或召唤小孢子；层数越高，污染优先级越高。 |
| Phase 3 | HP <= 30% | 预告“菌脉合唱”，对被标记物品施加中级污染并重击；之后疲惫 1 回合。 |

Boss 结算：

| 项 | 口径 |
|---|---|
| `RouteCorrosion` | 本次下潜变量；撤离或本层结束后清除。 |
| 物品污染 | 不因 Boss 后 SafeZone 自动清除。 |
| Boss 奖励 | 保底 `mat_core_tier3_seed`。 |
| Boss 后 SafeZone | HP / SAN 免费全恢复；保留背包、订单物、污染物和探索账本。 |

| `Boss` | `CombatNode` | `boss_mycelium_oracle` | 固定 Boss 行。 |

## 10. 第三层验收样例

### 10.1 `V-L3-CONFIG-COVERAGE-01`

| 项 | 内容 |
|---|---|
| 输入 | 扫描第三层配置目标清单。 |
| 期望 | 12 个 Item、8 个 Monster、2 个 MapProfile、14 个 RewardID、4 个 OrderID、3 个 EventID 都有配置或明确替代 ID。 |
| 失败 | 任一关键 ID 既不存在，也没有替代 ID 或后续批次标记。 |

### 10.2 `V-L3-DIRECT-3072-ROUTE-01`

| 项 | 内容 |
|---|---|
| 输入 | `HighestUnlockedDungeonLayer=3`，从小镇选择 `LayerID=3`，`MapProfileID=layer3_route_attrition`，`RunSeed=3072`。 |
| 期望 | 直接生成第三层地图；至少 3 条有效路线；至少 1 个路线侵蚀或污染遭遇；精英可绕；Boss 后 SafeZone 存在。 |
| 失败 | 重打一层或二层、第三层引用第二层怪物池、单线、精英必经、Boss 后没有撤离 / 深入选择。 |

### 10.3 `V-L3-ATTRITION-01`

| 项 | 内容 |
|---|---|
| 输入 | 玩家选择 `Attrition` 路线并接受 `event_mycelium_toll_gate` 的菌脉通行。 |
| 期望 | 获得 1 层本次下潜 `RouteCorrosion`；地图和 Boss 预告显示其影响；撤离或本层结束后该变量清除。 |
| 失败 | 侵蚀暗中生效、无法复盘来源、变成永久状态、或安全区错误清除物品污染。 |

### 10.4 `V-L3-CORRUPT-ITEM-01`

| 项 | 内容 |
|---|---|
| 输入 | 玩家撤离后保留 `loot_living_mycelium` 或被污染物品到次日。 |
| 期望 | 局外库存、账单或房间提示显示污染来源、隔夜风险和处理入口；可选择出售、净化、交付或承担成本。 |
| 失败 | 污染只在战斗中存在、撤离后无提示、隔夜暗扣资源或无法处理。 |

### 10.5 `V-L3-ORDER-CONFLICT-01`

| 项 | 内容 |
|---|---|
| 输入 | 玩家同时看到工坊、法师塔和黑市围绕 `order_contested_spore_core` 的订单。 |

| 失败 | 同一核心多次交付、背叛自动发生、声望变化不可见或订单失败原因不明。 |

### 10.6 `V-L3-BOSS-REWARD-01`

| 项 | 内容 |
|---|---|
| 输入 | 以 0-3 层 `RouteCorrosion` 击败 `boss_mycelium_oracle`。 |
| 期望 | Boss 根据路线侵蚀层数增强污染或召唤；击败后保底获得 `mat_core_tier3_seed`；Boss 后安全区免费恢复 HP / SAN，但保留物品污染、订单物和背包压力。 |
| 失败 | Boss 与路线选择无关、安全区错误净化所有污染、三阶成长材料无来源。 |

## 12. 后续落地顺序

后续真正进入配置实现时，建议拆成 6 个小任务：

1. `L3-ITEMS`：补第三层 12 件物品的字段、形状、污染生命周期、订单互斥和新增 ID。
2. `L3-REWARDS`：补第三层普通怪、精英、Boss、宝箱、事件、订单奖励表。
3. `L3-MONSTERS`：补第三层 8 个怪物 / Boss，接入污染、SAN、弱点标记和 Boss 阶段。
4. `L3-DUNGEONS`：补第三层 2 个 MapProfile、直达规则、路线侵蚀字段、节点池和固定 seed 验收。
5. `L3-ORDERS`：补第三层 4 个订单的目标、互斥、截止、失败、背叛和奖励引用。
6. `L3-EVENTS-RUMORS-MEMORY`：补第三层 3 个事件、3 条传闻和 4 个房间记忆钩子。

完成后，W2「前三层正式配置补齐」在策划设计层达到闭合：第一层低压入门、第二层背包压力、第三层路线侵蚀 / 订单冲突都已有 JSON 修改前策划清单。下一步应进入配置实现任务拆分、Validator 样例补强，或转入 W3「局外成长与经济目标补齐」。
