# 经济压力势力正式配置落地设计

> 本文承接 `46_经济压力正式配置承接审计.md` 的 `ECON-FACTIONS`。它把 `24_势力订单声望内容包.md` 的 5 个势力、正规声望阶梯和黑市信任阶梯转成 JSON 修改前字段级清单。本文不直接修改 `配置表(JSON)`，不代表势力配置已经完成。

---

## 1. 当前事实

当前 `配置表(JSON)/Factions/` 只有一个可运行样例：

| 当前 FactionID | 当前作用 | 正式判断 |
|---|---|---|
| `faction_mechanic_workshop` | 单个机械工坊势力，1 个可见订单槽，2 个最大激活订单，2 阶声望样例。 | 可作为机械工坊迁移原型，但字段、声望阶梯、订单池、解锁、黑市冲突和 UI 提示都不足。 |

当前缺口：

1. 缺 `faction_adventurer_guild`、`faction_mage_tower`、`faction_alchemy_guild`、`faction_black_market`。
2. 正规势力只有 2 阶样例，不能承接 `24` 的 Lv.0-Lv.5 解锁节奏。
3. 黑市没有独立信任阶梯，无法承接背叛订单、走私入口和正规势力怀疑。
4. 势力没有明确订单池引用，订单刷新只能依赖程序侧默认或单条样例。
5. 缺商店 / 服务 / 图纸 / 情报 / 剧情旗标的解锁引用。
6. 缺势力冲突规则，无法机械判断 Boss 核心互斥、黑市背叛和正规势力怀疑。

---

## 2. 本轮范围

`ECON-FACTIONS` 只处理势力定义与声望 / 信任框架，不处理 18 条订单模板完整字段。

| 范围内 | 范围外 |
|---|---|
| 5 个正式势力的字段级设计。 | 真实 JSON 修改。 |
| 正规声望 Lv.0-Lv.5 和黑市信任 0 / 3 / 7 / 12 / 15。 | 订单模板完整字段已由 `50_经济压力订单正式配置落地设计.md` 承接。 |
| 订单池引用、可见槽位、最大激活订单和刷新策略。 | 势力 NPC 全量对话和结局文本。 |
| 商店、服务、图纸、情报、剧情旗标和传闻提前量的解锁引用。 | 商店配置、奖励配置和剧情事件真实 JSON。 |
| 黑市背叛、正规势力怀疑、订单互斥和 Validator。 | UI 版式、美术资源和程序服务。 |

## 3. FactionConfig 正式字段

### 3.1 保留字段

| 字段 | 处理 |
|---|---|
| `FactionID` | 保留全局唯一 ID。 |
| `DisplayName` | 保留；正式配置可改为本地化 key。 |
| `IsBlackMarket` | 保留，用于区分黑市信任和正规声望。 |
| `VisibleOrderSlots` | 保留，但正式配置应支持随声望 / 信任调整。 |
| `MaxActiveOrders` | 保留，用于限制已接订单数量。 |
| `FactionTags` | 保留，用于传闻、订单、UI 和事件筛选。 |
| `ReputationRanks` | 保留，但扩展为 Lv.0-Lv.5 正规阶梯；黑市改用 `TrustRanks`。 |

### 3.2 新增 / 补齐字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `DisplayNameKey` | string | 是 | UI 文案 key。 |
| `DescriptionKey` | string | 是 | 势力说明、订单板提示和关系面板说明。 |
| `FactionRole` | enum | 是 | `Exploration`、`Engineering`、`Research`、`Alchemy`、`BlackMarket`。 |
| `OrderPoolIDs` | string[] | 是 | 该势力可刷新的订单池。 |
| `RefreshPolicy` | object | 是 | 周刷新槽位、冷却、保留已接订单、RankUp 是否立即刷新。 |
| `UnlockRefs` | object[] | 是 | 声望 / 信任达到阈值或完成订单后的解锁引用。 |
| `ConflictRules` | object[] | 是 | Boss 核心互斥、黑市背叛、正规势力怀疑和权重惩罚。 |
| `ShopRefs` | string[] | 否 | 势力商店或服务列表引用。 |
| `ServiceRefs` | string[] | 否 | 撤离信号、遗物鉴定、武器改造、净化、传闻提前量等服务引用。 |
| `RumorWeightModifiers` | object[] | 否 | 对传闻显示提前量、订单权重或顾客预算的影响。 |
| `SuspicionPolicy` | object | 否 | 正规势力对黑市信任 / 背叛次数的怀疑规则。 |
| `ValidationRefs` | object | 是 | 指向 Orders / Rewards / Economy / ScenarioEvents 需要校验的引用。 |

### 3.3 FactionRole 正式语义

| FactionRole | 含义 | 对应势力 |
|---|---|---|
| `Exploration` | 路线、地图、撤离和安全区支持。 | `faction_adventurer_guild` |
| `Engineering` | 底盘、义体、武器改造和大型工程委托。 | `faction_mechanic_workshop` |
| `Research` | 遗物、诅咒、心智催化和异常样本。 | `faction_mage_tower` |
| `Alchemy` | 消耗品、净化、市场传闻和顾客出价。 | `faction_alchemy_guild` |
| `BlackMarket` | 违禁品、背叛订单、走私入口和隐藏旗标。 | `faction_black_market` |

## 4. 通用阶梯

### 4.1 正规声望阶梯

正规势力统一使用 Lv.0-Lv.5，具体解锁内容由势力覆盖。

| Rank | Threshold | 设计含义 | 订单池变化 | 解锁方向 |
|---|---:|---|---|---|
| 0 | 0 | 陌生，只给基础试探单。 | 低风险采购、探索报告。 | 无或基础商品。 |
| 1 | 10 | 认识，玩家被视为可靠供货者。 | 增加稳定采购和低阶目标物。 | 基础折扣、基础图纸、基础服务。 |
| 2 | 30 | 熟人，允许接触内部需求。 | 增加指定节点、指定怪物、批量素材。 | 中阶商店、情报、服务升级。 |
| 3 | 70 | 伙伴，进入专属资源线。 | 增加大型委托物、活体捕获、专属链式订单。 | 底盘 / 义体 / 心智 / 经营关键解锁。 |
| 4 | 140 | 核心，势力愿意承担玩家风险。 | 高价值稀有订单、冲突订单、Boss 目标。 | 高阶服务、终局线索、稀有图纸。 |
| 5 | 250 | 盟友，一局中少数势力才能达到。 | 终局倾向订单、唯一奖励订单。 | 势力结局倾向、终极蓝图或隐藏路线。 |

### 4.2 黑市信任阶梯

黑市不使用正规声望，使用 `TrustRanks`。

| TrustThreshold | 解锁内容 | 长期代价 |
|---:|---|---|
| 0 | 高价收购低阶违禁品。 | 无明显风险。 |
| 3 | 出售低阶违禁义体材料，刷新普通黑市委托。 | 黑市交易日志开始影响剧情旗标。 |
| 7 | 接受正规势力委托物背叛。 | 原势力订单转 `Betrayed`，正规势力可进入怀疑。 |
| 12 | 解锁深渊走私入口。 | 正规势力订单高价值权重下降。 |
| 15 | 解锁面具商人身份线索。 | 进入隐藏剧情，同时提高正规势力冲突事件权重。 |

## 6. 冲突规则

### 6.1 Boss 核心互斥

```json
{
  "ConflictRuleID": "conflict_boss_core_claim_v1",
  "TargetTags": ["BossCore", "OrderBound"],
  "ExclusiveFactionIDs": [
    "faction_mechanic_workshop",
    "faction_mage_tower",
    "faction_black_market"
  ],
  "OnDeliveredToOneFaction": {
    "SetOtherOrdersUnavailable": true,
    "LogKey": "conflict.boss_core.claimed"
  }
}
```

同一 Boss 核心不能同时交给机械工坊、法师塔和黑市。若交给黑市，原正规订单必须转 `Betrayed`，而不是普通失败。

### 6.2 黑市怀疑

```json
{
  "SuspicionPolicy": {
    "PolicyID": "suspicion_black_market_default_v1",
    "AppliesToFactionRoles": ["Exploration", "Engineering", "Research", "Alchemy"],
    "BlackMarketTrustThresholds": [
      {"TrustMin": 7, "SuspicionLevel": 1, "OrderWeightPenaltyTags": ["HighValue"], "Multiplier": 0.85},
      {"TrustMin": 12, "SuspicionLevel": 2, "OrderWeightPenaltyTags": ["BossCore", "Rare"], "Multiplier": 0.65}
    ],
    "RecoveryActions": [
      {"Action": "CompleteHighDifficultyRegularOrder", "SuspicionDelta": -1},
      {"Action": "WeekWithoutBlackMarketTrade", "SuspicionDelta": -1}
    ]
  }
}
```

怀疑不是直接封死玩家，而是通过订单权重、商店价格、对话和风险提示表现长期代价。

### 6.3 传闻与势力请求

`48` 中的 `rumor_faction_medical_request` 必须能追到 `faction_alchemy_guild`，`rumor_scrap_workshop_shortage` 必须能追到 `faction_mechanic_workshop`。如果传闻引用的势力不存在，Validator 必须报 error 或在迁移期给 warning。

## 7. 与其它配置域关系

| 配置域 | 依赖 / 输出 |
|---|---|
| `Orders` | `OrderPoolIDs` 必须能追到订单池；5 个订单池和 18 条订单模板已由 `50_经济压力订单正式配置落地设计.md` 处理。 |
| `Rewards` | `UnlockRefs`、图纸、服务、情报和黑市材料必须能追到奖励或解锁配置。 |
| `Economy` | 黑市信任、怀疑、顾客预算、传闻提前量和价格风险要能被经济报告复盘。 |
| `Rumors` | `FactionRequest`、工坊短缺和黑市窗口传闻必须能引用实际势力。 |
| `Items` | `OrderBound`、`BossCore`、`Contraband`、`Cursed` 等标签决定冲突和背叛。 |
| `Dungeons` | 探索报告、路线节点、Boss 核心和订单目标必须能在已开放层级兑现。 |
| `ScenarioEvents` | 声望升级、背叛、怀疑、面具商人线索和势力冲突需要事件承接。 |
| UI / 美术 | 势力关系、声望 / 信任阶梯、怀疑状态、背叛确认和解锁提示必须可见。 |

## 8. Validator

| ValidatorID | 检查内容 | 失败级别 |
|---|---|---|
| `CFG-FACTION-001` | `FactionID` 唯一，`FactionRole`、`VisibleOrderSlots`、`MaxActiveOrders` 合法。 | error |
| `CFG-FACTION-002` | 正规势力必须有 Rank 0-5，阈值递增且最低为 0。 | error |
| `CFG-FACTION-003` | `IsBlackMarket=true` 的势力必须有 `TrustRanks`、黑市订单池、风险标签和背叛入口。 | error |
| `CFG-FACTION-004` | `OrderPoolIDs` 至少 1 个，且能在 Orders 或订单池设计中追到。 | warning / error |
| `CFG-FACTION-005` | `UnlockRefs` 引用 Rewards、Shops、Services、Blueprints 或 ScenarioEvents；迁移期缺引用给 warning。 | warning / error |
| `CFG-FACTION-006` | 正规势力必须声明与黑市怀疑或背叛的关系，不能让黑市无长期代价。 | error |
| `CFG-FACTION-007` | 传闻引用的 `FactionID` 必须存在，例如工坊短缺和医疗会需求。 | error |
| `CFG-FACTION-008` | 每个当前开放势力至少有一个可刷新订单池和一个玩家可见解锁方向。 | error |
| `CFG-FACTION-009` | Boss 核心互斥规则不能允许同一唯一物被多个势力同时完成。 | error |

## 9. 固定验收样例

| 验收 ID | 前置 | 操作 | 期望 |
|---|---|---|---|
| `V-ECON-FACTION-GUILD-01` | 冒险者公会解锁，玩家已到第二层。 | 周刷新订单。 | 公会能刷探索报告或安全区信号订单，且不生成越层目标。 |
| `V-ECON-FACTION-WORKSHOP-01` | 机械工坊声望跨过 Rank 3。 | 打开工坊解锁列表和订单池。 | 大型工程订单权重提高，`blueprint_chassis_overload_frame` 或同级图纸可见。 |
| `V-ECON-FACTION-MAGE-01` | 法师塔解锁，玩家持有未知遗物。 | 刷新法师塔订单并查看奖励。 | 遗物鉴定或心智催化方向可见，活体捕获不会在 Rank 0 强制出现。 |

## 10. 完成判定

`ECON-FACTIONS` 只有在以下条件满足后，才能视为势力配置设计局部完成：

1. 5 个势力都有 FactionID、Role、标签、订单池、刷新策略、可见槽位和最大激活订单。
2. 4 个正规势力都有 Rank 0-5 声望阶梯和玩家可见解锁方向。
3. 黑市有独立信任阶梯、背叛订单入口、走私入口和正规势力怀疑代价。
4. 势力与 `Orders`、`Rewards`、`Economy`、`Rumors`、`Items`、`Dungeons`、`ScenarioEvents` 的引用关系已定义。
5. `CFG-FACTION-*` 检查项和 `V-ECON-FACTION-*` 固定验收样例已定义。
6. `agent_status/design.md` 的 `DES-V4-001` 追加本文证据；如影响长期节点门禁，PM 同步 `09`，但整个经济压力配置仍不能因此标记为 `配置完成`。
