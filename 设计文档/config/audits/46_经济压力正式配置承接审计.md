# 经济压力正式配置承接审计

> **定位：** 本文是 `26_正式配置设计与填充推进计划.md` 中经济 / 订单 / 传闻配置的首轮承接审计，对应 `12_正式版长期版本节点规划.md` 的 `DES-V4-001`。它只审计 `Economy`、`Orders`、`Factions`、`Rumors` 当前 README 和 JSON 是否能承接正式经济压力规则；它不修改配置 JSON，也不代表经济压力配置已经完成。

---

## 1. 审计结论

当前经济压力配置已经有程序可读取的最小骨架：

| 配置域 | 当前源数据 | 当前能承接 |
|---|---|---|
| `Economy` | `economy_town_v1.json` | 7 天周、28 天月、月租曲线、轻债阈值、典当折扣、典当保护标签。 |
| `Orders` | `order_mechanic_scrap_drive.json` | 机械工坊单条采购订单、标签需求、截止日、奖励、声望 / 信任变化、失败惩罚。 |
| `Factions` | `faction_mechanic_workshop.json` | 单个机械工坊势力、可见订单槽、最大激活订单、声望阶梯样例。 |
| `Rumors` | `rumor_mechanical_price_up.json` | 单条机械标签涨价传闻、售卖渠道、持续天数、订单标签权重加成。 |

但它仍是“经济系统样例配置”，不是正式经济压力配置：

1. `Economy` 只覆盖月租 / 欠债 / 典当基础裁决，缺日结账单字段、周报、顾客、橱窗、黑市、违禁隔夜代价、维护支出和死锁保护。
2. `Rumors` 只有 1 条机械涨价传闻，无法覆盖 `22` 要求的 8 条传闻，也无法形成第一层目标、第二层路线、违禁窗口和订单预告的组合。
3. `Factions` 只有 1 个机械工坊，距离 `24` 要求的 5 个势力、5 套声望 / 信任阶梯和冲突规则差距较大。
4. `Orders` 只有 1 条低阶采购订单，距离 `24` 要求的 5 个订单池、18 个订单模板、背叛订单、大型委托物和活体捕获差距较大。
5. `Rewards`、`Items`、`Dungeons`、`ScenarioEvents`、UI 表现和 Validator 仍需要联动承接，否则经济目标无法反向改变下潜路线。

结论：`DES-V4-001` 已经可以进入策划配置设计阶段，但不能标记为 `配置完成`。经济压力 JSON 修改前落地设计见 `47` 到 `50`，整体验收规格见 `51`，配置实现派发顺序和证据模板见 `52_经济压力正式配置实现任务拆分.md`，当前工作区 ID 锁定证据见 `53_经济压力正式配置ID锁定与冲突检查.md`。

## 3. `Economy` 审计

### 3.1 当前字段

| 字段 | 当前情况 | 判断 |
|---|---|---|
| `WeekLength` / `MonthLength` | 已有，7 / 28。 | 与正式口径一致。 |
| `RentCurveID` / `RentCurve` | 已有，1-4 月月租阶梯。 | 可承接 `22` 的首批月租曲线。 |
| `WorkshopMaintenanceBase` / `LicenseFeeBase` | 已有，但当前为 0。 | 需要接维护支出、许可证和势力保护费。 |
| `DebtInterestRate` | 已有，0.1。 | 可承接欠债利息。 |
| `LightDebtThresholdRatio` | 已有，0.1。 | 可承接轻债阈值。 |
| `PawnValueMultiplier` | 已有，0.25。 | 可承接典当折扣。 |
| `PawnProtectedTags` | 已有。 | 与订单 / 剧情 / 情感锚点硬保护一致。 |

### 3.2 正式字段缺口

| 缺口字段 | 设计目的 | 来源 |
|---|---|---|
| `DailyReportSchemaID` | 日结报告列出倾倒箱、橱窗、订单、黑市、支出、未售物和 NightTax。 | `04` / `22` |
| `WeeklyReportPolicy` | 周报刷新传闻、订单、月租缺口和市场信息。 | `04` / `22` |
| `SellChannels` | 定义 `DumpBox`、`ShowcaseGrid`、`OrderSlot`、`BlackMarketSlot` 的基础规则。 | `04` |
| `CustomerPoolRefs` | 让橱窗和倾倒箱有不同买方与预算。 | `22` |
| `ContrabandRuleRefs` | 承接普通拒收、黑市高价和隔夜代价。 | `04` / `22` |
| `NightTaxPolicy` | 定义污染 / 违禁隔夜对 SAN、侵蚀、仓库污染和事件的影响。 | `04` |
| `MonthlyBillComponents` | 月租、工坊维护、许可证、债务利息、剧情加压拆分可读。 | `04` / `22` |
| `DeadlockGuard` | 避免前三层阶段因月租、维护、欠债形成不可恢复死锁。 | `26` |

### 3.3 Validator 建议

| ValidatorID | 检查内容 |
|---|---|
| `CFG-ECON-001` | `WeekLength`、`MonthLength`、`RentCurve`、`DebtInterestRate`、`PawnValueMultiplier` 合法。 |
| `CFG-ECON-002` | 月租曲线月份不重复，基础月租递增或有明确例外。 |
| `CFG-ECON-003` | `PawnProtectedTags` 引用的标签存在，且覆盖 `OrderBound`、`StoryLocked`、`Memento`、`MainQuest` 等硬保护。 |
| `CFG-ECON-004` | `MonthlyBillComponents` 中费用项不能全部为 0，且玩家可见账单来源。 |
| `CFG-ECON-005` | `DeadlockGuard` 能保证前三层阶段有欠债、典当、低层回刷或订单补救路径。 |
