# 小镇经济月租内容包

> **定位：** 本内容包把小镇经济从“规则可开发”推进到正式内容粒度。它不是配置 JSON，也不替代经济配置 README；它规定第一批传闻、顾客、账单、违禁品、月租曲线和典当压力应如何共同支撑“深渊收益 -> 出货选择 -> 月租压力 -> 再下潜目标”的长期循环。

---

## 1. 内容包总览

| 项 | 内容 |
|---|---|
| `PackID` | `pack_town_economy_rent_v1` |
| `PackName` | 小镇经济月租内容包 |
| 目标阶段 | 正式版核心纵切中的长期经济压力主干。 |
| 前置内容 | 第一层正式核心内容包、第二层背包压力内容包、人偶成长修复内容包。 |
| 目标体验 | 玩家每天都能复盘“今天为什么赚这些钱”，并在月租、维护、成长和订单之间做有压力但可理解的取舍。 |
| 覆盖系统 | 经济配置、Rumors、Customers、Bills、Contraband、Orders、Rewards、DailyReport、Pawn。 |
| 主要验收 | `V-P2-ECON-01`、`V-ECON-RUMOR-01`、`V-ECON-CONTRABAND-01`、`V-ECON-BILL-01`、`V-ECON-REPORT-01`、`V-PACK-ECON-RENT-01`。 |

小镇经济不是手动开店小游戏，而是深渊循环的压力泵。玩家的主要收益仍来自深渊战利品和订单，经济系统负责把这些收益转化为月租、维护、制造、义体、底盘和剧情风险之间的长期取舍。

---

## 2. 玩家体验目标

| 目标 | 设计说明 | 失败表现 |
|---|---|---|
| 结算可复盘 | 日终账单必须列出倾倒箱、橱窗、订单、黑市、支出、未售物和隔夜代价。 | 只显示金币最终变化。 |
| 传闻改路线 | 传闻必须让玩家下一次下潜更关心某类标签、层级或节点。 | 传闻只是售卖界面的倍率文字。 |
| 月租有预告 | 月租和缺口提前多日可见，让压力来自规划而不是突袭。 | 月末突然扣款或突然失败。 |
| 违禁有诱惑 | 违禁品有高收益，但普通渠道拒收、隔夜代价和黑市风险清楚。 | 高价物无风险，或风险暗扣。 |
| 顾客有偏好 | 橱窗和倾倒箱不是同一个按钮；高价值物需要顾客预算和偏好承接。 | 所有物品统一按基础价卖掉。 |
| 钱永远有出口 | 维护、人偶成长、订单准备和月租共同吃掉收益，避免财富自由。 | 玩家早期积累后经济压力消失。 |

## 3. 经济周期与月租曲线

### 3.1 周期口径

| 字段 | 正式口径 |
|---|---|
| `WeekLength` | 7 天。 |
| `MonthLength` | 28 天。 |
| 周结 | 第 7 / 14 / 21 / 28 天触发周报、传闻刷新、部分订单刷新。 |
| 月租 | 第 28 天营业结算后触发月租账单。 |
| 日终 | 每天进入 `DailyBillReport`，即使收入为 0 也生成日报。 |

### 3.2 首批月租曲线

| `RentCurveID` | 月份 | 基础月租 | 推荐月总收入压力 | 设计目标 |
|---|---:|---:|---:|---|
| `rent_curve_workshop_v1` | 1 | 1200G | 约 55%-65% | 教会账单压力，但允许玩家犯错和维护。 |
| `rent_curve_workshop_v1` | 2 | 2400G | 约 65%-75% | 迫使玩家开始利用传闻、订单和橱窗。 |
| `rent_curve_workshop_v1` | 3 | 4200G | 约 75%-85% | 进入构筑、成长和高风险路线取舍。 |
| `rent_curve_workshop_v1` | 4+ | 按周数指数 / 阶梯增长 | 80% 左右 | 吃掉背包扩大和熟练度收益，维持长期压力。 |

> 数值解释：这里不是最终平衡表，而是正式内容包的压力方向。具体金币数要继续和 `数值模型设计/01_经济循环与通缩模型.md`、掉落期望和维护成本一起校准。

### 3.3 月租预告规则

| 时间点 | 玩家必须看到 |
|---|---|
| 月初 | 本月预计月租、上月欠债、当前金币、推荐收入目标。 |
| 每周结 | 已完成收入、本月预计缺口、下周传闻和订单机会。 |
| 月末前 3 天 | 强提示缺口、典当入口、黑市诱惑或高价订单。 |
| 月租结算 | 应付、已付、缺口、欠债 / 典当 / 违约裁决和下月影响。 |

## 6. 账单内容

账单不是惩罚弹窗，而是经济复盘和压力预告。

| `BillID` | 展示名 | 触发时机 | 显示内容 | 裁决 | 玩法职责 |
|---|---|---|---|---|---|
| `bill_daily_settlement_v1` | 每日营业日报 | 每日营业后 | 倾倒箱、橱窗、订单、黑市、支出、未售物、NightTax。 | 结算当日收入 / 支出，生成日志。 | 让玩家复盘今天为什么赚或亏。 |
| `bill_weekly_market_report_v1` | 周市场报告 | 每 7 天 | 本周收益、下周传闻、订单刷新、月租缺口。 | 刷新传闻和订单池。 | 把经济信息推回下潜目标。 |
| `bill_monthly_rent_v1` | 月租账单 | 第 28 天营业后 | 应付月租、当前金币、缺口、上月债务、典当建议。 | 扣款、欠债、典当或违约。 | 长期压力核心。 |
| `bill_debt_notice_v1` | 欠债通知 | 月租不足或连续违约 | 欠款、利息、债主事件、下月风险。 | 写入债务状态，触发剧情或黑市诱惑。 | 让失败变成长线压力而非立即中断。 |

### 6.1 月租与欠债样例

| 状态 | 玩家行为 | 期望 |
|---|---|---|
| 月租 1200G，金币 1350G。 | 支付月租。 | 成功进入下月，账单记录剩余金币和下月预计。 |
| 月租 1200G，金币 1120G。 | 接受轻度欠账。 | 欠款 80G 进入下月利息，债务提示明确。 |
| 月租 2400G，金币 1600G，仓库有普通高价值物。 | 打开典当。 | 玩家可选典当物补足；普通物可典当，情感锚点 / 委托物不可典当。 |
| 连续两月重度违约。 | 无力补足。 | 触发债主事件或破产分支，写入剧情队列。 |

## 7. 违禁品内容

违禁品的核心不是“更贵的战利品”，而是把短期收益、SAN / 侵蚀、人偶情绪、势力声望和黑市渠道连起来。

| `ContrabandRuleID` | 适用标签 | 普通渠道 | 黑市渠道 | 隔夜代价 | 清理方式 | 玩法职责 |
|---|---|---|---|---|---|---|
| `contra_polluted_sample_v1` | `CorruptionSample` | 普通顾客拒收或折价极低。 | 黑市 / 医疗传闻可高价收。 | SAN 小损、侵蚀上升或仓库污染。 | 净化冲洗、手动丢弃、医疗订单。 | 高收益和人偶维护压力绑定。 |
| `contra_forbidden_relic_v1` | `ForbiddenRelic` | 禁止倾倒箱，橱窗需特殊顾客。 | 黑市高价，公开声望下降。 | 黑市事件、债主注意、房间窗外风险。 | 黑市出售、剧情交付、封存。 | 诱导背叛和长期社会风险。 |
| `contra_order_leak_v1` | `OrderBound, Suspicious` | 不可普通出售。 | 可背叛出售。 | 委托势力怀疑上升。 | 正规交付、黑市背叛、放弃订单。 | 把订单系统和黑市收益连接。 |
| `contra_cursed_keepsake_v1` | `Cursed, MementoCandidate` | 普通渠道拒收。 | 黑市可售但触发人偶抗拒。 | 低 SAN 时额外情绪压力。 | 房间封存、剧情净化、特殊赠礼。 | 经济诱惑和情感锚点冲突。 |

### 7.1 违禁品验收要点

| ID | 路径 | 期望 |
|---|---|---|
| `V-PACK-ECON-CONTRA-01` | 污染样本留在 SafeBox 过夜。 | 触发 NightTax，账单说明 SAN / 侵蚀 / 污染来源。 |
| `V-PACK-ECON-CONTRA-02` | 黑市窗口开启，出售禁忌遗物。 | 高价成交，同时记录黑市收入和声望 / 债主风险。 |

## 8. 典当与保护边界

普通出售保护不做。玩家可以自己处理普通物品，经济系统只对不可替代对象提供硬保护。

| 类型 | 是否硬保护 | 说明 |
|---|---|---|
| 普通战利品 | 否 | 可出售、倾倒、典当或丢弃。 |
| 普通装备 | 否 | 若玩家确认出售，系统不额外阻止。 |
| 订单绑定物 | 是 | 不可普通出售；背叛必须走黑市确认。 |
| 剧情锁定物 | 是 | 由剧情旗标保护，除非剧情允许。 |
| 人偶情感锚点 | 是 | 例如关键赠礼、房间纪念触发物；出售需特殊确认或禁止。 |
| 不可替代主线物 | 是 | 不能被典当算法选中。 |

### 8.1 典当推荐规则

当月租不足且玩家打开典当时，推荐排序为：

```text
非绑定普通物
  -> 高估值低构筑依赖物
  -> 重复材料
  -> 当前传闻低价值物
  -> 玩家手动选择其他可典当物
```

系统不得自动典当订单物、剧情锁定物或情感锚点。若玩家拒绝典当，进入欠债或违约裁决。

| `V-PACK-ECON-DEBT-01` | 月租缺口较小 -> 接受欠账 -> 下月周报显示利息和债主风险。 | 欠债成为长期压力，有预告和复盘，不是立即失败。 |
| `V-PACK-ECON-BLACK-01` | 黑市窗口开启 -> 玩家出售禁忌遗物 -> 正规势力声望受损。 | 高收益、声望损失、债主 / 黑市风险进入日志。 |
| `V-PACK-ECON-MAINT-01` | 人偶高侵蚀需要净化，医疗会净化物传闻刷新。 | 玩家在卖钱、保留维护材料、接医疗订单之间做取舍。 |

## 11. 内容边界

| 不做 | 原因 |
|---|---|
| 不做逐个顾客手动议价。 | 小镇经济是阶段结算，不是低频经营小游戏。 |
| 不做普通出售保护。 | 普通物品由玩家手动判断；保护只给订单、剧情和情感锚点。 |
| 不让月租随机突袭。 | 压力必须可预告、可规划、可复盘。 |
| 不让违禁品只等于高价物。 | 违禁必须带渠道限制、隔夜代价和长期风险。 |
| 不让传闻生成当前版本不可兑现目标。 | 所有传闻必须能在已开放层级、掉落池、订单或事件中追踪。 |
| 不让房间承担仓库。 | 经济压力通过背包、SafeBox、出售、制造和典当处理，房间只记录经历。 |

## 12. 完成判定

本内容包达到可交付开发，需要同时满足：

1. 8 条传闻、6 类顾客、4 套账单、4 类违禁品规则和 1 条月租曲线都有配置落点、玩家可见信息和验收路径。
2. 玩家能在备战、出货、日结、周报、月租、欠债和黑市窗口中读懂收益与代价。
3. 传闻至少一条能改变第一层捡取目标，至少一条能改变第二层路线目标。
4. 月租不足时能进入欠债或典当裁决，且不会自动处理订单物、剧情物或情感锚点。
5. 违禁品能证明普通拒收、黑市高价、隔夜代价三种状态。
6. 至少通过 `V-PACK-ECON-DAILY-01`、`V-PACK-ECON-ROUTE-01`、`V-PACK-ECON-RENT-01`、`V-PACK-ECON-BLACK-01` 四条联合验收。

当以上条件满足后，小镇经济月租主干可进入配置表、UI 表现规格和验收拆分。
