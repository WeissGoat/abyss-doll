# 第二层正式配置落地设计

> **定位：** 本文是 `26_正式配置设计与填充推进计划.md` 中 W2「前三层正式配置补齐」的第二份落地产物。它只负责第二层 `Items` / `Rewards` / `Monsters` / `Dungeons` 的配置落地设计，把 `20` 内容包和 `27-30` 审计结论转成后续改 JSON 前的策划清单。本文不直接修改 JSON，不替代配置 README，也不表示配置已经完成。

---

## 1. 落地目标

第二层配置落地的目标是让“腐蚀甬道”从第一层的低压入口升级为稳定背包压力层：

```text
已通层直达 -> 备战留空间 / 接订单 -> 第二层路线选择 -> 对包干涉战斗 -> 反制或绕路 -> 精英高收益取舍 -> Boss -> 免费恢复但压力保留 -> 撤离 / 深入 / 交订单
```

本轮第二层配置设计必须满足：

| 目标 | 完成口径 |
|---|---|
| 直达闭环 | 已解锁第二层后，小镇出发直接生成第二层地图，不重复生成第一层。 |
| 物品闭环 | 12 件第二层物品都有明确 `ConfigID`、形状、职责、来源和去向。 |
| 背包压力闭环 | 至少有塞包、封格、低级腐蚀或污染中的两类压力，并提供清晰反制。 |
| 订单闭环 | 至少 1 个委托物占格订单和 1 个经济 / 黑市目标能改变路线选择。 |
| 怪物闭环 | 4 个普通怪、2 个精英、1 个 Boss 有独立职责、意图、奖励和反制方式。 |
| 地图闭环 | 2 个 MapProfile、至少 3 条路线倾向、1 个可绕精英、Boss 后 SafeZone。 |
| 奖励闭环 | 普通怪、精英、Boss、宝箱、事件、订单奖励职责拆开，Boss 保底从精英奖励中迁出。 |
| 验收闭环 | 至少能支撑 `V-L2-DIRECT-2048-ROUTE-01`、`V-L2-PACK-RUN-01`、`V-L2-PACK-ORDER-01`、`V-L2-PACK-ELITE-01`、`V-L2-PACK-BOSS-01`。 |

---

## 2. 本轮不处理范围

| 范围外 | 原因 |
|---|---|
| 第三层路线侵蚀 JSON | 第三层需要先单独定义污染、路线侵蚀和订单冲突样例。 |
| 完整订单系统实现 | 本文只给第二层订单配置设计；订单系统字段仍以 `07`、`17`、`24` 为准。 |
| 完整黑市背叛链 | 第二层只做首次诱惑和风险预告，不完成完整黑市线。 |
| 永久污染 / 永久封格 | 第二层只投放低级、可反制、可解释的压力。 |
| 实际 JSON 改值 | 后续单独进入配置实现批次时处理。 |

---

## 3. 第二层配置落地顺序

建议按以下顺序改配置，避免引用断裂：

1. `Items`：先补第二层物品 ID、委托物、反制物、风险材料和去向。
2. `Rewards`：补普通怪、精英、Boss、宝箱、事件和订单奖励表，保证物品有来源。
3. `Monsters`：补第二层怪物、精英和 Boss，把 `RewardID` 指到奖励表。
4. `Dungeons`：补第二层直达、MapProfile、节点池、BossNode、SafeZone 和固定 seed 样例。
5. Validator / 验收样例：最后把第二层固定路径、直达层和订单路径纳入机械检查。

### 5.2 Boss 保底迁移规则

当前 `reward_monster_elite_mutant_amalgam` 带有 Boss 级保底。正式落地时必须迁移：

```text
reward_monster_elite_mutant_amalgam.Guaranteed 移除 mat_core_tier2 / mat_core_tier2_fragment
reward_boss_spore_foundry.Guaranteed 新增 mat_core_tier2_fragment
```

迁移后：

| 来源 | 保底成长材料 | 说明 |
|---|---|---|
| `elite_mutant_amalgam` | 无 | 精英奖励更高，但不承担层级通关成长钥匙。 |
| `boss_spore_foundry` | `mat_core_tier2_fragment` | Boss 是第二层成长钥匙来源。 |

### 6.2 第二层意图边界

| IntentType | 第二层允许程度 | 说明 |
|---|---|---|
| `Attack` | 常规 | 继续作为基础威胁。 |
| `Defend` | 常规 | 结晶系和精英使用。 |
| `Charge` | 常规 | 精英 / Boss 用来给玩家反制窗口。 |
| `AddJunk` | 常规 | 塞入低级残渣，不覆盖已有物品。 |
| `GridLock` | 常规 | 临时封边或封弱槽，战后解除。 |
| `SanPressure` | 常规低压 | 主要由窃魂虫群承担。 |
| `CorrodeItem` | 低级 | 只增加低级损伤 / 腐蚀标签，不销毁。 |
| `PolluteItem` / `PolluteCell` | 低级 | 只做低级污染提示，可用反制物处理。 |
| 永久封格 / 高阶污染 | 不投放 | 留给第三层及以后。 |

### 6.3 Boss 行为模板

`boss_spore_foundry` 建议用三阶段：

| 阶段 | 条件 | 行为 |
|---|---|---|
| Phase 1 | HP > 60% | `Attack`、`AddJunkSmall`、`Defend` 轮换。 |
| Phase 2 | HP <= 60% | 加入 `PolluteCellLow` 和小孢子召唤。 |
| Phase 3 | HP <= 25% | 预告重击并塞入 1 个 2 格孢子囊，之后进入疲惫回合。 |

Boss 不做永久封格；击败后进入 Boss 后 SafeZone，免费恢复 HP / SAN，但保留背包、污染、订单和探索账本。

## 9. 第二层验收样例

### 9.1 `V-L2-CONFIG-COVERAGE-01`

| 项 | 内容 |
|---|---|
| 输入 | 扫描第二层配置目标清单。 |
| 期望 | 12 个 Item、7 个 Monster、2 个 MapProfile、12 个 RewardID、3 个 OrderID 都有配置或明确替代 ID。 |
| 失败 | 任一关键 ID 既不存在，也没有替代 ID 或后续批次标记。 |

### 9.2 `V-L2-DIRECT-2048-ROUTE-01`

| 项 | 内容 |
|---|---|
| 输入 | `HighestUnlockedDungeonLayer=2`，从小镇选择 `LayerID=2`，`MapProfileID=layer2_bag_pressure`，`RunSeed=2048`。 |

## 11. 后续落地顺序

后续真正进入配置实现时，建议拆成 5 个小任务：

1. `L2-ITEMS`：补第二层 12 件物品的字段、形状、订单绑定和新增 ID。
2. `L2-REWARDS`：补第二层普通怪、精英、Boss、宝箱、事件、订单奖励表。
3. `L2-MONSTERS`：补第二层 7 个怪物 / Boss，回归精英职责。
4. `L2-DUNGEONS`：补第二层 2 个 MapProfile、直达规则、节点池和固定 seed 验收。
5. `L2-ORDERS`：补第二层 3 个订单的目标、截止、失败、背叛和奖励引用。

完成后再进入第三层配置落地设计，重点处理路线侵蚀、订单冲突、污染字段和第三层 Boss 入场变量。
