# 剧情智能体阅读入口

> 本页只负责剧情 Role 的阅读顺序。剧情事实以 `设计文档/剧情/` 为入口；本页不保存剧情正文、配置进度或运行时验收状态。

## 必读

1. `PROJECT_STATUS.md` 的当前阶段、优先级、阻塞和交接快照。
2. `设计文档/剧情/README.md`：确认剧情目录职责、当前事实来源和文档拆分边界。
3. 当前任务对应的剧情大纲、序章节奏、角色关系、对白或目标叙事文档。

剧情任务先回答“写什么故事、为什么驱动当前玩家循环”，不默认展开程序字段、美术流水线和完整配置历史。

## 按任务读取

| 任务范围 | 进一步读取 |
|---|---|
| 主线大纲、角色关系、记忆拼图、结局 | `设计文档/剧情/00_剧情大纲.md` 和目标剧情文档 |
| 序章对白、情绪曲线和交互节奏 | `设计文档/剧情/01_序章演出与对话节奏.md`、目标细案 |
| 事件触发、队列、字段和系统指令 | `设计文档/GDD/GDD_05_剧本调度引擎与世界观封装逻辑.md`、`设计文档/规则卡/10_剧本调度与事件队列规则卡.md` |
| 长期记忆、房间纪念物和内容粒度 | `设计文档/content_packs/23_长期记忆剧情内容包.md` |
| Yarn / 对白节点 / 命令桥 / 运行时播放 | `开发文档/18_全局叙事播放系统开发方案.md`、程序 View |
| CG、漫画页、Panel 一致性和运行时演出 | `美术文档/18_CG底图与漫画式播放演出工作流.md`、美术 View |

## 验收 / 恢复时读取

- 影响全局体验、开放节奏或 Owner 模块完成口径时，读取导演 View 和 `agent_status/director.md` 当前快照。
- 影响 GDD、规则、配置源或文案字段时，读取策划 View 和 `agent_status/design.md` 当前快照。
- 叙事 CG / 漫画页生产与运行时验收使用 `p3-narrative-cg-comic`；纯图像生成 / 编辑使用 `p3-generate-image`。
- 恢复长期剧情任务时，读取已有详细来源材料和 P3 Mission 当前状态，不通读无关历史日志。

## 边界提醒

- 剧情是独立 Role，不归入策划；系统规则、配置字段和运行时实现仍分别回到策划、程序和美术事实来源。
- Owner 可以切换到剧情 Role，但剧情事实不会因此归入 Owner 状态页。
- 新增剧情文档前先判断能否补入现有剧情母版，避免产生第二套剧情事实来源。
- CG / 漫画画面通过不等于剧情结构通过；剧情验收与美术运行时验收需要分别给出证据。
