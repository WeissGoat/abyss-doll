# MVP 需要补充的配置调整

> **更新时间：** 2026-05-10  
> **定位：** 本文档只锁定 MVP 阶段体验验证所需的配置收口。当前不追加复杂系统，不追求正式版内容量，只把现有功能配置成一条稳定、可试玩、可观察的最小闭环。

> **阶段状态：** 2026-05-20 起，项目已转入正式版核心纵切 Alpha。本文保留为 MVP 配置验证期复盘；当前阶段路线以 `版本规划/09_正式版核心纵切开发路线.md` 为准，具体系统规则以 `设计文档/` 为准。

MVP 的核心验证链路是：

**单线下潜 -> 战斗/拾取 -> 背包取舍 -> 撤离或战败结算 -> 卖出多余物品 -> 底盘/义体成长 -> 解锁并选择更深层入口 -> 进入 2 层验证压力**

---

## 1. MVP 体验范围锁定

### 1.1 本阶段要验证什么

MVP 配置只服务以下 5 个体验判断：

*   **背包取舍成立：** 玩家会因为格子有限，在装备、消耗品、战利品、核心材料之间做选择。
*   **经济回流成立：** 玩家能把多余物品卖成金币，并把金币投入底盘升级或义体制造。
*   **局外成长成立：** 底盘扩大、义体增益能在下一次下潜中被明显感知。
*   **2 层压力成立：** 毒性携带、武器腐蚀、诅咒塞包等配置能让 2 层不只是纯数值提高。
*   **后续钩子成立：** 打完 2 层后至少获得一个“下一阶段成长素材”信号，证明完整版内容可以接上。

### 1.2 本阶段明确不验证什么

以下内容不进入当前 MVP 配置收口：

*   杀戮尖塔式网状地图与路线构筑。
*   完整房租、账单、治疗费用曲线。
*   商店刷新、黑市、价格波动。
*   好感度、剧情事件、势力订单。
*   大量新怪物、新装备、新消耗品。
*   材料出售保护、误售保护、材料锁定。
*   撤离后自动转入仓库、仓库分页、仓库分类和筛选。

### 1.3 当前实现口径

*   **地图结构：** MVP 继续使用单线节点；节点池负责提供战斗、安全区、Boss 等内容。网状地图留到完整版阶段重新设计。
*   **分层入口：** 玩家通关 1 层后，应从小镇直接选择 2 层出发；不要求每次挑战 2 层都重复打一遍 1 层。
*   **物品带出：** 背包就是本阶段的携带容器。撤离后物品继续留在背包即可，不强制转仓。
*   **卖出规则：** 玩家手动决定卖什么。当前不做出售保护，配置只需要把“材料/卖钱战利品/核心物”的职责标清。
*   **测试便利口径：** 开发测试可保留高初始资源；正式 MVP 白盒试玩必须有单独或可切换的低资源配置。

## 2. 当前配置覆盖度

当前内容数量已经足够支撑 MVP：

*   2 个人偶配置：正式 MVP 档 `doll_proto_0`，开发测试档 `doll_proto_0_test`。
*   2 级底盘配置。
*   2 个义体插件。
*   2 个深渊层级。
*   4 个怪物。
*   13 个局内物品，含二阶污染核心。
*   2 个义体制造配方。
*   4 张怪物奖励表。

后续配置工作不应继续堆数量，而应集中在 4 件事：

*   把测试便利配置和正式试玩配置分离。
*   把关键成长奖励稳定送达。
*   把物品职责、标签、售价和格子压力对齐。
*   把 1 层收益、2 层压力、局外成长的节奏调到可试玩。

## 3. P0：正式白盒试玩前必须收口

### 3.1 正式 MVP 初始配置

**当前状态：** 已将 `doll_proto_0` 收口为正式 MVP 初始档，并新增 `doll_proto_0_test` 保留开发测试便利装。运行流程中的开发期金币/核心投放已默认关闭，仅保留 Debug 开关。

**问题：** 这会削弱 1 层压力，让玩家跳过“从短剑过渡到更好装备”的早期体验。

**配置目标：** 拆分“开发测试档”和“正式 MVP 档”。

建议：

*   `doll_proto_0`：用于正式 MVP 白盒试玩。
*   `doll_proto_0_test`：保留当前测试便利装，用于开发回归。

正式 MVP 初始装建议：

| 物品 | 数量 | 目的 |
| :--- | :--- | :--- |
| 生锈短剑 | 1 | 提供最低战斗能力 |
| 木制小盾 | 1 | 让防御动作可被验证 |
| 便携修复剂 | 1 | 给玩家一次容错 |
| 廉价镇静剂 | 1 | 验证 SAN 消耗品与背包占格 |

**不建议：** 正式开局直接给【战术长刀】。它应作为 1 层战利品或稀有奖励出现，否则 1 层装备成长和背包取舍都会变弱。

### 3.2 移除或隔离开发期资源投放

**当前状态：** 正式开局金币已收口为 250；`GameFlowController` 中 1500 金币和一阶核心的开发期投放已默认关闭，保留 Inspector Debug 开关。

**配置口径：**

*   正式 MVP 开局金币应只够完成极少数操作，建议先以 `200-300` 金币试跑。
*   开局不直接给 `mat_core_tier1`。
*   开发测试需要的金币、核心、强武器应挂在测试配置或 Debug 入口下。

**验收：** 从正式档进入游戏时，玩家需要至少完成一次 1 层下潜，才有足够资源升级底盘或制造义体。

### 3.3 固定效果的 `Level` 口径统一

**当前问题：** 部分效果配置写了 `Level: 1`，如果程序实现会根据 `Level` 做额外成长，可能出现“配置写 10，实际生效 15”的偏差。

**MVP 口径：**

*   固定数值效果统一使用 `Level: 0`。
*   真正需要成长的效果，再单独配置并在数值文档里标出成长公式。

建议优先检查：

| 配置 | 效果 | 建议 |
| :--- | :--- | :--- |
| 木制小盾 | `AddRuntimeShield` | 固定护盾，`Level: 0` |
| 铁片装甲 | `AddRuntimeShieldOnTurnStart` | 固定每回合护盾，`Level: 0` |
| 动力臂增幅插件 | `DamageMultiplier` | 固定近战增伤，`Level: 0` |
| 稳压散热插件 | `RestoreSANOnCombatEnd` | 固定战后回 SAN，`Level: 0` |
| 充能手枪 | 右侧增伤 | 若是固定条件增伤，`Level: 0` |

本轮已将以下固定数值效果从 `Level: 1` 调整为 `Level: 0`：

*   `Items/gear_charge_pistol.json`
*   `Items/gear_iron_armor.json`
*   `Items/gear_wooden_shield.json`
*   `Prosthetics/pros_cooling_system.json`
*   `Prosthetics/pros_power_arm.json`

**目标：** 让 `Params` 成为策划可直接读懂的实际数值。

### 3.4 一阶动力核心保底奖励

**当前状态：** 1 层 Boss 奖励表已保底掉落【一阶动力核心】，这个方向正确，需要保持稳定。

配置要求：

```json
{
  "RewardID": "reward_monster_elite_scrap_guard",
  "Guaranteed": [
    { "Type": "Item", "ItemID": "mat_core_tier1", "Count": 1 }
  ]
}
```

MVP 要点：

*   一阶核心必须保底出现。
*   一阶核心继续占 2x2。
*   是否带得走核心，应由背包格子和玩家取舍决定，而不是由掉落随机决定。

### 3.5 物品职责标签清理

**当前问题：** 部分物品标签容易混淆“卖钱战利品”和“制造材料”。当前不做出售保护，所以更需要配置本身清晰，避免后续配方误引用。

建议职责：

| 物品 | MVP 职责 | 建议标签 |
| :--- | :--- | :--- |
| 废旧齿轮 | 义体制造材料，可卖但卖掉会延缓成长 | `Material`, `Mechanical` |
| 生锈线圈 | 1 层纯卖钱战利品 | `Mechanical` |
| 污染滤芯 | 2 层高价有毒战利品 | `Toxic`, `Mechanical` |
| 一阶动力核心 | 底盘升级关键物 | `CoreMaterial`, `Heavy` |

**说明：** 标签本阶段主要用于展示、配方、后续筛选和策划统计，不用于强制保护玩家决策。

## 4. P1：第二轮压力验证前补齐

### 4.1 战术长刀正式数值定稿

**当前状态：** 【战术长刀】已回调为 2 AP / 35 伤害，作为 1 层过渡奖励。

正式 MVP 配置：

```json
{
  "ConfigID": "gear_tactical_blade",
  "Combat": {
    "APCost": 2,
    "BaseValue": 35
  }
}
```

设计意图：

*   短剑：低占地、低伤害、AP 灵活。
*   长刀：占 3 格、2 AP、高单次效率，但压缩战利品空间。
*   大剑：2 层后高伤害巨物，用来验证底盘扩大后的爽感。

若保留 50 伤害，应将其标记为测试便利或稀有掉落，并降低奖励权重。

### 4.2 2 层 Boss 补二阶成长素材

**当前问题：** 2 层 Boss 奖励表没有保底二阶素材。打完 2 层后，玩家有战利品和装备收益，但缺少“下一阶段成长”的明确目标。

新增物品建议：

```json
{
  "ConfigID": "mat_core_tier2",
  "Name": "二阶污染核心",
  "ItemType": "QuestItem",
  "Rarity": "Epic",
  "BaseValue": 0,
  "IconID": "item_mat_core_tier1_icon",
  "Grid": {
    "Shape": [[0,0], [0,1], [1,0], [1,1]],
    "GridCost": 4
  },
  "Combat": null,
  "Tags": ["CoreMaterial", "Toxic", "Heavy"]
}
```

奖励表建议：

```json
{
  "RewardID": "reward_monster_elite_mutant_amalgam",
  "Guaranteed": [
    { "Type": "Item", "ItemID": "mat_core_tier2", "Count": 1 }
  ]
}
```

MVP 口径：

*   二阶核心可以暂时没有实际用途。
*   二阶核心图标在美术资源补齐前，临时复用一阶核心图标。
*   只要能在背包、结算、卖出界面中被识别，就足以作为后续成长钩子。
*   因为它带 `Toxic`，带出它本身也可以形成 2 层末端取舍。

### 4.3 2 层压力权重

当前 2 层的核心压力来自三件事：

*   【污染滤芯】：高价值，但移动额外消耗 SAN。
*   【酸液软体】：概率腐蚀随机武器，使下回合输出下降。
*   【畸变融合体】：概率向背包塞入诅咒废件。

建议首轮白盒权重：

| 内容 | 普通行为 | 特色干涉 |
| :--- | :--- | :--- |
| 酸液软体 | 普通攻击 70% | 腐蚀武器 30% |
| 畸变融合体 | 高伤攻击 55% | 塞诅咒物 45% |

若试玩中压力不明显：

*   腐蚀武器提高到 40%。
*   塞诅咒物提高到 40%。
*   污染滤芯权重略提高，鼓励玩家主动承担毒性。

若试玩中过于恶心：

*   先降低 2 层节点数或群怪权重。
*   不优先削弱怪物特色动作，否则 2 层会退化成纯数值层。

当前自动化复测口径：

*   通关 1 层后，后续下潜直接从 2 层入口开始。
*   畸变融合体当前建议暂定为 `150 HP / 45 伤害 / 55%高伤 / 45%塞诅咒`。
*   该数值在 30 个 campaign 自动试玩中，二阶核心获得率约为 60%，能形成 2 层后续钩子，同时保留腐蚀、诅咒和背包取舍压力。

### 4.4 污染滤芯携带代价

**当前状态：** 【污染滤芯】已经配置 `ModifyResourceCost / OnDungeonMoveCost / SAN / AddFlat / 1`，方向正确。

```json
{
  "ConfigID": "loot_toxic_filter",
  "Tags": ["Toxic", "Mechanical"],
  "Combat": {
    "TriggerType": "Passive",
    "Effects": [
      {
        "EffectID": "ModifyResourceCost",
        "Level": 0,
        "Target": "Self",
        "Trigger": "OnDungeonMoveCost",
        "Resource": "SAN",
        "Operation": "AddFlat",
        "Params": [1]
      }
    ]
  }
}
```

MVP 口径：

*   `Toxic` 标签只做分类、展示和未来条件筛选，不直接触发扣 SAN。
*   真正的携带代价由 `ModifyResourceCost` 效果表达。
*   白盒试玩只需验证“带着污染滤芯进入新节点时，SAN 消耗确实 +1”。

### 4.5 安全区正式口径

安全区按 **免费全恢复** 处理，并作为正式版节奏节点保留。

当前口径：

*   安全区允许整理背包、使用消耗品、撤离或继续深入。
*   进入安全区后可以免费恢复 HP / SAN 到上限。
*   安全区不是成本点，而是深渊节奏缓冲和鼓励继续深入的奖励节点。
*   后续压力不压在安全区成本上，而应来自战斗损耗、背包空间、深层怪物机制、高价值战利品携带代价和局外长期经济压力。

## 7. 推荐配置调整顺序

### 批次 A：正式白盒试玩前

1.  拆出正式 MVP 初始配置，移除测试便利金币、核心、强武器。
2.  固定效果统一 `Level: 0`，确保 `Params` 即实际数值。
3.  清理物品职责标签：齿轮是材料，线圈是卖钱，滤芯是有毒高价战利品。
4.  确认 1 层 Boss 保底一阶核心。
5.  统一义体显示名为中文。

### 批次 B：2 层压力验证前

1.  战术长刀正式数值定稿。
2.  新增二阶污染核心。
3.  2 层 Boss 奖励表加入二阶核心保底。
4.  验收污染滤芯携带 SAN 代价是否生效。
5.  根据试玩反馈微调酸液腐蚀、塞诅咒物、污染滤芯权重。
6.  明确安全区免费全恢复规则，并把深渊压力转移到战斗、背包和深层机制上。

### 批次 C：表现接线前

1.  4 个怪物补齐 `PortraitID` 和必要的 `CombatVisualID`。
2.  检查物品图标、怪物头像、节点图标、背景图是否在 Registry 中可查。
3.  缺失资源统一回退到 `ui_missing_sprite`。

## 8. 配置验收口径

正式 MVP 配置完成后，应满足：

*   玩家从正式初始装出发，能完成 1 层下潜并面对真实资源压力。
*   击败 1 层 Boss 后，一阶核心必定出现。
*   玩家能通过卖出多余物品筹钱，并选择升级底盘或制造义体。
*   升级或义体至少有一种能在下一次战斗中被明显感知。
*   进入 2 层后，毒性、腐蚀、诅咒至少有一种压力能被玩家实际遇到。
*   击败 2 层 Boss 后，能获得二阶成长素材作为后续版本钩子。
*   玩家不依赖网状地图、出售保护、仓库转存，也能完成本阶段闭环。

当前状态：

*   自动化单轮验收已通过。
*   5 批稳定性验收已通过，共 150 个 campaign。
*   当前配置标记为 **MVP 白盒候选配置 v0.1**。
*   后续不再优先做机器侧大幅调参，除非真人白盒暴露明确卡点。

这份配置文档的核心原则是：**锁定 MVP 验证范围，少加内容，多校准职责、节奏和初始条件。**
