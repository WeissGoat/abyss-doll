# T1 第一层搜打撤成形

## 1. 时长定位

本文是 `30 分钟-2 小时` 的游戏设计细案，承接 `T0 序章首次循环` 留下的再次下潜理由、人偶状态、小镇资源状态和玩家对第一层的初始理解。

`T0` 让玩家知道“为什么要下去”；`T1` 要让玩家开始知道“进去以后怎么走、怎么打、怎么拿、什么时候撤”。这一段不是把第一层的节点网络、Boss、安全区、怪物、掉落逐条拆成验收点，而是把它们编排成一段玩家逐渐学会搜打撤的体验。

本段设计的核心句是：

```text
第一层不再是序章里的一次短遭遇，而是一片可以反复进入、可以选择路线、可以贪也可以撤的风险空间。
```

T1 结束时，玩家不需要完全理解经济、订单、构筑或长期日程；但玩家应该已经有过一次清楚的判断：这次我是为了某个目标下去，在第一层做了选择，也带着选择的结果回到小镇。

## 2. 核心设计命题

T1 的核心玩家问题是：

```text
我该走哪条路、捡什么、什么时候撤？
```

这句话背后有四个体验转变。

第一，深渊从“下潜按钮”变成“路线空间”。玩家要看到至少两种路线气质：更稳的路线和更诱人的路线。这里不需要复杂地图教学，但需要让玩家意识到节点不是按顺序播放，而是在邀请他承担不同风险。

第二，战斗从“赢了就好”变成“读懂意图后用有限资源应对”。怪物意图、AP、护盾、HP / SAN 消耗和背包状态要在低压环境中一起出现，让玩家第一次体会到战斗不是纯数值碰撞。

第三，战利品从“拿到奖励”变成“占用空间的选择”。战后掉落、宝箱或事件物都要让玩家面对：要不要为了它移动装备、消耗品或低价素材。

第四，撤离从“结束按钮”变成“保住结果的判断”。玩家可以因为状态差、包满、拿到高价值物或已经完成目标而选择回城；也可以因为状态还好、第二层露出或更深处的诱惑而想继续。

## 3. 玩家旅程

推荐的 T1 旅程分为七个连续片段。实现 Owner 后续可以调整具体节点、怪物、镜头和 UI 形式，但不应改变这些片段承担的体验功能。

### 3.1 带着上一轮结果再次准备

T1 开始时，玩家不是从零开始。他已经见过一次下潜、一次回城和一次小镇转化。新的准备阶段应承接 `T0` 的结果：

- 人偶状态可能恢复了一点，也可能因为上次消耗留下轻微问题。
- 小镇资源不够充裕，玩家仍然需要钱、材料或更明确的深渊物。
- 玩家知道第一层浅处能带回东西，但还不知道第一层内部如何规划路线。

准备阶段可以比序章多给一点信息，但仍保持克制。玩家应能看到当前人偶状态、背包空间、可带入的基础装备 / 消耗品、第一层入口和一个简单目标。

目标可以很朴素，例如：

- 再带回一批可卖材料。
- 找到能维护人偶的浅层部件。
- 尝试走到更深的第一层节点。
- 听到小镇传闻后寻找某类浅层物。

这里的重点不是让玩家做完整构筑，而是让他第一次带着“本轮目标”下潜。

### 3.2 第一次看懂第一层地图

进入第一层后，玩家应看到一张可读的浅层节点网络，而不是一串固定战斗。

地图应该让玩家一眼看懂当前所在位置、下一步能去哪里、不同节点大概意味着什么。早期只需要露出近距离信息：

- 当前节点完全可见。
- 下一行节点类型可见。
- 再远处可以用迷雾、轮廓或弱提示表达未知。

第一层建议至少出现两种路线感受：

- 安全路线：普通战斗、低风险事件或休息点更多，收益平稳。
- 冒险路线：精英、宝箱或未知事件更诱人，但会制造状态或背包压力。

玩家不需要马上理解所有地图规则，只要第一次产生“我可以不走那条危险路”的判断，就达到了 T1 的路线学习目标。

### 3.3 第一组可读战斗

T1 的第一组战斗应让玩家读懂战斗的基本语言。

怪物意图必须清楚，最好从简单攻击、防御或低压 SAN 干涉开始。玩家应能看到：

- 怪物下一步准备做什么。
- 自己当前有多少 AP。
- 武器、防具、消耗品如何改变本回合结果。
- 不应对意图会造成什么损耗。

这一段的战斗不追求难，而追求“可解释”。玩家打赢以后应该能说出原因：我抢杀了它、我挡住了攻击、我用了消耗品、我没有管它所以掉了血。

如果使用 `mob_scavenger_bug`、`mob_rust_hound` 或等价怪物，重点是让它们承担教学功能，而不是快速堆复杂机制。

### 3.4 第一次战后拾取和背包取舍

战斗胜利或事件结束后，玩家第一次面对稍微真实的拾取压力。

掉落物不应全部都是规整小件。T1 需要至少出现一种让玩家移动、旋转、放弃或暂时不拿的物品，例如长条武器、小型材料组合、L 形风险物或高价 2x2 遗物。

玩家在这一段应理解：

- 背包空间是收益上限。
- 战利品不是自动进账，拿不下就要放弃。
- 有些物品现在能卖钱，有些物品可能用于维护或后续成长。
- 高价值物如果占格大，会让之后战斗更危险。

这个片段的情绪不是惩罚，而是“刚好塞进去”的小小成就感，或者“我先不贪”的第一次自控。

### 3.5 中段路线选择开始有后果

走过 2-3 个节点后，玩家应开始感到第一层不是单条教程线。

此时可以出现更清楚的选择：

- 要不要绕开可见精英。
- 要不要走宝箱 / 事件路线。
- 当前 HP / SAN 是否支持再走一个节点。
- 背包已经快满时是否还要走高收益路线。

这里的设计重点是让玩家把路线、战斗和背包连起来。不是“精英节点更难”这么简单，而是：

```text
如果我去打精英，可能拿到更好的东西；
但我现在状态一般，背包也快满了；
如果打赢却塞不下奖励，或者打输丢掉新获物，上一轮收益就会变得很痛。
```

第一层精英应当可绕开。玩家选择绕开也应该被视为正确玩法，而不是错过内容。

### 3.6 第一次撤离 / 深入判断

T1 中后段要出现第一次明确的“保住结果还是继续贪”的节点。

如果玩家抵达第一层深处或层间安全点，画面和节奏应从紧张转为短暂安静。人偶可以放下背包，地图可以给出撤离和继续深入的选择，第二层入口可以以门、阶梯、雾后轮廓、陌生生态光或小镇传闻对应物的形式露出。

这一段不需要把第二层完整开放成新系统。它更像一次心理预告：

- 下面有更好的东西。
- 下面也会让背包和状态更吃紧。
- 现在带回去已经有收获。
- 如果继续，玩家是在主动冒险。

对谨慎玩家来说，T1 可以在撤离中成立；对贪心玩家来说，T1 可以在“我想再往下看一眼”的冲动中成立。两者都应该是合理体验。

### 3.7 回城后带回第一层经验

T1 的回城复盘不应只显示收益数字。它要让玩家看到第一层选择留下的差异。

可复盘的内容包括：

- 这次走了哪类路线。
- 拿回了哪些物品，哪些被放弃。
- 人偶状态比出发时怎样变化。
- 某个战利品、传闻或维护缺口如何成为下一轮目标。
- 第二层或更深第一层的线索是否被小镇或人偶提到。

这一段会把玩家推向 T2：小镇开始不只是处理结果，而是用账单、维护、出售、传闻和目标把下一轮下潜组织起来。

## 4. 系统自然开放设计

| 系统 | 30 分钟-2 小时出现方式 | 设计意图 |
|---|---|---|
| 深渊地图 | 第一层从短入口扩展为 5-6 行左右的浅层节点网络，至少有安全路线和冒险路线。 | 让玩家理解深渊是风险空间，不是线性关卡。 |
| 战斗 | 普通怪承担攻击 / 防御 / 低压意图教学，精英可作为可绕开的高收益压力。 | 让玩家读懂意图和 AP 决策，而不是只看输赢。 |
| 背包 / 战利品 | 战后拾取、旋转、放弃、保留装备和高价物占格开始出现。 | 把收益直接压到空间选择上。 |
| 撤离 / 深入 | 第一层深处或安全点给出保守回城与继续深入的对照。 | 让撤离成为主动选择，而不是流程结束。 |
| 小镇 | 仍以轻量复盘、出售、维护和传闻提示为主。 | 为 T2 的小镇压力机器做铺垫，不提前堆完整经济。 |
| 人偶状态 | HP / SAN / 磨损或情绪反馈随战斗、路线和撤离选择变化。 | 让玩家知道人偶不是无损工具。 |
| 日程 | 只表现一次下潜会占用时间或推进“今天”的状态。 | 让时间存在，但不在 T1 压完整周 / 月规则。 |
| 叙事反馈 | 用人偶短句、物品描述、第一层环境和小镇传闻回应玩家选择。 | 让路线和战利品带世界感。 |
| UI / 美术 | 地图节点、怪物意图、背包占格和撤离 / 深入选择必须可读。 | 让玩家看懂当前选择，而不是读大段说明。 |

## 5. 关键选择与压力

T1 的选择应该低压但真实。玩家第一次犯错可以付出小代价，但不应被长时间惩罚到失去继续意愿。

| 选择 | 玩家在想什么 | 好的结果 | 过度设计风险 |
|---|---|---|---|
| 走安全路线还是冒险路线 | 我现在状态够不够？奖励值不值得？ | 玩家主动绕开或挑战危险节点。 | 地图过早复杂，玩家只是在猜。 |
| 先攻击还是先防御 | 怪物下一步会打我吗？ | 玩家能用意图解释本回合选择。 | 怪物行为太多，意图读不懂。 |
| 拿战利品还是保装备 | 这个东西值不值得拆包？ | 背包整理成为收益选择。 | 全部物品都太小，取舍不存在。 |
| 用消耗品还是留着 | 现在回血 / 稳定 SAN 会不会腾出空间或保住收益？ | 消耗品成为未来空位和安全感。 | 消耗品太贵，玩家不敢用。 |
| 打精英还是绕开 | 我是否愿意为高收益承担风险？ | 绕开和挑战都成立。 | 精英不可绕，变成强制门槛。 |
| 撤离还是深入 | 我现在已经赚够了吗？ | 撤离带来安全感，深入带来贪婪。 | 第二层过早完全展开，压过 T1。 |

## 6. 剧情与情绪节奏

T1 的情绪曲线是“从紧张试探到第一次自我判断”。

建议节奏：

1. 从 T0 回城后的现实压力开始，而不是重新开新教程。
2. 让第一张地图显得比序章更大，但仍然可读。
3. 用普通战斗建立信心。
4. 用战利品占格打破“赢了就全拿”的直觉。
5. 用精英、宝箱或事件制造第一次路线诱惑。
6. 用撤离 / 深入选择让玩家第一次承认“我已经在冒险”。
7. 回城后用人偶反馈和小镇复盘证明这轮选择不是白做。

人偶反馈应短而具体。她可以因为状态好而想继续，也可以因为背包太满、SAN 下降或战利品带有不安气息而提醒玩家收手。

第一层视觉方向延续 `13` 的日系二次元地底奇幻冒险主轴。推荐感受是浅渊回廊、入口废墟、失落矿道、发光洞穴植物、潮湿石阶、少量旧工具和浅层腐蚀。旧工具可以作为局部语义出现，但不要把整体拉回黄铜、暖灯、蒸汽朋克或棕金机械主轴。

## 7. UI / 美术方向

T1 的 UI / 美术目标是“让玩家看懂选择”。

优先表达：

- 第一层地图节点类型和路线连线。
- 当前可选下一步，而不是整张地图的所有细节。
- 怪物意图、AP、HP / SAN 和关键防御反馈。
- 战利品形状、预估用途、风险标签和是否能放入背包。
- 撤离 / 深入选择的情绪差异。

避免：

- 用大段教程文本解释搜打撤。
- 让节点图标、怪物意图和物品标签同时堆满屏幕。
- 把第二层入口做成普通菜单按钮。
- 让战斗胜利后的拾取自动结算，绕开背包取舍。
- 把第一层视觉做成厚重机械工坊，而不是浅层地底奇幻空间。

## 8. 留给 T2 的状态与钩子

`T1` 结束时，`T2 2-5 小时：小镇压力与下潜目标成形` 应能承接以下设计状态：

- 玩家已经知道第一层有路线选择，不只是重复刷同一个节点。
- 玩家至少经历过一次战斗意图和背包取舍的共同压力。
- 玩家带回过一批有不同用途的物品：可卖物、材料、风险物或潜在展示物。
- 玩家见过撤离 / 深入的选择，知道继续冒险是主动承担风险。
- 玩家对第二层产生好奇，但还没有进入完整第二层压力。
- 小镇可以开始用传闻、账单、维护、材料缺口或基础订单重组下一轮目标。

T2 不需要重新教学“地图是什么”或“战利品为什么占格”；它应把重点转向“我为什么必须再下去，这次要带回什么”。

## 9. Owner 可创作空间

后续实现 Owner 可以根据现有工程、配置和 UI 状态决定：

- 第一层地图是标准 `layer1_tutorial_branching`，还是更轻的等价浅层地图。
- 第一组怪物使用哪只普通怪承担意图教学。
- 第一件制造背包取舍的战利品是长条武器、L 形材料、2x2 遗物还是宝箱物。
- 精英是作为可见节点、事件后选择，还是深处路线诱惑出现。
- 撤离 / 深入是在 Boss 后安全点、第一层深处传送门，还是等价的层间歇脚点表达。
- 第二层露出是视觉预告、传闻、阶梯、门、雾后生态，还是人偶反馈。

不应改变：

- T1 必须让玩家理解路线选择，而不是只打固定序列。
- 战斗意图和背包取舍都要成为玩家可感知的选择来源。
- 撤离 / 深入必须是玩家主动判断，而不是自动流程。
- 第二层露出只能作为下一阶段钩子，不应在 T1 抢完整第二层规则。
- 全局视觉仍以日系二次元地底奇幻冒险为主轴。

## 10. 实现承接提示

以下内容只作为后续实现 Owner 拆方案时的提示，不是本文主体：

- 第一层具体规则、节点网络、怪物、物品和安全区事实来源优先读取 `GDD_01`、`GDD_02` 和 `设计文档/content_packs/19_第一层正式核心内容包.md`。
- 已有配置或程序能力应先做证据审计；如果已有能力覆盖目标，只做缺口补强、UI 可达、真实服务绑定或表现补强。
- 实现方案可以拆具体地图、战斗、背包、撤离、第二层露出等切片，但不得把 T1 细案重新拆回 `T1-01 / T1-02 / T1-03` 式验收点主轴。
- 如果当前工程无法一次承接完整 T1，应优先保证“路线选择 -> 战斗可读 -> 战利品取舍 -> 撤离 / 深入判断 -> 回城复盘”这条玩家体验链不断。
