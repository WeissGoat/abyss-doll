# T0-01 序章首次循环

> V2 重规划：本文是 `0-30 分钟` 的游戏设计细案，回答玩家第一次进入游戏时具体经历什么。它不写开发任务包，不写程序类名，不把现有运行时条件通过当作完整序章通过。当前目标是重新立住商业化序章体验，再让 Owner 具体设计和开发方案按这个体验向下承接。

## 1. 本段定位

T0-01 承担正式版前 30 分钟的第一件事：让玩家在一次短循环里理解“她是谁、为什么要下去、下去会带回什么、回来为什么还想继续”。

这段不是功能教学集合，也不是把工坊、地下城、出售、维护全部一次性打开。玩家应该先经历一段对话式序章，再亲手启动零号，随后通过一次很短的浅层行动和回城照看，建立主循环的第一印象。

核心体验句：

```text
我把最后一点资源交给她，让她醒来；她还能陪我下去一次。
下去能带回活下去的东西，也会让她付出代价。
回来以后，我不只是更有钱了一点，也更清楚下一次为什么要下去。
```

本文上承 `13` 的按游戏时长横向切分和 `14` 的三层文档关系。下游开发入口固定为：

```text
T0-01_序章首次循环.md              -> 细案，定义完整 0-30 分钟玩家体验
T0-01_序章首次循环开发总方案.md      -> 完整 T0 开发总入口，拆 PRE / A / B / C / VAL
T0-01A_*                           -> A 段：开场到首次下潜许可
T0-01B_*                           -> B 段：第一层浅缘短遭遇到带回第一件东西
T0-01C_*                           -> C 段：回城照看到下一轮目标
T0-VAL-02_*                        -> 完整 T0 验收，待 A/B/C 可跑后新增
```

`T0-01A` 只覆盖“开场到进入第一层”。本细案还规划它之后的第一次浅层遭遇、第一件带回物和回城照看回声；这些后续内容应继续拆 `T0-01B / T0-01C` 等 Owner 具体设计，而不是塞回 T0-01A。`T0-VAL-01` 只保留为 A 段运行时效果验收记录，不再作为完整 T0 完成口径。

## 2. 体验原则

### 2.1 先处境，后系统

玩家开局看到的是破败工坊、债务、手记、最后一枚核心碎片和防尘布下的零号。前半段以过程 CG、镜头、环境音和短对白推进，不出现完整 HUD、调查点、功能按钮墙或系统菜单。

玩家第一次输入只发生在发现零号之后：

```text
[启动人偶]
```

这个输入不是普通确认按钮，而是玩家第一次承担关系：救她、押上最后资源、把序章从观看推入行动。

### 2.2 系统随情绪打开

每个系统第一次出现都必须有剧情理由。

| 系统 | 第一次出现的理由 |
|---|---|
| 人偶状态 | 零号苏醒后，她的核心和身体状态需要被理解。 |
| 整理 / 维护雏形 | 玩家先做一次很小的照看动作，让她能撑过一次浅层下潜。 |
| 浅层入口 | 手记、债务和零号的低语共同把入口变成当下唯一办法。 |
| 第一层确认 | 玩家要亲自决定是否让她下去，而不是被系统直接送入关卡。 |
| 战斗 / 事件 | 深渊必须用一次真实行动证明它会消耗状态。 |
| 战利品 | 带回物必须能连接钱、维护或记忆，不只是掉落列表。 |
| 小镇 / 回城 | 回城把结果转成压力、照看和下一轮目标。 |

### 2.3 第一次循环必须闭合

T0 不以“进入第一层”结束。进入第一层只是序章中段。真正的 T0 结束点是玩家完成一次浅层行动并回到工坊，看见结果对零号、小镇压力和下一轮目标产生影响。

T0 结束时，玩家至少应知道：

- 零号不是普通战斗单位，她需要照看。
- 深渊会带回钱、材料或记忆线索。
- 每次下潜也会消耗她的状态。
- 小镇会把深渊结果变成账单、维护和下一轮目标。
- 第一层还可以继续深入。

## 3. 0-30 分钟流程总览

| 段落 | 预计时长 | 玩家操作密度 | 体验功能 |
|---|---:|---|---|
| 1. 黑屏与破败工坊 | 0:00-1:00 | 无 | 先用声音和画面建立压力。 |
| 2. 债务、手记、核心碎片 | 1:00-3:00 | 无 | 交代今天必须行动、浅层有办法、资源只够一次。 |
| 3. 发现零号 | 3:00-4:30 | 无 | 让玩家真正看见她。 |
| 4. 启动零号 | 4:30-6:00 | 单按钮 | 玩家第一次输入，完成仪式感交互。 |
| 5. 苏醒与第一次照看 | 6:00-8:30 | 轻交互 | 开放状态小卡和整理动作。 |
| 6. 浅层入口与出发许可 | 8:30-10:00 | 主行动 + 确认 | 让下潜成为决定，而非跳关按钮。 |
| 7. 第一层浅缘短遭遇 | 10:00-18:00 | 少量战斗 / 事件操作 | 证明深渊会带回东西，也会消耗她。 |
| 8. 带回第一件东西 | 18:00-22:00 | 背包 / 取舍轻操作 | 把深渊结果和小镇用途连接起来。 |
| 9. 回城照看与下一轮目标 | 22:00-30:00 | 轻复盘 / 主行动 | 形成“下潜 -> 带回 / 消耗 -> 回城转化 -> 再下潜理由”。 |

节奏允许压缩，但不要删除第 9 段。没有回城照看，T0 就只剩“进第一层”的技术纵切，不是序章首次循环。

## 4. 段落设计

### 4.1 黑屏与破败工坊

开场黑屏，先听见旧工坊漏雨、机器空转、门外脚步和纸张从门缝滑入。字幕只出现一句：

```text
主角：又到早上了。
```

随后淡入工坊。画面不出现 HUD。构图优先让玩家看到：

- 防尘布下的人形轮廓。
- 门边催缴纸。
- 桌上的旧工匠手记。
- 工具匣里的核心碎片。
- 右后方半掩的深渊暗门。

玩家此时没有输入。不是因为“不能玩”，而是因为序章正在把玩家放进处境。

### 4.2 债务、手记、核心碎片

镜头自动带过三个信息点，每个信息点 3-6 秒。

债务纸只保留三行可读语义：

```text
工坊封存预告
今晚钟响前
可估价器械抵扣
```

主角短对白：

```text
主角：他们连坏掉的东西也收。
主角：不，他们最喜欢收坏掉的东西。
```

旧手记提示浅层晶核可暂时稳定魔偶核心，但不可替代长期修复。工具匣只剩干净核心碎片、绝缘带和旧钳子。玩家在这一段理解：今天必须做选择，且这个选择和防尘布下的人偶有关。

这一段不做调查点击。债务、手记、工具匣都是镜头语言，不是 point-and-click 教程。

### 4.3 发现零号

镜头扫过其他残件：断臂、烧坏核心仓、旧底盘、破损面部外壳。主角掀开防尘布，零号完整露出。

零号表现：

- 白布遮眼，灰披肩，简洁内衬。
- 核心灯几乎熄灭。
- 肩部和腿部有细裂线。
- 手保持抓握姿势，像在抓一段丢失的记忆。

主角对白：

```text
主角：没有第二台了。
主角：也没有第二个早上。
```

画面停在零号脸部和核心仓之间。玩家第一次输入出现。

### 4.4 启动零号

屏幕只出现一个动作：

```text
[启动人偶]
```

它必须有仪式感，不能像普通菜单按钮。按下后播放核心接入反馈：

- 主角把核心碎片推进核心仓。
- 核心灯从暗红转为微弱冷白。
- 工坊灯短亮一下，又熄掉一半。
- 环境音压低，只留下零号启动的细小声音。

这次点击消耗“最后一枚核心碎片”的叙事意义，但不要求 T0 立刻开放完整库存系统。实现上可以用剧情旗标或轻量状态承接；体验上玩家必须感觉自己把最后资源押给了她。

### 4.5 苏醒与第一次照看

零号苏醒对白要短，不像功能助手。

```text
零号：……这里……
零号：不是下面。

主角：你醒了？

零号：我还……能动。
零号：不要拆掉我。

主角：没人会拆你。

零号：他们会。
零号：你也会。等你没钱的时候。

主角：那就先别走到那一步。
```

对白后出现第一张状态小卡：

```text
零号
核心：不稳定
身体：多处裂纹
意识：断续
判断：无法长时间行动
```

状态小卡不是完整维护界面。它只是告诉玩家：她现在醒了，但不适合直接长期行动。

随后只开放一个整理动作：

```text
[擦去核心仓灰尘]
```

点击后小卡刷新：

```text
零号
核心：短时稳定
身体：多处裂纹
意识：断续
判断：可进行一次浅层下潜，返回后需要照看
```

短对白：

```text
零号：你手在抖。
主角：灰太多。
零号：你说谎的声音……很明显。
```

这一段让玩家第一次理解：照看她不是 UI 养成菜单，而是玩家和她之间的动作关系。

### 4.6 浅层入口与出发许可

整理完成后，远处钟声响起，催缴纸轻轻震动。主角把前面所有信息合成下潜理由。

```text
主角：浅层有稳定材料。
主角：带回来，能让你撑过今晚，也能让他们暂时闭嘴。

零号：如果带不回来？

主角：那就先带你回来。
```

深渊暗门亮起，半开放工坊 UI 第一次出现。

半开放工坊只允许：

- 零号作为画面主体。
- 状态摘要：`短时稳定 / 可浅层下潜一次`。
- 主行动：`浅层入口`。
- 角落压力：`今晚前`。

出售、完整维护、义体、底盘、订单、传闻、势力均不开放。灰态反馈统一保持一句：

```text
现在先让她撑过这一次。
```

点击 `浅层入口` 后进入首潜许可卡。

许可卡内容：

```text
第一层：旧矿井浅缘
可抵达

可能带回：
稳定核心碎屑 / 可售废料 / 记忆噪声

当前状态：
零号可行动一次，返回后需要照看。
```

按钮：

```text
[出发]
[再看她一眼]
```

`再看她一眼` 返回工坊，零号只说：

```text
零号：我还在。
```

点击 `出发` 后切黑 1 秒，工坊滴水声消失，深渊风声进入。

### 4.7 第一层浅缘短遭遇

第一次深渊要很短，但必须是真实可玩的深渊，不是结算插画。

推荐场景：旧矿井浅缘。画面有地下矿道、湿石阶、菌光、低矮晶簇和被根须包住的旧轨道。它是“浅层入口”，不是完整第一层大地图。

首次遭遇建议使用一个三步节点：

1. **听见声音**：零号停下，说下面有一段像自己的声音。
2. **低风险行动**：玩家选择接近、绕开或让零号试探。只开放 1-2 个行动，不展示完整复杂战斗菜单。
3. **小消耗换结果**：无论是短战斗还是事件，都要产生轻微状态变化和一个带回物。

可选遭遇形态：

| 形态 | 内容 | 适用 |
|---|---|---|
| 短战斗 | 1 个低威胁怪物，2-3 回合结束。 | 如果战斗系统已可承接。 |
| 事件 + 拾取 | 旧矿车旁有菌光材料，取走会造成轻微 SAN 或磨损压力。 | 如果想先强调照看与取舍。 |
| 战斗 + 事件混合 | 小怪挡在材料旁，击退后选择拿材料或拿可售物。 | 最符合首次循环目标。 |

第一次不要求玩家理解全部地图路线、背包旋转、怪物意图和撤离系统。只要求玩家理解：深渊行动会改变她，且会带回东西。

### 4.8 带回第一件东西

第一件带回物不应只是“金币 +1”。它必须暗示用途。

首件带回物建议三选一或组合：

| 物品 | 玩家理解 | 后续用途 |
|---|---|---|
| 稳定核心碎屑 | 这能让零号今晚稳定一点。 | 维护 / 照看。 |
| 可售废料 | 这能抵一部分债务。 | 出售 / 账单。 |
| 记忆噪声片 | 这东西和零号的“下面声音”有关。 | 记忆 / 剧情钩子。 |

如果需要背包教学，只做最低限度：

- 物品占一个小格或直接进入临时带回槽。
- 玩家只需要决定“带回稳定材料”还是“带回可售废料”。
- 不在 T0 第一次遭遇里展开完整背包旋转教学。

这一段最重要的是选择语义，而不是格子复杂度。

### 4.9 回城照看与下一轮目标

回城后先回到工坊，不直接进入大结算面板。玩家先看见零号坐回工作台或床边，核心灯比出发前更乱或更亮，取决于结果。

回城复盘使用三行结构：

```text
带回：稳定核心碎屑 x1
消耗：核心短时稳定下降
可处理：先照看她 / 先抵一部分债
```

然后给玩家一个明确但很轻的选择：

```text
[先照看她]
[先看催缴纸]
```

这不是正式出售 / 维护全系统开放，而是让玩家第一次看见回城结果的分叉。

#### 如果玩家先照看她

消耗稳定核心碎屑，让状态从：

```text
短时稳定，返回后需要照看
```

变为：

```text
今晚稳定，但不能连续下潜太久
```

零号反馈：

```text
零号：刚才的声音……还在。
零号：但没那么疼了。
```

下一轮目标：去第一层更远一点，找声音来源。

#### 如果玩家先看催缴纸

可售废料或浅层材料被估价，提示钱仍不够，但可以暂时抵一点。

```text
账面：还差很多。
备注：浅层物可以抵扣，但他们会压价。
```

零号反馈：

```text
零号：我可以再下去。
主角：先别急着证明这个。
```

下一轮目标：再下一次，找更值钱或更稳定的东西。

#### 如果带回记忆噪声片

零号短暂说出一个不完整词：

```text
零号：矿井……不是矿井。
零号：那里以前有灯。
```

下一轮目标：第一层更深处可能有她的记忆线索。

T0 的结尾不需要让玩家真正进入 T1 的完整第一层路线，但必须把动机交给 T1：更深一点、更有价值、更危险，也更接近她。

## 5. 系统开放边界

| 系统 | T0 开放程度 | 不开放内容 |
|---|---|---|
| 叙事播放 | 开场过程 CG、短对白、单按钮仪式交互、回城结果回声。 | 长分支对话、复杂选择树、长期事件队列。 |
| 人偶状态 | 状态小卡、短时稳定、回城后轻变化。 | 完整维护树、底盘、义体、特质构筑。 |
| 工坊 | 半开放工坊，只显示零号、状态、浅层入口和压力角标。 | 市场、订单、传闻、势力、完整房间编辑。 |
| 下潜许可 | 固定第一层许可卡。 | 多层地图列表、扫荡、自动编队。 |
| 第一层 | 只开放浅缘短遭遇。 | 完整节点网络、Boss、安全区、路线侵蚀。 |
| 战斗 / 事件 | 一次低风险真实行动。 | 完整怪物池、多怪协同、复杂意图教学。 |
| 背包 / 战利品 | 第一件带回物和轻取舍。 | 完整旋转背包、订单占格、战败归属。 |
| 出售 / 维护 | 回城复盘中的轻转化。 | 完整小镇经济、月租周报、维护方案列表。 |

## 6. UI / 美术方向

### 6.1 序章前半段

使用运行时漫画页 / 过程 CG。重点是让画面先讲故事：

- 黑屏醒来。
- 破败工坊。
- 催缴纸。
- 旧手记。
- 核心碎片。
- 防尘布下的零号。
- 启动人偶。

参考 `美术文档/19_T0-01序章CG细案.md` 的 6 页漫画结构。本文不要求重新定义 Panel VisualID，但要求它们服务 T0 体验：不要只是背景 + 对话框。

### 6.2 半开放工坊

工坊要按 Formal V2 的“低信息密度 + 主视觉 + 主行动”处理：

- 零号是视觉中心。
- 浅层入口是唯一高权重主行动。
- 债务压力在角落存在，但不压过零号。
- 其他系统入口不做按钮墙。

如果运行时仍出现 `AUTO / LOG`、调试感小按钮、厚金边、黄铜暖灯、密集横排字段，应视为最终商业化 polish 未完成。

### 6.3 第一层浅缘

第一层浅缘要有“可爱与危险并存”的地底奇幻气质。不要做成纯黑洞穴、工业矿井或灰色 UI 背景。

可用视觉元素：

- 菌光。
- 湿石阶。
- 旧矿车。
- 晶簇。
- 根须。
- 远处像呼吸一样亮灭的浅层门。

### 6.4 回城照看

回城画面不是普通结算页。它应回到工坊和零号身边，把带回物、消耗和下一步放在同一个情绪空间里。

## 7. 文案语气

序章文案要短、克制、有留白。不要把世界观解释成百科。

可用语气：

```text
她还撑得住。
这个能让她今晚稳定一点。
他们会压价，但至少能拖过今天。
再往里一点，也许有更干净的碎屑。
她说那下面有声音，像她自己的。
```

避免：

- “恭喜解锁维护系统”。
- “当前目标：收集材料 0/3”式任务面板主导开场。
- 长篇解释晶化病、魔偶技术、势力和订单。
- 让零号像教程助手一样说明规则。

## 8. T0 结束状态

T0 结束时，玩家状态应满足：

- 已亲手启动零号。
- 已看过她的初始状态小卡。
- 已完成一次轻照看或至少理解她返回后需要照看。
- 已进入第一层浅缘并完成一次短遭遇。
- 已带回至少一个有用途暗示的东西，或经历一次有意义的失败 / 放弃。
- 已回到工坊，看见结果对钱、维护或记忆产生影响。
- 已获得 T1 动机：更深一点的第一层、有更明确的材料 / 钱 / 记忆目标。

T0 不要求：

- 完整清债。
- 完整维护。
- 完整小镇经济。
- 完整第一层地图。
- 完整背包旋转教学。
- 多人偶选择。
- 订单 / 传闻 / 势力系统开放。

## 9. 后续 Owner 切片建议

后续开发统一先读 [T0-01 序章首次循环开发总方案](T0-01_序章首次循环开发总方案.md)。本文只保留体验方向，具体开发顺序、职能承接和验收边界由开发总方案维护。

当前已存在：

| Owner 设计 ID | 范围 | 状态 |
|---|---|---|
| `T0-01A` | 开场到首次下潜许可并进入第一层。 | 已有 Owner 具体设计和开发方案，运行时纵切条件通过，但不是完整商业封板。 |

建议后续新增 Owner 具体设计，而不是继续把所有内容塞进 T0-01A：

| `T0-01C` | 回城照看到下一轮目标。 | 工坊回声、照看 / 抵债轻选择、零号反馈和 T1 钩子。 |

`T0-01B / T0-01C` 需要先写 Owner 具体设计，再写开发方案。不要直接从本细案生成程序任务包。

## 10. 实现承接提示

实现 Owner 承接时应先判断目标切片属于：

- `T0-01A`：开场、启动零号、半开放工坊、首潜许可。
- `T0-01B`：第一层浅缘、短遭遇、首件带回物。
- `T0-01C`：回城复盘、照看 / 抵债轻选择、下一轮目标。

所有切片都必须保留本文的体验意图：

- 不把序章变回完整工坊功能页。
- 不用 UI 文字替代情绪和镜头。
- 不用条件通过的技术截图替代最终商业化体验。
- 不把回城照看省略成普通结算。
- 不让 T0 过早开放 T2 以后才该承担的订单、传闻、势力和完整经济系统。

如果工程现实要求删减，必须优先保留“启动她 -> 下去一次 -> 回来照看 -> 下一轮理由”的闭环。
