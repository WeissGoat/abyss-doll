# T0-01A 开局人偶状态到首次下潜许可实现设计

本文在三层文档关系中属于第二层 `Owner 具体设计`，上承 [T0-01 序章首次循环](T0-01_序章首次循环.md) 与 [T0-01 序章首次循环开发总方案](T0-01_序章首次循环开发总方案.md)，下接 [T0-01A 开局人偶状态到首次下潜许可开发方案](T0-01A_开局人偶状态到首次下潜许可开发方案.md)。本文只负责把“开局人偶状态到首次下潜许可”这一段设计到足够具体：镜头顺序、对白节奏、玩家第一次输入、UI 逐步开放、状态变化、阻断反馈和转场节奏。它不拆策划、美术 / UI、程序、配置 / 文案或验证工作包；这些内容放在开发方案中。

2026-07-11 文档重构后，本文只代表完整 T0 的 `A 段`，不得继续承接第一层浅缘短遭遇、首件带回物、回城照看或下一轮目标；这些内容应分别进入后续 `T0-01B` 与 `T0-01C`。

这一段从玩家第一次进入游戏开始，到点击“出发”进入第一层为止。开场前半段全部用过程 CG、画面和对白推进：没有调查点、没有选择轮廓、没有确认弹窗。玩家可以点击推进字幕和漫画页，但这只是叙事阅读操作；第一个会改变游戏状态的玩法输入，只发生在主角发现零号魔偶之后。画面停在她身上，出现唯一按钮 `启动人偶`。按下后零号苏醒，才逐步开放状态小卡、整理动作、浅层入口和第一层出发确认。

2026-07-11 封板候选版按 `T0-PRE-01..11` 锁定画面。后续美术、UI 和程序不再用“有这个节点”作为完成标准，而是要让以下 11 个画面在连续 Play 路径中按顺序成立。

## 1. 流程总览

```text
黑屏醒来
  -> 工坊过程 CG 建立处境
  -> 镜头带过债务 / 手记 / 工具匣
  -> 主角发现零号魔偶
  -> 玩家第一次输入：启动人偶
  -> 零号苏醒
  -> 状态小卡出现
  -> 玩家擦去核心仓灰尘
  -> 状态变为短时可行动
  -> 浅层入口亮起
  -> 第一层出发确认
  -> 点击出发，进入第一层
```

首次体验建议 6-9 分钟。前半段的核心是把玩家带入处境，不是让玩家点物件。唯一需要玩家亲手做的，是启动零号。

### 1.1 封板候选逐镜脚本

#### `T0-PRE-01` 黑屏醒来

- 画面：全黑，黑色不叠加边框、品牌标、进度条或 HUD。
- 声音顺序：漏雨 1.2 秒 -> 旧机器空转 -> 门外脚步停下 -> 纸从门缝摩擦进来。
- 字幕：脚步停下后出现 `又到早上了。`，屏幕下方居中，不显示姓名栏和对白框。
- 推进：本镜头为唯一自动离开的叙事镜头；字幕停留 1.5 秒后淡入工坊。
- 离开条件：纸张摩擦声完整播放，总时长控制在 4-6 秒。
- 禁止：“点击开始”、跳过按钮、LOG/AUTO、加载提示、任何功能入口。

#### `T0-PRE-02` 破败工坊全景

- 主画面：漫画页上方为工坊宽镜，工作台偏右，防尘布人形是暗中心；左侧门缝、催缴纸，右后方浅层暗门同时可读。
- 取景：相机保持人眼高度，不俯视成功能平面图；防尘布人形占宽度约 18%-24%，不先露出零号正脸。
- 播放：全景自下而上显露，雨光在窗边缓慢滑过；画面完整显示 1.5 秒后才出现字幕。
- 字幕：`窗缝里透进来的光，照不亮整间工坊。`
- 推进：默认不自动跳页；字幕完整显示后，右下角出现弱提示，点击进入债务纸特写。
- 禁止：可点轮廓、任务文字、底部大对白框、工坊按钮栏。

#### `T0-PRE-03` 债务纸特写

- 主画面：催缴纸和门缝占画面 45%-60%，纸角被风吹起，下方隐约露出布下手指。
- 可读内容：`工坊封存预告 / 今晚钟响前 / 可估价器械抵扣`，字在纸上是画面道具内容，不是 UI 列表。
- 对白：`他们连坏掉的东西也收。` -> 点击 -> `不，他们最喜欢收坏掉的东西。`
- UI：只使用窄幅透明字幕条，不显示头像、对白框底板、金币和账单列表。
- 声音：纸张颤动、远处钟摆空响；第二句后钟摆停半拍。
- 离开条件：第二句完成后点击，风吹起纸角，镜头被手记页的浅色纸面接走。
- 禁止：把债务纸做成桌面弹窗、红色警报卡、数值结算页。

#### `T0-PRE-04` 手记与核心碎片

- 主画面：两段同页漫画格。上格是旧工匠手记和被圈出的浅层晶核；下格是打开的工具匣，最后一枚干净核心碎片为唯一高亮。
- 手记文字：`浅层晶核可暂时稳定魔偶核心 / 不可替代长期修复 / 不可连续使用`。
- 对白节拍：`父亲写字从不写“也许”。` -> 点击切下格 -> `卖掉它，够一天。` -> 点击 -> `用掉它，也许够她醒一次。`
- 动画：手记页缓慢翻动，浅层暗门在页缘后闪一次冷光；核心碎片的微光照到画外的布下手指。
- UI：字幕条随漫画格位置避让，不使用背包格、物品卡和数量弹窗。
- 离开条件：第三句完成后点击，核心碎片光线引导视线回到工作台。
- 禁止：“选择卖出 / 使用”选项；此处还没有资源选择权。

#### `T0-PRE-05` 发现零号

- 主画面：三格连续动作。第一格扫开残件，第二格揭开防尘布，第三格停在零号的脸、蒙眼白布和几乎熄灭的核心仓。
- 零号占比：最后一格中零号上半身占画面高度 58%-72%，脸和核心仓不被字幕遮挡。
- 对白：`没有第二台了。` -> 点击 -> `也没有第二个早上。`
- 声音：揭布声后环境音被压低；只保留零号核心仓的微弱断续声。
- 推进：第二句后不再显示字幕提示，画面停留 0.6-1.0 秒，然后进入独立启动画面。
- 禁止：人偶选择列表、属性表、稀有度、角色详情、“是否启动”弹窗。

#### `T0-PRE-06` 启动零号

- 主画面：脱离漫画页黑底，进入全屏零号近景。脸部位于上三分之一，核心仓位于下三分之一，其余工坊细节压暗。
- UI：对白框完全收起；屏幕下方中央只出现 `启动人偶`，按钮与核心仓使用同一冷白光呼吸频率。
- 输入：此按钮是序章第一个改变游戏状态的交互；不加二次确认，不显示成本数字。
- 点击反馈：按钮文字淡出 -> 主角手将核心碎片推入仓体 -> 锁扣合拢 -> 暗红光熄灭 0.15 秒 -> 冷白光从中心扩散。
- 声音/灯光：插入声、两次失败般的短启动音、第三次心跳式低频；工坊灯短亮 0.2 秒后只留一半。
- 离开条件：零号手指轻微收紧，呼吸声成立，画面在她开口前停 0.8 秒。
- 禁止：按钮嵌在对白框里、同屏出现状态卡/浅层入口/AUTO/LOG、金色稀有度光柱、抽卡式角色获得演出。

#### `T0-PRE-07` 零号苏醒

- 主画面：零号从近景回到半身镜头，背后仍是真实工坊；眼部白布、表情和核心仓必须保持可见。
- 对白框：第一次出现正式角色对白框，宽度约为屏幕 64%-72%，位于下方安全区，高度不超过 24%；姓名签与框体相连，不另做悬浮小卡。
- 推进：默认手动点击，`AUTO` 默认关闭；文字完整显示前的第一次点击只完成文字，第二次点击才换句。
- 辅助控件：`LOG` 与 `AUTO` 使用小图标/短标签收在框体右上，低于姓名和台词层级；默认不显示 `AUTO OFF` 大字状态牌。
- 表情/小动作：`不要拆掉我` 时手指再收紧；`你也会` 时脸偏向主角声音来处；`像我的` 时核心灯出现一次异常脉冲。
- 离开条件：对白节点完成后框体淡出，镜头不切走，直接让状态小卡从零号身侧进入。
- 禁止：底部滚动长文、露出内部 node/key、对白中途弹教程或工坊功能热点。

#### `T0-PRE-08` 状态小卡与擦灰前

- 主画面：零号仍占画面主体；状态小卡在她身侧空白区滑入，不遮挡脸和核心仓。
- 卡片内容：只保留 `核心：不稳定`、`身体：多处裂纹`、`判断：无法长时间行动` 三行；`意识：断续` 作为角色表演，不再单独占一行。
- 行动：`擦去核心仓灰尘` 贴近核心仓与小卡之间，让按钮看起来在作用于她，不是一个菜单选项。
- 输入：擦灰按钮与对白继续完全分离；点击前浅层入口和其他功能不存在于交互层。
- 视觉状态：小卡用低饱和危险红只标核心行，不把整卡染红；边框细、软、不用厚金属框。
- 禁止：完整属性面板、HP/SAN 大数值、维护树、义体/底盘标签、教程弹窗。

#### `T0-PRE-09` 擦灰后短时稳定

- 动作：玩家点击后，主角的手和布从画面下方进入，三次短擦拭露出核心窗；不做持续拖拽或擦拭小游戏。
- 反馈：灰尘透明度下降，核心脉冲从断续变为均匀，零号肩部稍微放松。
- 卡片刷新：`核心：短时稳定`、`身体：多处裂纹`、`判断：可浅层下潜一次`；刷新只高亮变化行，不弹奖励。
- 对白：`你手在抖。` -> `灰太多。` -> `你说谎的声音……很明显。`，三句均手动推进。
- 转场：对白完成后，状态小卡缩成零号身边的摘要标签，钟声与催缴纸轻震同时发生，工坊空间开始开放。
- 禁止：“整理成功”、经验值、系统解锁清单、绿色全屏成功特效。

#### `T0-PRE-10` FormalV2 半开放工坊

- 空间布局：使用 FormalV2 `workshop_main` 房间骨架。零号和工作台占中心约 45% 的主视觉；右侧浅层暗门是唯一强入口；左侧工具/维护区和远处账本角落只做环境暗示。
- 顶部：只保留日期/时段与 `今晚钟响前` 轻压力，不出现完整货币、声望、订单或导航栏。
- 零号区：她的立绘/场景人物与背景同处一个空间，旁边只有 `短时稳定 / 可浅层下潜一次` 摘要；不做人物详情卡。
- 主行动：右侧暗门冷光增强，入口标签为 `浅层入口`，副文案 `她还能撑一次。`；整个门区是热区，不只是一个悬浮矩形按钮。
- 弱入口：维护台、出货台、账本保留空间轮廓，不用成排锁定卡；玩家尝试时只返回 `现在先让她撑过这一次。`
- 底部目标：窄条显示 `带零号去浅层，找到能稳定核心的东西。`，不使用任务列表和完成度。
- 验收读图：2 秒内先看到零号，再看到右侧暗门，最后才看到压力和灰态区。
- 禁止：左右各一块高饱和矩形信息牌、黑边画布、黄铜棕金主色、底部按钮菜单。

#### `T0-PRE-11` 首潜许可卡

- 转场入场：点击暗门后，工坊的 UI 先退场，镜头向门缝冷光推进；门打开一条缝后，许可文件从暗部滑入，而不是弹出通用层选择窗。
- 主构图：许可文件占画面 48%-58%，背后仍能读到暗门/井口和站在一侧的零号；文件、门和她是同一个出发仪式，不是三块独立面板。
- 固定文案：`第一层：旧矿井浅缘`、`许可：入口稳定，零号还能撑一次`、`可能带回：稳定核心碎屑 / 可售废料 / 记忆噪声`、`返回后需要照看`。
- 按钮：`出发` 为唯一强按钮，位于文件下方或门缝方向；`再看她一眼` 为弱文字按钮，靠近零号一侧。
- 返回：点击 `再看她一眼` 时，许可文件收起，回到同一个半开放工坊状态；零号说 `我还在。`，不重播擦灰和系统解锁。
- 出发：点击 `出发` 后，手动推进三句短对白，然后许可文件的封印光沿门缝扫过，画面切黑。
- 阻断：真实不可出发时，在许可文件的“许可”位置改成一句玩家语言，并把强按钮替换为对应回城行动；不另弹错误框。
- 禁止：多层列表、扫荡、自动编队、风险数值表、issue code、底部深色按钮横条。

## 2. 步骤 1：黑屏醒来

画面：黑屏。

声音：

- 旧工坊漏雨。
- 低频机器空转。
- 门外脚步停下。
- 纸从门缝塞进来。

字幕：

```text
主角：又到早上了。
```

不出现“点击继续”。黑屏自动进入工坊。

## 3. 步骤 2：工坊过程 CG 建立处境

淡入后没有完整 HUD，没有可点击物高亮。

构图：

- 中央偏右是防尘布盖住的人偶，露出一只手。
- 左侧门边有催缴纸。
- 桌上有旧工匠手记。
- 前景有工具匣。
- 右后方能看到深渊入口暗门轮廓，但不可点。

画面停 2 秒，让玩家先看工坊。随后镜头自动带过三个信息点。

## 4. 步骤 3：债务、手记、工具匣由镜头带过

这一段完全是过程 CG。每个信息点用 3-6 秒完成。

### 4.1 债务压力

镜头推到催缴纸。

纸上可读：

```text
工坊封存预告
今晚钟响前
可估价器械抵扣
```

主角对白：

```text
主角：他们连坏掉的东西也收。
主角：不，他们最喜欢收坏掉的东西。
```

催缴纸被风吹动，露出工作台上防尘布下的手指。

### 4.2 浅层修复线索

镜头移到旧工匠手记。

页面上圈出的笔记：

```text
浅层晶核可暂时稳定魔偶核心。
不可替代长期修复。
不可连续使用。
```

主角对白：

```text
主角：父亲写字从不写“也许”。
主角：所以浅层至少还有一点办法。
```

深渊暗门的缝隙短暂透出冷光，然后熄掉。

### 4.3 最后一枚核心碎片

镜头落到工具匣。主角打开匣子。

匣中内容：

```text
干净核心碎片 x1
绝缘带 x1
旧钳子 x1
```

主角对白：

```text
主角：卖掉它，够一天。
主角：用掉它，也许够她醒一次。
```

核心碎片的微光照到防尘布下的人偶手指。

## 5. 步骤 4：发现零号魔偶

镜头回到工作台。主角扫开周围残件：断臂、烧坏核心仓、旧底盘、破损面部外壳。这里仍然是 CG，不出现可点轮廓。

主角掀开防尘布。零号完整露出：

- 核心灯几乎熄灭。
- 肩部和腿部有裂线。
- 手保持抓握姿势。

主角对白：

```text
主角：没有第二台了。
主角：也没有第二个早上。
```

画面停在零号脸部和核心仓之间。此时出现开场第一个玩家输入。

## 6. 步骤 5：启动人偶

屏幕只有一个按钮：

```text
[启动人偶]
```

这个按钮同时承担：

- 确认救起零号。
- 使用最后一枚核心碎片。
- 完成核心接入并启动她。

除 `启动人偶` 外，不出现其他按钮或选项。

点击 `启动人偶` 后：

- 主角把核心碎片推进核心仓。
- 核心灯从暗红转为微弱冷白。
- 工坊灯短亮一下，又熄掉一半。
- 环境音压低，只留下零号启动声。

这是开场从过程 CG 转入可互动系统的门槛。

## 7. 步骤 6：零号苏醒

对白：

```text
零号：……这里……
零号：不是下面。

主角：你醒了？

零号：我还……能动。
零号：不要拆掉我。

主角：没人会拆你。

零号：他们会。
零号：你也会。等你没钱的时候。

主角：那就先别走到那一步。

零号：下面……有一段声音。
零号：很浅。
零号：像我的。
```

节奏：

- 零号句子之间保留短停顿。
- “你也会。等你没钱的时候。”后停 0.8 秒。
- 不在这一刻弹教程、属性表或地下城说明。

## 8. 步骤 7：第一次状态小卡

对白结束后，小型状态卡从零号身侧浮出。

初始内容：

```text
零号
核心：不稳定
身体：多处裂纹
意识：断续
判断：无法长时间行动
```

这是苏醒后的第一层 UI。它不是完整维护面板，只是让玩家理解她现在的状态。

## 9. 步骤 8：第一次整理

状态卡下方只开放一个动作：

```text
[擦去核心仓灰尘]
```

点击后：

- 主角用布擦开核心仓灰尘。
- 核心灯稳定一点。
- 状态卡刷新。

刷新后：

```text
零号
核心：短时稳定
身体：多处裂纹
意识：断续
判断：可进行一次浅层下潜，返回后需要照看
```

短对白：

```text
零号：你手在抖。
主角：灰太多。
零号：你说谎的声音……很明显。
```

这一刻以后，玩家才开始有“我能整理她、影响她状态”的感觉。完整维护、义体、底盘、背包深操作仍不开放。

## 10. 步骤 9：下潜理由合成

远处钟声响起。催缴纸角标轻轻震动。

主角对白：

```text
主角：浅层有稳定材料。
主角：带回来，能让你撑过今晚，也能让他们暂时闭嘴。

零号：如果带不回来？

主角：那就先带你回来。
```

右后方深渊暗门亮起，变成主行动。

主行动文案：

```text
浅层入口
她还能撑一次。
```

## 11. 步骤 10：半开放工坊 UI

此时才进入半开放工坊 UI。

可见内容：

- 零号仍是画面主体。
- 状态小卡收起成摘要：`短时稳定 / 可浅层下潜一次`。
- 主行动：`浅层入口`。
- 角落压力提示：`今晚前`。

不开放或灰态：

- 出售。
- 完整维护树。
- 义体 / 底盘。
- 订单 / 传闻 / 势力。

灰态反馈只写一句：

```text
现在先让她撑过这一次。
```

## 12. 步骤 11：点击浅层入口

玩家点击 `浅层入口`。

转场：

1. 工坊环境音降低。
2. 镜头从零号移到暗门。
3. 暗门打开一条缝，深渊风声进入。
4. 切到第一层出发确认。

不要直接进战斗。第一次出发必须有确认感。

## 13. 步骤 12：第一层出发确认

界面内容：

```text
第一层：旧矿井浅缘
状态：可抵达

可能带回：
稳定核心碎屑
可售废料
记忆噪声

同行状态：
零号可行动一次，返回后需要照看。
```

按钮：

```text
[出发]
[再看她一眼]
```

点击“再看她一眼”：

- 返回工坊半开放界面。
- 零号只说一句：

```text
零号：我还在。
```

点击“出发”：

```text
零号：下面比这里安静。
主角：那不是好事。
零号：我知道。
```

然后切黑，进入第一层。

## 14. 许可通过与阻断反馈

正常首次体验应通过许可。阻断只在真实状态不允许时出现。

### 14.1 通过态

按钮状态：

```text
[出发] 可点击
```

摘要：

```text
可进行一次浅层下潜。
返回后需要照看。
```

### 14.2 警告但可出发

如果状态较差但未硬阻断：

```text
她的状态不稳，但还能完成一次浅层下潜。
```

按钮仍可点击。

### 14.3 阻断态

| 阻断情况 | 玩家看到 | 按钮 |
|---|---|---|
| 没有可出战人偶 | 没有人能下去。 | 返回工坊 |
| 核心极端不稳定 | 她现在会在入口处失去意识。 | 先照看她 |
| 身体极端损坏 | 她的身体撑不住下潜。 | 先处理损伤 |
| 第一层入口异常 | 浅层入口无法确认。 | 返回工坊 |

阻断时不要显示内部 issue code，不要 fallback 到假成功或 debug 战斗。

## 15. UI 逐步开放表

| 时点 | 开放内容 | 不开放内容 |
|---|---|---|
| 黑屏 | 无输入，CG 自动推进 | HUD |
| 工坊建立 | 镜头演出 | 可点击调查物、完整按钮栏 |
| 信息带过 | 债务 / 手记 / 工具匣特写 | 背包、出售、订单 |
| 发现零号 | CG 掀布与停顿 | 人偶选择列表、确认弹窗 |
| 启动人偶 | `启动人偶` 单按钮 | 角色池、属性面板、额外确认选项 |
| 苏醒后 | 状态小卡 | 完整维护树 |
| 整理后 | 浅层入口主行动 | 义体、底盘、势力 |
| 点击入口 | 第一层确认 | 多层地图列表 |
| 出发确认 | 出发 / 再看她一眼 | 其他层、扫荡、自动编队 |

## 17. 转场节奏

### 17.1 黑屏到工坊

黑屏结束后自动淡入工坊，不立刻点亮 UI。

### 17.2 工坊到发现零号

镜头先带过债务、手记和工具匣，再回到工作台。主角掀布，画面停在零号身上。

### 17.3 启动人偶到苏醒

玩家点击 `启动人偶` 后，主角接入核心碎片，环境声压低，让零号第一句清楚出现。

### 17.4 苏醒到整理

状态小卡从她身边浮出，整理动作紧跟其后。玩家第一次轻系统操作从这里开始。

### 17.5 工坊到浅层入口

深渊入口从背景暗门变成主行动。重点是“门打开”，不是“地图功能解锁”。

### 17.6 出发确认到第一层

点击出发后切黑 1 秒，工坊滴水声消失，换成深渊风声。

## 18. 留给后续切片

本段到“进入第一层”为止。后续切片继续处理：

- 第一层第一场短遭遇。
- 第一次战利品。
- 背包第一次取舍。
- 回城后出售 / 修复 / 债务反馈。
- 零号对第一次结果的回声。

不要把这些内容塞回开场，否则序章会从“启动她”这个干净动作散成过长教程。

## 19. 实现备注

实现时可以复用现有工坊、层选择和下潜许可链路。关键是前半段不要做成多点调查或人偶选择 UI：债务、手记、工具匣、发现零号都由过程 CG 和对白完成；玩家的第一个输入只有 `启动人偶`。之后才逐步开放状态卡、整理和浅层入口。
