# T0-01A 开局人偶状态到首次下潜许可实现设计

本文在三层文档关系中属于第二层 `Owner 具体设计`，上承 [T0-01 序章首次循环](T0-01_序章首次循环.md)，下接 [T0-01A 开局人偶状态到首次下潜许可开发方案](T0-01A_开局人偶状态到首次下潜许可开发方案.md)。本文只负责把“开局人偶状态到首次下潜许可”这一段设计到足够具体：镜头顺序、对白节奏、玩家第一次输入、UI 逐步开放、状态变化、阻断反馈和转场节奏。它不拆策划、美术 / UI、程序、配置 / 文案或验证工作包；这些内容放在开发方案中。

这一段从玩家第一次进入游戏开始，到点击“出发”进入第一层为止。开场前半段全部用过程 CG、画面和对白推进：没有调查点、没有选择轮廓、没有确认弹窗。玩家第一次输入只发生在主角发现零号魔偶之后，画面停在她身上，出现唯一按钮 `启动人偶`。按下后零号苏醒，才逐步开放状态小卡、整理动作、浅层入口和第一层出发确认。

## 1. 流程总览

```text
黑屏醒来
  -> 工坊过程 CG 建立处境
  -> 镜头带过债务 / 手记 / 工具匣
  -> 主角发现零号魔偶
  -> 玩家第一次输入：启动人偶
  -> 零号苏醒
  -> 状态小卡出现
  -> 玩家擦去核心仓灰尘
  -> 状态变为短时可行动
  -> 浅层入口亮起
  -> 第一层出发确认
  -> 点击出发，进入第一层
```

首次体验建议 6-9 分钟。前半段的核心是把玩家带入处境，不是让玩家点物件。唯一需要玩家亲手做的，是启动零号。

## 2. 步骤 1：黑屏醒来

画面：黑屏。

声音：

- 旧工坊漏雨。
- 低频机器空转。
- 门外脚步停下。
- 纸从门缝塞进来。

字幕：

```text
主角：又到早上了。
```

不出现“点击继续”。黑屏自动进入工坊。

## 3. 步骤 2：工坊过程 CG 建立处境

淡入后没有完整 HUD，没有可点击物高亮。

构图：

- 中央偏右是防尘布盖住的人偶，露出一只手。
- 左侧门边有催缴纸。
- 桌上有旧工匠手记。
- 前景有工具匣。
- 右后方能看到深渊入口暗门轮廓，但不可点。

画面停 2 秒，让玩家先看工坊。随后镜头自动带过三个信息点。

## 4. 步骤 3：债务、手记、工具匣由镜头带过

这一段完全是过程 CG。每个信息点用 3-6 秒完成。

### 4.1 债务压力

镜头推到催缴纸。

纸上可读：

```text
工坊封存预告
今晚钟响前
可估价器械抵扣
```

主角对白：

```text
主角：他们连坏掉的东西也收。
主角：不，他们最喜欢收坏掉的东西。
```

催缴纸被风吹动，露出工作台上防尘布下的手指。

### 4.2 浅层修复线索

镜头移到旧工匠手记。

页面上圈出的笔记：

```text
浅层晶核可暂时稳定魔偶核心。
不可替代长期修复。
不可连续使用。
```

主角对白：

```text
主角：父亲写字从不写“也许”。
主角：所以浅层至少还有一点办法。
```

深渊暗门的缝隙短暂透出冷光，然后熄掉。

### 4.3 最后一枚核心碎片

镜头落到工具匣。主角打开匣子。

匣中内容：

```text
干净核心碎片 x1
绝缘带 x1
旧钳子 x1
```

主角对白：

```text
主角：卖掉它，够一天。
主角：用掉它，也许够她醒一次。
```

核心碎片的微光照到防尘布下的人偶手指。

## 5. 步骤 4：发现零号魔偶

镜头回到工作台。主角扫开周围残件：断臂、烧坏核心仓、旧底盘、破损面部外壳。这里仍然是 CG，不出现可点轮廓。

主角掀开防尘布。零号完整露出：

- 核心灯几乎熄灭。
- 肩部和腿部有裂线。
- 手保持抓握姿势。

主角对白：

```text
主角：没有第二台了。
主角：也没有第二个早上。
```

画面停在零号脸部和核心仓之间。此时出现开场第一个玩家输入。

## 6. 步骤 5：启动人偶

屏幕只有一个按钮：

```text
[启动人偶]
```

这个按钮同时承担：

- 确认救起零号。
- 使用最后一枚核心碎片。
- 完成核心接入并启动她。

除 `启动人偶` 外，不出现其他按钮或选项。

点击 `启动人偶` 后：

- 主角把核心碎片推进核心仓。
- 核心灯从暗红转为微弱冷白。
- 工坊灯短亮一下，又熄掉一半。
- 环境音压低，只留下零号启动声。

这是开场从过程 CG 转入可互动系统的门槛。

## 7. 步骤 6：零号苏醒

对白：

```text
零号：……这里……
零号：不是下面。

主角：你醒了？

零号：我还……能动。
零号：不要拆掉我。

主角：没人会拆你。

零号：他们会。
零号：你也会。等你没钱的时候。

主角：那就先别走到那一步。

零号：下面……有一段声音。
零号：很浅。
零号：像我的。
```

节奏：

- 零号句子之间保留短停顿。
- “你也会。等你没钱的时候。”后停 0.8 秒。
- 不在这一刻弹教程、属性表或地下城说明。

## 8. 步骤 7：第一次状态小卡

对白结束后，小型状态卡从零号身侧浮出。

初始内容：

```text
零号
核心：不稳定
身体：多处裂纹
意识：断续
判断：无法长时间行动
```

这是苏醒后的第一层 UI。它不是完整维护面板，只是让玩家理解她现在的状态。

## 9. 步骤 8：第一次整理

状态卡下方只开放一个动作：

```text
[擦去核心仓灰尘]
```

点击后：

- 主角用布擦开核心仓灰尘。
- 核心灯稳定一点。
- 状态卡刷新。

刷新后：

```text
零号
核心：短时稳定
身体：多处裂纹
意识：断续
判断：可进行一次浅层下潜，返回后需要照看
```

短对白：

```text
零号：你手在抖。
主角：灰太多。
零号：你说谎的声音……很明显。
```

这一刻以后，玩家才开始有“我能整理她、影响她状态”的感觉。完整维护、义体、底盘、背包深操作仍不开放。

## 10. 步骤 9：下潜理由合成

远处钟声响起。催缴纸角标轻轻震动。

主角对白：

```text
主角：浅层有稳定材料。
主角：带回来，能让你撑过今晚，也能让他们暂时闭嘴。

零号：如果带不回来？

主角：那就先带你回来。
```

右后方深渊暗门亮起，变成主行动。

主行动文案：

```text
浅层入口
她还能撑一次。
```

## 11. 步骤 10：半开放工坊 UI

此时才进入半开放工坊 UI。

可见内容：

- 零号仍是画面主体。
- 状态小卡收起成摘要：`短时稳定 / 可浅层下潜一次`。
- 主行动：`浅层入口`。
- 角落压力提示：`今晚前`。

不开放或灰态：

- 出售。
- 完整维护树。
- 义体 / 底盘。
- 订单 / 传闻 / 势力。

灰态反馈只写一句：

```text
现在先让她撑过这一次。
```

## 12. 步骤 11：点击浅层入口

玩家点击 `浅层入口`。

转场：

1. 工坊环境音降低。
2. 镜头从零号移到暗门。
3. 暗门打开一条缝，深渊风声进入。
4. 切到第一层出发确认。

不要直接进战斗。第一次出发必须有确认感。

## 13. 步骤 12：第一层出发确认

界面内容：

```text
第一层：旧矿井浅缘
状态：可抵达

可能带回：
稳定核心碎屑
可售废料
记忆噪声

同行状态：
零号可行动一次，返回后需要照看。
```

按钮：

```text
[出发]
[再看她一眼]
```

点击“再看她一眼”：

- 返回工坊半开放界面。
- 零号只说一句：

```text
零号：我还在。
```

点击“出发”：

```text
零号：下面比这里安静。
主角：那不是好事。
零号：我知道。
```

然后切黑，进入第一层。

## 14. 许可通过与阻断反馈

正常首次体验应通过许可。阻断只在真实状态不允许时出现。

### 14.1 通过态

按钮状态：

```text
[出发] 可点击
```

摘要：

```text
可进行一次浅层下潜。
返回后需要照看。
```

### 14.2 警告但可出发

如果状态较差但未硬阻断：

```text
她的状态不稳，但还能完成一次浅层下潜。
```

按钮仍可点击。

### 14.3 阻断态

| 阻断情况 | 玩家看到 | 按钮 |
|---|---|---|
| 没有可出战人偶 | 没有人能下去。 | 返回工坊 |
| 核心极端不稳定 | 她现在会在入口处失去意识。 | 先照看她 |
| 身体极端损坏 | 她的身体撑不住下潜。 | 先处理损伤 |
| 第一层入口异常 | 浅层入口无法确认。 | 返回工坊 |

阻断时不要显示内部 issue code，不要 fallback 到假成功或 debug 战斗。

## 15. UI 逐步开放表

| 时点 | 开放内容 | 不开放内容 |
|---|---|---|
| 黑屏 | 无输入，CG 自动推进 | HUD |
| 工坊建立 | 镜头演出 | 可点击调查物、完整按钮栏 |
| 信息带过 | 债务 / 手记 / 工具匣特写 | 背包、出售、订单 |
| 发现零号 | CG 掀布与停顿 | 人偶选择列表、确认弹窗 |
| 启动人偶 | `启动人偶` 单按钮 | 角色池、属性面板、额外确认选项 |
| 苏醒后 | 状态小卡 | 完整维护树 |
| 整理后 | 浅层入口主行动 | 义体、底盘、势力 |
| 点击入口 | 第一层确认 | 多层地图列表 |
| 出发确认 | 出发 / 再看她一眼 | 其他层、扫荡、自动编队 |

## 17. 转场节奏

### 17.1 黑屏到工坊

黑屏结束后自动淡入工坊，不立刻点亮 UI。

### 17.2 工坊到发现零号

镜头先带过债务、手记和工具匣，再回到工作台。主角掀布，画面停在零号身上。

### 17.3 启动人偶到苏醒

玩家点击 `启动人偶` 后，主角接入核心碎片，环境声压低，让零号第一句清楚出现。

### 17.4 苏醒到整理

状态小卡从她身边浮出，整理动作紧跟其后。玩家第一次轻系统操作从这里开始。

### 17.5 工坊到浅层入口

深渊入口从背景暗门变成主行动。重点是“门打开”，不是“地图功能解锁”。

### 17.6 出发确认到第一层

点击出发后切黑 1 秒，工坊滴水声消失，换成深渊风声。

## 18. 留给后续切片

本段到“进入第一层”为止。后续切片继续处理：

- 第一层第一场短遭遇。
- 第一次战利品。
- 背包第一次取舍。
- 回城后出售 / 修复 / 债务反馈。
- 零号对第一次结果的回声。

不要把这些内容塞回开场，否则序章会从“启动她”这个干净动作散成过长教程。

## 19. 实现备注

实现时可以复用现有工坊、层选择和下潜许可链路。关键是前半段不要做成多点调查或人偶选择 UI：债务、手记、工具匣、发现零号都由过程 CG 和对白完成；玩家的第一个输入只有 `启动人偶`。之后才逐步开放状态卡、整理和浅层入口。
