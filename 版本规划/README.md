## 已移除的重复文档

`10_正式版核心纵切版本节点规划.md` 已删除，不再维护。

删除原因：旧 `10` 和 `09` 的阶段 / 优先级、`11` 的 GDD 批次关系高度重复，容易造成版本规划互相抢事实来源。后续需要判断宏观优先级时维护 `09`；需要判断某份 GDD 的批次、完成口径和需求承接时维护 `11`；需要拆长期版本节点和各职能阶段产出时维护 `12`。

原 `12_版本规划需求文档承接审计.md` 已合并进 `11_纵切批次与需求文档承接矩阵.md`，不再单独维护。现在的 `12_正式版长期版本节点规划.md` 只负责长期里程碑和各职能节点工作，不替代 `09` 的宏观优先级或 `11` 的需求承接门禁。

## 归档文档

旧 MVP 规划文档已移动到：

```text
版本规划/_archive/mvp_2026-05/
```

归档文档只用于追溯 MVP 阶段验证过程、旧调参依据和自动化试玩复盘。它们不是当前开发目标，也不覆盖当前 GDD、`09` 路线、`11` 承接矩阵或 `12` 节点规划。

## 判断顺序

如果文档之间发生冲突，按以下顺序判断：

```text
当前 GDD 具体规则 > 09 正式版宏观路线 > 11 批次与需求承接矩阵 > 12 长期版本节点规划 > 状态页 > 归档 MVP 文档
```

状态页用于记录当前事实和交接，不承载完整系统规则；具体规则仍回到 GDD、开发文档、美术文档或配置 README。
