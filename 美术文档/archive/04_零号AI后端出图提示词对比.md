# 零号AI后端出图提示词对比

> 历史定位：本文保留 2026-07 的零号初版三后端提示词实验、批次结果和母版选择依据，仅用于追溯。当前图片生成 / 编辑由 `generate-image` Skill 决策，正式角色立绘生产由 `p3-art-asset-production` Skill 和 `美术文档/人设/05_零号立绘素材设计与交付清单.md` 承接；本文不再作为执行入口。

## 1. 批次目标

- 每个后端各出 3 张。
- 统一尺寸：`832x1216` 竖版角色设定图。
- 统一角色要求：白布遮眼、灰披肩完整覆盖双肩、简单超短内衬裙、裸腿裸足、娇小可爱但非儿童化、轻微人偶关节、少量灰尘磨损、核心仓不可见、初始三无 / 冷感。
- 禁止：黑眼罩、2B 服装 cosplay、粉披肩、紫裙、乞讨牌、胸前装饰、外露核心、半边露肩、成熟高挑御姐比例、靴子、高跟、重机械、血腥、幼态色情、文字水印。
- 新一轮以第一轮 ChatGPT 组立绘为概念图气质基准；Gemini 必须白背景纯人设图，NovelAI 必须重点修正披肩不完整和人物偏成熟的问题。

## 2. 后端策略

| 后端 | Provider | 策略 |
|---|---|---|
| ChatGPT / GPT image | `openai_images` | 以第一轮 ChatGPT 组立绘为概念气质，保留精修概念图质感和灰披肩体块。 |
| Gemini / nanobanana | `gemini_chat_image` | 改成白背景纯人设图，明确禁止复杂场景、房间和多角色。 |
| NovelAI | `novelai` | 用标签化 prompt + 原生 negative prompt 强化完整灰披肩、娇小可爱比例和非露肩。 |

.\tools\美术工具\Generate-ZeroPrototypeBackendBatch.ps1 -Only gemini_nanobanana -Count 1
