# T0-01 序章 CG 细案

> 定位：本文是 T0-01 序章的美术侧 CG 细案，承接 `18_CG底图与漫画式播放演出工作流.md` 的运行时漫画页拼装方案。它不替代 T0-01 玩法细案、剧情对白事实来源或程序开发方案，只回答“序章 CG / 背景 / 漫画分格应该画什么、怎么生产、怎么验收”。

## 1. 目标

T0-01 序章 CG 的任务不是把世界观讲完，而是在玩家第一次操作前建立三件事：

- 玩家身处一个快被收走的破败工坊。
- 零号是坏掉但仍想行动的人偶，不是普通战斗单位。
- 第一次下潜是当下唯一可行的办法，而不是系统教程按钮。

核心观感：

```text
安静的压力 -> 看见零号 -> 把最后资源交给她 -> 她醒来 -> 她还能下去一次
```

美术上要让玩家先被画面和留白带入，再看到极少量 UI。序章第一段应像一组可播放漫画页，而不是背景图上叠对白框。

## 2. 范围

### 2.1 本文负责

- T0-01A 开场前 3-5 分钟漫画式 CG 页分镜。
- 每页 `PageID`、`LayoutPreset`、Panel 主题、Panel VisualID 和 reveal 顺序。
- 每格构图、安全区、风格关键词、禁用项和 AI 出图要求。
- 运行时字幕条、关键按钮和半开放工坊过渡的美术验收口径。
- 后续进入 Manifest、Prompt、Approved、Registry 和截图验收的交接边界。

### 2.2 本文不负责

- 不重写 T0-01 完整 0-30 分钟玩法细案。
- 不重写最终对白文本，只给字幕功能位和美术语气约束。
- 不定义下潜战斗、战利品、回城结算的完整规则。
- 不声明 Panel 已生成、Approved、接入或验收通过。
- 不把文字烘焙进图片。

## 3. 总体播放结构

序章 CG 使用运行时拼页：

```text
NarrativeNode
  -> ComicPage(PageID)
  -> LayoutPreset
  -> Panel VisualID 列表
  -> RevealIndex 逐格显现
  -> 底部字幕条
  -> 关键页出现单按钮 Action
  -> 退出漫画页，进入真实半开放工坊 UI
```

首批只做 6 页，证明语法成立：

| PageID | 目标 | 交互 |
|---|---|---|
| `t0_01a_p01_black_wake` | 黑屏醒来，先用声音和一句短旁白建立压力。 | 自动 / 继续 |
| `t0_01a_p02_workshop_establish` | 看到破败工坊、催缴纸和防尘布下的手。 | 无 |
| `t0_01a_p03_debt_pressure` | 明确今天的债务压力和工坊会被抵扣。 | 无 |
| `t0_01a_p04_repair_clue` | 明确浅层材料、暗门和最后一枚核心碎片。 | 无 |
| `t0_01a_p05_find_no0` | 掀开布，零号成为画面焦点。 | 无 |
| `t0_01a_p06_start_no0` | 玩家第一次输入：启动零号。 | `启动人偶` |

`p06` 后不继续做长 cutscene，应转入零号苏醒、状态小卡、擦灰、浅层入口和首次下潜许可的半开放工坊流程。

## 4. 分页细案

### 4.1 `t0_01a_p01_black_wake`

玩家感受：还没看到画面，先听见工坊像一个快坏掉的身体。

版式：`single_wide` 或纯黑页。可以没有 Panel 资产，也可以用极暗环境底图。

字幕功能位：

```text
主角：又到早上了。
```

声音 / 节奏建议：

- 雨声落进金属盆。
- 旧设备低频空转，时响时停。
- 门外脚步停下，纸张从门缝滑进来。

美术验收点：

- 黑屏不是加载感，要有字幕安全区和可控停顿。
- 不出现菜单、Logo、教程提示或系统按钮堆叠。

### 4.2 `t0_01a_p02_workshop_establish`

玩家感受：这里是玩家今天必须撑住的地方，零号已经在画面里，但还没被正式看见。

LayoutPreset：`wide_top_two_bottom`

| Reveal | Slot | VisualID | 画面要求 |
|---|---|---|---|
| 1 | `top_wide` | `cg_t0_01a_p02_panel01_workshop_wide` | 破败工坊远景。旧工作台偏右，防尘布下的人形轮廓是中心；左侧门缝有纸，右后方有浅层暗门轮廓。 |
| 2 | `bottom_left` | `cg_t0_01a_p02_panel02_debt_notice_door` | 门缝纸张滑入，湿边、冷光、纸面不要出现可读乱字。 |
| 3 | `bottom_right` | `cg_t0_01a_p02_panel03_no0_hand_cloth` | 防尘布下露出零号的手，手指像在抓一段失去的记忆。 |

字幕功能位：

```text
主角：他们连坏掉的东西也收。
```

构图要求：

- 工坊整体偏冷、潮湿、安静，不走黄铜暖灯蒸汽朋克。
- 零号轮廓必须在首屏就埋入画面，不能像随机背景物。
- 画面信息量克制，玩家一眼读到“工坊、催缴、布下有人形”。

### 4.3 `t0_01a_p03_debt_pressure`

玩家感受：今天不是普通的一天，玩家没有充裕选择。

LayoutPreset：`wide_top_two_bottom`。如果后续新增 `three_focus` preset，可以切换为三焦点页。

| Reveal | Slot | VisualID | 画面要求 |
|---|---|---|---|
| 1 | `top_wide` | `cg_t0_01a_p03_panel01_debt_notice_close` | 催缴纸近景，只保留“封存 / 今晚 / 抵扣”的语义，不画随机文字。 |
| 2 | `bottom_left` | `cg_t0_01a_p03_panel02_collateral_shadow` | 可被抵扣的旧机器阴影，像沉默的威胁。 |
| 3 | `bottom_right` | `cg_t0_01a_p03_panel03_broken_parts` | 工作台残件和断线，暗示已经没有第二台可用人偶。 |

字幕功能位：

```text
主角：不，他们最喜欢收坏掉的东西。
```

美术验收点：

- 债务纸是镜头特写，不是 UI 小卡。
- 不把长文案烘进图里；纸上可用形状、印章、粗线和留白表达。
- 压力要安静，不要做成夸张恐怖或黑色幽默警匪感。

### 4.4 `t0_01a_p04_repair_clue`

玩家感受：不是绝望到底，还有一个很窄、很危险的办法。

LayoutPreset：`four_panel_focus` 或 `wide_top_two_bottom`

| Reveal | Slot | VisualID | 画面要求 |
|---|---|---|---|
| 1 | `top_left` | `cg_t0_01a_p04_panel01_repair_note_close` | 旧手记页，圈出浅层晶核线索；不要出现 AI 乱字。 |
| 2 | `top_right` | `cg_t0_01a_p04_panel02_shallow_gate_glow` | 工坊暗门缝隙透出冷光，像地下在呼吸。 |
| 3 | `bottom_wide` | `cg_t0_01a_p04_panel03_core_shard_box` | 工具匣中最后一枚核心碎片，微光照到布下人偶。 |

字幕功能位：

```text
主角：浅层至少还有一点办法。
```

构图要求：

- 三个信息点要连成因果：手记提示浅层，暗门证明入口，核心碎片证明还能启动一次。
- 核心碎片是道具特写，不是发光 UI 图标。
- 色彩以冷白、灰蓝、低饱和菌光为主，少量核心微光作为焦点。

### 4.5 `t0_01a_p05_find_no0`

玩家感受：玩家终于真正看见“她”，而不是看见一个任务道具。

LayoutPreset：`left_tall_right_stack`

| Reveal | Slot | VisualID | 画面要求 |
|---|---|---|---|
| 1 | `left_tall` | `cg_t0_01a_p05_panel01_broken_doll_parts` | 断臂、烧坏核心仓、旧底盘等残件扫过，说明没有第二台人偶。 |
| 2 | `right_top` | `cg_t0_01a_p05_panel02_no0_half_reveal` | 掀开防尘布后零号半身。白布遮眼、灰披肩、简洁内衬轮廓，脆弱但干净。 |
| 3 | `right_bottom` | `cg_t0_01a_p05_panel03_no0_core_dim` | 核心仓弱光近景，被披肩或破损边缘半遮住。 |

字幕功能位：

```text
主角：没有第二台了。
```

零号表现要求：

- 必须符合当前初版人设方向：白布遮眼、灰披肩、简洁短内衬、裸足 / 下半身留白、人偶关节轻微可见。
- 她不能像战斗机甲、性感机器人、恐怖人偶或赛博义体。
- 核心仓只在演出需要时显露，平时由披肩遮住。

### 4.6 `t0_01a_p06_start_no0`

玩家感受：第一次输入不是“开始游戏”，而是把最后资源交给零号。

LayoutPreset：`two_top_wide_bottom`

| Reveal | Slot | VisualID | 画面要求 |
|---|---|---|---|
| 1 | `top_left` | `cg_t0_01a_p06_panel01_no0_close` | 零号脸部和上半身近景，白布遮眼，表情克制，画面安静。 |
| 2 | `top_right` | `cg_t0_01a_p06_panel02_core_insert` | 核心碎片接入核心仓，主角手部可入镜但不抢焦点。 |
| 3 | `bottom_wide` | `cg_t0_01a_p06_panel03_core_wake` | 核心由暗红 / 熄灭转为微弱冷白，工坊灯短亮一下。 |

Action：

```text
启动人偶
```

字幕功能位：

```text
主角：那就先别走到那一步。
```

交互验收点：

- 这一页只能出现 `启动人偶` 一个动作按钮。
- 按钮不能像普通菜单按钮，需有仪式感和明确安全区。
- 点击后继续播放核心启动反馈，再退出到苏醒对白 / 状态小卡流程。

## 6. 视觉方向

### 6.1 正向关键词

- 日系二次元地底奇幻冒险。
- 低信息密度、清晰剪影、安静的压迫感。
- 冷雨、灰蓝工坊、菌光 / 晶核微光。
- 破旧但干净的手作空间，不是工业废墟。
- 零号脆弱、克制、被照看的存在感。

### 6.2 禁用方向

- 不用黄铜、厚金边、暖灯、蒸汽朋克作为默认主轴。
- 不做都市 noir、警匪、犯罪漫画口吻。
- 不做低多边形、写实照片、恐怖娃娃、重装机甲。
- 不出现随机文字、水印、签名、AI 乱码。
- 不把对白、旁白、按钮、教程文字烘焙进图片。
- 不让 UI 面板感压过画面叙事。

### 6.3 零号一致性

零号在 CG 中必须服从当前人设事实：

- 白布遮眼，而不是 2B 原样眼罩。
- 灰披肩 + 简洁短内衬裙，胸前无复杂装饰。
- 裸腿 / 裸足 / 下半身留白，轻微人偶关节。
- 初始情绪冷感、安静、三无，不卖萌，不夸张表情。
- 核心仓平时半遮，启动或维护镜头才显露。

## 7. 出图规格

| 项 | 规格 |
|---|---|
| 单 Panel 源格式 | PNG |
| 推荐源尺寸 | `1920x1080` |
| 最低临时尺寸 | `1280x720`，仅限开发 fallback |
| 图片文字 | 禁止烘焙对白、旁白、按钮、教程文字 |
| 背景透明 | 禁止透明黑洞；场景 Panel 默认不透明 |
| 裁切适配 | 运行时 `cover` |
| 安全区 | 关键主体在中心 4:3 区域 |
| 字幕 | 运行时字幕条，不写入图片 |
| 变体数量 | 每个 VisualID 至少 3-4 张候选 |

AI prompt 只写画面，不写玩法黑话或项目名。示例：

```text
anime style underground fantasy workshop, cinematic comic panel, low visual noise, cold rain light, old workbench, dust cloth covering a fragile doll silhouette, clear composition, no text, no watermark
```

## 8. 运行时验收

### 8.1 截图清单

首批至少需要 6 张运行时截图：

| 截图 | 必须证明 |
|---|---|
| `t0_comic_p01_black_wake.png` | 黑屏 / 字幕安全区 / 节奏成立。 |
| `t0_comic_p02_workshop_establish.png` | 三格读图顺序成立，工坊和零号轮廓清楚。 |
| `t0_comic_p03_debt_pressure.png` | 债务压力像镜头，不像 UI 小卡。 |
| `t0_comic_p04_repair_clue.png` | 手记、暗门、核心碎片因果清楚。 |
| `t0_comic_p05_find_no0.png` | 零号成为画面焦点，符合人设。 |
| `t0_comic_p06_start_no0.png` | 只出现 `启动人偶` 一个动作按钮。 |

### 8.2 失败条件

- 任一 Panel missing sprite、蓝屏、空白或比例严重错误。
- 字幕条遮挡零号脸部、核心仓或关键道具。
- CG 看起来仍是背景图 + 对话框，而不是漫画分格播放。
- `启动人偶` 页出现多个无关按钮。
- 画面风格滑向黄铜暖灯蒸汽朋克、警匪 noir 或恐怖娃娃。
- 播放结束不能进入真实半开放工坊 / 首潜许可流程。

## 9. 完成口径

| 层级 | 可声明内容 |
|---|---|
| 规格完成 | 本文档、Page、Panel VisualID、构图要求和验收口径已确定。 |
| 素材完成 | Panel 已进入 Approved，清单和快照已刷新。 |
| 接入完成 | VisualID 已登记，运行时漫画页能加载和逐格显示。 |
| 验收通过 | 截图 / Play 路径证明序章 CG 可按目标播放并进入真实 T0 流程。 |

当前本文完成后只能声明 `规格完成`。不得把本文档完成写成 `T0 序章商业 CG 完成`、`素材完成` 或 `运行时验收通过`。

## 10. 下一步建议

1. 将本文 Panel VisualID 写入 `art_requirements_seed.json` 或等待专用叙事 CG 配置源承接。
2. 刷新 Manifest 和 Prompt，先处理 P0 Panel。
3. 生成每个 Panel 的 3-4 张候选，并制作单页 contact sheet。
4. 先按页筛选，不只按单图好看筛选。
5. Approved 后刷新可接入素材清单和快照。
6. 程序侧接入运行时漫画页后，按第 8 节截图清单做人工美术验收。
