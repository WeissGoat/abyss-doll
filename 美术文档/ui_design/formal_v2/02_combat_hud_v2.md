# Combat HUD Formal V2 方案

> **状态：** 设计入口已建立。本文用于锁定 `combat_hud` 的 Formal V2 审查范围；在用户确认完整方案并迁移到 active 前，不作为程序或素材生成规格。

## 待解决问题

`combat_hud` Formal V1 已改成左玩家、右敌人实体和底部背包，但仍需要进一步正式化：

* 战斗舞台必须压过面板感。
* 怪物意图、玩家状态和背包行动应按回合决策组织。
* 行动按钮不能成为主视觉，背包指令区才是核心玩法。
* 敌人血条、状态、意图和受击反馈需要围绕实体布置。
