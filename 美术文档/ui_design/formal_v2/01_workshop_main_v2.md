# Workshop Main Formal V2 方案

> **状态：** 设计入口已建立。本文用于锁定 `workshop_main` 的 Formal V2 审查范围；在用户确认完整方案并迁移到 active 前，不作为程序或素材生成规格。

## 待解决问题

`workshop_main` 当前 Formal V1 已有工坊区域划分，但运行时表现仍容易退化成按钮菜单。Formal V2 需要把它改成正式 Hub：

* 深渊入口是主行动。
* 魔偶维护舱、工作台、市场 / 账本区是空间入口。
* 出售、维护、义体、订单、传闻、账单不再作为同等级按钮堆叠。
* 背包和底盘工作台保留 100x100 玩法格。
