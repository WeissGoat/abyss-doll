# Inventory Loot Formal V2 方案

> **状态：** 设计入口已建立。本文用于锁定 `inventory_loot` 的 Formal V2 审查范围；在用户确认完整方案并迁移到 active 前，不作为程序或素材生成规格。

## 待解决问题

`inventory_loot` Formal V2 需要从拾取弹窗升级为撤离清点界面：

* 玩家核心目标是决定哪些战利品带走。
* 背包容量压力应成为主信息，而不是附属文字。
* 战利品缓存、背包和详情区要形成明确比较关系。
* 确认带出是唯一主行动。
