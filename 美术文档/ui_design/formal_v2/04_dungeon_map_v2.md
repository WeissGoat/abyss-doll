# Dungeon Map Formal V2 方案

> **状态：** 设计入口已建立。本文用于锁定 `dungeon_map` 的 Formal V2 审查范围；在用户确认完整方案并迁移到 active 前，不作为程序或素材生成规格。

## 待解决问题

`dungeon_map` Formal V2 需要从节点按钮图升级为路线决策界面：

* 玩家核心目标是选择下一步路线。
* 节点风险、奖励预期、已探索状态和战争迷雾要清楚分层。
* 选中节点详情和进入节点主行动需要绑定。
* 背包整理入口必须降级，不能和进入节点等权。
