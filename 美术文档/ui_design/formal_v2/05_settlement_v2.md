# Settlement Formal V2 方案

> **状态：** 设计入口已建立。本文用于锁定 `settlement` 的 Formal V2 审查范围；在用户确认完整方案并迁移到 active 前，不作为程序或素材生成规格。

## 待解决问题

`settlement` Formal V2 需要从结果面板升级为撤离 / 战斗报告：

* 胜利、HP 战败、SAN 崩溃等结果要有明确情绪和风险表达。
* 收益、损失、遗失和带出物要分层。
* 下一步主行动应清楚，例如返回工坊或进入账本。
* 时间线 / 复盘信息应可读但不压过结果。
