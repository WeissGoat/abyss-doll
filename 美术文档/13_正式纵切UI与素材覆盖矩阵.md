# 正式纵切 UI 与素材覆盖矩阵

> **定位：** 把 `09` 路线和 `11` 批次矩阵翻译成美术侧 UI / 素材覆盖表。目标是先把需要的 UI 设计纳入系统，再按 Manifest 流程生产素材。

---

## 1. 当前覆盖结论

截至 2026-05-24，active `screen_layouts.json` 已覆盖 15 个 Formal V1 界面：

```text
workshop_main
combat_hud
inventory_loot
dungeon_map
settlement
sell_panel
prosthetic_panel
layer_select
safe_room
stairs_room
maintenance_panel
daily_bill_report
shop_staging
order_board
rumor_board
```

这些界面已经可以进入素材生产、程序接入或运行时截图验收。A4 出货分配、订单和传闻界面已经进入 active 规格，新增 UI 图标进入 Manifest / Prompt 队列。

## 5. 执行规则

1. 新 UI 先进入 `screen_layouts.json`，再补 `formal_v1/*.md`，最后跑 `Validate-UIDesign.ps1`。
2. 若新 UI 需要新 VisualID，先补 `art_requirements_seed.json`，再跑 Manifest 和提示词生成。
3. 每轮生成、预处理或 Approved 同步后，刷新 `可接入素材清单.*` 并留快照。
4. 未进入 active 的 UI 不作为程序接入口，也不作为批量跑图入口。
5. 剩余未覆盖队列从 P3 的 `faction_shop`、`doll_interaction` 开始，进入正式批次前不作为程序接入口。
