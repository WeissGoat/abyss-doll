# 正式纵切 UI 与素材覆盖矩阵

> **定位：** 把 `09` 路线和 `11` 批次矩阵翻译成美术侧 UI / 素材覆盖表。目标是先把需要的 UI 设计纳入系统，再按 Manifest 流程生产素材。

---

## 1. 当前覆盖结论

截至 2026-05-24，active `screen_layouts.json` 已覆盖 10 个 Formal V1 界面：

```text
workshop_main
combat_hud
inventory_loot
dungeon_map
settlement
sell_panel
prosthetic_panel
layer_select
safe_room
stairs_room
```

这些界面已经可以进入素材生产、程序接入或运行时截图验收。未进入 active 的 A4 经济/订单/账单界面暂不视为素材生产入口。

---

## 2. 按纵切节点覆盖

| 纵切节点 | 系统目标 | UI 覆盖 | 当前状态 | 下一步 |
|---|---|---|---|---|
| A2 | 背包与物品生命周期 | `inventory_loot`、`combat_hud`、`sell_panel` | active Formal V1 | 等程序接入后截图验收；素材侧继续做图标质量升级。 |
| A2 | 战斗与怪物机制框架 | `combat_hud` | active Formal V1 | 战斗实体、状态条、目标光环、行动点继续验收和迭代。 |
| A3 | 深渊探索与层级节奏 | `dungeon_map`、`layer_select`、`safe_room`、`stairs_room` | active Formal V1 | 先生成/修正不透明背景，再接入截图验收。 |
| A3 | 局外成长 | `workshop_main`、`prosthetic_panel` | active Formal V1 | 后续补维护/底盘升级专用界面。 |
| A4 | 经济压力 | `sell_panel`、`settlement` | 部分 active Formal V1 | 需要新增 `daily_bill_report` 和 `shop_staging`。 |
| A4 | 势力订单 | 未覆盖 | planned | 需要新增 `order_board` 和订单提交/奖励反馈 UI。 |
| A4 | 时间/传闻 | `workshop_main` 仅承载摘要 | planned | 需要新增 `rumor_board` 或在工坊扩展传闻入口。 |

## 5. 执行规则

1. 新 UI 先进入 `screen_layouts.json`，再补 `formal_v1/*.md`，最后跑 `Validate-UIDesign.ps1`。
2. 若新 UI 需要新 VisualID，先补 `art_requirements_seed.json`，再跑 Manifest 和提示词生成。
3. 每轮生成、预处理或 Approved 同步后，刷新 `可接入素材清单.*` 并留快照。
4. 未进入 active 的 UI 不作为程序接入口，也不作为批量跑图入口。
5. A4 队列按 `maintenance_panel -> daily_bill_report -> shop_staging -> order_board -> rumor_board` 推进。
