# 美术风格基准

> **定位：** 统一 AI 出图和人工筛选时的视觉方向。
> **更新时间：** 2026-06-07

---

## 1. 风格定位

当前美术基准：

```text
日系二次元地底奇幻冒险 + 轻蒸汽工艺
```

内部参考情绪：

* 类似“来自深渊”那类地底奇幻探索感：童话式好奇、巨大垂直空间、未知危险、可爱与残酷并存。
* 画风更贴近日系二次元游戏视觉：干净线条、柔和赛璐珞阴影、明亮但不轻飘的色彩、角色和场景带温度。
* 结合轻蒸汽工艺：黄铜、铜件、齿轮、管线、压力表、铆钉、旧机械、暖色灯光，但不做成硬核工业控制台。
* 场景要保留冒险童话感和生活感，避免欧美黑暗奇幻、厚重写实、油画质感和冷硬科幻面板。

注意：AI 绘图提示词不直接写作品名，不写“来自深渊”。应拆成视觉语言。

---

## 2. 英文风格基准

`PromptEN` 使用以下风格基底：

```text
Japanese anime-inspired 2D game art, subterranean fantasy adventure, whimsical yet ominous, soft cel-shaded painterly rendering, clean linework, gentle storybook mood, warm handcrafted steampunk details, brass and copper gadgets, worn wood and cloth, warm lamplight, subtle bioluminescent cave glow
```

可按资产类型追加：

* 图标：`centered single object`, `clean readable silhouette`, `transparent background`
* 怪物：`creature portrait`, `front or three-quarter view`, `dramatic rim light`
* 背景：`wide composition`, `low visual noise`, `large negative space`, `hand-painted anime background`
* 节点：`minimal map icon`, `bold silhouette`, `high contrast`, `embedded into the map terrain`
* UI 概念图：`anime fantasy game UI concept art`, `clean readable interface shapes`, `low information density`, `no fake readable text`

Formal V2 UI 概念图额外基底：

```text
Japanese anime fantasy game UI concept art, warm hand-painted 2D background, soft cel shading, clean UI silhouettes, low information density, cozy yet dangerous subterranean adventure mood, light steampunk craft details, no realistic western dark fantasy
```

`dungeon_map` 专用基底：

```text
vertical abyss cavern map, parchment and geological cross-section blended together, route nodes embedded on cave terraces and brass map plates, paths carved into terrain, no ocean, no floating disconnected nodes
```

## 3. 中文审阅描述

`PromptCN` 用于人类审阅，不直接给绘图工具。

中文描述应回答：

* 这个资产看起来是什么？
* 它的材质、形状、颜色和气质是什么？
* 是否符合“地底奇幻 + 蒸汽朋克”的方向？

---

## 4. 禁止项

`PromptEN` 和 `NegativePromptEN` 禁止出现：

* 项目名或作品名：`魔偶深渊`、`来自深渊`、`Made in Abyss`
* 玩法黑话：`搜打撤`、`塔科夫like`
* 引擎词：`Unity`、`UGUI`
* 抽象交互逻辑：`按钮可读性`、`站位空间`
* 直接风格仿写：`in the style of Made in Abyss`、`same characters as ...`

转换示例：

| 不要写 | 改成 |
|---|---|
| 类似来自深渊 | `subterranean fantasy adventure`, `whimsical yet ominous` |
| 蒸汽朋克 | `light steampunk craft details`, `brass and copper gadgets`, `worn metal` |
| 日系二次元 | `Japanese anime-inspired 2D game art`, `soft cel-shaded painterly rendering`, `clean linework` |
| 留 UI 空间 | `large negative space`, `low visual noise` |
| 左右站位 | `side-scrolling perspective`, `empty ground across the foreground` |
| 地图节点融合 | `nodes embedded on cave terraces`, `paths carved into terrain`, `brass map plates attached to parchment` |

## 5. 负面风格基准

`NegativePromptEN` 建议追加：

```text
western dark fantasy, grimdark, hyperrealistic, photorealistic, oil painting, heavy realistic armor, gritty sci-fi console, cyberpunk UI, dense button wall, cluttered text, fake readable text, ocean background, floating disconnected map nodes
```

如资产本身需要海、水面或写实质感，必须在单项 Manifest 的中文说明里写清楚原因，否则默认按上述负面风格排除。
