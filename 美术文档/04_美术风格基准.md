# 美术风格基准

> **定位：** 统一 AI 出图和人工筛选时的视觉方向。
> **更新时间：** 2026-07-05

---

## 1. 风格定位

当前美术基准：

```text
日系二次元地底奇幻冒险
```

内部参考情绪：

* 类似“来自深渊”那类地底奇幻探索感：童话式好奇、巨大垂直空间、未知危险、可爱与残酷并存。
* 画风更贴近日系二次元游戏视觉：干净线条、柔和赛璐珞阴影、明亮但不轻飘的色彩、角色和场景带温度。
* 机械、工坊、义体和旧工具只作为局部系统语义出现，不作为全局材质和色彩主轴；不要把黄铜、铜件、暖灯或蒸汽朋克写进通用风格基底。
* 场景要保留冒险童话感和生活感，避免欧美黑暗奇幻、厚重写实、油画质感和冷硬科幻面板。
* 人设参考研究以“美少女吸引力 + 玩家照看动机”为优先目标；零号初版外貌已收束为白布遮眼、灰披肩、超短内衬裙、裸腿裸足、轻微人偶关节与灰尘磨损。核心仓平时隐藏在披肩下，只在维护或演出时可见。

注意：AI 绘图提示词不直接写作品名，不写“来自深渊”。应拆成视觉语言。

---

## 2. 英文风格语义基准

以下内容定义项目风格语义锚点，不要求机械原样发送给所有 provider。`generate-image` 按 `05_AI图片网关接入方案.md` 将同一语义转换为 OpenAI / Gemini 自然语言或 NovelAI tags：

```text
Japanese anime-inspired 2D game art, subterranean fantasy adventure, whimsical yet ominous, soft cel-shaded painterly rendering, clean linework, gentle storybook mood, clear saturated accents, airy fantasy atmosphere, luminous cave flora, hand-painted storybook environment
```

可按资产类型追加：

* 图标：`centered single object`, `clean readable silhouette`, `transparent background`
* 怪物：`creature portrait`, `front or three-quarter view`, `dramatic rim light`
* 背景：`wide composition`, `low visual noise`, `large negative space`, `hand-painted anime background`
* 节点：`minimal map icon`, `bold silhouette`, `high contrast`, `embedded into the map terrain`
* UI 概念图：`anime fantasy game UI concept art`, `clean readable interface shapes`, `low information density`, `no fake readable text`

Formal V2 UI 概念图额外基底：

```text
Japanese anime fantasy game UI concept art, hand-painted 2D background, soft cel shading, clean UI silhouettes, low information density, cozy yet dangerous subterranean adventure mood, clear fantasy color accents, no realistic western dark fantasy
```

`dungeon_map` 专用基底：

```text
large scrollable layer route map, strong foreground-to-background depth, camera-travel feeling, terrain and route marks blended together, route nodes embedded into roads, terraces, ruins, trees, stone markers or fantasy signposts, each layer can have a distinct biome such as cave, grassland, forest, ruins or underground lake, no ocean horizon, no floating disconnected nodes
```

层地图不默认等于“深渊洞窟视觉”。每一层可以有完全不同的生态主题，但仍要保留“巨大未知空间 + 可推进路线 + 节点长在地貌上”的地图逻辑。提示词中可以写 `subterranean grassland`, `underground forest`, `crystal cave`, `ancient ruins`, `misty hollow` 等具体生态，不要只反复写 `abyss cave`。

## 3. 中文审阅描述

`PromptCN` 用于人类审阅，不直接给绘图工具。

中文描述应回答：

* 这个资产看起来是什么？
* 它的材质、形状、颜色和气质是什么？
* 是否符合“日系二次元地底奇幻冒险”的方向？

---

## 4. 禁止项

`PromptEN` 和 `NegativePromptEN` 禁止出现：

* 项目名或作品名：`魔偶深渊`、`来自深渊`、`Made in Abyss`
* 玩法黑话：`搜打撤`、`塔科夫like`
* 引擎词：`Unity`、`UGUI`
* 抽象交互逻辑：`按钮可读性`、`站位空间`
* 直接风格仿写：`in the style of Made in Abyss`、`same characters as ...`

转换示例：

| 不要写 | 改成 |
|---|---|
| 类似来自深渊 | `subterranean fantasy adventure`, `whimsical yet ominous` |
| 局部工坊 / 义体语义 | `handmade workshop tools`, `prosthetic craft parts`, `worn repair props` |
| 日系二次元 | `Japanese anime-inspired 2D game art`, `soft cel-shaded painterly rendering`, `clean linework` |
| 留 UI 空间 | `large negative space`, `low visual noise` |
| 左右站位 | `side-scrolling perspective`, `empty ground across the foreground` |
| 地图节点融合 | `nodes embedded on cave terraces`, `paths carved into terrain`, `route marks attached to terrain` |
| 层地图纵深推进 | `large scrollable route map`, `strong foreground-to-background depth`, `camera-travel feeling` |
| 每层生态差异 | `distinct biome per layer`, `subterranean grassland`, `underground forest`, `crystal cave`, `ancient ruins` |

## 5. 负面风格基准

`NegativePromptEN` 建议追加：

```text
western dark fantasy, grimdark, hyperrealistic, photorealistic, oil painting, heavy realistic armor, gritty sci-fi console, cyberpunk UI, dominant steampunk machinery, brass and copper palette, gaslamp UI, sepia brown interface, dense button wall, cluttered text, fake readable text, ocean background, floating disconnected map nodes
```

如资产本身需要海、水面或写实质感，必须在单项 Manifest 的中文说明里写清楚原因，否则默认按上述负面风格排除。

## 6. 可执行风格合同

Manifest 的风格不再由 VisualID、文件名或单段 Prompt 推断，而由以下层级显式解析：

```text
GlobalStyle -> Profile -> Family -> Role -> ContextAccent -> VisualIntent
```

当前稳定语义 ID：

| 层级 | ID | 语义 |
|---|---|---|
| GlobalStyle | `p3_global_v1` | 日系二次元地底奇幻冒险、童话好奇与深渊危险并存。 |
| UI Profile | `ui_v1` | 低噪声、可读、手绘幻想 UI。 |
| Character Profile | `character_portrait_v1` | 保持身份、比例、画布基线的角色立绘。 |
| Button Family | `ui_button_core_v1` | 连续边框、干净中心和可拉伸结构。 |
| Primary Role | `primary` | 绯红色主要行动语义。 |
| Neutral Accent | `none` | 不覆盖基础风格。 |

UI 的颜色角色合同为：

```text
墨灰底板 + 月白边线 + 绯红主行动
浅蓝只用于符文激活、选中和能量反馈
```

这些语义由 `design_tokens.json` 的 `ColorRoleAliases` 提供机器可读映射，实际 Prompt 由编译器生成。任何生成器不得从 `ui_button_primary` 的字符串内容猜测颜色或组件角色。

角色立绘另使用 `character_portrait_set` Profile 和 AssetSet 身份合同；角色成员的 `SetRole` 表达母版、姿态或差分关系，不等于 UI Family/Role，也不规定文生图、图生图或具体 provider。

## 7. Prompt 编译与格式

`VisualIntent` 是单项资产最终需求。编译器先将风格层、VisualIntent、Spec 和角色 AssetSet 合并为 `CanonicalVisualBrief`，再持久化生成多个 `PromptVariant`：

| PromptFormat | 默认后端 | 结果 |
|---|---|---|
| `natural_language_v1` | OpenAI/GPT image edit、Gemini image/chat image | 自然语言正面与负面 Prompt。 |
| `danbooru_tags_v1` | NovelAI | 结构化 tag、weight、负面 tag。 |

完整请求保存到 `美术文档/_generated/art_generation_requests.json`。批量脚本只读取已编译 Request；需求、风格、Spec 或编译器版本变化后必须重新编译，不能在执行时让 Agent 临时拼 Prompt。
