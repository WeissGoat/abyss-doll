# 零号初版人设方案

> 定位：本文记录 `doll_proto_0 / 原型机·零 / 零号` 的初版人设方向。它是后续母图、三视图、表情差分和 DollPuppet 分层的设计依据；尚不是 Approved 素材、Manifest 条目、Unity 运行时资源或最终封版。

## 1. 设计结论

零号初版采用：

```text
遮眼白布 + 灰披肩 + 简单超短内衬裙 + 裸腿裸足 + 轻微人偶关节与磨损
```

参考对象只用于人物外貌构成，不继承失明少女的性格、乞讨语义、受害桥段或照顾妹妹设定。性格初始为三无 / 冷感，接近 2B 式克制、寡言、任务导向；后续随玩家养成、维护和 SAN / 好感变化逐步产生情绪、依赖、松弛或破防差分。

核心设计目标：

- 第一眼是美少女，不是怪物、重机械或单纯病弱角色。
- 眼部遮挡要有强识别度：参考 `2b_(nier:automata)` 的遮眼符号，但改为白布，不使用黑色战斗眼罩。
- 下半身留白：灰披肩与上身形成包裹感，超短内衬裙、裸腿和裸足形成脆弱、空旷、未完全装备的状态。
- 核心仓平时被披肩遮住，只有维护、受损、启动或特殊演出时才可见。
- 2026-07-07 后续 AI 出图以第一轮 ChatGPT 组立绘作为概念图气质基准：保留精修概念图质感、灰披肩体块、白布遮眼和工坊人设氛围；NovelAI 组需要修正半边露肩和成熟感，Gemini 组需要去掉复杂背景。
- 2026-07-08 发型锁定为银白 / 灰白长发散发：自然披散、轻微凌乱、不扎发，不使用双马尾、单马尾、麻花辫、丸子头、短发或厚重卷发。
- 2026-07-10 眼部追加设定：白布眼罩后方是真实红眼；常态不直接露出眼睛，启动、低 SAN、受损或掀布维护时才允许红光透过白布或短暂露出。
- 2026-07-11 后续立绘以 Gemini 版本为视觉母版：锁定身体比例、长发散发、白布遮眼、灰披肩和动作轮廓；ChatGPT 只补披肩体块与完成度，NovelAI 只作结构备选。立绘资产范围和优先级以 `05_零号立绘素材设计与交付清单.md` 为准。

## 2. 外貌规格

| 部位 | 规格 |
|---|---|
| 体型 | 娇小、纤细、可爱的小体型少女 / 人偶比例，参考失明少女的轻薄感；避免成熟高挑御姐比例，也不可进入儿童化或色情化幼态。 |
| 头发 | 银白 / 灰白长发散发，发丝自然披散到肩后和背后，可略凌乱；发量轻柔，避免扎发、双马尾、单马尾、麻花辫、丸子头、短发或厚重贵族卷发。 |
| 眼部 | 白布遮眼，横向包覆或绕头固定；布料应柔软、干净偏旧，边缘可有轻微磨损。眼罩后方是真实红眼，常态不直接露出；启动、低 SAN、受损或掀布维护时可有红光透布。 |
| 表情 | 初始面部表情少，嘴角平直或极轻微无意识张口；不做失明少女式温柔微笑基线。 |
| 披肩 | 灰披肩 / 灰色罩布，必须完整覆盖双肩、胸和上臂，轮廓比原型粉披肩更朴素、更冷；常态不允许半边露肩或单肩滑落。 |
| 内衬裙 | 简单内衬裙，超短裙长度；颜色建议白灰、浅灰紫或旧象牙白，低装饰。 |
| 下半身 | 裸腿、裸足，下半身视觉留白明显；脚踝和膝部可见轻微人偶关节或磨损。 |
| 胸前 | 不要胸前装饰、吊牌、编号牌、乞讨牌、项链或大徽章。 |
| 人偶关节 | 肩、肘、腕、膝、踝保留细小关节线，克制、精致，不做球形关节大玩偶。 |
| 灰尘与磨损 | 少量灰尘、擦痕、布料破边；重点表现长期封存与刚被唤醒，不做重伤血污。 |
| 核心仓 | 位于胸口或锁骨下区域，但平时被披肩遮住；维护、换装、受损演出时才露出微光核心。 |

## 3. 服装层次

从外到内：

1. 白色遮眼布：第一识别符号。
2. 灰披肩：覆盖上半身，遮住核心仓，形成“被包覆 / 未完全展示”的保护感。
3. 简单内衬裙：超短、低装饰，强调临时素体状态。
4. 裸腿裸足：下半身空旷，表达未装备、未社会化、刚离开维修台。
5. 人偶素体：在关节处、手腕、脚踝和膝侧露出细小非人结构。

不使用：

- 粉披肩、紫裙、乞讨牌。
- 胸口吊坠、编号牌、醒目的核心外露装饰。
- 黑色 2B 式眼罩、女仆裙、哥特蕾丝、军装高跟靴。
- 重机械臂、大型外骨骼、机甲裙甲。
- 成熟高挑御姐比例、成人性感姿态、半边露肩披肩、复杂背景人设图。

## 4. 性格基线

初始性格不参考失明少女。

零号初始状态：

- 三无 / 冷感：表情少、语气平、行动指令化。
- 接近 2B 式克制：不主动示弱，不主动撒娇，不把痛苦表达给玩家。
- 礼貌但疏离：会回应维护指令，但不热情。
- 有服从残留：会问“下一项指令是什么”，但随着养成逐渐形成自己的选择。

养成变化方向：

| 阶段 | 性格变化 |
|---|---|
| 初醒 | 冷、空、少话，只执行维护 / 下潜相关命令。 |
| 稳定 | 开始短句表达偏好，例如不喜欢强光、不喜欢被突然触碰遮眼布。 |
| 信任 | 维护时允许玩家掀开披肩检查核心仓，语气变软。 |
| 低 SAN | 三无表面破裂，动作迟疑，遮眼布下出现不稳定红光或泪痕式冷凝。 |
| 高好感 | 不变成活泼少女，而是出现很小的主动靠近和短促关心。 |

## 5. 核心仓规则

核心仓是零号的重要非人符号，但不能作为常驻胸前装饰。

- 日常立绘：不可见，被灰披肩遮住。
- 维护界面：披肩被掀开或半解，核心仓微光可见。
- 受损 / 低 SAN：披肩边缘错位，露出一小段核心仓光。
- 启动演出：核心仓光从披肩下透出，而不是直接露出完整机械结构。
- DollPuppet 分层：核心仓必须独立成层，但默认隐藏或被披肩遮挡层盖住。

## 6. 红眼与眼罩规则

红眼是零号的内在异常符号，不替代白布遮眼作为第一识别点。

- 常态：白布完全遮眼，不直接看见瞳孔；最多在强背光或近景中有极弱红色压痕。
- 启动 / 战斗准备：白布后方出现克制的红色发光点或薄红光，不掀开眼罩。
- 低 SAN / 受损：红光变得不稳定，可透过布料形成断续亮点、冷凝痕或轻微光晕；仍不画血。
- 维护 / 信任：可以短暂掀开或半掀遮眼布，露出红眼作为特殊状态参考；不作为日常造型。
- 禁止：蓝眼、异色瞳、常态大面积露眼、血泪、恐怖怪物化、黑色眼罩替代白布。

## 8. 三视图要求

| 视图 | 必须看清 |
|---|---|
| 正面 | 白布遮眼、灰披肩体块、长发散发的前发层、超短内衬裙、裸腿裸足、整体美少女比例。 |
| 侧面 | 披肩厚度、遮眼布绕头方式、长发自然垂落到背后的层次、脚踝关节、站姿轻微不稳。 |
| 背面 | 披肩后摆、长发散发长度和发尾形状、遮眼布结 / 固定方式、背部是否有素体接缝。 |
| 维护半解状态 | 披肩掀开后核心仓位置和微光方式，仅用于维护 / 演出，不作为日常造型。 |

## 9. 表情与状态差分

| 差分 | 表现 |
|---|---|
| `neutral` | 三无、冷静、嘴角平直。 |
| `command_ready` | 听取指令，头部轻微偏转。 |
| `low_san` | 呼吸变浅，遮眼布下有不稳定红光或冷凝痕迹。 |
| `hurt` | 披肩错位，关节裂痕更明显，核心光从布下漏出，眼罩后红光变暗。 |
| `maintenance_open` | 披肩半解，核心仓可见，可短暂半掀白布露出红眼，表情仍克制但身体放松。 |
| `trust_soft` | 不大笑，只出现很轻的嘴角放松或主动靠近。 |

## 10. DollPuppet 分层清单

| 层 | 说明 |
|---|---|
| `hair_back` / `hair_front` | 银白长发前后层，支持轻微摆动。 |
| `blindfold_white_cloth` | 白布遮眼主层，可做轻微飘动或受损版本。 |
| `face_base` | 眼部不可见，但保留嘴、脸颊和低 SAN 冷凝细节。 |
| `red_eyes_hidden` | 红眼层，默认被白布遮挡；启动、低 SAN、维护半掀时可显示或透光。 |
| `gray_cloak_front` | 灰披肩前层，默认覆盖核心仓。 |
| `gray_cloak_back` | 灰披肩后层，用于动态摆动。 |
| `inner_short_dress` | 简单超短内衬裙。 |
| `body_doll_joints` | 手腕、膝、踝等轻微人偶关节。 |
| `bare_legs_feet` | 裸腿裸足基础层。 |
| `core_chamber_hidden` | 核心仓层，默认被披肩盖住。 |
| `dust_wear_marks` | 灰尘、磨损、细小划痕，可按状态开关。 |

## 11. 单张视角 / 动作人设图要求

单张动作图用于补充三视图之外的角度、状态和动作语义。每张图只画一个视角或一个动作，不把正面 / 侧面 / 背面塞在同一张图里。

首轮动作：

| ID | 内容 | 目的 |
|---|---|---|
| `pose_01_front_idle` | 正面待机 | 锁常态站姿、披肩体块和白布遮眼。 |
| `pose_02_three_quarter` | 3/4 斜侧 | 看披肩侧边体块、长发散发和脸部遮挡轮廓。 |
| `pose_03_side_walk` | 侧身行走 | 看裸足步态、侧面披肩厚度和长发拖尾。 |
| `pose_04_back_turn` | 背面回头 | 看后发长度、披肩后摆和遮眼布绕头。 |
| `pose_05_maintenance_sit` | 维护坐姿 | 看非战斗维护状态的身体收束。 |
| `pose_06_activation_ready` | 启动准备 | 允许白布后方微弱红光。 |
| `pose_07_low_san_red_eye` | 低 SAN 红眼透布 | 表现红眼设定，但不露完整眼睛。 |
| `pose_08_damaged_kneel` | 受损跪撑 | 表现磨损和不稳定，不画血。 |
