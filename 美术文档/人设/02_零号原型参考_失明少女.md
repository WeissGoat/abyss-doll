## 3. 原作角色信息摘录

### 3.1 设定与遭遇

- 她是没有公开姓名的贫困少女，在街头或商场附近乞讨。
- 她属于“被诅咒的孩子”这一群体，出身边缘区域 / 外围区，受到普通人的恐惧与排斥。
- 因红眼被母亲厌恶，眼睛遭到伤害并失明，之后被抛弃。
- 她有一个妹妹，需要靠乞讨养活自己和妹妹。
- 她会被路人戏弄，例如把易拉罐拉环当作硬币丢进乞讨容器，她仍会真诚道谢。
- 里见莲太郎和缇娜遇到她后，莲太郎给了她钱并劝她暂时不要再来危险的街头；后续又在她被殴打时救下她。

### 3.2 外观符号

可观察符号：

- 银白长发，长度很夸张，角色幼小、轻薄、易碎。
- 白灰色眼罩 / 绷带遮住双眼。
- 脏旧粉色披肩 / 斗篷，前部有纽扣。
- 内层为暗淡紫色连衣裙，裙摆破旧。
- 身上和衣物有泥污，表现贫困与被照料缺失。
- 胸前或手中有乞讨牌，画面识别强，但属于原作专属叙事符号，不能照搬到零号。

不建议直接继承：

- 原样的粉披肩 + 紫裙 + 乞讨牌组合。
- 牌子文字、商场乞讨构图、被路人欺负的具体桥段。
- “被母亲灌铅导致失明”这一极端原作设定。
- 红眼作为默认外观锁定。红眼在原作中是 Cursed Child 语义，不应直接挪给零号。

### 3.3 性格符号

- 她最强的角色记忆点不是战斗力，而是“被伤害后仍温柔微笑”。
- 她依赖他人生存，所以习惯性保持礼貌、道谢与微笑。
- 她有成熟、安静、忍耐的一面，也有通过触摸他人脸庞理解对方的好奇心。
- 她会照顾妹妹，形成“弱小者仍在承担照顾责任”的反差。
- 她能立刻激活观众 / 玩家保护欲，但风险是过度苦难化、工具人化。

## 5. 转译给零号的方向

### 5.1 可继承的外貌功能

| 原型符号 | 转译到零号 |
|---|---|
| 失明 / 眼部遮挡 | 转译为白布遮眼，参考 2B 式遮眼识别度，但不使用黑色眼罩。 |
| 粉披肩 | 改为灰披肩 / 灰色罩布，覆盖上半身并遮住核心仓。 |
| 暗淡内裙 | 改为简单超短内衬裙，配裸腿裸足，让下半身保持空旷。 |
| 脏旧与磨损 | 保留少量灰尘、擦痕和细小人偶关节，表现刚被唤醒的素体状态。 |
| 胸前乞讨牌 | 不转译；零号胸前不放装饰、编号牌、吊坠或核心外露件。 |

性格不继承本原型。零号初始性格以 [03_零号初版人设方案.md](03_零号初版人设方案.md) 为准：三无 / 冷感，后续随养成变化。

### 5.2 零号第一版人设建议

- 方向关键词：`被修复中的美少女人偶`、`安静礼貌`、`眼部遮挡`、`柔弱但不空洞`、`需要照看但有自己的责任心`。
- 初始母图不要直接写 `blind girl from Black Bullet`、`pink cape`、`begging sign`。
- 可以写入：`soft eye cover`、`temporary repair veil`、`small workshop tag`、`subtle doll joints`、`fragile but warm smile`、`long pale hair`。
- 银发可以作为候选方向之一，但不能因为原型而直接锁死；要和此前 Danbooru 参考规则保持一致，先出 2-3 个方向稿。
- 眼罩 / 遮挡不应压过“美少女吸引力”；要避免纯苦难、脏污或病弱工具人化。

## 6. 禁止照搬项

- 不复制原角色的粉色披肩、紫裙、双纽扣、乞讨牌、白色眼罩组合。
- 不复制原作截图姿势、商场乞讨场景、受伤仍微笑的具体桥段。
- 不复制原作文字设定：Cursed Child、Initiator、Gastrea、红眼被母亲厌恶、灌铅失明、妹妹乞讨生存。
- 不把“失明”作为零号卖点；零号应是“未完全启动 / 感知不完整 / 需要修复”的项目内语义。
- 不直接使用外部截图做训练集、贴图、Approved 素材、Live2D / DollPuppet 分层图或宣传图。

## 7. 承接到下一步

后续 `零号完整人设交付包 V1` 应至少包含：

- 2-3 个方向稿：保留“眼部遮挡 + 维修标签 + 被照看动机”，分别测试发色、服装和核心仓位置。
- 母图 prompt：明确禁止 `pink cape`、`begging sign`、`Black Bullet`、`Blind Girl` 等直接照搬词。
- 三视图要求：正面、侧面、背面，标注眼部遮挡、关节、核心仓、维修标签和临时包覆布。
- 表情差分：初醒、礼貌微笑、低 SAN、受损、维护后放松。
- DollPuppet 分层清单：头发前后层、眼部遮挡层、脸部表情层、核心仓微光层、手部触碰动作层、临时罩布层。
