## 方向（布局稿待制作人选）

- **A 测绘图**：本层场景上钉一张羊皮测绘纸，节点是墨水印章，走过的路描金，迷雾是没画的空白 / 墨晕，零号是纸偶图钉。
- **B 实景路线**：本层场景全屏，一根从零号手腕牵出的发光丝线铺在地面上，节点是路标，零号小立绘站在当前节点。
- **C 立体棋盘**（制作人放了参考图）：场景上浮一块斜俯视的棋盘，节点是一块块立体小地台，上面直接摆着那里有什么（怪物剪影、宝箱、帐篷、阶梯、大首领剪影），路线是格子路、按风险描不同颜色，零号是站在当前地台上的小人加一枚浮着的标记。

三个方向都有：左边零号状态栏、节点悬停说明（风险、可能的收获、要扣的 SAN）、走不到的分支淡化、背包用战斗里的底盘从下方升起、安全屋加「这趟收获」小结和零号。

## 制作人选定（2026-10-28）

A / B / C 都不用。按 2026-06 的正式版概念走：`美术文档/ui_design/formal_v2/concepts/dungeon_map_formal_v2_concept.png`（和它的上一版 `archive/2026-06-07_layer_map_depth_regen/`），说明在 `美术文档/ui_design/formal_v2/04_dungeon_map_v2.md`。**地图上不放零号。**

- 整张地图就是这一层的手绘地貌（高视角），节点是铜质圆徽章，嵌在踩出来的路、栈桥、石阶上，不是漂浮的按钮。
- 当前节点用小金色箭头标出，下一步能去的发光，走过的变暗，再往前的沉进雾里，只留首领的徽记隐约可见。
- 界面元素极少：左上一块细的状态牌，右下一个背包按钮。

节点网络是每次随机生成的，路不能画死在底图上：底图只画地貌，路（土路、栈桥、石阶的贴图）和徽章由程序按网络摆上去。

结构照 `drafts2/l1_002`，地貌照 `l1_001` / `l3_001`。**地图支持卷动**（制作人 2026-10-28）：比屏幕大，镜头跟着当前节点走，玩家也能拖动。

### 底图尺寸

- 现在的中转上，Gemini 默认出 1376×768，2K 出 2752×1536（实测），4K 要 Ult 账号、用不了；gpt-image 固定 1254²；NovelAI 约 100 万像素。
- 一层一张 2K 底图（约 1.4 屏宽、1.4 屏高）够 Demo 三层用：第 3 层最多 10 列，每列 260 px 左右也只要 2600 px 宽。
- 以后某层要更长（比如 20 列，约 5000 px），按段拼：下一段用上一段右边一条做参考图往外画，两段重叠 300–400 px，接缝用渐变遮罩融合，接缝尽量落在墙、雾这种本来就断开的地方；或者干脆把长层拆成上下两层。
- 2K 底图在 Unity 里按 4096 上限导入。
