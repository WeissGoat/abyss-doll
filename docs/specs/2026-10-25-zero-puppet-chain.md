# 零号的纸偶：现在的做法（2026-10-25）

给调研 Live2D 的人做对照：现在房间里的零号是怎么动的、为什么这样做、做到哪里为止、每张新立绘要花多少。做法和命令见 `美术文档/21_战斗姿势与动态素材工作流.md` 的「纸偶立绘」。

## 一句话

一张立绘拆成两层（身体、垂在身后的长发），在 UGUI 的 Image 上铺 64×96 的网格，每帧由程序算出每个网格点的位置。不用 Live2D、Spine 或骨骼插件，美术只有几张由脚本生成的图，加上一份写坐标的配置。

## 叠在一起的几样动作

| 动作 | 组件 | 做法 |
|---|---|---|
| 呼吸 | `UIStillMotion` | 整张图以脚底为基准，每 3.6 秒伸缩约 1.4% |
| 全身倾斜 | `UIPortraitPuppet` | 一条从下到上的链：膝盖以下不动，越往上转得越多，腰以上整体倾斜；头在这上面绕脖子再转一点（按头部权重）。每次歪头，身体承担 30%，头承担 70% |
| 头发 | `UIPortraitSway` + `UIPortraitPuppet` | 长发是单独一层，放在身体后面：发根随头移动，肩膀附近马上跟、发梢晚一点跟（两个弹簧）；另加一条从上往下传的小波浪（宽度的 1.2%） |
| 反应 | `UIPortraitPuppet` | 平时慢慢歪头 ±1.2°；鼠标靠近时朝那边歪 2.5°；摸头时从腰往上微微缩、低头，跟着拖动最多歪 6°，松手回弹、头发甩起来；牵手时朝手的方向低头 5°，换上一只画好的伸出的手臂（`_hold`）；被摸时脸红；说话时点一下头 |
| 跟着她动的东西 | `UIPuppetPin` | 污渍、裂痕、黑雾钉在她身上同一个位置 |
| 触摸 | `PortraitPatZone` | 头、肩、手三块看不见的触摸区，负责按下、拖动和松开 |

大厅和标题画面里不是纸偶，而是一段待机循环视频（`make_flow_loop.py`：H3 生成视频，只取其中的动作，套到清晰的立绘上），纸偶藏在视频下面。

## 每张立绘要的东西

| 素材 | 来源 |
|---|---|
| `<id>`（立绘本身） | 出图 |
| `<id>_hair`、`<id>_body`、`Rigs/<id>_rig`（头发层的摆动权重） | `split_hair_layer.py`（裙子边缘按轮廓线逐行描出；配色分不开时用手涂的 `--hair-mask`） |
| `Rigs/<id>_puppet`（R 头、B 手） | `build_puppet_rig.py`，要给出头的圆、脖子、手的位置 |
| `<id>_hold`（牵手时的手臂，可选） | Gemini 只改手臂，再用 `make_pose_patch.py` 只取改了的部分 |
| `配置表(JSON)/Portraits/<id>.json` | 手填：脖子、两颊、膝盖、腰、头发跟随的范围、牵手手臂的跟随点、三块触摸区、12 个污渍位置 |

## 试过、被制作人退回的

1. **只弯网格转头**：头往一边动，原来位置的头像素还在，像被拉过去或挤扁。
2. **头单独切一层，整块转**：头动、身体和长发不动，像纸片头插在身体上。
3. **头发和衣服在同一张图上一起弯**：网格每格 16 像素，一格里一边是头发、一边是裙边，头发一摆，裙边就被拉歪。
4. **裙摆自己左右晃**：交界处扭曲；而且她站着不动，裙子本来就不该自己晃。
5. **换嘴、抬手（网格把手往上推）**：房间里她太小，嘴只有 2–4 像素，看起来是一团在闪；抬手时小臂明显变短。

现在的做法就是针对这些改的：动作是全身一条链，转动分摊在整段身体上；头发和身体分成两层；幅度压小。

## 做不到的（Live2D 能补上的）

- **转身、侧脸**：只能在画面平面里转，没有前发、后发错位的立体感。Live2D 的角度参数加上分层补画能做到。
- **大动作**：头歪超过约 6°、低头超过宽度的 2%，就能看出拉伸。
- **换动作**：手臂只能整张换成画好的姿势，不能连续地抬、挥。
- **头发**：整片一起摆，不是一缕一缕地飘；被挡住的头发是脚本按行延伸出来的，不是画的，头发往外摆到最大时会露出几像素。
- **表情**：零号戴着遮眼布，房间里不做眨眼和嘴型；表情放在夜谈的半身像上（整张换图）。

## 成本

- **一张同类的新立绘**（同一角色换衣服、换姿势，或者设计相近的角色）：大部分时间在跑脚本、看预览、填配置、打包看录像，约 1–2 小时。Agent 的花费主要在看图（每张预览或截图约一两千 token）和读文档，大约 5–10 万 token 的上下文。
- **配色分不开的设计**（深色头发配深色衣服、头发搭在身前）：要手涂头发范围，多花 15–30 分钟；遇到新问题时，来回调整可能翻倍。
- **这一轮从发现问题到改好**：把上面五种做法一种种试过来，花费远高于以上（离线原型、多轮渲染对比、几次打包录像）。之后照这套流程做就不用再试。
- **不花钱**：不出图、不出视频（牵手的手臂要用 Gemini 出 3 张，可以忽略不计）。

## 如果换成 Live2D，要接上的地方

- 房间里的代码只调用 `UIPortraitPuppet` 的这几个接口：`Press`、`HoldHand`、`Stroke`、`React`、`Talk`、`PlayPat`、`TryFollow`（污渍跟随），测试读 `HeadAngle`、`HeadDip`、`HoldPoseShown`。Live2D 版本照这套接口实现，`ZeroPresence` 和 `StudioCareView` 就不用改。
- 触摸区和污渍位置在 `配置表(JSON)/Portraits`，和用什么技术驱动无关，可以继续用。
- 渲染：房间是 UGUI（Screen Space Overlay），Live2D 的 Cubism 模型是网格渲染，要么画到 RenderTexture 再交给 RawImage 显示，要么放到相机画布里，还要处理和污渍叠放的顺序。
- 大厅的待机视频（取动作套立绘）可以保留，也可以改成 Live2D 的待机动作。
