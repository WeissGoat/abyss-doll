# M4 锁定美术方向和声音：方案（2026-10-05）

## 目标

Demo 里玩家会看到的每个画面都用同一种画风，零号在所有画面里是同一个人，界面上没有英文调试字，游戏有声音。

不做：Demo 范围外的界面（订单、传闻、势力、人偶房间等隐藏入口）、Live2D / 动态立绘、第 3 层素材。

## 现状

- **画风割裂**：序章 CG 是青蓝洞穴风；战斗和拾取界面是棕金蒸汽朋克边框；工坊主界面是开发面板。`美术文档/04_美术风格基准.md` 写过"日系二次元地底奇幻"的方向，但正式素材没有按它统一过。
- **零号至少有 4 种长相**。初版人设（`美术文档/人设/03_零号初版人设方案.md`）：白布遮眼、灰披肩、超短内衬裙、裸腿裸足、轻微人偶关节和灰尘磨损。
- **已入库素材** `Art/Approved` 共约 300 张：UI 91、怪物 42、物品 35、订单 35、背景 18、序章 CG 16、零号 14，其余是节点、义体、房间等。
- **UI**：`UITheme` 已经集中定义颜色、字号和常用控件，M2 以后重做的界面都用它。中文字体是运行时从系统字体里找的（`Font.CreateDynamicFontFromOSFont`），没有打进包里：换一台没装这些字体的电脑，字可能会变成方块。
- **声音**：一个都没有。设置里的音量只存了数，没有任何东西在发声。
- **出图**：AI 图片网关本地配了 4 个后端：gpt-image-2（文生图）、Gemini 图生图、NovelAI（二次元 / tag 控制）、Grok。这些后端还没在 Claude 这边试过。流水线脚本在 `tools/美术工具/`，流程见 Skill `p3-art`。

## 批 1：方向对比怎么做

- **每个方向画同样 3 个题材**，方便横向比：
  1. 零号站在工坊里（角色 + 室内）；
  2. 第 1 层浅渊回廊的一个场景（地底空间感）；
  3. 一张战斗画面样张（界面框 + 一只怪 + 背包格）。
- **3 个候选方向**（都还是"日系二次元地底奇幻"，差在色调和氛围）：
  - **A 童话深渊**：柔和赛璐珞、大块冷暖对比、巨大的垂直空间，可爱和危险并存。偏《来自深渊》的情绪。
  - **B 暖色小镇养成**：明亮、低饱和的暖色，生活感强，地底也带一点童话的温度。偏《火山的女儿》的情绪。
  - **C 沿用序章的青蓝洞穴**：现有序章 CG 的方向。好处是 16 张 CG 不用重画，成本最低。
- 每张出 2–3 个候选，挑最好的一张进对比页。对比页放在 `tmp/art_explore/`（不进 git），发给制作人看。
- 选定后把结论写进 `美术文档/04_美术风格基准.md`，包括调色板、线条、阴影、UI 材质、禁止项，以及各后端的提示词锚点。不另起新文档。
- 风格基准里已有的规矩照旧：提示词里不写作品名，拆成具体的视觉语言。

## 批 6：声音

- **范围**：背景音乐 4 首（标题、小镇、深渊第 1 层、战斗 / 首领）。音效约 20 个：点击、翻页、攻击命中、举盾、受伤、物品拿起和放下、放置失败、金币、节点移动、战败、撤离成功、房租结算等。
- **代码**：一个 `AudioService`，背景音乐和音效两条通道，各自跟着设置里的音量。各系统通过现有事件总线触发音效，规则代码里不直接调声音。
- **来源需要制作人定**：
  - **免费 CC0 素材库**（Kenney、Freesound 的 CC0 部分、OpenGameArt）：不花钱，许可清楚，风格不一定统一。我可以找好候选清单，你确认后再下载。
  - **买素材包**（itch.io、Unity Asset Store 上的 RPG 或奇幻音乐 / 音效包，大约 20–60 美元）：风格统一、质量稳定，需要你来购买。
  - **AI 生成**（Suno、Udio 做背景音乐，ElevenLabs 做音效）：最容易贴合风格，需要你的账号，商用许可要看各家条款。
  - 我的建议：音效用 CC0（Kenney 的界面和战斗音效包质量够用），背景音乐用买的或 AI 生成。

## 制作人决定（2026-10-05）

1. **方向**：B 暖色小镇养成（偏《火山的女儿》），深渊部分偏《来自深渊》。不必照搬已有素材和流程：序章 CG 和所有界面都可以重做。
2. **零号人设**：可以沿用初版，也欢迎更好的方案。我提了一版 v2（见下），和 v1 一起出三视图对比，制作人选。
3. **声音**：音效用 CC0（Kenney，已接入 13 个，来源记在 `Resources/Audio/SFX/CREDITS.txt`）；背景音乐买包或 AI 生成，等制作人定具体渠道。
4. **字体**：正文用 Noto Sans SC（已打进包，`Resources/Fonts/`，OFL 许可放在旁边）。

批 0 也已确认：gpt-image-2、Gemini 图生图、NovelAI 都能用（`tools/美术工具/Test-AIImageBackends.ps1`）。gpt-image-2 走的代理会限流（"Too many requests"）和超时（504），不管请求什么尺寸都只回 1024²；要一张一张串行出图，失败等 60 秒再重试。

### 第一轮风格锚点（`tmp/art_explore/2026-10-05_m4_style/round1/`，不进 git）

- **小镇**：深渊边缘的阶梯小镇，暖木、白墙、红瓦、花盆、晾衣绳，货运吊笼挂着灯垂进深渊。B 方向的"生活感"和"小镇就在深渊上面"一张图都说清了。
- **深渊第 1 层**：青绿色荧光蘑菇、巨树根、吊桥和旧脚手架，光从上面斜着打下来。
- **规则：上暖下冷。** 小镇和工坊是琥珀色的午后光、亚麻和木头；深渊越往下越青、越暗，只有灯笼和人造物是暖色。玩家一眼能分清"家"和"外面"。
- **界面材质**：缝线的亚麻布面板、皮革包边、黄铜扣和铆钉；AP 是嵌在铜框里的蓝色宝石；意图是红色圆章。替换现在的棕金蒸汽朋克边框和开发面板。
- **零号 v2 在工坊里**：亚麻兜帽斗篷、象牙色及膝连衣裙、人偶关节缝线、赤脚，读起来清楚。遮眼布上的红线没出来，下一轮加强。

### 零号 v2 提案（和 v1 的差别）

保留银长发、白布遮眼（下面是红眼）、人偶关节缝线、冷淡的性格。改四处：

- **斗篷**：灰披肩 → 燕麦色亚麻兜帽斗篷，带一块手缝补丁。之后每次照看可以多一块补丁，"被照顾"的痕迹看得见。
- **衣服**：超短内衬裙 → 象牙色及膝直筒连衣裙。贴合暖色养成的调子，小尺寸下轮廓更好认，也避开分级风险。
- **脚**：工坊里赤脚；下潜时缠布条，作为第一件礼物 / 装备。
- **遮眼布**：系带换成一根褪色的红线，作为全身唯一的强调色。

## 验收

- 前 30 分钟（标题 → 序章 → 首潜 → 回城 → 第 2 天）和一次第 1 层下潜，每个界面截一张图，和选定方向的对比图放在一起看，风格一致。
- 包在没装中文字体的环境下也能显示中文（字体打进包里）。
- 每个界面都没有英文调试文字和原始 ID。
- 有背景音乐和关键音效，设置里的两路音量都起作用。
- 全量测试通过，打包自检 PASS，制作人试玩。

## 风险

- **出图后端不稳定**（第三方代理、NovelAI 限流）：批 0 先冒烟。不通就如实说，不悄悄换后端。
- **零号一致性**：AI 出图很难让同一个角色每张都一样。做法是：以标准设定图为参考图，用 Gemini 图生图出差分，每张都和设定图并排检查。
- **工作量**：画面素材是大头。范围只到 Demo 的前 30 分钟加第 1、2 层；第 2 层背景和怪物图先沿用现有的，只要不和新方向冲突就不重画。
