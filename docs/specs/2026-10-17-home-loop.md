# 家：回城之后的一晚（2026-10-17，待制作人确认）

## 问题

制作人试玩的感受：回城复盘比较一般，下潜和回城串不起来。现在回城依次经过四个界面：结算表（拾取、带出、损失的件数）、工坊夜晚、营业面板、「第 N 天结束」卡片。每个都只是在报数字，零号也只是背景里站着的一张图。下潜里发生的事，回家后看不到痕迹；家里做的事，也影响不到下一次下潜。

参考：旧 GDD_11（人偶房间）、GDD_12（交互管理器）、《火山的女儿》主界面（角色居中，房间里的家具就是入口，头顶气泡显示心事）。旧设计偏向长线正式版，内容太多（好感 10 级、五类交互、结局房间）。下面按 Demo 的体量重新设计，保留其中最能把两边串起来的几样。

## 核心思路：带出去、带回来

让三条线跨过「下潜 / 回家」这条边界，每次回家都接上一次下潜，每次出门都带着家里的事：

| 线 | 在家里 | 在深渊里 | 回到家 |
|---|---|---|---|
| **痕迹** | 擦干净、修好、净化 | 每次受伤、被腐蚀，都在她身上留下记号 | 记号就在她身上，点哪里修哪里 |
| **心愿** | 早上她头顶冒出一个小心愿 | 心愿给路线一个软目标（去泉水、带回发光的东西） | 交给她，她收下，放上架子 |
| **手账** | 墙上的手账本记着每一次下潜 | 走过的路、受伤的地方、打倒的首领都被记下 | 回家第一眼看到的是这一页，由她来讲 |

金钱这条线（战利品 → 营业 → 房租）已经有了，保持不变。

## 回家的一晚：四步，每步一个画面

每步都能一键跳过；熟练之后整晚不超过一分钟。

**1. 进门（替换结算表）**
- 工坊黄昏。零号站在中间，身上带着这次的记号。左边翻开一页手账：
  - 一行路线简笔（走过的节点图标，受伤的格子画红叉，首领盖章）；
  - 手写体的「带回 N 件、丢下 N 件」。
- 零号说一句「今天最记得的事」。按优先级从这次下潜的记录里挑：
  1. 战败；
  2. 差点倒下（HP 低于两成）；
  3. 打倒首领；
  4. 绕开了精英；
  5. 背包满了，丢下东西；
  6. 心愿完成；
  7. 平常的一天。
- 现在结算表上的数字都还在，只是写进了手账页。

**2. 照看（替换维护列表）**
- 零号的立绘上叠着记号：
  - **污渍**：每场战斗一块；
  - **裂痕**：按磨损 30 / 60 / 90 分档；
  - **黑雾**：按侵蚀分档。
- 怎么处理：
  - 点污渍：按住擦掉，免费，SAN +1，羁绊 +1。
  - 点裂痕：弹出修补用的油，现有维护配置换个包装：廉价机油、润滑脂，以及新增的花香护理油（贵，修得更多，她会道谢）。
  - 点黑雾：净化。
  - 拖一件仓库物品到她身上：送给她（见心愿）。
- 「先这样吧」随时离开。记号不处理就一直留着，第二天早上还在，她也会提起。

**3. 理货、营业（营业面板换成工作台）**
- 规则不变：倾倒、橱窗、开始营业。新增两个去处：
  - 「放上架子」：当纪念物摆着，不卖也不占仓库；
  - 「给她」：交付心愿。
- 带回来的东西在这一步分完，不再先进仓库、再到营业面板里重新挑。

**4. 夜谈（替换「第 N 天结束」卡片）**
- 营业收入和房租的数字照旧显示。
- 零号说一到三句话，偶尔有两个选项，只影响羁绊和语气，不影响剧情。
- 话题从当晚的状态里挑：今天的下潜记录、房租紧不紧、她的 SAN、羁绊等级、刚放上架子的东西。
- 「晚安」进入第二天早上。

**早上（已有的「今天做什么」）**
- 窗外天亮。
- 零号头顶可能冒出一个心愿气泡，大约每三天一个，同时最多一个。
- 然后照旧选：跳下深渊或停工休息。

## 四个轻量机制

**羁绊（0–5 级，复用 `DollBondComponent.AffectionLevel`）**
- 来源：擦污渍、用好油、完成心愿、夜谈选项、送礼（每天递减）。
- 不会掉。冷落她的结果是没有长进，加上一句话，不扣分。
- 每级解锁一件看得见的事：

| 等级 | 解锁 |
|---|---|
| 1 | 夜谈多一组话题 |
| 2 | 安全区里她会提醒一句（例如"右边那条路有怪物的气味"） |
| 3 | 每次下潜一次「撑住」：致命伤害留 1 HP，她咬牙站起来（GDD_03 的奇迹，做小） |
| 4 | 一页专属漫画 CG |
| 5 | Demo 结尾多一段话 |

- 数值不碰战斗主干。不刷羁绊也能通关。

**心愿（配置驱动，Demo 约 12 个）**
- 三种：
  - 带回某类东西：按标签，例如「发光的」「会响的」；
  - 去某个地方：节点类型或第 2 层；
  - 在家做一件事：休息一天、买留声机、把她擦干净。
- 完成后：羁绊 +2、一句话、一件纪念物。
- 几天没完成就悄悄放下（"算了，下次吧"），没有惩罚。
- 它和接下来要做的 T1「选路线」是同一件事的两面：给玩家一个理由选这条路，而不是那条。

**架子和纪念物**
- 工坊的架子上有 6 个位置，放两种东西：
  - **自动出现的里程碑**：第一次打倒首领、第一次战败（墙上多一道裂痕，修不掉）、第一次交上房租、完成心愿时收到的东西。
  - **玩家放上去的物品**。
- 点一件，零号说一句话，并显示是哪天得来的。
- 没有数值效果。这一块是手账的另一半：看到架子，就想起那几次下潜。

**家的改造（给钱多一个去处，Demo 5 件）**
- 每件在工坊背景上都有可见的变化，价格交给数值代理和房租、底盘一起调：

| 改造 | 效果 |
|---|---|
| 新床垫 | 休息多回一些 SAN |
| 工作台灯 | 修补便宜 15% |
| 橱窗扩建 | 4×4 变成 5×4 |
| 留声机 | 夜里 SAN +5 |
| 第二层架子 | 纪念物位置 +3 |

## 工坊主界面：房间就是菜单

参考《火山的女儿》：
- 把右边三张卡片（工作室、账本、补给铺）换成画面里的热点，每处有一个小木牌标签，悬停时发亮：

| 热点 | 打开 |
|---|---|
| 工作台 | 照看、义体、底盘 |
| 柜台 | 账本、营业 |
| 门 | 补给铺（出门买东西） |
| 床（或阁楼梯子） | 休息 |
| 墙上的手账 | 翻看过去的下潜 |
| 架子 | 纪念物 |
| 零号 | 说话、摸头（摸头每天前几次加羁绊，`DollInteractionService` 已有） |

- 底部「今天做什么」两大按钮保留：这是一天里最重要的决定，不藏进房间。
- 早上、黄昏、夜里三种光：
  - 叠色，再加上灯的光晕；
  - 夜里换一张工坊夜景（出一张图）。

```
┌ 第 5 天 · 星期四 ─ HP SAN 磨损 侵蚀 ─ 资金 ─ 房租 600G 还有 2 天 ┐
│ [手账]          (心愿气泡)                    [架子]          │
│                 零号（记号叠在身上）           [柜台]          │
│ [门]                                           [工作台]       │
│               ┌ 今天做什么？ [跳下深渊] [停工休息] ┐  [床]     │
└───────────────────────────────────────────────────────────────┘
```

## 实现

**后端（纯 C#，在 `Workshop/` 下）**
- `DiveLogService`：听 `DungeonEventBus` 和 `CombatEventBus`，记下一次下潜的节点、战斗对手、受到的伤害、最低 HP、拾取、丢弃、结局。
- `HomeEveningService`：管四步流程的状态和顺序。
- `BondService`：从 `DollInteractionService` 里抽出等级和解锁。
- `WishService`、`MementoService`、`HomeUpgradeService`。
- 存档加字段。

**配置**
- 新目录 `配置表(JSON)/Home/`，内容：
  - 心愿、纪念物、改造、羁绊等级；
  - 夜谈和「今天最记得的事」的台词池（按条件挑）。
- 台词我来写（约 100 句）。制作人看口吻。

**界面**
- `HomeEveningController`（进门、照看、夜谈）。
- 营业面板换成工作台皮。
- 工坊热点层，加上光照。
- 记号叠层用程序画：污渍和裂痕是贴在立绘上的小图，黑雾是按立绘透明度遮罩的烟。

**美术（Gemini 图生图，同一风格锚点）**
- 一张工坊夜景；
- 五件改造的叠加图；
- 约 8 个纪念物图标；
- 心愿气泡；
- 手账纸和手写体的标题字（复用现有字体，不新增手写字库）；
- 羁绊 4 级的 CG 可以放到最后。

**测试**
- EditMode 测试：下潜记录、四步流程、羁绊升级和撑住、心愿的完成和过期、改造效果。
- 回家整晚的流程加进 `P3BuildSmoke`。

## 分批（分支 `m6/home-loop`，约 2–3 周）

1. **回家的一晚**：下潜记录、进门手账页、夜谈。最直接解决"串不起来"。
2. **照看**：记号、动手修补、羁绊。
3. **心愿、架子、羁绊解锁**，包括安全区提醒和撑住。
4. **房间即菜单**：热点、三种光、家的改造。
5. 全量测试、打包自检、交给制作人试玩。
