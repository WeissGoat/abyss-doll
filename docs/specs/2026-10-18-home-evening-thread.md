# 回家的一晚 · 第二轮：一条线、她会回应、约定

制作人 2026-10-18 试玩第一轮（`docs/specs/2026-10-17-home-loop.md`）后的反馈：家里的事散在三个房间里，营业没合进回家流程，零号还不能互动（触摸、闲聊）。制作人同意：照看给一个很小的战斗效果；先用现有立绘，不出新图；闲聊按羁绊一点点讲深渊和她自己的事。

目标一句话：**一晚是一条线，零号牵着线走**。下潜在家里留下痕迹，家里的事也要回到下一次下潜里去。

## A. 今晚的线

**四个印章**（夜里才有，顶栏下方）：卸货 · 照看 · 开张 · 晚安。
- 卸货：今天带回来的东西都有了去处。
- 照看：她身上没有污渍。
- 开张：营业过了（开张后直接上阁楼夜谈）。
- 晚安：夜谈结束。
- 做完一件盖一个章；点印章就走到对应的房间。下一件事所在房间的木牌会轻轻跳动。不强制顺序。

**进门那一句**：夜里走进一个房间，零号说一句和这个房间、今天有关的话（台词池 `room`），每个房间每晚只说一次。

**卸货（柜台）**：夜里点柜台，先打开「今天带回来的」，每件东西四个去处：
- 卖掉：放进橱窗第一个放得下的位置，放不下就进倾倒箱；之后在营业面板里还能调。
- 收着：留在仓库。
- 架子：摆上阁楼的架子（纪念物）。
- 给她：只有合她心愿的东西才有这个选项。
- 零号对其中一件说一句（台词池 `haul`，按物品标签挑）。全部分完，进营业面板开张；也可以先不分，直接去营业，剩下的留在仓库。
- 规则在 `HomeEveningService`：今天带回来的物品记在 `PlayerProfile.TonightHaul`（实例 ID），每决定一件就划掉一件。

**出门送别**：早上在大厅，零号说一句（台词池 `morning`），按昨晚的情况挑。
- **精神好**：昨晚晚安的时候她身上干净，而且那天和她说过话，第二天下潜的**第一场战斗第一回合 +1 AP**（可以超过上限一点）。顶栏和战斗里都写明来源。只管一场战斗，不叠加。

## B. 她会回应

大厅和阁楼里，零号身上有三块可以碰的地方（头、肩、手），旁边一块木牌「和她说话」。工作室里点她仍然是照看。

**闲聊**（`ZeroInteractionService.Chat`）
- 一句话，按房间、早晚、今天的状态、羁绊挑（台词池 `chat`）。
- 每天第一次闲聊：羁绊 +1，并且如果羁绊够了，讲下一段「她自己的事」（台词池 `lore`，按顺序，每段要求一个羁绊等级）。之后再聊只说话、不加数值。

**触摸**（`ZeroInteractionService.Touch`）
- 头 / 肩 / 手各有反应（台词池 `touch`），立绘做一个小动作：跳一下、缩一下、靠过来，旁边冒一个小气泡。
- 状态决定反应：SAN 很低时摸头她会躲开；受伤时碰肩会缩一下；羁绊 3 级以上会靠过来。
- 每天第一次被接受的触摸：羁绊 +1。躲开不扣分（羁绊不会掉）。

讲到的设定只用 `设计文档/剧情/00_剧情大纲.md` 已有的内容（记忆缺失、深渊下面有她缺的东西、八音盒、晶化病、下面的声音），Demo 里只露线头，不揭示核心真相。

## C. 夜谈的选项和约定

**选项**：有些晚上她说完那句话，给两个回应（配置 `night_talks.json`）。
- 回应只影响羁绊（0 或 +1）和她的回答。
- 大约两三晚一次；当晚有特别的事（差点倒下、战败、交不起房租）时优先。

**约定**（配置 `promises.json`）：有的回应会和她约好下次下潜的一件事，例如「别硬撑」「去营地看看」「这次早点回来」。
- 下潜界面左上角常驻一行「和零号的约定：……」。
- 下一次下潜结束时判定：做到了，进门那句换成约定的回答，羁绊 +1，手账页记一笔；没做到只是一句话。休息日不判定，约定留到下一次下潜。
- 和心愿是两面：心愿是她想要的东西，约定是你答应她的事。

## 实现

- 后端（纯 C#，`Workshop/`）：
  - `HomeEveningService`：印章、卸货、精神好、送别那句；
  - `ZeroInteractionService`：闲聊、触摸、讲到第几段；
  - `PromiseService`：夜谈选项、约定的设立和判定。
- 存档字段：
  - `TonightHaul`、`Spirited`、`TalkedDay`、`InteractionDay`、`ChatsToday`、`TouchesToday`、`LoreHeard`；
  - `ActivePromiseID`、`PromiseSinceDay`、`LastNightTalkDay`、`KeptPromises`。
- 配置（`配置表(JSON)/Home/`）：
  - 台词池 `room`、`haul`、`morning`、`chat`、`touch`、`lore`；
  - `night_talks.json`（`Talks`）、`promises.json`（`Promises`）。
- 界面：
  - `HomeEveningStamps`（印章）；
  - `HomeUnpackView`（卸货）；
  - `ZeroPresence`（每个房间里的她：气泡、触摸区、小动作）；
  - 夜谈加选项；
  - 下潜界面加约定那一行。
- 测试：EditMode 覆盖卸货的四个去处、印章状态、精神好、闲聊和触摸的每日上限与羁绊、讲到第几段、约定的判定。打包自检里加卸货、闲聊和一次夜谈选项。

## 分批（分支 `m6/home-loop`，接着第一轮）

1. A：今晚的线、卸货、出门送别和精神好。
2. B：闲聊、触摸、讲她自己的事。
3. C：夜谈选项和约定；全量测试、打包自检，交给制作人试玩。
