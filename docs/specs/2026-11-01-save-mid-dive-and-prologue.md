# 下潜中途存档、序章存档点、物品按配置重建（阶段 2 · 里程碑 0 · 第 2 批）

规则写在 `设计文档/GDD/GDD_02_深渊地图遍历与搜打撤抉择.md` §5.3，这里只记这一批的取舍和验收。

## 做什么

- 下潜中途能退出、能继续：地图上两个节点之间存一次；踏上节点之前再存一次，并记下这个节点没走完。
- 序章分阶段存：半开放工坊、第一趟下潜（同普通下潜）、回家。开场（黑屏到状态卡）不存。
- 存档里的物品只存配置 ID 和它自己的状态，读档时按当前配置重建。
- 存档版本 1 → 2，Demo 包的旧存档照常能读。

## 取舍

- **退出时站在节点里，继续时从头进这个节点，而不是接着打到一半的战斗。** 战斗、事件、拾取界面都不用存，存档只在地图上。代价是退出能重打一场战斗（同样的出手结果相同，换出手可能不同），跟《杀戮尖塔》的做法一样，可以接受。
- **每个节点的随机数由这一局的地图种子和节点 ID 决定**（`GameRandom.Seed`，在 `MoveToNode` 里）。没有这一条，退出重进可以刷宝箱、刷事件。副作用：同一个种子跑出来的模拟数据和以前不一样了，但每次跑的结果仍然固定。
- **地图不存，用种子重新生成。** 存档小，也不会存下一份和配置对不上的地图。改了层的配置以后，旧存档继续时地图会变，走过的节点按位置 ID 对，可能对到别的节点上；这种情况只出现在开发中改配置，不另做处理。
- **怪物塞进背包的东西会改标签和价格（废料的 `Junk` 标签、价值 0）**，这些作为物品自己的状态存下来（`StampedTags` / `StampedValue`）。版本 1 的存档没有分开记，读的时候把比配置多出来的标签当作塞进来时打的，价格跟着取。
- **新游戏在开场期间不写存档**，所以旧存档一直留到半开放工坊那一刻才被覆盖。
- 序章半开放工坊继续时，不重播解锁浅层入口时的那几句台词，直接回到工坊；剧情旗标和看过的节点原样带回。
- 存档读不回下潜（层被删掉了）时，背包里的东西放回仓库，人在小镇。

## 验收

- `SaveServiceTest`：
  - 物品读档后用的是当前配置（改了模板的伤害和名字，读回来的物品跟着变）；
  - 位置、磨损、侵蚀、废料标记不丢；
  - 配置里删掉的物品被丢弃，不会报错；
  - 版本 1 的存档能读，背包完整。
- `SaveRunTest`：
  - 开始下潜存 1 次，踏上节点再存 1 次；
  - 继续时地图（种子、每格节点 ID、类型、奖励、连线）和原来一样，没走完的节点不算走过，并且会被自动重新进入；
  - 序章：听过声音后继续，仍然记得听过，仍然会给记忆碎片；带东西回家后继续，回家那段重新播，回顾里写着带回的东西，播完序章结束；
  - 开场不存；序章中和下潜中城里的自动存档不写；存档点会写。
- EditMode 83/83。PlayMode 9 个场景里 8 个通过；`MotionCGPlayScenario` 等视频帧超时，Editor 没有焦点时就会这样，跟本批无关，留给打包自检确认。
- 打包版：要等里程碑 0 剩下的几批做完一起打包验证，现在还没测（打包版里中途退出再继续的完整流程）。
