# T0 首次循环：浅缘短遭遇（B 段）和回城照看（C 段）

日期：2026-10-05（M3 第 1–2 批）。体验来源：`版本规划/0-12小时细案/T0-01_序章首次循环.md` §4.7–4.9。本页是 Demo 版的裁剪实现，代替原计划里 "T0-01B / T0-01C 各写设计 + 开发方案" 的两层文档。

## 现状和问题

A 段（开场 → 启动零号 → 状态卡 → 半开放工坊 → 首潜许可 → 出发）已经可以玩。出发后进入的是完整的第 1 层随机地图。回城后工坊一直停在序章的半开放状态（`ExitPrologueHalfOpen` 只有测试在调用），玩家点下潜入口，会再次打开首潜许可，进不了正式循环。

## B 段：旧矿井浅缘（首潜固定路线）

首潜不生成随机地图，改用一条固定的 3 格直线路线，背景沿用 T0 浅层入口。

1. **下面的声音**（事件格）：零号停下，说下面有一段像她自己的声音。两个选项：
   - 「跟着声音走」：没有消耗。
   - 「让她先听清楚」：SAN -5。这样会多出一个带回选项「记忆噪声片」。
2. **拾荒虫**（战斗格）：一只拾荒虫，用真实的战斗界面打，大约 2–3 回合。这场战斗不掉战利品，带回什么在下一格决定。
3. **旧矿车**（带回格）：三选一（「记忆噪声片」只有在第 1 格听过声音才出现）。选完点「带她回去」，直接回城，不显示结算面板。
   - **稳定核心碎屑**：能让她今晚稳定一点。
   - **老旧齿轮**：可以拿去抵债，但对方会压价。
   - **记忆噪声片**：和她说的那段声音有关。

规则写在 POCO 里（`PrologueShallowRun`、两个新节点类）。界面用一个通用的 `PrologueChoicePanel`：先逐句显示对白，再显示选项按钮。

## C 段：回城照看

回城后先回到工坊、在零号身边，不弹夜间营业，也不弹结算面板。

先显示三行复盘：

```
带回：X
消耗：HP a→b，磨损 +n
可处理：先照看她 / 先看催缴纸
```

两个选项：

- **先照看她**：HP、SAN 回满，磨损和侵蚀清零（只有这一次免费）。如果带回的是核心碎屑，用掉它，零号说「但没那么疼了」。下一轮目标：去第一层更远一点，找声音的来源。
- **先看催缴纸**：显示房租（600G，还有 7 天）。如果带回的是齿轮，当场按倾倒箱价（八折）卖掉，零号说「我可以再下去」。零号的状态不变，之后可以去维护。下一轮目标：找更值钱的东西。
- **带回的是记忆噪声片**：不管选哪个，都追加「矿井……不是矿井。那里以前有灯。」。

结束后依次执行：

1. 当晚直接结束：营业为 0，不弹夜间卡片。
2. 退出半开放工坊，进入第 2 天的正式循环（状态栏、下潜 / 休息、维护、营业都开放）。
3. 标记 C 段已完成（`PrologueRunState.ReturnHomeDone`），开始自动存档。

存档只从这里开始写。序章中途退出的话，下次重新播放序章。
