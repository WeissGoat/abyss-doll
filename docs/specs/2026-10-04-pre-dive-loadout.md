# 出发前整备与下潜日结算（M1 第 3 批）

状态：已实现（2026-10-04，M1 第 3 批）。实现时补了一条：同一局重复收到撤离或战败事件只结算一次，防止连点「返回小镇」多跳一天。

## 要解决的问题

1. 撤离时背包里的所有物品都进仓库（规则卡 02 §5.2），但规则卡里「局前带入装备」这一步从没做过：没有任何办法把仓库里的东西放回背包，第二次下潜背包是空的，必输。
2. 下潜不推进日期：`TownEconomyService.SettleDailyBusiness` 只有测试在调，游戏里从没执行过当天结算，房租倒计时不动。规则卡 01 写的是"回到地面后进入营业结算期，然后日期 +1"。

## 玩家看到什么

**出发前整备**是出发前的一步：工坊 → 浅层入口 → 选层 → **整备** → 出发。

- 画面左边是背包格子（和深渊里"整理背包"是同一个格子），右边是仓库清单，按"装备 / 消耗品 / 战利品与材料"分组。
- 点仓库里的物品：放进背包第一个放得下的位置，放不下就提示"背包放不下"。
- 点背包里的物品：放回仓库。背包里照旧可以拖动和旋转。
- 「带上上次的装备」：把上次出发时背包里、现在还在仓库的物品按原位置放回去，原位置被占就放第一个空位。
- 「出发」：背包里没有武器时先弹确认"背包里没有武器，确定出发吗？"，可以继续出发，不硬拦。
- 「返回」：回到选层。

序章首次下潜（首潜许可卡）不经过整备：那时背包里已经有初始装备，保持现在的流程。

**下潜日结算**：下潜结束（撤离或战败）回到工坊时，执行当天结算，然后日期 +1，房租倒计时随之减少。整备、出售、维修等工坊操作不推进日期（规则卡 01 §3）。

## 规则

- 仓库里的任何物品都可以带入，背包格子和形状是唯一的限制。
- 带入的物品按"局前带入装备"处理：标记为绑定，战败时保留（规则卡 02 §5.3）。战败时的耐久 / 磨损代价留到 M2。
- 撤离和战败照旧按规则卡 02 处理，不改。

## 实现要点

- 领域服务（`Items/` 下，不写进 UI）：从仓库放入背包、放回仓库、出发时记住当前背包摆放、恢复上次摆放。物品生命周期加一个"仓库 → 背包"的迁移。
- 上次摆放存在 `PlayerProfile` 上（物品实例 ID 和位置），以后做存档时一起保存。
- 界面复用现有的背包格子和交互服务，仓库清单仿照工坊出售面板的行。
- 回工坊时调用现有的 `SettleDailyBusiness`，营业收入先按现有经济服务的默认值，营业玩法本身留到 M2。

## 验证

- 自动测试：撤离后仓库里有武器 → 恢复上次装备 → 背包里有武器；整备里的放入 / 放回；下潜后日期 +1；整备不改日期。
- 跑局模拟按新流程更新（回城后在仓库出售、恢复上次装备），并设门槛：30 局里至少八成能下潜 3 次以上，而且有出售和升级。
- `P3DevTools.RunDive()` 连跑 3 次下潜不卡住；在 Play Mode 里截整备界面。

## 这次不做

拖放的手感打磨、战败耐久代价、休息日（停工疗愈）选项、营业玩法，都留到 M2。
