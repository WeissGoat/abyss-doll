# 第 3 层进 Demo 和 Demo 结尾（2026-10-24）

制作人 2026-10-20 定：Demo 终点是打倒第 3 层首领。本页先记摸底结果，再列结尾演出的三个方案供制作人选。

## 摸底

### 已经有的

- 配置：第 3 层「菌脉深庭」的地图、5 种普通怪、2 个精英、首领菌脉神谕体、掉落表、宝箱和事件都在，引用的怪物都存在，全量配置校验通过。
- 美术：8 个怪物都有新画的战斗三姿势；战斗背景是蘑菇林，和主题对得上。
- 流程：打倒第 2 层首领后选层界面出现第 3 层；在 Editor 里从选层进第 3 层、地图生成、和首领开打都正常，首领开场意图「攻击 34」，310 HP。
- 打完第 3 层首领后，安全区的按钮是灰的「深渊尽头」，只能回城。Demo 结尾就接在这里。

### 跑局模拟（30 局，第 2–15 天）

跑局机器人原来最多只下到第 2 层，这次教它：去第 2 层时，打完第 2 层首领、HP 还有 60% 以上就继续下第 3 层；第 3 层解锁后直接从第 3 层出发，在第 3 层输了就退回第 2 层。

| 指标 | 机器人只下到第 2 层 | 会下第 3 层 |
|---|---|---|
| 第 1 层成功 | 88% | 91% |
| 第 2 层成功 | 51%（123 次） | 25%（65 次） |
| 第 7 天 / 第 14 天按时交房租 | 83% / 69% | 83% / 48% |
| 第 15 天剩余资金 | 810G | 187G |
| 进过第 3 层的局 | — | 43%（35 次下潜） |
| 第 3 层成功 | — | 23%（8 / 35） |
| 打倒第 3 层首领（通关）的局 | — | 7%（2 / 30，第一次在第 8 天左右） |

- 第 3 层输的 27 次里 16 次输给首领；进首领时平均 61 HP。
- 第 3 层成功回城那晚的营业平均只有 192G，第 2 层成功是 667G：第 3 层的东西卖不上价，或者机器人没把它们带回来，要查。
- 去第 3 层输掉会丢掉整次下潜的东西，机器人因此变穷，第 2 层也跟着变难（买不起装备、维护）。真实玩家会更谨慎，但方向一样：现在第 3 层又难又不赚钱。

### 要补的

1. **第 3 层地图背景**：现在是一张旧画风的黄色机械图，和「菌脉深庭」、和蘑菇林战斗背景都对不上。前两层的地图背景也是旧画风（已知问题），可以一起换。
2. **地图最左一列贴着屏幕边**：第 3 层 7 列、比前两层宽，第一列节点和「可前往」标签被切掉一半。
3. **首领登场**：只有第 1 层守门者有登场视频，第 2 层铸孢炉、第 3 层神谕体都没有。首领在战斗里和零号差不多大，压迫感不够，可以放大。
4. **难度和收益**：第 3 层首领偏难（310 HP、单下 34），第 3 层收益偏低。按 Demo 通关目标重定数值，见下文。
5. **Demo 结尾**：没有，见下面的方案。

### 数值目标（制作人 2026-10-24 定方向）

制作人：副本不是要一命通关。副本的核心是产出经济、能持续玩下去；玩家在里面做的是背包取舍（贪心带更值钱的东西，还是谨慎留着道具）和进退取舍（马上在安全区撤，还是贪心往前走）。通关不是核心目标，能下到多深应该跟着游戏进度（装备、底盘、天数）走。

所以目标按经济和进度定，不按通关率定：

- **越深越赚**：每次下潜带回来当晚的营业，第 1 层 < 第 2 层 < 第 3 层，大约 300 / 650 / 1000G。现在第 3 层的掉落反而比第 2 层便宜（按基础价算每场的期望值：第 3 层普通怪约 290–525，第 2 层多数 450–840；第 3 层首领 753，第 2 层 904），先把这个倒过来。
- **越深越险，撤退有用**：第 3 层下潜里战败的不超过约三分之一；机器人在安全区按伤势和背包价值撤退，撤回来的下潜仍然赚钱。
- **进度跟着装备走**：典型的一局在第 7–10 天第一次下第 3 层；第 15 天前大约一半的局打倒过第 3 层首领（可以输几次再打），这时看到 Demo 结尾。
- **经济不被拖垮**：第 14 天按时交房租 60% 以上，破产 5% 以下。

机器人也要像玩家一样做取舍：中途遇到安全区时，HP 偏低或者背包里已经很值钱就撤；打完第 2 层首领、HP 够才往第 3 层走。

### 调完的结果（2026-10-24，150 局）

改了什么：第 3 层普通怪的主战利品必掉、精英多一件、首领必掉低唱化石；第 3 层首领 310 HP / 34 → 160 / 30；底盘升级 1000G → 500G。机器人学会了撤退、先升底盘、余钱买装备、装备不够不下第 3 层。每一步的数见 `docs/specs/2026-10-05-demo-tuning-targets.md` 末尾。

| 目标 | 结果 |
|---|---|
| 越深越赚（每次下潜 约 300 / 650 / 1000） | 282 / 561 / 991；平安回来那晚 327 / 1066 / 1635 |
| 第 3 层战败不超过约三分之一 | 39%，几乎都输在首领 |
| 第 7–10 天第一次下第 3 层 | 第 9 次下潜（约第 10 天） |
| 一半的局第 15 天前打倒第 3 层首领 | 17%；进过第 3 层的局里约六成。没达到，见下 |
| 第 14 天按时交房租 60% 以上，破产 5% 以下 | 66%，3% |

没达到的那一项：只有约三成的局走到第 3 层，卡在打倒第 2 层首领和升级底盘上，这就是「进度跟着装备走」。机器人比真人保守（只按写死的规则组背包），真人应该更快，以试玩为准；如果试玩时也觉得第 3 层来得太晚，下一个能调的是第 2 层首领。
## Demo 结尾：三个方案

前提：剧情大纲和「她自己的事」那几段说好了 Demo 不揭示核心真相（魔偶心智来自晶化病少女）。已经埋下的线头有：下面有声音在叫她、像在叫一个名字、八音盒的歌、窗台有花的房间、「如果我变成下面的东西，请你亲手拆掉我」。

### A. 一句话收尾（约 1 天）

打倒神谕体 → 安全区一张 CG：零号站在散开的菌丝前，远处更深的地方有光 → 她说一两句（「下面……还有。」）→「Demo 到此为止」卡，可以回标题，也可以接着玩这个存档。

- 新素材：1 张 CG。
- 优点：快，不碰剧情。缺点：结尾轻，和夜谈、表情这些铺垫比，情绪落不下来。

### B. 声音和回家（推荐，约 2–3 天）

1. **首领倒下**：一页 3 格漫画。
   - 第 1 格：神谕体崩开，菌丝散去，露出下面更深的竖井。
   - 第 2 格：零号停住，捂着胸口，听见声音，这次听清了是一段旋律，就是八音盒那首歌。
   - 第 3 格：她回头看你：「它在唱……我知道这首歌。」
2. **回城**：手账页照常，她那句换成固定台词。
3. **当晚夜谈**：一段专门的夜谈，两个回应。
   - 「我们一起去找。」她答应，开心的脸。
   - 「先好好休息。」她点头，害羞的脸。
   - 两句都说完就是这一章的结尾。
4. **说「晚安」后**：Demo 结束卡，写「第一章 · 完」，加一句预告（「深渊下面，有人在唱她的歌。」），再列这一局的统计：第几天、下潜几次、羁绊等级、守住几个约定、带回的纪念物。最后选「回到标题」或「继续经营」。

- 新素材：3 格漫画（Gemini 图生图，以零号半身像和第 3 层背景当参考），文字 6–8 句。
- 结尾卡复用夜谈和半身像，不用新做界面。
- 只把已经埋的「声音」「八音盒」两条线收一下，不揭示真相；夜谈和回家都已经有，玩家熟悉。
- 可选：羁绊 3 以上，第 3 格的台词换成「……那首歌，以前是谁唱给我听的。」

### C. 揭开一角（约 4–5 天）

在 B 的基础上，神谕体核心里有一块晶化残片，零号碰到后闪回 3–4 格：窗台上有花的房间、一个女孩、八音盒、一只牵住她的手。回城后夜谈里她说：「我好像……以前不是这样的。」

- 新素材：6–7 格漫画，闪回要换一种画风区分（褪色、暖光）。
- 优点：结尾最有分量，玩家最想往下玩。
- 缺点：等于在 Demo 里揭开了中期真相的一半，和原定「Demo 不揭示核心真相」冲突；画量和风格统一的风险也最大。

### 决定

制作人 2026-10-24 选 B。

### 我的建议（选之前）

选 B。它把家里那条线（夜谈、表情、约定）和深渊那条线（声音、八音盒）在结尾接上，情绪够，又不提前揭底。C 的闪回可以留到正式版第二章开头。

## 定了以后的做法

1. 数值：按上面的目标调第 3 层首领、第 3 层收益和第 2 层，跑局模拟对表。
2. 素材：第 3 层地图背景，首领登场视频（H3，预计每段不到 1 美元），结尾漫画。
3. 结尾流程：打倒第 3 层首领时记一个旗标；回城后手账台词和当晚夜谈用固定内容；说晚安后显示结束卡；存档里记「已通关」，标题画面可以显示。
4. 打包自检加一条「直接到第 3 层首领、打完、看到结束卡」的路线。
