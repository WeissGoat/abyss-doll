# PM / 版本规划 兼容入口

## 当前状态

旧 PM / 版本规划智能体不再作为 Project P3 的 active 工作角色。

PM 原本承担的阶段判断、优先级、里程碑、跨职能交接和完成口径，已并入 `游戏导演 / 制作人` 角色。新的 active 状态页是：

```text

```

新的 active 阅读入口是：

```text

```

新的顶层体验总线是：

```text

```

## 兼容规则

- 新任务不得再派发给“PM / 版本规划智能体”。
- 旧文档中指向本页的链接只用于兼容和迁移。
- 后续涉及玩家体验、系统开放节奏、任务 Owner 工作流、阶段优先级或跨职能验收口径时，维护 `agent_status/director.md`。
- 后续如果需要清理旧 PM 命名，应作为独立文档迁移任务处理，避免一次性删除造成知识库断链。
