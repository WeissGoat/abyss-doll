# 智能体状态页说明

本目录存放不同职能智能体的交接状态。

- `art.md`：美术 / UI / 视觉流水线状态。
- `design.md`：策划 / 数值 / GDD / 配置意图状态。
- `program.md`：程序 / Unity / 验证状态。

每个复制出来的智能体完成一次有实际意义的任务前，应更新对应状态页。记录要简洁、稳定，让下一个智能体不读聊天记录也能继续接手。
